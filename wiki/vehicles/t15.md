## 参数

| 项目 | 数值 |
|---|---|
| 座位 | 6 |
| 发动机 | 柴油，怠速 760 rpm，断油 4300 rpm |
| 扭矩 | 240 N·m @ 2400 rpm |
| 变速箱 | 5 挡手动 + 倒挡，离合自动 |
| 分动箱 | 两驱 2H / 四驱 4H / 低速四驱 4L（×2.28） |
| 最高速度 | 约 100 km/h |
| 油箱 | <V j="PickupTruckEntity.TANK" u="L" />，只烧柴油 |
| 油耗 | 每 kWh 0.28 L + 怠速每小时 0.2 L |
| 仪表 | 转速表、车速表（0–180 km/h）、油量、水温 |

发动机、变速箱和油耗的数值写在车辆参数构造里，暂时不能从游戏数据自动读取

## 驾驶

- 坐上驾驶座，**按住 G** 点火，发动机起来后松开
- **R / F** 加减挡，离合是自动的
- **X** 切换分动箱：车速低于 20 km/h 才能切 4H / 4L
- 车速低于 <V j="PickupTruckEntity.GET_OUT_SPEED" u="m/s" /> 才能下车
- 开车时两只手都在方向盘和挡杆上：坐上驾驶座时手里的武器会自动收起，开车期间不能切出武器；坐副驾和后排不受影响
- 右上角的按键提示可以按 **Caps Lock** 收起，再按一次显示，下次上车还是收起的
- <StatusTag s="new" /> 按 **F5** 切到环绕镜头：镜头跟在车后，动鼠标绕车看，滚轮调远近
- 全部按键见 [操作按键](../guide/controls)

## 轮胎

<StatusTag s="new" /> 土路、砂石、沙地、草地和雪地上，轮胎会往后扬起土块和尘土，打滑、急刹时更多；下雨时柏油路上会甩起水丝和水雾，车越快越多（开光影时由光影包画，Aureveil 还没支持）；干的硬路面上只有急刹打滑时冒胎烟。粒子设置为"最少"时没有

## 灯光

- **H** 开关大灯，按住切远光；刹车灯自动亮
- **← / →** 转向灯，**↓** 应急灯，闪烁约每分钟 90 次
- 不开光影时车灯也会照亮路面和墙（需要 Embeddium），128 格内最多 3 辆车
- 光影包下由光影包自己处理

## 雨刷

**C** 依次切换：关 → 间歇（停 <V j="WiperSystem.PAUSE" u="秒" />）→ 慢速（每次 <V j="WiperSystem.LOW_STROKE" digits="2" u="秒" />）→ 快速（每次 <V j="WiperSystem.HIGH_STROKE" digits="2" u="秒" />）

下雨时挡风玻璃、后窗和门窗上都会有水珠，雨刷刮过的地方会变清楚

<StatusTag s="new" /> 下雨时能听到雨刷刮动；柏油路上的轮胎声会变成湿路面的沙沙声；坐在驾驶室里听到的是雨打车顶和玻璃的声音

<StatusTag s="planned" /> 玻璃水

## 暖风和冷气

<StatusTag s="new" /> **V** 依次切换：关 → 暖风 → 冷气。中控台上暖风面板的推杆会跟着动，仪表条上亮暖风或雪花灯

- 坐在驾驶座和副驾驶上不会淋雨，驾驶室有自己的气温：关着门比外面暖和一点，白天晒着会变热；开着门就和外面一样
- **暖风**用的是发动机冷却水的热量，不额外烧油：冷车时没有热风，水温上来以后（约 <V j="CabClimate.WARM_FROM" u="°C" /> 起，<V j="CabClimate.WARM_FULL" u="°C" /> 最足）车里几分钟内暖到约 <V j="CabClimate.HEAT_SET" u="°C" />。钥匙要拧到通电
- **冷气**靠发动机带压缩机，只在发动机运转时工作，会多烧一点油；最低吹到约 <V j="CabClimate.COOL_SET" u="°C" />
- 开着车门时暖风和冷气效果差很多
- 货斗里不算驾驶室，照样淋雨

## 排气

<StatusTag s="new" /> 尾管在右后轮后面，朝后、朝外，管口是空的，里面熏黑了；冒烟的样子像一台老式涡轮柴油车。别的玩家的车也会冒烟

- **点火**：着车时冒一团深灰烟
- **冷车**：偏白的灰烟，比较浓，水温上来后慢慢变淡（约 <V j="TruckExhaust.WARM_AT" u="°C" /> 时就没了）
- **热车怠速**：几乎看不见，带负载时多一点
- **低转速猛踩油门**：涡轮起压前冒一小股黑烟（约 <V j="TruckExhaust.LUG_RPM" u="rpm" /> 以下）
- **天冷**：室外低于约 <V j="TruckExhaust.VAPOUR_FROM" u="°C" /> 时一直有白色水汽，越冷越明显
- 烟留在排出来的地方，车开走了就拖在后面

| 声音 | 范围 |
|---|---|
| 发动机 | <V j="PickupTruckEntity.ENGINE_NOISE" /> |
| 发动机大油门 | <V j="PickupTruckEntity.ENGINE_LOUD_NOISE" /> |
| 喇叭 | <V j="PickupTruckEntity.HORN_NOISE" /> |
| 撞击 / 重撞 | <V j="PickupTruckEntity.CRASH_NOISE" /> / <V j="PickupTruckEntity.CRASH_HEAVY_NOISE" /> |
