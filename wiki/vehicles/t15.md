## 获取

<StatusTag s="verified" d="2026-10-21" /> <StatusTag s="creative" /> 创造物品栏的“车辆”标签页里有 <ItemIcon id="pickup_t15" />。对地面使用会打开生成界面：

- 左边是车的 3D 预览，拖动可以旋转
- 车漆：8 种出厂色，森林绿配米色腰线
- 磨损程度：0–100% 滑条，或选择全新、二手、老旧
- 油量：0 到满箱 <V j="PickupTruckEntity.TANK" u="L" />
- 钥匙位置：驾驶侧遮阳板（默认）、手套箱、插在点火锁上，或车内随机
- 点“放置”后，车出现在点击的位置，车头朝向玩家视线方向。钥匙已经和这辆车配对。创造模式下物品不消耗

也可以用开发命令生成（需要管理员权限）：

```
/afl dev vehicle spawn [颜色]
```

不会在世界中自然生成

<StatusTag s="verified" d="2026-10-21" /> 车头格栅中间是霍尔斯特德的松树铬标，尾门上压着 HALSTEAD 字样

## 参数

| 项目 | 数值 |
|---|---|
| 座位 | 6 |

| 扭矩 | 240 N·m @ 2400 rpm |
| 变速箱 | 5 挡手动 + 倒挡，离合自动 |
| 分动箱 | 两驱 2H / 四驱 4H / 低速四驱 4L（×2.28） |

发动机、变速箱和油耗数值写在车辆参数构造中，暂时无法从游戏数据自动读取

## 驾驶

- 坐上驾驶座后**按住 G** 点火，见下方 [钥匙](#钥匙)
- <StatusTag s="verified" d="2026-10-21" /> 坐上驾驶座时手放在腿上，可以拿东西、用东西。对准方向盘按**使用键**握住方向盘，握住以后才能踩油门、刹车、转向、换挡；再按一次**使用键**松开。松开时车速很低会自动拉手刹，开着车松开会一直滑行
- **R / F** 加挡 / 减挡，离合自动
- **X** 切换分动箱挡位：车速低于 20 km/h 时才能切入 4H / 4L
- 车速低于 <V j="PickupTruckEntity.GET_OUT_SPEED" u="m/s" /> 时才能下车
- <StatusTag s="verified" d="2026-10-21" /> 坐在前排要先开自己那边的车门才能下车：对准车门按**使用键**开门，再按**潜行**下车。车门关着时按潜行只会提示“先开门”。下车后车门保持打开
- <StatusTag s="verified" d="2026-10-21" /> 发动机开着下车，发动机会继续怠速，钥匙留在点火锁上，直到油烧完或有人熄火
- 握着方向盘时双手都在方向盘和挡杆上：手中的武器自动收起，无法切出武器，也不能用别的东西；副驾驶和后排不受影响
- 右上角的驾驶提示可按 **Caps Lock** 隐藏，再按一次显示；下次上车时仍保持隐藏
- <StatusTag s="verified" d="2026-10-19" /> 按 **F5** 切换到环绕镜头：镜头跟在车后，移动鼠标绕车观察，滚轮调节距离
- 全部按键见 [操作按键](../guide/controls)

## 钥匙

<StatusTag s="verified" d="2026-10-21" /> 每辆 T15 只配一把钥匙 <ItemIcon id="pickup_t15_key" />，只能启动这一辆车。没有钥匙时无法点火

- <StatusTag s="verified" d="2026-10-21" /> 每种车型的钥匙都不一样，钥匙柄上嵌着车厂的车标。T15 的钥匙两面是 Halstead 的镀铬三杠松树标，和车头格栅上的一样
- 点火锁在仪表板上、方向盘右边，透过方向盘右侧的空当能看到
- <StatusTag s="verified" d="2026-10-21" /> 坐在驾驶座上**按住 G**：镜头转向钥匙孔，右手从身上取出钥匙插进点火锁，顺时针拧到通电位置，预热约 0.8 秒后拧到起动位置，发动机着车后松手，镜头转回。钥匙不必拿在手上，只要带在身上（手上、装备格子、背包或物品栏）
- 钥匙已经插着时，按住 **G** 直接拧钥匙；发动机运转时按住 **G** 是熄火
- 中途松开 **G** 会停止，钥匙弹回但留在点火锁上。身上和锁上都没有钥匙时提示“没有钥匙”
- 也可以对准钥匙孔按**使用键**：身上带着钥匙时，右手把钥匙插进去；钥匙插着、发动机关着时，右手把钥匙拔出来放回身上
- 熄火状态下离开驾驶座时，先拔下钥匙带在身上，然后下车；身上放不下时钥匙留在点火锁上。发动机开着下车时钥匙不拔
- 熄火时，坐在前排对准钥匙孔按使用键也能拔下钥匙
- 找到的车，钥匙大多不在车里。少数插在点火锁上，或留在车里：遮阳板背面、手套箱、烟灰缸、座椅上
- 坐在驾驶座或副驾驶座上，对准遮阳板、手套箱或烟灰缸按使用键打开；里面有钥匙时再按一次拿走钥匙
- 测试用开发命令：`/afl dev vehicle key <位置|random>` 把钥匙放到指定位置或随机位置，`/afl dev vehicle key give` 直接拿到钥匙
- <StatusTag s="planned" /> 没有钥匙时用螺丝刀拆下转向柱下护罩、短接点火线

## 轮胎

<StatusTag s="verified" d="2026-10-19" /> 在土路、砂石、沙地、草地和雪地上，轮胎会向后扬起土块和尘土，打滑和急刹时更多；下雨时，柏油路面上会甩起水丝和水雾，车速越快越多（开启光影时由光影包绘制，Aureveil 暂不支持）；干燥的硬路面上只有急刹打滑时才冒胎烟。粒子设置为“最少”时不显示

## 灯光

- **H** 开关大灯，长按切换远光；刹车灯自动点亮
- **← / →** 转向灯，**↓** 双闪，闪烁频率约每分钟 90 次
- 不开光影时，车灯同样会照亮路面和墙面（需要 Embeddium），128 格内最多 3 辆车
- 使用光影包时由光影包自行处理

## 雨刷

**C** 依次切换：关 → 间歇（间隔 <V j="WiperSystem.PAUSE" u="秒" />）→ 低速（每次 <V j="WiperSystem.LOW_STROKE" digits="2" u="秒" />）→ 高速（每次 <V j="WiperSystem.HIGH_STROKE" digits="2" u="秒" />）

下雨时，挡风玻璃、后窗和车门玻璃上都会出现水珠，雨刷刮过的区域会变清晰

- <StatusTag s="verified" d="2026-10-19" /> 下雨时能听到雨刷刮擦声；柏油路上的胎噪变为湿路面的沙沙声；坐在驾驶室内听到的是雨点打在车顶和玻璃上的声音
- <StatusTag s="planned" /> 玻璃水

## 暖风和冷气

<StatusTag s="verified" d="2026-10-19" /> **V** 依次切换：关 → 暖风 → 冷气。中控台暖风面板上的推杆随之移动，仪表条上点亮暖风或雪花指示灯

- 坐在驾驶座和副驾驶座上不会淋雨。驾驶室有独立的气温：关门时比室外略暖，白天日晒会升温；开门时与室外相同
- **暖风**利用发动机冷却液的热量，不额外耗油：冷车时没有热风；水温升高后（约 <V j="CabClimate.WARM_FROM" u="°C" /> 起，<V j="CabClimate.WARM_FULL" u="°C" /> 时最足），车内几分钟内升到约 <V j="CabClimate.HEAT_SET" u="°C" />。钥匙需拧到通电位置
- **冷气**由发动机驱动压缩机，只在发动机运转时工作，油耗略有增加；车内最低降到约 <V j="CabClimate.COOL_SET" u="°C" />
- 车门打开时，暖风和冷气的效果明显变差
- 货斗不属于驾驶室，仍会淋雨

## 排气

<StatusTag s="verified" d="2026-10-19" /> 排气尾管位于右后轮后方，朝向后外侧，管口中空，内壁熏黑；排烟表现接近老式涡轮增压柴油车。其他玩家的车同样会排烟

- **点火**：着车时冒出一团深灰色烟
- **冷车**：偏白的灰烟，较浓，水温升高后逐渐变淡（约 <V j="TruckExhaust.WARM_AT" u="°C" /> 时消失）
- **热车怠速**：几乎看不见，带负载时略多
- **低转速猛踩油门**：涡轮起压前冒出一小股黑烟（约 <V j="TruckExhaust.LUG_RPM" u="rpm" /> 以下）
- **天冷**：室外气温低于约 <V j="TruckExhaust.VAPOUR_FROM" u="°C" /> 时持续冒白色水汽，越冷越明显
- 烟停留在排出的位置，车开走后会拖在车后

## 能互动的部件

| 部件 | 操作 |
|---|---|
| 车门（4 扇） | 对准车门按使用键开关 |
| 引擎盖 | 对准车头按使用键 |
| 尾门 | 对准车尾按使用键 |
| 油箱盖 | 位于车身左后侧，打开后才能加油 |
| 货斗 | 9×7 格；<StatusTag s="test" /> 目前只能用开发命令打开 |
| 遮阳板（2 块） | 坐在前排对准遮阳板按使用键翻下 / 收起 |
| 手套箱 | 副驾驶一侧仪表台，坐在前排按使用键开关 |
| 烟灰缸 | 仪表台中间，坐在前排按使用键拉出 / 推回 |
| 点火锁 | 仪表板上、方向盘右边；熄火时按使用键拔钥匙，带着钥匙时按使用键插上 |
| 方向盘 | 坐在驾驶座按使用键握住，再按一次松开 |
