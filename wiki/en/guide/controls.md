# Controls

AFL's keys are under Options → Controls → "Apocalypse First Light" and can be rebound. These are the defaults

## General

| Key | Action |
|---|---|
| E | Open the grid inventory |
| Use (right click) | Pick up the item you look at (no auto pickup) |
| Sneak + Use | Put the item you look at straight into your grid |
| Sneak + Use on water, empty hand | Take a sip of raw water |
| 1 / 2 / 3 | Long gun / pistol / melee |
| 4–9 | Quick binds: in the inventory, hover an item in a pocket or the rig and press 4–9 |
| R (inventory) | Rotate the item you drag |
| Q (inventory) | Drop the item under the cursor |
| F | Does nothing: AFL has no off hand |

## Camera

| Key | Action |
|---|---|
| F5 | First person / orbit camera (vanilla's front view is gone) |
| Mouse (orbit) | Swing the camera all the way round you or the vehicle |
| W A S D (orbit, on foot) | Walk the way the camera looks; your character turns by itself |
| Left / right click (orbit, on foot) | Turn to the dot in the middle of the screen first, then dig, place or use; aiming a gun (right click) drops to first person until you let go |
| Scroll (orbit, in a vehicle) | Camera distance |

<StatusTag s="verified" d="2026-10-19" /> In a vehicle the camera chases behind it; the mouse swings it round, and a moment after you let the mouse be it eases back behind while the vehicle moves

## Guns

| Key | Action |
|---|---|
| Left / right click | Fire / aim |
| R | Reload |
| B | Switch fire mode |
| V | Inspect |
| Z | Change attachments in the field |

## Driving (in the driver's seat)

| Key | Action |
|---|---|
| W / S / A D | Throttle / brake / steer |
| Space | Handbrake |
| Sneak | Get out (stop first) |
| G (hold) | Ignition |
| R / F | Shift up / down |
| X | Transfer case: 2H / 4H / 4L |
| H | Headlights; hold for high beam |
| Y (hold) | Horn |
| ← / → | Left / right turn signal |
| ↓ | Hazards |
| C | Wipers: off / intermittent / low / high |
| V | Climate: off / heat / A/C |
| Caps Lock | Hide / show the key hints at the top right (remembered) |

While you drive, these keys lend out their usual actions
