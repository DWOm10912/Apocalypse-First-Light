# 操作按键

AFL 的按键都在 设置 → 按键 → “黎明启示录” 分类中，可以修改。下面列出默认按键

## 通用

| 按键 | 作用 |
|---|---|
| E | 打开格子背包 |
| 使用键（右键） | 捡起准星对准的地面物品（不会自动拾取） |
| 潜行 + 使用 | 把准星对准的物品直接收进背包格子 |
| 潜行 + 空手对水源使用 | 喝一口生水 |
| 1 / 2 / 3 | 主武器 / 手枪 / 近战 |
| 4–9 | 快捷绑定：在背包界面中，鼠标悬停在口袋或胸挂里的物品上，按 4–9 绑定 |
| R（背包界面） | 拖动时旋转物品 |
| Q（背包界面） | 丢弃鼠标下的物品 |
| F | 无作用：AFL 没有副手 |
| 左 Alt | 所有状态徽章的名称和效果一起滑出 4 秒，6 秒内只能按一次 |
| N | <StatusTag s="verified" d="2026-10-20" /> 坐在地上 / 站起（跳跃或潜行也能站起）。只能坐在方块的碰撞面上，坐着算休息 |

## 镜头

| 按键 | 作用 |
|---|---|
| F5 | 第一人称 / 环绕镜头（原版的正面视角已移除） |
| 鼠标（环绕镜头） | 镜头绕人物或车辆转一整圈 |
| W A S D（环绕镜头，步行） | 朝镜头方向移动，人物自动转身 |
| 左键 / 右键（环绕镜头，步行） | 人物先转身对准屏幕中央的小点（转半圈约 0.3 秒），再挖掘、放置、使用或开枪；按住时身体一直朝向小点，移动键变成侧移；持枪按右键瞄准时，转过去后切回第一人称，松开后恢复 |
| 滚轮（环绕镜头，乘车） | 调整镜头远近 |

<StatusTag s="verified" d="2026-10-19" /> 乘车时镜头跟在车后，移动鼠标可以绕车观察；鼠标停下一段时间后，如果车辆在行驶，镜头会慢慢转回车后

## 枪械

| 按键 | 作用 |
|---|---|
| 左键 / 右键 | 开火 / 瞄准 |
| R | 换弹 |
| B | 切换开火模式 |
| V | 检视武器 |
| Z | 即时配件改装 |

## 地图

- <StatusTag s="verified" d="2026-10-21" /> 见 [地图](./map)

| 按键 | 作用 |
|---|---|
| 拿着「地图」按使用键（右键） | 翻开世界地图；在地图里按右键或 Esc 收起 |
| 显示或隐藏小地图 | 默认没绑键 |

## 驾驶（坐在驾驶座上）

| 按键 | 作用 |
|---|---|
| 使用键（对准方向盘） | 握住方向盘；握着时按使用键松开 |
| W / S / A D | 油门 / 刹车 / 转向（握着方向盘时） |
| 空格 | 手刹（握着方向盘时） |
| 潜行 | 下车（需先停稳；前排需先打开自己那边的车门） |
| G（按住） | 点火；发动机运转时为熄火 |
| R / F | 加挡 / 减挡（握着方向盘时） |
| X | 分动箱：两驱 / 四驱 / 低速四驱（握着方向盘时） |
| H | 车灯；按住切换远光 |
| Y（按住） | 喇叭 |
| ← / → | 左 / 右转向灯 |
| ↓ | 双闪 |
| C | 雨刷：关 / 间歇 / 低速 / 高速 |
| V | 空调模式：关 / 暖风 / 冷气 |
| Caps Lock | 显示 / 隐藏右上角的驾驶提示（会记住选择） |

坐在驾驶座上时，这些按键原有的功能暂时让给驾驶操作；R、F、X 只在握着方向盘时让出
