# 操作按键

AFL 自己的按键都在 设置 → 按键 → “黎明启示录” 分类里，可以改。下面是默认键

## 通用

| 按键 | 作用 |
|---|---|
| E | 打开格子背包 |
| 使用键（右键） | 捡起看着的地上物品（不会自动拾取） |
| 潜行 + 使用 | 把看着的物品直接收进背包格子 |
| 潜行 + 空手对水源使用 | 喝一口生水 |
| 1 / 2 / 3 | 主武器 / 手枪 / 近战 |
| 4–9 | 快捷绑定：在背包界面把鼠标放在口袋或胸挂里的物品上按 4–9 绑定 |
| R（背包界面） | 拖动时旋转物品 |
| Q（背包界面） | 丢掉鼠标下的物品 |
| F | 没有作用：AFL 没有副手 |

## 枪械

| 按键 | 作用 |
|---|---|
| 左键 / 右键 | 开火 / 瞄准 |
| R | 换弹 |
| B | 切换开火模式 |
| V | 检视 |
| Z | 原地换配件 |

## 驾驶（坐在驾驶座上）

| 按键 | 作用 |
|---|---|
| W / S / A D | 油门 / 刹车 / 转向 |
| 空格 | 手刹 |
| 潜行 | 下车（要先停稳） |
| G（按住） | 点火 |
| R / F | 加挡 / 减挡 |
| X | 分动箱：两驱 / 四驱 / 低速四驱 |
| H | 车灯；按住切换远光 |
| Y（按住） | 喇叭 |
| ← / → | 左 / 右转向灯 |
| ↓ | 应急灯 |
| C | 雨刷：关 / 间歇 / 慢 / 快 |

驾驶时这些键上原来的功能会暂时让出来
