# 地图

- <StatusTag s="test" /> <StatusTag s="creative" /> 还在分支上，用户在分支上实机看过

AFL 有自己的世界地图和小地图。路和镇按真实的路形画，斜着走的匝道也是平滑的

## 「地图」

一张折起来的地图和一支铅笔。带在身上（背包、快捷栏、网格背包里都行），走过的地方就画上去

- 记身边 <V j="MapClient.RADIUS" u="m" /> 以内的地面：群系颜色、起伏、水面
- 路、镇、建筑不用记：走到哪儿，那里的路和镇就露出来。老宅和它的碎石车道也画在上面
- 现在只能在创造栏「近战与装备」里拿，没有配方
- 记录跟着这张地图走，退出世界再进来还在。扔掉再捡回来，记录也还在；换一张新地图就从空白开始。地图丢了，记录也就丢了

## 小地图

屏幕右上角。跟着视角转，前方朝上，边框上的 N 指着北；设置里可以改成北朝上

- 带着地图：显示画过的地方
- 没带地图：只显示身边 <V j="MapClient.RADIUS" u="m" /> 的一圈，往外是暗的，什么也不记
- 走路时显示 <V j="MinimapHud.SPAN" u="m" /> 宽，开车越快拉得越远，最多 <V j="MinimapHud.SPAN_MAX" u="m" />
- 下面显示坐标、所在群系，在镇里时显示镇名
- 按键设置里有「显示或隐藏小地图」，默认没绑键

## 罗盘

- <StatusTag s="test" /> 还在分支上，用户在分支上实机看过

屏幕正上方的一条方位刻度，跟着视线转。每 15° 一个度数，每 45° 一个方位字母（N 北、E 东、S 南、W 西），中间下面的小框是你现在朝的度数：0 是北，90 是东

- 要有指南针：拿在手里，或者挂在胸挂的挂点上（见 [装备](../arms/equipment)）。放在背包里不显示
- 设置「地图」一节里可以隐藏

## 世界地图

拿在手里按右键，地图像书页一样翻开，展开成大地图。不会暂停游戏

| 操作 | 作用 |
|---|---|
| 左键拖动 | 移动 |
| 滚轮 | 缩放 |
| 空格 | 回到自己 |
| 右键 / Esc | 收起 |

- 没去过的地方是暗的
- 放大到镇里能看到街名、建筑和加油站
- 地图上的镇名、街名、路号都是英文，和路牌一样。鼠标指着镇时弹出卡片，下面一行是中文名
- 鼠标指着别的地方显示那里的坐标和群系
