# 材料与加工

<StatusTag s="creative" /> 下列矿石目前还不会在世界中生成，机器也没有合成配方。加工配方已经可用

## 矿石

| 矿石 | 加工 |
|---|---|
| <ItemIcon id="galena_ore" /> 方铅矿石 | 粉碎机 → <ItemIcon id="galena" />方铅矿 → 工业熔炉 → <ItemIcon id="lead_brick" />铅砖 |
| <ItemIcon id="pentlandite_ore" /> 镍黄铁矿石 | 粉碎机 → <ItemIcon id="pentlandite" />镍黄铁矿 → 化学反应器 → <ItemIcon id="electrolytic_nickel" />电解镍 |
| <ItemIcon id="spodumene_ore" /> 锂辉石矿石 | 粉碎机 → <ItemIcon id="spodumene_concentrate" />锂辉石精矿 → 化学反应器 → <ItemIcon id="lithium_carbonate" />碳酸锂 |
| <ItemIcon id="wolframite_ore" /> 黑钨矿石 | 粉碎机 → <ItemIcon id="wolframite" />黑钨矿 → 化学反应器 → <ItemIcon id="tungsten_oxide" />氧化钨 → 工业熔炉 → <ItemIcon id="tungsten_powder" />钨粉 |
| <ItemIcon id="bauxite_ore" /> 铝土矿石 | 尚无加工配方 |
| <ItemIcon id="sphalerite_ore" /> 闪锌矿石 | 尚无加工配方 |
| <ItemIcon id="cassiterite_ore" /> 锡石矿石 | 尚无加工配方 |

工业矿石都需要钻石镐才能开采。粉碎机每块矿石产出 1–3 个；化学反应器每次消耗 20 L 水，产出 20 L 工业废液

## 钨和钢

- <ItemIcon id="tungsten_filament" />钨粉在工业熔炉中烧结成 **钨丝**
- <ItemIcon id="tungsten_carbide_powder" /><ItemIcon id="cemented_carbide_blank" />钨粉加碳在合金炉中合成 **碳化钨粉**，碳化钨粉再加电解镍，在合金炉中合成 **硬质合金坯件**
- <ItemIcon id="steel_billet" />铁锭加碳在合金炉中炼成 **钢坯**

## 其他配方

- <ItemIcon id="lead_shielding_bricks" />4 块铅砖合成 **铅屏蔽砖**（用于屏蔽辐射，见 [辐射](../guide/radiation#屏蔽)）
- 钢筋混凝土用粉碎机回收，产出混凝土碎块和废钢（各 3–5 个）
- 路缘石：草方块或混凝土人行道加混凝土碎块合成

机器功耗见 [工业制造](./)

## 木材

AFL 有自己的六个树种：白栎、白松、北方红栎、裂皮山核桃、红枫、加拿大铁杉。每种木材都有木板、圆角方木和木梁
