# 材料与加工

<StatusTag s="creative" /> 下面的矿石现在还不会在世界里生成，机器也没有合成配方。加工配方已经能用

## 矿石

| 矿石 | 加工 |
|---|---|
| 方铅矿 | 破碎 → 方铅矿 → 工业熔炉 → 铅砖 |
| 镍黄铁矿 | 破碎 → 镍黄铁矿 → 化学反应器 → 电解镍 |
| 锂辉石 | 破碎 → 锂辉石精矿 → 化学反应器 → 碳酸锂 |
| 黑钨矿 | 破碎 → 黑钨矿 → 化学反应器 → 氧化钨 → 工业熔炉 → 钨粉 |
| 铝土矿、闪锌矿、锡石 | 还没有加工配方 |

工业矿石都要钻石镐才能挖。破碎每块矿出 1–3 个；化学反应器每次用 20 L 水，产出 20 L 工业废液

## 钨和钢

- 钨粉在工业熔炉里烧结成 **钨丝**
- 钨粉加碳在合金炉里合成 **碳化钨粉**，再做成 **硬质合金坯**
- 铁锭加碳在合金炉里炼成 **钢坯**

## 其他配方

- 4 块铅砖合成 **铅屏蔽砖**（挡辐射，见 [辐射](../guide/radiation#屏蔽)）
- 钢筋混凝土可以破碎回收成混凝土碎块
- 路缘石：草方块或人行道加混凝土碎块

机器耗电见 [工业制造](./)
