# 旧身体（SkinMesh C-min）肩和髋的连接：改前 / 改后

用户 2026-10-26："好，先修髋部和肩部"。只改蒙皮，动画数据没动。做法见 `docs/dev/player_skeleton_v1_design.md` 第 2.1.1 节。

离线导出：`gradlew skinJointCompare -Pout=<dir>`（改前 = 每个关节一圈的旧网格，改后 = 现在的 `SkinMesh`），Blender Workbench 正交渲染，贴图是 `survivor/m01.png`。

## hips_before_after.png

每行一个姿势，三个角度（侧面、斜后上方、后下方），每个角度左边改前、右边改后：

1. 坐地（body.sit 0.5）
2. 起身（body.stand_up 0.2）
3. 起身（body.stand_up 0.45）
4. 蹲（locomotion.crouch_idle 0.2）
5. 跑（locomotion.run 0.15）
6. 站着双腿前抬 90°
7. 站着双腿前抬 130°

看点：屈髋时屁股后面原来是大腿顶端转出去的方角，现在圆过去；腿顶和躯干底面之间不再露缝。跑步的弯曲小，前后差别很小。

## shoulders_before_after.png

每行一个姿势，三个角度，每个角度左边改前、右边改后：

1. 双臂前平举（-90°）
2. 双臂侧平举（90°）
3. 双臂交叉向前（-60° / -30°）
4. 双臂后摆（45°）

看点：上臂顶端只转一半，侧平举时肩膀是一道斜坡，不再是上臂方块的顶角戳在肩膀上。

## hip_bands_r1.png

调试图：腿按环带从上往下上色（红、黄、绿、青、蓝、紫），只画底层。上两行坐地，下两行起身。

- 第 1、3 行：两圈方案（1.5 px 处 0.5、3 px 处 1），红 0–1.5 px、黄 1.5–3 px、绿 3–6 px 到膝、青 小腿；
- 第 2、4 行：现在的三圈等分方案（1、2、3 px 处 1/3、2/3、1），红 0–1、黄 1–2、绿 2–3、青 3–6 px 到膝、蓝 小腿。

两种都弯得顺，三圈的稍圆一点。
