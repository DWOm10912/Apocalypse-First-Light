# 备用柴油发电机组 V1

状态（2026-10-09）：**已实现（模型、方块、方块实体、加油、供电、仪表、提示、Jade、A1 摆放脚本），编译通过，还没有进游戏验证**。
- 离线检查都过了：网格全部闭合、没有同面重叠、没有落在外侧网格面上朝里的面、外观 15 texel/px、指针 / 钥匙 / 小时计 / 门 / 加油口盖 / 防雨帽的转向都用数值验过（见"验证"一节）。
- 声音还没有：三个声音事件已注册，但没有音频文件（等用户的录音），游戏里是静音的。
- A1 的摆放脚本写好了，没跑（要进游戏、恢复灯光地块后跑）。

## 为什么做

- A1 现在靠 3 个用 `/dev energy fill` 充满的测试能量单元供电（店后 u 22..24、v 6），生存模式拿不到。
- [Building Power V1 方案](../gameplay/building_power_v1_plan.md) 早就写了"玩家把发电机接到后墙外的电表箱，合上总闸，冷柜、冰柜、灯就一起工作"；电表箱、配电盘、电缆都有了，差发电机。
- 柴油、地下油罐、加油机、油桶（20 / 60 / 200 L）和手摇泵都已做好，是现成的燃料来源。

## 用户的决定（2026-10-09）

- 先做柴油发电机，再重做热力发电机。热力发电机的身份还没定（A 烧木头 / 煤的蒸汽机发电机；B 木煤气；C 保持"固体燃料发电机"、外观重做成网格），等柴油机之后。
- 做**固定式备用机组**（不是便携式），有了网格系统就按真实尺寸做多格整体，不做单格方块。
- 数值由我定。
- **不做打开式界面**：现实里是加油、拧钥匙 / 按按钮就启动。玩家只控制开关，加油沿用油桶倒油。
- 机器界面（热力发电机、能量单元、粉碎机、工业熔炉、合金炉、压缩机、化学反应器 7 台）**先不改**："如果改机器的 UI，我们最好把背包的 UI 来一次重置"。
- 第二版概念图后："机械结构有点太简单了，也就是细节不行"——回答：现实的带罩机组从外面看确实是方箱子（防雨、隔音、防盗），细节在罩子上和门里面；第三版补了罩子细节、能开的检修门和完整的发动机舱。
- 第三版仪表盘改成指针表组（用户给了实物图："柴油发电机的仪表盘需要那么现代吗？我觉得这种会好看很多"）。
- 批准第三版（"就这样做吧"），加了三点：
  1. 仪表盘文字：**统一英文**（和现实北美设备一样；不是本地化贴图）。
  2. 通用电缆接口：用**标准钢电源接口**，放在主格背面中心（机组背面的接线盒上）。
  3. 从哪倒油：底座油箱台阶上**带盖的加油口盒**，右键开盖，拿油桶倒。
  - 配色：**暖白**；"做好 PBR，一轮做进游戏"。

## 游戏里的样子（tools/build-diesel-generator-v1.mjs）

3 格长 × 1 格深 × 2 格高（多格整体，`RectMultiblockBlock`），主格是**中间那一列的下格**（`c1r0`），它画整台机组、带方块实体、背面中心是电源接口。放置时正面朝放的人。

- 隔音罩 2.4 m × 0.88 m，罩顶 1.59 m；底座油箱 2.65 m × 0.94 m × 0.3 m，在进风端比罩子多出 0.25 m 的台阶。罩子暖白粉末涂层，框和条暖白稍深，底座深灰。
- 罩子：四个角柱、上下腰线、带滴水边的罩顶、四个吊环、水箱加水检修盖、排气管和隔热圈、排气管顶的防雨帽（带配重，运行时翻开）。排气管是空心管（壁厚 6 mm），管口和内壁是烟熏的黑色，往下 10 cm 有一块黑色堵头，所以看进去是黑的；管口下面一道卡箍（2026-10-09 用户："里面没有模型，只是一个圆柱"，原来是实心圆柱）。散热端上部是带框的出风百叶（0.92–1.42 m），下面一截是实心墙板，装供油接线盒；进风端是外凸、向下开口的防雨进风罩。里面所有内表面是深灰吸音棉。
- 正面两扇检修门（可开，100°，0.8 秒）：门板上的压纹板、三个外露铰链、压紧锁 + T 形把手；门缝 5 mm，后面是黑色橡胶门封。左门下部是进风罩。右门上是仪表盘（带黑色胶框和遮雨檐），下面是红色急停（黄底座）；门内侧是仪表盘后面的控制箱。
- 仪表盘（0.46 × 0.368 m）：负载表（%，0–125，100 以上红区）、燃油表（E–½–F）、水温表（COOLANT，40–120 °C）、机油压力表（OIL PRESS，0–10 bar），四块表都有镀铬表圈和表玻璃（半透明）；机械运行小时计（5 个鼓轮，最后一位白底是 0.1 小时）；三盏灯 RUN（绿）/ LOW FUEL（黄）/ FAULT（红）；钥匙开关 OFF / RUN / START；START / STOP 两个按钮。文字和刻度是印刷贴图（`tools/draw-diesel-generator-panel-v1.mjs` 用浏览器画，`src/main/blockbench/textures/diesel_generator_panel_v1.png`），在图集里单独一块，每个 px 约 68 texel（其它地方 15）；表圈、玻璃、指针、灯、钥匙、按钮、鼓轮都是网格。
- 发动机舱（开门可见）：水箱、风扇罩和风扇、发动机（油底壳、缸体、缸盖、气门室盖和螺栓、加机油盖、正时盖、三个皮带轮和皮带、充电发电机、机滤、柴滤、油尺）、排气歧管、涡轮、波纹管、罩顶下的消声器、空气滤清器和进气管、上下水管、燃油管、启动马达、飞轮壳、带散热筋的发电机（端盖通风口、顶上接线盒）、输出电缆到背面接线盒、蓄电池、底架和减震垫。
- 底座：两个贯通的叉车孔（镀锌包边）、顶边焊接沿；正面机械油位表（指针跟燃油量走）、漏油检查口、放油螺塞、接地铜排；台阶上加油口盒（盖子可开，里面是加油颈）、鹅颈通气管、液位传感器。
- 散热端（2026-10-09 用户加）：镀锌的供油接线盒（0.75 × 0.74 m，从罩子端墙伸到格子边界），上面是**标准流体接口**（`tools/afl-fluid-port.mjs`，在第三列下格 `c2r0` 端面的中心，`FACING` 顺时针那一面）。外面那一格接流体管道，柴油从管道进油箱，只进不出。
  - 第一版放在台阶那一端，接线盒紧挨着加油口盒，把它挤住了（用户截图："加油口怎么可以和管道接口放在一边呢？不能放在另一边吗？这个加油口就放在原位？"）。改到另一端；那里原来整面是出风百叶，接线盒会挡住下半截出风口，所以百叶改从 0.92 m 开始（12 片），下面做成实心墙板。
- 背面：平墙、两个进风罩、中间的接线盒，接线盒上是**标准钢电源接口**（`tools/afl-power-port.mjs`，6 × 6 px 钢板，配合面在主格背面的格子边界上）。

## 操作（没有打开式界面）

| 动作 | 结果 | 准星提示 |
|---|---|---|
| 右键仪表盘（门关着） | 停机时启动：钥匙拧到 START，盘车 3 秒（60 tick）后转入运行，排气管冒一股黑烟；运行 / 盘车时停机（钥匙回 OFF） | 启动 / 停机 |
| 右键急停 | 只停机 | 急停 |
| 右键检修门（门关着） / 发动机舱（门开着） | 两扇前门一起开 / 关 | 打开 / 关上 |
| 右键油箱台阶上的加油口盒 | 盖子开 / 关 | 打开加油口 / 关上加油口 |
| 盖子开着时拿油桶右键机组 | 蹲下往油箱倒油（油桶自己的倒油流程，4 L/s） | 加油 |
| 散热端的流体接口接上管道 | 管道里的柴油流进油箱（管道每 tick 最多 25 L），只收柴油，不会被抽走 | — |
| 拿创造模式汽油桶 / 柴油桶右键打开的加油口 | 一次倒进能装下的量（每桶 5000 L，见 [fuel_containers_v1.md](../models/fuel_containers_v1.md)） | 加油 |
| Jade | 状态（运行 / 启动中 / 停机 / 缺油停机）、运行时的负载 FE/t、柴油 L / 600 L | — |

- 只接受柴油；倒汽油时提示"这里只加柴油"。
- 没油时也能盘车，3 秒后启动失败，故障灯亮；运行中烧干了油自己停机，故障灯亮；下一次启动清掉故障。
- 门开着时仪表盘转到侧面，不能点（先关门）。

## 贴图和 PBR

- 一张 2048 图集（`textures/block/diesel_generator.png` + `_s` + `_n`，LabPBR）。外观 15 texel/px（每格 240，按"人造方块 240 texel"的约定）。
- 内部按块降密度（`cube-slab-mesh-lib.mjs` `unwrap` 新增的 `islandScale`）：发动机舱 0.6、吸音棉和百叶后的网 0.5、橡胶 0.7、底座深灰漆 0.9——这些地方暗、只在开门时看到。不这样的话外观只能做到 10.75 texel/px。
- 看不见的面不占图集（2026-10-09）：整面埋在另一个零件里的面（门板被压纹板盖住的部分、油箱顶被焊接沿压住…）和贴地朝下的面，仍留在闭合网格里，但贴图指到一小块纯黑，不上色。判定：面的中心、角和每条边四等分点各往里 1 mm、沿法线往外 0.375 mm，**全部**落在**同一个**别的零件里才算。第一版判定允许"落在不同零件里"，结果门板外露的 4 cm 边和散热端墙的一块被当成埋住、画成黑的（预览图里看到的），已改。
- 框形的面（滴水边、前框、散热端墙、百叶框、门封、油箱顶沿）改成几根相接的条：整圈挤出的环形面在图集里占一个和整圈一样大的空岛，浪费了约 60 万 texel。相接的条在侧条那里缩进 0.3 mm，不共边。
- 仪表盘贴图在图集右下角单独一块（`unwrap` 新增的 `reserve`）。
- 表玻璃和小时计玻璃是半透明层（alpha 56，光滑度 235）；亮着的灯是全亮度零件，LabPBR 自发光 220–230。
- 三角形 14 874（运行时上限 16 384），网格元素按骨骼合并成 24 个（上限 128；表玻璃单独一个，半透明层）。
- 2026-10-09 加流体接口后外观掉到 14.5 texel/px，内部再降一点（发动机舱 0.65 → 0.6、底座 0.95 → 0.9）回到 15。

## 声音

- 门：配电盘的门声（音高 0.82）；加油口盖：同一套，音高 1.25、音量 0.7；钥匙：配电盘的锁扣声，音高 1.35。
- `diesel_generator_start`（盘车 + 着车）、`diesel_generator_run`（运转循环，`BlockLoopSoundController`）、`diesel_generator_stop`：**已注册，没有音频**（`sounds.json` 里 `sounds` 为空）。要用户录：
  - 启动：从拧钥匙到稳定运转，约 3–4 秒（前 3 秒盘车）；
  - 运转：稳定怠速 / 带载，至少 10 秒，能剪成无缝循环；
  - 停机：停油后转速掉下来到停，约 2–3 秒。
  - 有了录音以后，运转循环的听见距离要大于现在循环控制器统一的 8 格。

## 加油站要不要放这台机组（用户 2026-10-09 问）

- 现实：美国大多数加油站**没有**固定的备用发电机。飓风多的州立了法：佛罗里达州法 526.143（2006 年，2004–2005 年飓风后油荒）要求州际公路或疏散路线半英里内、加油枪位达到一定数量（按县人口 8 / 12 / 16 个以上）的加油站预装转换开关、能用备用电源带动加油机、安全系统和收款机；2006 年 7 月以后新建或大改的加油站一律预装转换开关。很多站是灾后拖来移动发电机接上，不一定常驻一台。
- 所以 A1（州道边、加油枪不少的中型站）放一台固定备用机组说得通，但不是"每个加油站都有"。另一种做法：A1 只留电表箱下面的发电机插座盒（转换开关），玩家自己找发电机来接。
- 还在等用户定；A1 的摆放脚本没跑。
