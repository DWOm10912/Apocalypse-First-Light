## 1. 起因和范围

用户 2026-10-24 看了不开光影时的新水面，说"这个效果已经蛮不错了，所以说需要给原版也加一下伪光影和画质优化"。之前还说过："原版和光影版的差太多了"，"锯齿效果简直是太离谱了"，并问到有人把 RTX 引进了游戏。

结论：
- **硬件光追不做。** Java 版用 OpenGL，要光追得把整个渲染器换成 Vulkan，和 Forge 1.20.1、Embeddium、Oculus 以及 AFL 自己的 OpenGL 渲染（Mesh、植被、雨、水）都不兼容。
- **真实阴影不做。** 要从太阳方向把世界再画一遍，等于重写光影包，留给 Aureveil（项目只支持 Aureveil 和原版两种画面）。
- **原版路径做一条内置后处理链。** 只在不开光影包时生效，每一项都能单独开关。

## 2. 分包

| 包 | 内容 | 状态 |
|---|---|---|
| V1a | 后处理链；环境光遮蔽（SSAO）；边缘抗锯齿（FXAA 方法）；调色（S 曲线 + 饱和度） | 编译通过，没进游戏 |
| V1b | 泛光（只取高亮处：太阳、灯、水面高光）；时间抗锯齿（TAA：相机每帧抖动亚像素、按深度把上一帧投影回来混合），压住细线（电线、草叶）和远处贴图闪烁，比 FXAA 干净 | 等 V1a 看过 |
| V1c | 写进 AFL 的画面设置界面，开关和强度存进客户端配置 | 等 V1a、V1b 定下默认值 |

## 3. V1a 的做法

代码在 `client/post/AflPost`，接入点是 `mixin/client/PostGameRendererMixin`，开发命令是 `/afl_render post`。

### 3.1 什么时候生效

- 不开光影包时生效（`AflShaderCompat.shaderPackInUse()` 为假）。开了光影包整条链关掉，画面全交给光影包。
- 程序加载失败或运行出错时自动关掉，日志里有一条 `AFL post:`，画面退回原版。

### 3.2 环境光遮蔽（SSAO）

- **接入点：** `RenderLevelStageEvent.AFTER_BLOCK_ENTITIES`，也就是不透明的地形、实体、方块实体画完以后，半透明层（玻璃、AFL 的水）画之前。水的画面拷贝在这之后才拷，所以水底看到的是已经压暗的地面。
- **计算：** 只用深度缓冲。
  - 法线由相邻像素的深度重建，台阶处取较近的一边，边缘不糊；
  - 每个像素在法线上方的半球里取 12 个固定采样点，半径 0.6 m，绕法线按每像素的噪声角度转；
  - 采样点所在位置的深度在它前面，就算被挡住；离得远超出半径的（柱子后面的墙），按距离减弱；
  - 32–64 m 之间淡出，远处不做；
  - 输出到 RG16F 纹理：R 是剩下的光，G 是距离。
- **应用：** 5 × 5 双边模糊，只混距离相近的像素，近处物体边缘不出暗晕；然后乘进画面（混合用目标颜色），强度可调。

### 3.3 抗锯齿和调色（`afl_final`）

- **接入点：** `GameRenderer#render` 里 `renderLevel` 之后。这时世界和手都已经画完，界面（HUD、准星、温度和伤口的屏幕效果）还没画。先拷贝一份画面，再整屏画回去。
- **抗锯齿：** 按公开的 FXAA 方法自己写：
  - 找亮度突变的像素；
  - 判断边是横的还是竖的，沿边往两头走到边的尽头；
  - 按像素在边上的位置，从边的另一侧取一部分颜色；
  - 很细的线（电线、草叶）按它和周围的反差混一点。
- **调色：**
  - 一条 S 曲线，0 还是全黑、1 还是全白，所以真实黑暗不受影响，夜里不会被调亮，强度 0.18；
  - 饱和度 ×1.08。

### 3.4 开发命令

| 命令 | 作用 |
|---|---|
| `/afl_render post status` | 读数：开没开、各项开关和参数；带 `-Dafl.gputimer=true` 启动时还有 GPU 耗时 |
| `/afl_render post all on/off` | 整条链 |
| `/afl_render post ao / smooth / grade on/off` | 单项 |
| `/afl_render post strength 0–1.5` | SSAO 强度（默认 1） |
| `/afl_render post radius 0.1–3` | SSAO 半径，米（默认 0.6） |
| `/afl_render post contrast 0–1` | S 曲线强度（默认 0.18） |
| `/afl_render post saturation 0–2` | 饱和度（默认 1.08） |

开关和参数现在只存在内存里，重进游戏回到默认值（V1c 存进配置）。

### 3.5 预算

- 目标：1440p 时 SSAO 不超过 1 ms，抗锯齿 + 调色不超过 0.3 ms（RTX 3080 Ti）。
- 进游戏用 `-Dafl.gputimer=true` 量一次，超了就把 SSAO 改成半分辨率。

## 4. 已知限制（V1a）

- 抗锯齿是单帧的边缘处理：几何边缘好很多，但远处细线和贴图闪烁（不是边缘，是采样不足）压不住，要 V1b 的 TAA。
- SSAO 只看屏幕里的东西：屏幕外的遮挡物不算，镜头转动时屏幕边缘的暗角会变。
- SSAO 也乘在动态光、火把照亮的地方（物理上本来就该这样，偏暗再调强度）。
- 极佳画质能用，但半透明的东西（玻璃、水）不做 SSAO。

## 5. 请用户在游戏里看

不开光影：
1. `/afl_render post status`：第一项应该是 `on`；
2. 抗锯齿：看方块边、栏杆、电线、车身，用 `post smooth off` 和 `on` 对比；
3. SSAO：墙角、墙根、屋檐下、车底、树根，用 `post ao off` 和 `on` 对比，太重或太轻告诉我，或者自己用 `strength`、`radius` 调；
4. 调色：用 `post grade off` 和 `on` 对比；夜里和洞里是不是还和以前一样黑；
5. 手里的枪、HUD、屏幕效果没有错位，F1 隐藏界面后抗锯齿照常生效。

开光影包时：`status` 应该显示 `off under a shader pack`，画面和以前完全一样。

## 6. 用户实机看过（2026-10-24）

用户开着 SSAO 和调色，对比了抗锯齿开和关："抗锯齿开了之后好一点，但是怎么感觉有点发糊？目前就这样吧，先继续做水体"。

发糊的原因：这套抗锯齿只看亮度，原版像素贴图内部本来就有很强的亮度反差（草、泥土的像素块），也被当成边缘去平滑；细线那一项（`sub * sub * 0.75`）对贴图内部也起作用。

下次改的方向（放进 V1b，用户先不改）：
- 只在真正的几何边缘平滑：在画手之前拷一份世界深度，画完手再拷一份手的深度，按深度跳变算边缘遮罩，贴图内部保持清楚；
- 细线那一项降到 0.25 左右；
- 再往后用 TAA 代替。
