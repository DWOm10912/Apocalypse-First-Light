# 真实黑暗 V1 / V2（2026-10-24，C 分支 `feature/underground-u2`；用户 2026-10-24 实机 PASS，开不开光影都看过，光影 Aureveil alpha.74）

用户 2026-10-24：先定了"不开光影的洞穴保持光照 0 的真实黑暗，靠火把和手电"，进游戏一看"其实并不黑呢？我想做一个全局真实黑暗，现在原版的 MC，就算光照等级是 0，也并不黑，改成现实中的黑暗就会更有感觉吧"。

## 1. 原版为什么光照 0 不黑

`LightTexture.updateLightTexture` 给 16 × 16 种（天空光，方块光）组合算光照图颜色。主世界的亮度曲线 x / (4 − 3x)（x = 等级 / 15）在 0 级就是 0，但每一格颜色还会被往灰色 (0.75, 0.75, 0.75) 拉两次，各 4%：一次在亮度选项之前，一次在之后。所以光照 0 也有约 6% 的灰，洞里能看清轮廓。亮度选项（gamma）再把暗的等级提亮，但 0 级经过 1 − (1 − 0)^4 仍然是 0。

## 2. 改了什么

- **光照图**（`mixin/client/LightTextureDarknessMixin`，只在主世界）：去掉这两次往灰色拉。光照 0 就是纯黑；曲线、昼夜、闪电、夜视、黑暗效果、亮度选项都照原版。亮度选项只提亮有光的地方，没有光的地方提不亮。
- **雾的颜色**（`client/TrueDarkness#fogColor`）：原版的雾色是天空的颜色，不管镜头在哪（只在世界最底部附近变暗），洞里远处、大洞厅会淡成白天的灰色。现在乘上眼睛所在格子的亮度（那里的天空光和方块光取较亮的一个，用光照图的曲线；雾色本身已经带昼夜），约 0.5 秒跟上，像眼睛适应。
- **光影**：Aureveil 那边要对齐：光照图坐标 0 的地方没有任何环境光（已通知 Aureveil，见 alpha.73 以后的版本）。

## 3. 影响

- 洞里、没开灯的室内、地下：没有光源就什么都看不见，要放火把、开灯或开车灯。
- 夜里露天：月光（天空光 15 乘夜里的天空亮度）照常，比原版暗一点（少了灰色底）。
- 车灯等动态光源（`docs/rendering/dynamic_lights_v1.md`）是自己算灯光再和光照图做滤色叠加，不受影响。**手持手电和火把现在还没有动态光源**（Wiki 天气页"动态光源"），黑暗里只能靠放下的火把和灯；要手电真正照亮，是 Main 的手持光源工作。
- 界面、手里的物品不受影响（物品在手里按所在格子的光照，黑暗里手里的东西也是暗的）。

## 4. 进游戏看

- 洞深处不开光影和开 Aureveil 都应该是黑的；放一个火把，火把附近亮，往外按原版曲线暗下去。

## 6. V2 夜晚（2026-10-24，用户实机 PASS）

用户 2026-10-24 进游戏看了 V1（洞里的黑“很像《森林》”），又看夜里露天：“晚上就算有月光，我感觉还是有点亮，现实中也是这样的么”。

**现实参考（地面照度，眼睛适应以后）**

| 情况 | 照度 | 看到的样子 |
|---|---|---|
| 白天 | 1 万–10 万 lux | 正常 |
| 满月、晴空 | 约 0.1–0.3 lux | 开阔地看得清路和地形，树是剪影，颜色基本没了，偏灰蓝 |
| 半月 | 约 0.01–0.03 lux | 勉强看出路的方向 |
| 只有星光 | 约 0.001 lux | 开阔地只剩轮廓，林子里几乎全黑 |

**原版为什么亮：** 夜里天空光是白天的 24%（`getSkyDarken` 最低 0.2，× 0.95 + 0.05），颜色是淡紫 (0.48, 0.48, 1)。亮度选项的提亮曲线 1 − (1 − c)^4 对整格颜色起作用：C 工作树的设置是 1.0（明亮），满月夜露天一格会被抬到约 (0.39, 0.39, 0.67)。另外原版夜光不管月相。

**改了什么**（`client/TrueDarkness`、`mixin/client/LightTextureDarknessMixin`，只在主世界）：
- **月相：** 夜里的天空光乘 k = 0.04 + 0.96 × 月亮亮度^1.5（原版月亮亮度按月相是 1、0.75、0.5、0.25、0）。夜晚程度按太阳高度渐变，用原版天空变暗的同一个公式（不含天气），黄昏和黎明平滑过渡。闪电照亮天空时不乘。
- **颜色：** 夜里的天空光从淡紫改成灰蓝 (0.62, 0.70, 0.90)，按夜晚程度渐变；白天和雨天照原版。
- **亮度选项：** 照旧提亮方块光（火把、灯）；夜里不再提亮天空光，白天照旧。同时有两种光的格子按两者的占比提亮。

**露天一格（天空光 15、方块光 0）夜里的光照图值，任何亮度设置都一样：**

| 月相 | k | 光照图 RGB |
|---|---|---|
| 满月 | 1.00 | 0.149, 0.168, 0.216 |
| 凸月 | 0.66 | 0.099, 0.111, 0.143 |
| 半月 | 0.38 | 0.056, 0.064, 0.082 |
| 娥眉月 | 0.16 | 0.024, 0.027, 0.035 |
| 新月 | 0.04 | 0.006, 0.007, 0.009 |

满月约为原版“明亮”的三分之一，新月接近全黑，只有天空和星星能衬出树和地形的轮廓。参数是 `NEW_MOON`、`PHASE_CURVE`、`TINT`。

**做不到的：** 原版光照图只能调色调，没法让贴图本身褪色（人眼暗视觉看不出颜色）；这要靠光影。开 Aureveil 时的月光是光影自己算的，已请 Aureveil 对齐：月光乘同一个月相系数、灰蓝色、不受亮度选项影响，可以的话暗处降低饱和度。

**Aureveil alpha.74（2026-10-24，已装进 C 工作树 `run/shaderpacks`，`oculus.properties` 已切换，SHA-256 dd80f834…cd45；用户实机 PASS）：** 月相按上面的 k 定档：包里是线性光，按包的显示曲线反算成线性系数（满月 1、凸月 0.550、半月 0.278、娥眉月 0.124、新月 0.036），让屏幕上的比例一致。月光直射、天空、云、深夜补光共用这个系数。原来的固定下限（月相最低 0.15、夜间补光底、夜间提亮）都改成乘月相。满月整体降到 0.54 倍，气辉降到 0.35 倍。实测露天白面的绿通道：满月约 0.15（原版路径 0.17），半月约 0.06（0.065），新月约 0.01（0.006）。颜色本来就是灰蓝，暗光降饱和原来就有。不读亮度选项，不加最低环境光。
