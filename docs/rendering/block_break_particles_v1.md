# 方块破坏粒子取样 V1（2026-10-06）

状态：**已实现**，`compileJava --offline` 通过，mixin 映射表（refmap）已生成。**没有实机验证**。

## 问题

用户 2026-10-06：挖方块时掉出来的碎屑是一大片一大片的贴图，颜色乱七八糟（蓝色油桶掉红色碎片）。

原版的方块破坏 / 挖掘粒子（`TerrainParticle`）从方块模型的 `particle` 贴图里随机截 1/4 宽高的一块。16 px 的原版贴图截出来是 4 px，正好是方块本身的一小块颜色。AFL 的方块大多用整张图集做 `particle` 贴图（128–2048 px，常常几种方块共用一张，比如油壶、两种油桶、手摇泵共用 `block/fuel_containers` 1024 px），截出来是 256 px 见方的一片图集，里面什么颜色都有。受影响的方块：管道、储罐、加油站全套、油桶、货架、收银台、办公家具等，凡是 `particle` 贴图超过 32 px 的都算。

## 做法

不改各方块的模型，统一改粒子取样（`client/BlockParticleSampler`，`mixin/client/TerrainParticleSampleMixin`）：

- 粒子所用的贴图宽或高超过 32 px（`SMALL`）时：
  - 从这个方块状态的模型实际画出来的面（烘焙后的四边形，`BakedModel#getQuads`，各个方向加不分方向的）里随机挑一个，按面积加权；
  - 在这个面内部取一点（双线性插值四个角的 UV，参数取 0.3–0.7，离开 UV 岛的边缘），截一个 3 × 3 texel 的小窗口（不超过这个面 UV 跨度的 15%）；
  - 每个碎屑就是方块自己表面上的一小块颜色。
- 模型没有面（由方块实体渲染器画、模型只有粒子贴图）时：在粒子贴图里随机一点截同样大小的小窗口。
- 32 px 及以下的贴图（原版方块、AFL 的普通方块贴图）保持原版做法。
- 粒子创建时取样一次，Forge 按模型数据换贴图（`updateSprite`）后再取一次。
- 每个方块状态的面数据缓存起来；资源重载后模型对象变了会重新计算。
- 挖掘时的碎屑和方块被破坏时的碎屑都走 `TerrainParticle`，所以都生效；落地时的灰尘、奔跑时脚下的碎屑也是同一种粒子。

## 已知不足

- 由方块实体渲染器画的方块（模型里没有面）仍然从整张贴图里随机取一点，颜色可能和方块本身不符。
- 只看模型的四边形，不看贴图内容：面上如果有大片透明，取到的可能是透明像素。
