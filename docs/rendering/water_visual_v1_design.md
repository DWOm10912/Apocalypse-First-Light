# 水体视觉 V1：材质和素材方案

状态：**设计稿（2026-10-24），用户同日批准（第 9 节）。还没有代码和素材，跟物理第 6 包一起做。**
负责：B。牵涉：Aureveil（光影包里的水）。物理部分见 [物理水体 V1](../gameplay/water_v1_design.md)：水面网格、水深、流速都由物理给，本文只管"看起来像水"。

## 1. 目标

用户 2026-10-24：把原版水的视觉换成真正像独立游戏的水，不是只换一张 `water_still.png`，要一整套水的材质。

真实的水有这几个特点，原版一个都没有：

- **水本身几乎没有颜色。** 看到的颜色来自水体吸收（越深越蓝绿越暗）、悬浮泥沙（浑）、反射的天空。原版是一张染色的贴图。
- **表面靠法线，不靠贴图。** 波纹、涟漪、流动都是法线在动，配合菲涅尔反射：低头看透明，远看像镜子。
- **白色只在破碎的地方出现。** 泡沫在岸边、急流、跌水、雨点处，其余地方没有白色。
- **流水的纹理顺着流向拉长并移动。**

## 2. 现状（核对过）

**原版：**

- `water_still` / `water_flow` 两张 16 px 动画贴图，按群系染色；
- 流动面的贴图按流向旋转。

**Aureveil**（`shaderpack/shaders/lib/water*.glsl`）已经有很完整的写实水，而且全是程序化的，没有用 2D 贴图：

| 功能 | 现在的做法 |
|---|---|
| 颜色 | 按水体厚度吸收 `AV_WATER_ABSORPTION`，厚度从深度缓冲 `depthtex1` 量 |
| 反射 | 屏幕空间反射 + 天空 |
| 波浪 | 包里 3D 噪声体（云的噪声）两层，只改法线 |
| 流动 | 从原版流动面贴图坐标的旋转反推流向（`avWaterFlowDirection`），波纹沿流向拉长、搬运 |
| 泡沫 | 浅处（不到 0.15 格）的岸边泡沫带，流动面带泡沫条纹，跌水是白的 |
| 区分 | `block.properties`：50 水源、51 流动、52 跌落 |

**问题：**

1. AFL 的物理水不是方块，Aureveil 认不出来（没有 50/51/52，也没有可反推的流动贴图坐标）；
2. 不开光影时是原版的水，和 Aureveil 的差距很大；
3. 河、湖、海、坑里的积水、洞里的水在两条路径下都长一个样。

## 3. 素材清单

**原则：** 水的素材以程序生成为主，用仓库里的脚本带种子生成。这样能无缝平铺、能随时改参数重出、版权完全是自己的。照片素材只用在泡沫这种"有机纹理"上，而且不是必须。

| 素材 | 文件 | 尺寸 / 格式 | 通道 | 作用 | 来源 |
|---|---|---|---|---|---|
| 底色 / albedo | **不做贴图** | — | — | 水没有底色。颜色由每种水体的吸收系数、散射色、浑浊度决定，写在参数表里（第 7 节 `water_types.json`） | 参数 |
| 颜色查表（可选） | `water_color_lut.png` | 64 × 16，RGB | 横轴水深 0–8 m，纵轴浑浊度 | 不开光影时按水深、浑浊度一次查出颜色，省去着色器里的指数运算 | **自制**（脚本按吸收系数算） |
| 法线 · 大波 | `water_normal_0.png` | 512²，RG（XY，Z 重建） | 切线空间 | 湖、海的主波纹，约 8 m 一个周期 | **自制**：按真实波谱（JONSWAP）叠加正弦波，周期性平铺 |
| 法线 · 细波 | `water_normal_1.png` | 512²，RG | 同上 | 风吹的细碎波，约 1.5 m 一个周期，和大波错开方向、速度叠用 | **自制** |
| 法线 · 流水 | `water_flow_normal.png` | 512²，RG | 同上 | 沿 v 方向拉长的条纹波，给河、沟、溢流用流向图法滚动 | **自制** |
| 雨点涟漪 | `water_ripples.png` | 512²（4 × 4 帧图集），RG + A（相位） | 法线 + 时间偏移 | 下雨时水面上的同心圆涟漪，雨大就密 | **自制**：脚本模拟环形衰减波 |
| 泡沫 | `water_foam.png` | 512²，R 覆盖度 + G 细节 | 灰度 | 岸边、急流、跌水、溢流口的泡沫和白沫：按"泡沫量"阈值显示，量越大越连成片 | **自制**（Worley 噪声 + 气泡斑点）为主版本；CC0 照片泡沫可作参考或混入细节 |
| 噪声 | `water_noise.png` | 256²，RGBA | R 值噪声、G Worley、B 蓝噪声、A 低频大块 | 打散周期感、泡沫边界抖动、透明度抖动、浑浊团块 | **自制** |
| 焦散 | `water_caustics.png` | 256²，R | 灰度 | 浅水底的光纹（洞穴积水、清澈小溪、坑底），按水深淡出 | **自制**：脚本让平行光穿过 `water_normal_1` 的波面折射，在底面累计亮度 |
| 粗糙度 | **不做贴图** | — | — | 水面本身极光滑（约 0.02），只按类型和雨量调（雨中 0.08–0.15），泡沫处约 0.6，写在参数里 | 参数 |
| 流向图 | **不做贴图** | — | — | AFL 的水由物理逐顶点给流速（物理方案 5.4），比画好的流向图更真实，也能实时变化。只有以后静态装饰水（喷泉、展示水池）才需要画流向图 | 物理数据 |

合计 V1 最多 8 张小图（其中 2 张可选），全部 ≤ 512²，显存不到 2 MB。

### 3.1 自制和 CC0 的分工

| 类别 | 结论 | 理由 |
|---|---|---|
| 法线（三张）、涟漪、噪声、焦散、颜色查表 | **必须自制**（脚本） | 本质是数学：真实波谱、可平铺、可调参数。网上的"水法线贴图"多数是别人程序生成的、授权不清，或者不能完美平铺，没有必要用 |
| 泡沫 | **自制为主**，CC0 照片可选 | 照片泡沫更有机，但要去光照、做平铺、转成覆盖度。CC0 来源：ambientCG、Poly Haven（两站的素材都是 CC0）。只取泡沫、水花这类，记录出处 |
| 地面变湿、雨后积水贴片 | 不需要新素材 | 用 `water_noise` 做积水形状遮罩，地面变暗、变光滑是参数 |
| 原版 `water_still` / `water_flow` | **不再用于 AFL 的水** | 是 Mojang 的素材，AFL 以后独立出去不能带 |

## 4. 六种水体的差异

数值是起点，原型里对着真实照片调（`water_types.json`）。

| | 河流 | 湖泊 | 海水 | 洞穴积水 | 雨后浅积水 | 急流 / 瀑布 / 白沫区 |
|---|---|---|---|---|---|---|
| 颜色（吸收 + 散射） | 绿褐，浅处透出河床 | 深处蓝绿偏暗，浅处清 | 深处深蓝，浅处碧绿；沙底泛青 | 几乎透明，底部清楚；没光就是黑 | 透明，只看见地面变暗 | 白色为主 |
| 浑浊度 | 中（雨后升高，变土黄） | 低（雨后岸边浑） | 低（破浪带浑） | 极低 | 中（泥地上浑） | 高（气泡） |
| 法线 | 流水条纹 + 细波，沿流向滚动，速度 = 实际流速 | 大波弱 + 细波，随风 | 大波强 + 细波，随风；V1 只有法线，没有真实浪高（海浪是物理 V4） | 几乎镜面，偶尔滴水涟漪 | 细波很弱；下雨时满是涟漪 | 强烈扰动 |
| 流动 | 按物理流速 | 几乎不动 | 漂移慢 | 不动 | 不动（汇流处慢流） | 快，沿坡度 |
| 泡沫 | 浅滩、石头后、岸边少量条纹 | 岸边细线 | 岸边泡沫带（V1 静态，V4 破浪） | 无 | 无 | 泡沫量 = 流速 × 坡度，跌水全白 |
| 反射 | 中 | 强（风小时是镜子） | 强 | 弱（洞里没有天空，只有光源的高光） | 强（薄水膜反光是雨夜街道的关键） | 弱（粗糙） |
| 焦散 | 浅水有 | 浅水有 | 浅水有 | 有光源照时明显 | 无（太浅） | 无 |
| 雨点涟漪 | 有 | 有 | 有（被浪掩盖） | 无（头顶有顶） | 有，最明显 | 被掩盖 |
| 声音（另做） | 流水声按流速 | 安静，岸边轻拍 | 浪声 | 滴水回声 | 雨打水面 | 轰鸣 |

**物理给的判据：** 类型（物理的水体类型：天然河、湖、海，AFL 盆地按所在位置是露天还是洞里）、水深、流速、浑浊度都在水面网格的顶点上（物理方案 5.9）。

**雨后浅积水的两档：**

- **几毫米：** 不是水面网格，只是"地面变湿"：地面变暗 20–35%、粗糙度降低（光影路径），低洼处按噪声出现反光的薄水膜；
- **超过 2 mm 的积水：** 物理方案里的盆地，画真正的水面。

## 5. 最小可行 V1

**目标：** 工作量可控，又让人一眼看出比原版真实。

**素材 4 张：**

1. `water_normal_0`；
2. `water_normal_1`；
3. `water_foam`；
4. `water_noise`。

`water_flow_normal`、涟漪、焦散、颜色查表放到 V1.1，先用细波法线拉伸代替流水条纹。

**着色器参数（每种水体一组，`water_types.json`）：**

| 参数 | 意义 |
|---|---|
| `absorption` RGB（每米） | 越深越暗、越偏蓝绿 |
| `scatter` RGB | 水体自身的散射色 |
| `turbidity` | 浑浊度（物理顶点值叠加） |
| `normal_strength_0/1`、`normal_scale_0/1`、`normal_speed` | 两层法线的强度、尺度、漂移 |
| `flow_stretch` | 流水时法线沿流向拉伸的倍数 |
| `foam_shore_depth` | 岸边泡沫带深度（米） |
| `foam_from_speed` | 流速多少开始起白沫 |
| `roughness`、`rain_roughness` | 平时和下雨时的粗糙度 |
| `reflect_strength` | 反射强度 |

**能得到：**

- 深浅有颜色变化；
- 菲涅尔反射；
- 两层错动的波纹不再看出周期；
- 河水沿流向流；
- 岸边、溢流口有泡沫；
- 下雨时水面变粗糙。

这已经和原版是两种东西。

### 5.1 开光影：Aureveil 接口

> **2026-10-28 更新**：下面方块 id 53/54/55 的设想走不通。AFL 的水面是立即画的，没有方块 id。现在的方案见 [AFL 水面 ↔ Aureveil 光影接口 V1](afl_water_shader_interface_v1.md)：按贴图矩形认出水，数据放在顶点颜色和动态贴图 `afl_water` 里，包选项 `AFL_WATER`。AFL 这边已实现，等 Aureveil。下面保留原设想作记录。

Aureveil 的写实水已经很好，接口只做"让包认出 AFL 的水，并拿到物理数据"，不改包的画法：

- AFL 水面网格在 Oculus 下按半透明水的程序画，给新的方块 id：

  | id | 水体 |
  |---|---|
  | 53 | AFL 静水（盆地、湖） |
  | 54 | AFL 流水 |
  | 55 | 洞穴积水 |

  天然水体仍是 50/51/52。
- **流向：** 不再靠贴图坐标反推。顶点里直接带流速向量和速度（编码进一组顶点属性，具体通道和 Aureveil 商定，参考雨 alpha.49、植被 alpha.70 两次的做法）。
- **水深：** 顶点带"这里的水底高度"。包可以不再从深度缓冲量厚度，浅水泡沫也更准（水底被别的东西挡住时也对）。
- **浑浊度、水体类型：** 一个字节，包按类型换吸收、散射。
- **雨：** 包已经有雨的数据（alpha.49），水面涟漪由包自己画。
- **版本：** 包的新 alpha 号 + `docs/afl-interface-water-alphaXX.md`。AFL 检测到旧版包时，AFL 的水按 id 50/51 退回，至少画得出来。
- **素材：** 包要用的贴图放在包自己的目录（包只能读自己的文件），和 AFL 用同一个生成脚本的产物。

### 5.2 不开光影：AFL 自己的水

- 一个核心着色器 `afl_water`（和 `afl_rain` 同一套做法），画物理的水面网格。
- **颜色：** 用顶点上的水深（物理直接给，不用读深度缓冲）按 `absorption` 算，浅处透明度高，深处不透明。
- **法线：** 两层法线；流水时用流向图法（两份相位错开半个周期的法线沿流速平移、交替淡入淡出，Valve 2010 公开的做法），滚动速度 = 物理流速。
- **反射：** 菲涅尔 × 天空色（用原版的天空 / 雾颜色），加太阳 / 月亮的高光。没有屏幕空间反射，这是和光影路径的主要差距。
- **泡沫：** `foam_amount` = 岸边浅度 + 流速项 + 坡度项，用 `water_foam` 和 `water_noise` 阈值化。
- **下雨：** 粗糙度升高，高光变散。
- **天然水体（原版几何）：** 不开光影时用资源覆盖把原版水的贴图换成按 `water_normal_1` 生成的低对比度动画贴图，降低原版的方格感；V2 物理接管天然水体以后整体换成 `afl_water`。

## 8. 版权和以后独立

- **最适合长期保留的：**
  - 生成脚本 + 它的产物（法线、涟漪、噪声、焦散、泡沫、颜色查表）；
  - `water_types.json`；
  - `afl_water` 着色器。

  这些全部是自己写的，AFL 独立成单独的游戏或引擎时可以直接带走：脚本是 Node，不依赖 Minecraft。
- **CC0（ambientCG、Poly Haven）：** 可以商用、可以改、不用署名，但仍在 `design/water/SOURCES.md` 记录出处，方便以后审计。
- **不用：**
  - 原版的水贴图（Mojang 版权）。V1 的天然水体在不开光影时也换成 AFL 生成的版本，不再显示原版贴图；
  - 其他模组、光影包的贴图和代码（项目规定只用真实世界参考）；
  - 标着"仅个人使用"或授权不明的素材包；
  - 授权不清的 AI 生成贴图。
- **Aureveil 本身：** 是 AFL 自己的包，接口和贴图双方都能保留。

## 9. 用户的决定（2026-10-24）

1. 素材程序化生成优先；泡沫允许混入来源明确的 CC0 素材（记进 `design/water/SOURCES.md`）。
2. V1 先做四张核心贴图（`water_normal_0`、`water_normal_1`、`water_foam`、`water_noise`）和参数表 `water_types.json`。
3. V1 同步替换不开光影时天然水的纹理。

做的时间跟物理方案的第 6 包（连续水面完整版）；第 2 包的最简水面先用单色。
