# 第一人称身体 V1

状态：**已实现两轮，第二轮未经游戏内验证**（2026-10-15）。第一版用户进游戏看过并反馈（见下“第二轮”）。编译通过；GameTest（第一轮跑过）只确认没有新增失败（这块是纯客户端渲染，GameTest 碰不到，第二轮没重跑）；数值检查见 4.2、4.5。分支 `feature/first-person-body`，从 master `1eed4ac7` 开出，工作区 `D:/Minecraft Modding/AFL-survivor-v0`。方案经用户确认（“手臂先藏，背上的枪照画，默认开”）后实现。

**后续（2026-10-15，同日）：** 用户看了第二轮的录像（往右转头时右手贴上肩膀），决定改做统一的骨骼人物：第一、第三人称一套骨架一个身体，见 [player_skeleton_v1_design.md](../dev/player_skeleton_v1_design.md)。本分支**暂不合并**。这里的后仰、颈部后让、手滑出画面、限制手臂都是过渡补丁，会被骨架取代；"世界那一遍画自己身体"的挂钩、渲染层跳过表、护甲隐藏会沿用（设计第 3.1 节）。

**骨骼 P1（2026-10-15，同一工作区，分支 `feature/player-skeleton-p1`，用户实机 PASS）：** 骨架原型已经接在这套第一人称身体上，由客户端配置 `[skeleton] enabled` 控制，当时默认关（详见设计第 12 节）；2026-10-16 起默认开（见 [player_actions_v1_plan.md](../dev/player_actions_v1_plan.md) 第 13 节）。
- **关着时**：本文档描述的行为不变。
- **打开时**：
  - 身体由骨架画，"世界那一遍画自己身体"的挂钩继续用（`LevelRendererFirstPersonBodyMixin` 同时通知 `PlayerSkeleton.worldBegin/worldEnd`）；
  - 后仰、颈部后让、手滑出画面、限制手臂这几个补丁不再生效（`FirstPersonBody` 里只在骨架关着时调用）；
  - 空手或只拿 BR51 时，原版画手那一遍被取消，手只来自身体；
  - P2 第一段（2026-10-15，分支 `feature/player-skeleton-p2`，**用户实机 NOT PASS**，第一人称手臂约粗 2.2 倍、握姿不对，要重新设计，见设计第 13.9 节）：拿 BR51 或 P9 时都一样，正在收回挂点的枪也一样；枪按实物大小画，全部片段在身体上播放（设计第 13 节）；
  - 其他物品仍走本文档的旧逻辑：第一人称视图模型，身体手臂隐藏。

**第二轮（2026-10-15，同日）：** 用户进游戏看了第一版，反馈“手的位置怪怪的”“人有点矮”。原因（量过，4.5）：原版第一人称的手固定在屏幕右下角，身体又没有手臂；低头时眼睛正下方 0.21 格就是躯干平顶，正下方看时肩膀顶面从屏幕中间铺到底边，腿和脚又被躯干、胸挂挡住。用户确认的改法：空手和普通物品时画身体手臂，低头时第一人称的手滑出画面；拿枪、撬棍照旧；低头时身体按颈部前屈往后让 0.13 格。第二轮编译通过，没有游戏内验证。

## 1. 目标

第一人称下低头能看到自己的身体：胸口、腰、腿、脚，以及穿在身上的东西：
- 胸挂、背包肩带；
- 枪背带；
- 大腿上的枪套和里面的手枪；
- 衣服和裤子（皮肤）。

别的玩家看到的、F5 第三人称、物品栏里的人物预览，都和以前一样。

## 2. 以前为什么看不见（量过）

- **原版：** `LevelRenderer.renderLevel` 的实体循环里有一条判断：实体是摄像机实体、摄像机不是第三人称（`camera.isDetached()` 为假）、人没在睡觉，就跳过不画。整个 `LevelRenderer` 只有这一处调用 `isDetached`（1.20.1 / Forge 47.4.22 源码第 1201 行）。
- **Oculus 阴影：** 阴影 pass 不走上面那条判断。`ShadowRenderer.renderEntities` 遍历全部实体、不排除自己（光影包关了实体阴影时，用 `renderPlayerEntity` 单独画自己），都经过 `LevelRenderer.renderEntity`。所以开光影时，第一人称下地上本来就有自己完整的影子（头和手臂都在）。
- **Embeddium：** 不接管这个实体循环。
- 开发环境的依赖里，没有别的模组的 mixin 碰 `Camera.isDetached`、`RenderLayer.render`、`HumanoidArmorLayer.setPartVisibility` 这几处（2026-10-15 查过）。

## 3. 怎么画（已实现）

### 3.1 让自己进入实体循环

- `mixin/client/LevelRendererFirstPersonBodyMixin`：`@Redirect` 上面那处 `isDetached`，改成 `isDetached() || FirstPersonBody.shown(camera)`。第一人称、这一帧该画身体（见 4.3）时，自己就像别的实体一样在正常的实体阶段画出来。
- 走的是原版实体渲染那条路：光影下用实体程序（`gbuffers_entities`），光照、PBR、雾都和别的实体一致，不在某个渲染阶段手动补画。

### 3.2 只在“世界里的自己”上改

- 同一个 mixin 在 `LevelRenderer.renderEntity` 的 HEAD / RETURN 调 `FirstPersonBody.begin(entity)` / `end()`：只有画摄像机实体、而且 `shown` 为真的那一次打开标记。标记分两种：
  - `AflShaderCompat.activeShadowPass()` 为真：阴影 pass，只后仰，不藏东西；
  - 否则：主画面，后仰并且藏东西。
- 物品栏人物预览、维护台、F5、别的玩家都不经过这个标记，不受影响。
- 每帧开始时（`RenderTickEvent`）标记清零，防止某次绘制被取消后标记留到下一帧。

### 3.3 显示什么、藏什么（主画面）

| 部分 | 第一人称 | 怎么做 |
|---|---|---|
| 头、帽子层 | 藏 | `RenderPlayerEvent.Pre` 把模型部件设为不可见，`Post` 还原 |
| 两只手臂、袖子层、护甲的手臂部分、手上拿的东西 | 看手上（见 3.4） | 空手或普通物品：画；拿枪、撬棍、倒油的油桶，或正在使用物品：藏 |
| 头盔 | 藏 | `HumanoidArmorLayerFirstPersonBodyMixin`：`setPartVisibility` 末尾把头、帽子（手臂藏时连两臂）设为不可见 |
| 头部物品、披风、鞘翅、身上插的箭 / 蜂刺、肩上的鹦鹉、三叉戟旋转特效、deadmau5 耳朵 | 藏 | `LivingEntityRendererFirstPersonBodyMixin`：`@Redirect` 层循环里的 `RenderLayer.render`，这几类层跳过（手上物品层只在手臂藏时跳过） |
| Curios 头部网格（耳罩） | 藏 | `ClientEquipmentSlots.WornMeshRenderer`：所在部件不可见就不画 |
| 身上着火的火焰（`EntityFlames`） | 藏 | `EntityRenderDispatcherFireMixin` 里判断；第一人称已有屏幕上的火焰效果 |
| 躯干、腿（含外套层、裤子层）、胸部和腿部护甲、鞋 | 画 | |
| 胸挂、背包、枪背带、枪套和手枪、背上的长枪（`CarriedWeaponsLayer`） | 画（背上的枪：用户决定照画） | 跟着身体动；背上的枪在身后，低头看不到 |
| 脚下的圆形影子（不开光影时） | 照旧 | |

- 别的模组的 Curios 头部渲染器不一定看部件可见性，这个管不了，记为已知限制。

### 3.4 手（第二轮，用户 2026-10-15 确认）

`FirstPersonBody#bodyArms` 按手上的东西决定用哪双手：

| 手上 | 身体的手臂 | 第一人称的手 |
|---|---|---|
| 空手、方块、普通物品 | 画，垂在身体两侧，东西拿在身体的手里（原版 `ItemInHandLayer`） | 低头 25° 开始往下滑，45° 滑出画面（`ItemInHandRendererFirstPersonBodyMixin`，在 `renderArmWithItem` 前后压栈并下移，最多 0.7 格，平滑曲线） |
| 枪（`NativeGunItem`）、撬棍、倒油的油桶（自己有第一人称手臂） | 藏 | 照旧（它们取消 `RenderHandEvent`，自己画） |
| 正在使用物品：吃喝、拉弓、举盾、温度计；手持已上弦的弩 | 藏 | 照旧（这些动作的手臂会指向视线方向，伸进摄像机） |

- **手臂前摆限制**（`HumanoidModelFirstPersonBodyMixin` → `FirstPersonBody#limitArms`）：原版走路手臂往前摆可达 49°，跑步 57°，低头 16–22° 就会在画面底角露出身体的手，和第一人称的手同时出现。第一人称身体画手臂时，前摆限制在 20°（0.35 rad，真人走路摆臂的幅度），身体手臂要到低头 45.6° 才进画面，正好接上第一人称的手滑完的 45°。
- **挥手：** 低头不到 45° 时第一人称的手还在，身体手臂的挥击也按 20° 限制，只看到第一人称的手挥；45° 以后第一人称的手已经滑走，身体手臂完整挥击，低头挖脚下的方块时由它给反馈。
- 阴影 pass 不限制手臂摆动。

## 4. 怎么避免穿模

### 4.1 量出来的位置（原版尺寸）

- 玩家模型：缩放 0.9375，1 模型像素 = 0.0586 格，模型顶（脖子）在渲染原点上方 1.407。眼睛离脚 1.62（站）/ 1.27（蹲）。
- 摄像机在实体正中（前后方向），躯干前后各 2 像素，所以原版躯干前沿在眼睛竖直线**前方 0.117 格**。低头时往下看会看到躯干的顶面、甚至在躯干里面。

### 4.2 绕渲染原点后仰（已实现）

`RenderPlayerEvent.Pre` 里在姿态矩阵上乘 `Ry(-身体朝向) · Rx(-后仰) · Ry(身体朝向)`，整个模型绕渲染原点往后仰，让躯干前上角落在眼睛竖直线**后方 0.03 格**。渲染原点站着时在脚底，蹲着时原版把它下移 0.125（`PlayerRenderer.getRenderOffset`）。

角度按姿势算一次（`FirstPersonBody#lean`，用原版站 / 蹲的躯干位置和倾角），不是每帧量模型：`Pre` 事件发生在 `setupAnim` 之前，那时模型里还是上一个被画的玩家的姿态。

`tools/check-first-person-body-geometry.py` 的输出（2026-10-15）：

| 姿势 | 后仰 | 躯干顶面在眼睛下方 | 躯干最高处前沿 | 身体离眼睛最近的角 |
|---|---|---|---|---|
| 站立 | 5.98° | 0.208 格 | 眼睛竖线后 0.030 | 0.315 格（近裁面 0.05 的 6.3 倍） |
| 蹲下 | 6.52° | 0.139 格 | 眼睛竖线后 0.247（蹲姿躯干前倾，最高处是后沿） | 0.328 格（6.6 倍） |

- 外套层大 0.25 像素，站立时前上角在眼睛竖线后 0.017。
- 方案里蹲下写的是 7.3°，那是按“绕脚”算的；实际转轴是下移了 0.125 的渲染原点，力臂更长，算出来是 6.52°。
- 胸挂网格比躯干往前凸，低头时会看到它的上沿在眼睛竖线前面一点（没有量具体数）。
- 走路时腿前后摆，离眼睛 0.75 格以上，不会靠近摄像机。
- 上面这张表是平视时的位置；低头时还有 4.5 的颈部前屈，身体离眼睛只会更远。

### 4.3 什么时候不画身体（`FirstPersonBody#shown`）

- 设置关了；摄像机实体不是自己；
- 旁观模式、隐身、睡觉（原版本来就画睡觉，不加后仰）、正在死亡；
- 姿势不是站立或蹲下（游泳 / 爬行、鞘翅、三叉戟旋转），或者 `isVisuallySwimming` / `isFallFlying` / `isAutoSpinAttack`；
- **摄像机离眼睛太远：** 水平超过 0.3 格，或者上下超过 0.6 格（上下放宽，是因为蹲下时眼睛高度有过渡）。维护台锁定视角、发电机拉绳都会挪摄像机，用这一条统一处理，以后新的锁定视角也自动适用。
- 骑乘照常画（坐姿腿往前）；以后皮卡上车时单独看。

### 4.4 其它

- 原版视角摇晃作用在整个世界上，身体跟着世界一起动。
- 原版站着转头时，身体最多落后头 50° 才跟上；第一人称下表现为“转头时身体没马上转”，保留。

### 4.5 颈部前屈（第二轮，用户 2026-10-15 确认）

真人低头是脖子往前弯，眼睛往前移到胸口前面，看到的是胸口正面，看不到肩膀顶。我们不动摄像机（不影响瞄准和点方块），改成身体往后让：`RenderPlayerEvent.Pre` 里先沿视线的水平方向往后平移 0.13 × sin(低头角)，平视和抬头时不动，正下方看让 0.13 格。主画面和阴影 pass 一起挪。

`tools/check-first-person-body-geometry.py` 第二部分的输出（站姿，屏幕纵坐标 -1 = 底边，+1 = 顶边；第一轮没有前屈时，90° 的躯干顶前沿在 -0.21，肩膀顶面铺满下半屏）：

| 低头 | 躯干顶前沿 | 胸挂翻盖上沿 | 腰带前沿 | 脚尖 |
|---|---|---|---|---|
| 45° | -5.46（画面外） | -1.21（画面外） | -1.55 | -1.39 |
| 60° | -2.98（画面外） | -0.75 | -0.95 | -0.82（被胸挂挡住） |
| 75° | -1.81（画面外） | -0.36 | -0.50 | -0.39（被胸挂挡住） |
| 90° | -1.10（画面外） | +0.01 | -0.12 | -0.01（被胸挂挡住） |

- 肩膀顶面在任何低头角度都不再进画面。
- 穿胸挂时脚被挡住：Minecraft 的脚尖只在身体中线前 0.117 格，胸挂口袋凸到 0.25 格。不穿胸挂时，正下方看能看到脚尖。

身体手臂第一次进画面的低头角（同一脚本）：原地垂着 59.4°；前摆 20°（限制后的上限）45.6°；不限制时前摆 40° 是 30.4°、57° 是 16.0°。

## 5. 光影怎么处理

- **不开光影：** 正常的实体光照，只有脚下的圆影子。
- **Oculus 主画面：** 走实体程序，和别的玩家一样。第一人称的手和枪照旧在手部 pass 里最后画，叠在身体前面。
- **Oculus 阴影 pass：** 头和手臂照旧画进阴影；后仰也画进阴影，和主画面一致，自己身上的阴影才对得上。F5 时两边都不后仰。
- **Sundial / 其它光影包：** 没有在游戏里看过。要看：身体光照是否和别的玩家一致；开着体积云时身体边缘有没有拖影。其它包只要求不出错。

## 6. 设置

- 新的客户端配置文件 `config/apocalypse_firstlight-client.toml`（`ModConfig.Type.CLIENT`，在 `ApocalypseFirstLight` 构造里注册），代码 `client/FirstPersonBodyConfig`：

```toml
[first_person]
    show_body = true
```

- 默认开（用户决定）。不加快捷键。这是 AFL 第一个客户端配置，以后的客户端选项放进同一个文件。
- 同一个文件里后来加的：`[vehicle_hud]`（仪表盘样式和速度单位，2026-10-16，见 [第一辆车 第 8.12 节](../vehicles/first_pickup_v0_design.md)）。这一节在 AFL 的设置界面里能改（`client/settings/AflSettingsScreen`，模组列表的"配置"按钮）；`[first_person]` 还没放进界面。

## 9. 已知限制

- 别的模组的 Curios 头部渲染器、别的模组加的层，不一定会被藏（只跳过了原版那几类层）。
- 拿枪、撬棍、油桶，或正在使用物品时，身体没有手臂（第一人称的手另外画）。
- 穿胸挂时低头看不到脚（4.5）。
- 低头 25–45° 之间、拿着普通物品时，第一人称的手正在滑走；跑动中身体手臂被限制在 20° 前摆，不会和它同时出现，但挥击动作在这个区间只有第一人称的手。
