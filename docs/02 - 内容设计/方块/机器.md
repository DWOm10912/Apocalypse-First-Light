### 2. 能量单元
- 储能上限：100万 FE
- 最大输入：128 FE/t
- 最大输出：128 FE/t
- 默认进入充电模式：只接收 FE，不主动向能源线缆网络输出。
- 可在 GUI 右上角手动切换为放电模式：停止接收 FE，并按当前最大输出向能源线缆网络供能。
- 充电 / 放电模式保存到 Block Entity NBT；正常挖掘后的物品同时保留当前 FE 与模式，重新放置后恢复。
