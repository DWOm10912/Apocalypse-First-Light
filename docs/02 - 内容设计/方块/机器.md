# 1. 热力发电机

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 储能上限 | 100,000 FE |
| 发电速度 | 16 FE/t |
| 最大输出 | 16 FE/t |

## 燃料

| 燃料 | 总发电量 |
|---|---:|
| 煤炭 | 500 FE |
| 木炭 | 500 FE |
| 煤炭块 | 5,000 FE |
| 熔岩桶 | 20,000 FE |

熔岩桶消耗完成后返回空桶。

每 tick 实际生成：

`min(16 FE, 当前燃料剩余能量, 剩余储能空间)`

因此燃料总能量会精确结算，不会因为无法被 16 整除而损失。

## 特殊规则

- 储能满时暂停燃烧。
- 当前燃料剩余能量不会被浪费。
- 储能重新出现空间后继续燃烧同一份燃料。
- 作为能源网络的发电端参与供电。

# 2. 能量单元

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 储能上限 | 1,000,000 FE |
| 最大输入 | 128 FE/t |
| 最大输出 | 128 FE/t |
| 默认模式 | 充电 |

## 工作模式

### 充电模式

- 只接收 FE。
- 不主动向能源线缆网络输出。
- 作为能源网络的用电端。

### 放电模式

- 停止接收 FE。
- 最大输出 128 FE/t。
- 作为能源网络的发电端。

## 状态保存

机器会保存：

- 当前 FE
- 充电 / 放电模式

正常拆除并重新放置后恢复。

# 7. 化学反应器

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 储能上限 | 60,000 FE |
| 最大输入 | 128 FE/t |
| 工作消耗 | 32 FE/t |
| 输入液槽容量 | 8,000 mB |
| 废液槽容量 | 8,000 mB |
| 物品输入槽 | 1 |
| 物品输出槽 | 1 |
| 配方类型 | `apocalypse_firstlight:chemical_reacting` |

## 接口

以玩家面对机器正面为准：

| 位置 | 功能 |
|---|---|
| 左侧 | 输入液体 |
| 右侧 | 输出废液 |
| 背面 | 输入 FE |
| 正面 | 无流体接口 |
| 顶部 | 无流体接口 |
| 底部 | 无流体接口 |

### 左侧流体口

- 只能输入。
- 自动化速率最高 25 mB/t。

### 右侧废液口

- 只能输出。
- 自动化速率最高 25 mB/t。

左右两个端口拥有独立的 tick 预算。

因此理论上可以在同一 tick：

- 左侧输入 25 mB
- 右侧输出 25 mB

互不占用对方预算。

---

## 配方

### 黑钨矿湿法处理

| 项目 | 内容 |
|---|---|
| 物品输入 | 黑钨矿 ×1 |
| 液体输入 | 水 1,000 mB |
| 物品输出 | 氧化钨 ×1 |
| 废液输出 | 工业废液 1,000 mB |
| 时间 | 300 ticks / 15 秒 |
| 总能耗 | 9,600 FE |

## 工作条件

只有以下条件全部满足时加工进度才会前进：

- 输入物品正确
- 输入液体足够
- 输出物品槽有空间
- 废液槽有足够空间
- 当前 FE 足够

任意条件不满足时：

- 加工暂停
- 不消耗 FE
- 当前加工进度保留

完成时再次检查全部条件，并统一结算：

- 物品输入
- 液体输入
- 物品输出
- 废液输出

---

## 状态保存

化学反应器保存：

- 当前 FE
- 输入液体
- 废液
- 物品
- 加工进度

正常拆除时：

- 内部物品单独掉落
- 机器物品保留 FE
- 机器物品保留输入液体
- 机器物品保留废液

---

## Jade 显示

显示顺序：

1. 能量
2. 输入液体
3. 加工进度
4. 废液
5. 输出物品

规则：

- 能量始终显示。
- 空液槽不显示。
- 没有加工进度时不显示进度。
- 空输出槽不显示。
- 暂停加工时保留已有进度显示。

| 属性 | 当前值 |
|---|---:|
| 容量 | 20,000 mB |
| 等效桶数 | 20 桶 |
| 同时存储流体种类 | 1 |
| 顶部自动输入 | 25 mB/t |
| 底部自动输出 | 25 mB/t |
| 水平侧自动接口 | 无 |

---

## 自动接口

### 顶部

只允许：

`输入流体`

最大：

`25 mB/t`

### 底部

只允许：

`输出流体`

最大：

`25 mB/t`

### 四个水平侧面

不提供自动流体能力。

---

## 手动容器

玩家使用：

- 桶
- Forge 流体容器

可以从储罐的可交互面进行输入或取出。

手动交互按照容器自身容量一次结算。

例如：

`Bucket = 1,000 mB`

不受自动端口：

`25 mB/t`

限制。

---

## 储存规则

流体储罐一次只能保存一种流体。

例如：

已经存有：

`工业废液`

则不能继续加入：

`水`

直到当前储液被完全清空。

---

## 状态保存

正常拆除后的储罐物品会保留：

- 当前流体类型
- 当前流体数量

Tooltip 显示：

`流体名称    当前储量 / 20,000 mB`

空储罐不显示流体信息。

# 9. 机器通用规则

## 能量

加工机器的总能耗由：

`工作消耗 FE/t × 加工 ticks`

计算。

配方本身原则上只负责：

- 输入
- 输出
- 时间

机器负责自己的功率等级。

---

## 暂停加工

以下情况不会继续增加加工进度：

- FE 不足
- 输入不足
- 输出堵塞
- 必要流体不足
- 废液槽空间不足

暂停时：

- 不额外消耗 FE
- 不清空已有进度

---

## 自动化

FE 自动化遵循《工业》中的能源网络规则。

流体自动化遵循《工业》中的流体管道规则。

机器页面只记录：

- 这个设备哪些面可以连接
- 每个接口允许输入还是输出
- 设备自身的端口速率

不在这里重复记录完整网络算法。
