# 创造模式标签页

战斗物品统一放在「AFL 武器与弹药」（英文：AFL Weapons & Ammunition），注册名 `apocalypse_firstlight:weapons_and_ammunition`，图标为制式手枪。

当前顺序：制式手枪、撬棍、9mm 手枪弹。它们不再出现在 AFL 普通物品标签页，原版 Search 和 Forge 搜索规则不变。

后续战斗内容按枪械、近战武器、弹药、弹匣、配件、投掷物排列；尚未实现的类别不创建占位物品。

注册位置：`src/main/java/com/antaurora/apofirstlight/registry/AflCreativeTabs.java`。名称使用 `itemGroup.apocalypse_firstlight.weapons_and_ammunition` 中英文翻译键。
