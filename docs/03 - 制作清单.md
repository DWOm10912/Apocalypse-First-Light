#  Battery Appliance

不要每台设备各写一套电池代码。

可以抽一个很轻量的公共层：

```
BatteryPoweredAppliance
├─ Battery Slot
├─ Charge
├─ Drain Rate
├─ Powered State
└─ Shift+RightClick Maintenance GUI
```

然后设备各自只定义：

```
饮料冷柜
→ drain = medium

卧式冰柜
→ drain = medium/high

饮水机
→ drain = low

自动售货机
→ drain = low/medium

工作灯
→ drain = low

无线电
→ drain = very low
```

这样以后新增小型电器基本只需要接这个模板。
