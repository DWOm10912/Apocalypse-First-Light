# Fuel Dispenser V1（加油机 V1）

状态（2026-10-04）：**已实现，未实机验证**。`compileJava --offline` PASS。外观只看过离线预览（生成器 `--preview` 输出）。以下内容都还没在游戏里看过：模型、PBR、六格结构、碰撞、生存挖掘掉落、拔枪 / 挂回、自动回枪、软管渲染、手持油枪模型。

## 定位

- 加油站用的双面加油机。参考的是双立柱、油管从顶棚下垂的样式（用户 2026-10-04 给的参考图）：
  - 褪色红顶棚；
  - 每面一块液晶屏、一个键盘；
  - 每面两把枪：顾客左手是汽油枪（红色枪套），右手是柴油枪（暗绿色枪套）；
  - 枪正面朝外，插在带不锈钢框的斜凹槽里。
- V1 只有静态外观加第一版交互：拔枪、挂回。没有燃料，也没有电。

## 结构

### 方块状态

| 属性 | 取值 |
|---|---|
| `facing` | 正面朝向，放置时朝向玩家 |
| `cell` | `a0`、`b0`、`a1`、`b1`、`a2`、`b2`。a 是主格那一列，b 在主格顺时针一侧；数字是层 |
| `front_gasoline`、`front_diesel`、`back_gasoline`、`back_diesel` | true 表示这把枪挂在枪座上 |

### 主格与其它格

- **主格 a0**：
  - 画整台加油机（静态 OBJ，区块烘焙）：机身模型，加上每把挂着的枪各一个模型；
  - 有方块实体；
  - 负责掉落。
- **其它五格**：只有碰撞和选择形状，渲染为不可见，模型只有粒子贴图。
- 正面朝 `facing`，背面是正面转 180°，两面一样。

### 放置与拆除

- **放置**：六格都要能放（可替换、没有流体、在世界边界内、玩家能交互、不被实体挡住），下面两格要有结实的地面。放置是一次 BlockItem 操作，任何一格写入失败就全部还原。
- **结构检查**：任何一格缺了，其余格会自己移除。下面失去支撑时，整台从主格破坏并掉落。
- **挖掘**：
  - 镐，钻石级：`minecraft:mineable/pickaxe` 加 `minecraft:needs_diamond_tool`，`requiresCorrectToolForDrops`；
  - 强度 5.0 / 6.0，金属音效；
  - 生存模式用正确工具拆任何一格，都会掉一台加油机。主格走战利品表，其它格由 `playerWillDestroy` 在主格位置掉落；
  - 战利品表带 `survives_explosion`。
- **活塞**：推不动（`PushReaction.BLOCK`）。

### 碰撞与选择形状

模型坐标（px）：脚印中心为原点，x 沿加油岛，正面朝 -z。这些盒子按六格切开，再随 `facing` 旋转。

| 部分 | 盒子 |
|---|---|
| 路缘 | x -16..16，y 0..3，z -8..8 |
| 底座 | x ±10.4，y 3..4.2，z ±4.6 |
| 两根立柱 | x ±7.8..±10，y 4.2..40.67，z ±4.2 |
| 机身（检修门、枪座区、绿带、显示头） | x ±7.9，y 4.2..29.4，z ±4.12 |
| 枪座框和挂着的枪（两面） | x ±5.4，y 10.45..20.15，z ±5.3 |
| 灯箱 | x ±4.6，y 38.15..40.65，z ±2.2 |
| 顶棚 | x ±11.6，y 40.6..44.2，z ±6 |

油管没有碰撞。

## 拔枪与挂回（V1 交互）

- **拔枪**：主手空着，右键某一面的枪座区（模型 y 9.5..21.5、离中线 3 px 以外），就拿起对准的那把枪。
  - 主手里出现汽油枪或柴油枪；
  - 枪座上那把枪和它挂着的油管不再显示；
  - 渲染器画一根从出管口连到手上的软管。
- **挂回**：主手拿着这台加油机的油枪，右键这台加油机的任何一格，油枪回到它原来的枪座。
- **自动回枪**：出现下面任何一种情况，油枪回到枪座，手里和背包里的那把油枪消失：
  - 换了主手物品格，或把油枪移到别的格子、副手、光标、容器里；
  - 扔掉油枪，或油枪以任何方式变成掉落物（掉落物实体会立刻消失）；
  - 死亡、下线、换维度、切到旁观模式；
  - 手离出管口超过 5.0 格：拉断阀脱开，在手的位置播放脱开声。
- **油枪物品的绑定**：
  - 记着加油机位置、维度、枪位和一个随机会话号；
  - 加油机方块实体每 tick 检查每把拿出去的枪：拿着它的玩家是否在线、活着、在同一维度、主手拿的正是这把枪（会话号一致）、距离没超；
  - 油枪物品自己每 tick 也检查：只要不在主手，或加油机不认这个会话号，就自己消失。所以旧的、复制出来的油枪都留不住。
  - 同一把枪同一时间只能一个人拿。
- **重新进入世界**：拿着枪的玩家不在线（例如存档后重进），加油机会把枪收回。
- **准星提示**（画在枪套上）：
  - 空手对着挂着的枪："拿起汽油枪"或"拿起柴油枪"；
  - 拿着这台的油枪对着加油机："挂回油枪"。
- **音效**：`fuel_nozzle_take`（拿起）、`fuel_nozzle_hang`（挂回；自动回枪时音量小一些）、`fuel_nozzle_breakaway`（拉断阀脱开）。
  - 字幕分别是"油枪拿起""油枪挂回""油管拉断阀脱开"。
  - 暂时借用原版音频：铁甲穿戴、锁链、铁活板门（音调 1.2），以后换专属录音。

## 软管渲染

`client/FuelDispenserRenderer` 是方块实体渲染器，只画拿出去的枪的软管；加油机和挂着的枪都是烘焙模型。

- **起点**：那把枪的出管口，在顶棚下面（模型 x ±10.7，y 39.3，z ±4.6）。
- **终点**：手里那把油枪的尾部旋转接头。用原版画手持物品的同一套变换加上油枪物品模型自己的显示参数算出来（2026-10-04 用户实机发现第一版的估算点和枪对不上，改成这样）：
  - 第一人称：`ItemInHandRenderer` 的手部晃动和手臂偏移；手是用固定 70° 视野画的，所以把这个点挪到世界视野下屏幕上的同一位置；
  - 第三人称和别的玩家：`ItemInHandLayer` 挂在玩家模型的手臂上，包括身体朝向、走路摆臂、拿物品的手臂姿势、待机微晃和潜行。
  - 软管顺着接头的方向接出，再往下垂。
- **形状**：三次曲线：出管口一端向下，油枪一端沿接头方向。
  - 出管口的收管器在直线距离之外留 0.7 格余量，但总长不超过 4.5 格；离得越远越直，到 4.5 格绷直。
  - 低于路缘顶或玩家脚下的部分贴在那个高度，不穿进地面。
- **网格**：8 边形截面，28 段，半径 0.42 px（和挂着的油管一样）；光照在两端之间插值。
- **贴图**：用加油机图集里预留的一块橡胶色像素（`HOSE_UV`），同样带 LabPBR 的 `_s` / `_n`，所以光影下和挂着的油管一样。生成器会检查渲染器里的这行常量和图集一致。
- **渲染范围**：有枪拿出去时，方块实体的渲染范围放大到 4.5 格外，离屏时也画。

## 模型

- **生成器**：`tools/build-fuel-dispenser-v1.mjs`（另有 `--check`、`--preview DIR`）。
- **尺寸**（px）：
  - 路缘 32 × 16 × 3；
  - 机身宽 20（立柱外侧）；顶棚 23.2 × 12，顶面在 44.2（离地 2.76 m）；
  - 显示屏中心离地约 1.6 m。
- **机身部件**：
  - 带钢包边的路缘；黑色底座；两根浅灰立柱；
  - 黑色检修柜，配两扇浅灰门，门上有百叶通风口和锁；
  - 枪座区，每面两个斜凹槽（背壁上深下浅，不锈钢框，槽顶有接枪座）；
  - 褪色绿带；
  - 灰色显示头：一块未通电的灰绿液晶屏（带黑框），一个键盘（3 × 4 个不锈钢键，上面有读卡小屏）；
  - 顶棚下的灯箱：两面百叶，底面是灯罩；
  - 褪色红顶棚；
  - 四个出管口接头（六角螺母加旋转接头）。
- **每把枪的模型**：枪加挂着的油管。
  - 油枪：黑色握把，彩色前罩，扳机和 D 形护手环，弯钢枪嘴，尾部旋转接头。
  - 挂法：正面朝外，往里倾斜 18°，枪嘴插进槽顶的接枪座；扳机和护手环朝里，握把下端和接头露在槽外。
  - 油管：从出管口沿立柱外侧垂下，在路缘上方绕弯，接进枪尾。
- **手持油枪**：同一套油枪网格，在油枪自己的坐标里，枪嘴朝 -Z。
  - 物品模型：`fuel_dispenser/held_gasoline`、`held_diesel`；
  - 手上的显示参数（2026-10-04 用户实机反馈后，按原版手持物品的变换离线拟合）：第三人称 rotation `[65,0,0]`、translation `[0,1,0.5]`、scale 0.8，枪嘴朝前略向下，握把在拳头里；第一人称 rotation `[0,6,0]`、translation `[0.5,4.2,-1]`、scale 0.85，整把枪在右下角露全（第一版太大、太低，护手环被屏幕底边切掉一截）。
- **电源接口**：主格底面正中有一个标准接口（6 × 6 px 钢板、r 1.95 插座、触点）。
  - 嵌在路缘底层的方孔里，板面就在方块底面上；
  - 这是地下供电设备的例外，见 [Power Cable V2](power_cable_v2.md)；
  - V1 不用电，所以没有声明 `hasPowerPort`。
- **PBR**：一张 2048 图集（14.5 texel/px），加 `_s` / `_n`。
  - 底色只有低频纹理：立柱和门的旧化瓷漆、顶棚顶面的日晒褪色、混凝土的斑驳；
  - 没有印刷文字、标志或贴纸。
- **三角面数**：机身（含路缘）2388；每把枪连油管 952；手持油枪 424。同一模型内共面重叠为 0。

## 还没做 / 已知问题

- 没有燃料、没有电，加油机不出油；油枪只能拿起和挂回。
- 软管没有碰撞，会穿过加油机自己（比如拿着正面的枪走到背面）。
- 软管末端按原版变换算，没有计入两样：切换物品时的抬起动画、奔跑等改变视野的效果。这两种情况下第一人称的末端可能短暂偏一点。
- 音效暂时用原版音频。
- 还没做：加油岛的其它部件（端头、防撞柱）、地下储罐、加油机下面的 UDC 底槽、输油管接口。
