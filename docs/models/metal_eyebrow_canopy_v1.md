# Metal Eyebrow Canopy V1（深灰金属雨篷）

状态（2026-10-07）：**已实现，用户实机 PASS**。
- `compileJava --offline` 通过；生成器 `--check` 通过。
- 用户进游戏看过后直接给了 PASS。没有逐项记录看过哪些地方（拉杆方向、端头收口、门框里的衔接），挖掘掉落也没有单独的检查记录。

## 为什么做

[AFL Fuel Stop A1](../worldgen/fuel_stop_a1_design_v1.md) 外墙 P0 的最后一项：店面上方 3 m 处的金属雨篷。出挑 1 m，带封檐板，连成一长条，穿过两个入口门框。

## 用户 2026-10-07 定下的方向

概念图对比了三个方案：
- A：平板悬挑；
- B：拉杆雨篷；
- C：格栅遮阳。

用户的选择：
- **选 B**。
- 颜色由我定，以后可以加变体。用深灰，和门框墙板同一种材质，让门框和雨篷读成一个系统。真实的 QuikTrip 用红色立缝雨篷，以后可以做成变体。

### 方块状态

| 属性 | 含义 |
|---|---|
| `facing` | 封檐板朝向，也就是朝外的方向 |
| `left` / `right` | 雨篷在 `facing` 的顺时针 / 逆时针一侧是否连续。从外面看墙时，顺时针一侧是左手边。连续的条件：那一侧是同朝向的雨篷，或者是带着这条雨篷的门框侧板。不连续的一端用封檐板收口 |
| `rod` | 斜拉杆，默认关 |

- **放置**：按下面的顺序决定 `facing`：
  1. 点在雨篷上，或者点在带着雨篷的侧板上：沿用它的朝向，往旁边接就能连成一条。
  2. 点在墙或玻璃的侧面上：背对那面墙。
  3. 点在地面或顶面上：朝向玩家。
- **拉杆**：空手潜行右键切换。潜行看着雨篷时有准星提示"加上 / 去掉拉杆"。一般每两三格开一根。
- 旋转只转 `facing`；镜像时交换 `left` / `right`。

### 穿过入口门框

门框外凸那一排两端的格子被门框侧板（[metal_wall_panel_v1.md](metal_wall_panel_v1.md)）占着，雨篷放不进去。为此侧板加了状态 `eyebrow`（`none` / `cw` / `ccw`）：
- 侧板内侧那一格是雨篷、并且雨篷顺着侧板方向朝外时，侧板自动把自己这一格剩下的 11 px 显示成同一条雨篷。`cw` / `ccw` 表示雨篷朝向是侧板 `facing` 的顺时针还是逆时针方向。
- 旁边的雨篷把这块侧板当成连续的邻居，不收口，所以门框里看起来是一条完整的雨篷，两端插进侧板。
- 门框里不加拉杆：门框背后是整面玻璃，没有地方拉。

## 几何（px，一格；朝外在 −Z，即 `facing=north`，墙在 z 16）

| 部件 | 尺寸 |
|---|---|
| 封檐板 | z 0..0.8（5 cm），y 0..3.5（22 cm）。底边比雨篷板低 0.5 px，形成滴水边 |
| 雨篷板 | y 0.5..2.1（10 cm），z 0.8..16，抵到墙。底面是门框墙板的条板，缝平行于墙，所以雨篷底面和门框吊顶是同一种吊顶 |
| 端头收口 | 0.8 px 宽，和封檐板一样高，从封檐板一直到墙 |
| 拉杆 | 0.7 px 见方（约 4 cm）的钢杆。下端在封檐板后面的小支座里（z 1.2，y 3.4）；按 45° 升到墙面（z 16，y 18.2，约雨篷底以上 1.14 m，即 A1 的 4.14 m，落在玻璃顶上方的砖带里）；墙上有一块 2 × 2 px 的钢板 |

整格放在 3 m 那一层，雨篷底就是 3.0 m。拉杆和墙板伸到上面一格里，上面那格应该是空气。

## 材质

- **生成器**：`tools/build-metal-eyebrow-canopy-v1.mjs`，加 `--check` 校验输出。
  - 原版 JSON 元素模型，能用平滑光照；拉杆用原版的 45° 元素旋转。
  - 生成器就是可编辑源，不需要 Blockbench 源。
  - 侧板的 blockstate（含雨篷部分）由 `tools/build-metal-wall-panel-v1.mjs` 生成。
- **贴图**：`textures/block/facade_eyebrow/`，每张 240 px，都带 `_s` / `_n`。

  | 贴图 | 颜色 | 光滑度 | F0 | 说明 |
  |---|---|---|---|---|
  | `eyebrow_coat` | [60,62,65] | 96 | 16 | 和门框墙板相同；只有 ≤ 1.5% 的淡斑驳，法线是平的 |
  | `eyebrow_steel` | [42,44,47] | 120 | 20 | 涂装钢 |

  - 底面直接用 `facade_metal_panel/metal_wall_panel`。
- **运行时文件**：
  - `models/block/facade_eyebrow/`：
    - `canopy`：两端都连续；
    - `canopy_cap_w` / `canopy_cap_e`：一端收口；
    - `canopy_cap_both`：两端都收口；
    - `canopy_rod`；
    - `jamb_canopy_w` / `jamb_canopy_e`：侧板格子里的雨篷部分，侧板在雨篷的西侧或东侧。
  - `blockstates/metal_eyebrow_canopy.json`：multipart。
  - `models/item/metal_eyebrow_canopy.json`：两端收口，不带拉杆。

## 在 A1 里怎么用

- 店面：3 m 那一层，外凸一排，从门框外侧的壁柱前面一直放到另一个门框。每 2–3 格开一根拉杆，拉杆尽量对准玻璃竖梃。
- 门框里：在两块侧板之间放雨篷，侧板会自动接上。
- 东西两面的转角玻璃上方：也用同一个方块，端头自动收口。
- 后门小雨篷：设计稿是 2.5 m 高、出挑 1 m，也可以用这个方块。

## 已知问题 / 以后

- 只有直段，没有转角件。东西面和正面的雨篷在转角处不相交，A1 里正面转角是门框，碰不到。
- 只有深灰一种颜色。以后可以加褪色红立缝的变体。
- 拉杆只能每格一根、在格子正中。
