# Fluid Pipe V2（流体管道：钢框 + 钢化玻璃）

状态（2026-10-04）：**已实现**，`compileJava --offline` PASS（包括 `src/dev`）。

用户实机看过这一版（方截面），材质很满意（"这个材质我觉得非常不错"），但嫌它太方。同日试了圆截面版：16 边形玻璃管加四根钢拉杆，管内液体画成 16 边形柱。用户实机看后要求撤销：流动的液体贴图绕着多边形柱显得很奇怪，方截面版的液体显示没问题。所以这里保持方截面：角条外角倒角，所谓"圆角方形"。

圆版的代码已全部恢复回来，包括：
- 生成器；
- `FluidPipeBlock` 的尺寸；
- 零件名；
- 液体渲染，删掉了 `FluidRenderHelper.renderPrism`。

玻璃改用冷柜配方、钢件压暗之后，用户实机 **PASS**（2026-10-04）。方截面版的连接规则、潜行切换和提示、管卡没有单独的检查记录，GameTest 按规则没有运行。

## 是什么

`apocalypse_firstlight:fluid_pipe`（流体管道）的外观和连接规则重做，用户 2026-10-04 定下：
- 保留 V1 的做法：钢管的侧面是钢化玻璃，能看到里面流的是什么液体；
- 管子加粗：6 px → 8 px；
- 连接规则复用电缆 V2；
- 箍带每 3 格一道，旁边有墙时换成管卡；
- 钢框深灰色；
- 弯头、三通这些管件做成钢件，也带玻璃。

注册 ID、物品、挖掘（`minecraft:mineable/pickaxe` + `minecraft:needs_diamond_tool`）、掉落、重量都没变。管道之间的液体传输（`fluid/FluidPipeTransfer`）、流动时管内液体的显示（`fluid/FluidPipeVisualManager`、`client/FluidPipeRenderer`）和发光液体的亮度（`fluid/FluidLighting`）沿用原来的逻辑。只改了两处：
- 哪两格算连通：`FluidPipeBlock.canPipeEdgeConnect`；
- 液体的绘制范围。

## 外形

- **直管**：截面 8 px，四个角是近黑的深灰钢条（1.3 px，外角倒角 0.3 px），四个侧面嵌钢化玻璃（离轴线 3.6..3.85 px），透过玻璃看到里面的液体。直管连续，格与格之间没有接缝。
- **箍带**：直管上每 3 格一道（沿管子方向的世界坐标能被 3 整除的那一格），一圈钢箍（±4.6 px，厚 1.8 px），顶上一个夹紧螺栓。
- **管卡**：这一格旁边有实心面（`isFaceSturdy`）时，箍带换成镀锌管卡：一圈箍、一条支脚伸到那个面、底板加两颗螺丝。和电缆一样，优先地面，其次四面墙（北、南、西、东），最后天花板。
- **管件**：不是直通的格都是一个钢方框（±4.6 px，12 条边各 1.2 px），包括弯头、三通、四通，以及一个方向都没连的单独一格。
  - 接管的开口：一圈螺栓法兰（±5.4 px，厚 0.8 px，四颗六角螺母），再接一小段直管到方块边界。
  - 没接管的面：嵌玻璃，管件里的液体也能看到。
- **末端**：只连一个方向时，管子到中心附近结束，用一对法兰加盲板封口，四颗螺母。
- **接口端**：连向储罐、机器的那一端，在方块边界上有一圈接口法兰（7.2..8 px，螺母朝管子一侧）。

## 连接规则（同电缆 V2）

- **流体接口总是接上**：
  - 储罐：没被别的储罐挡住的顶面和底面；
  - 热能发电机：进液面和出液面；
  - 化学反应釜：进料面和废液面。
- **放下一根新管时**，依次按这三条连：
  1. 连放置时点的那根管；
  2. 连它笔直接续的线头：孤零零一根的管，或只有一个连接、并且这个连接朝远离新管方向的管；
  3. 前两条都没连上管时，周围只有一个连接的线头全部接上（用于拐弯、闭合一圈）。

  已经有两个及以上连接的管不会被自动连上，所以并排的两路管保持分开。
- **之后不会自己变**：两根相邻管之间的那一面，两边永远一致。
- **手动切换**：空手潜行右键管道，断开或接上一面，只对管和管之间有效。
  - 点在臂上：切换那个方向；点在中段或管件上：切换点的那个面。
  - 准星提示"断开这一侧"/"接上这一侧"（`hint.apocalypse_firstlight.fluid_pipe.cut` / `.join`）。
  - `block/PowerCableToggleEvents` 让潜行右键对管道也生效。
- **液体只走连着的边**：`canPipeEdgeConnect` 判断两格是否连通。
  - 管和管之间：看方块状态里的那一面；
  - 管和接口之间：有接口就通。

  V1 那套"同一轴向才连"的判断和 `show_core` 状态已删除。老存档读档时会丢掉 `show_core`，六个方向的连接保持原样。
- **自动摆放**：`FluidPipeBlock.withStructuralConnections`（GameTest 用）现在按"在空中放下"的规则算连接。
- **形状**：直管 ±4 px，管件 ±4.6 px，加上每个连接方向的臂。

## 流体接口规格（2026-10-04 起，以后所有流体设备照此做）

用户 2026-10-04 定下：流体接口和电缆的电源接口一样，做成通用标准，以后所有需要流体的设备都复用。第一个按这个规格做的是地下油罐，接口在罐顶正中，见 [underground_fuel_tank_v1.md](underground_fuel_tank_v1.md)。第二个是取液泵（2026-10-05）：出口在岸上那格的顶面正中，由圆变方的变径接到接口板，泵往管道里推，见 [intake_pump_v1.md](intake_pump_v1.md)。2026-10-05 又加了：地下油罐罐尾的卸油口、潜油泵的出油口（侧面）、卸油口盖的底面、加油机底槽两头的汽油口和柴油口，见 [fuel_station_sump_v1.md](fuel_station_sump_v1.md)。2026-10-09：柴油发电机组的进油口，在散热端（第三列下格 `c2r0` 的端面，`FACING` 顺时针那一面，出风百叶下面）的镀锌接线盒上，只进不出（这一格的方块实体 `DieselGeneratorPortBlockEntity` 把管道转给主格的油箱），见 [diesel_standby_generator_v1.md](../machines/diesel_standby_generator_v1.md)。

- **位置**：方块某个面的正中心，接口板的对接面落在方块边界上。设备外形没到边界时，做一个凸台把接口伸到边界。
- **设备侧外形**（`tools/afl-fluid-port.mjs` 的 `addFluidPort`，尺寸只在那里定义）：
  - 方钢接口板 ±5.5 px，深 0.6 px；
  - 中间是 ±4.0 的流体口，和管道内孔一样大，后面是一个深色喉管；
  - 四个角 (±4.65, ±4.65) 各一颗螺柱，伸出板面 0.32 px，正好对上管道接口法兰的四颗螺母；接上管道时螺柱藏在法兰里。
- **管道侧**：管道 V2 的接口法兰（±5.4，从 7.2 px 到方块边界，螺母朝管子一侧），见上面"外形"。
- **代码**：
  - 设备方块实现 `fluid/AflFluidPortBlock`，用 `hasFluidPort(state, face)` 返回哪些面是流体口；
  - 那一格的方块实体在这个面上提供 `FLUID_HANDLER` 能力；
  - `FluidPipeBlock.isFluidPort` 先问这个接口，管道才会连上并往里灌。
- **还没换成新标准的老设备**：热能发电机、化学反应釜，仍由 `FluidPipeBlock` 直接判断，外观也还是原来的。以后重做它们的模型时再换。立式储罐 2026-10-05 已换成新标准（V2：每格顶面进液、底面出液，见 [fluid_tank_v2.md](fluid_tank_v2.md)）。

## 已知问题 / 以后

- 只连一个方向的末端格，如果有液体流过，渲染器还是会画中心的液体方块，会从盲板外面露出一点。死端一般没有流动。
- 在另一条管没接东西的开口端旁边起一条新管，会被当成拐弯接上（和电缆一样），潜行右键断开即可。

## 结构旋转（2026-10-10）

油管（`FluidPipeBlock`） 继承原版 `PipeBlock`，原版没有 `rotate` / `mirror`：结构转 90 / 180 / 270° 放下后，六个面的连接还指着原来的方向，方块更新再按同样错的邻居重算，沿转后方向的整段线全断开。A1 第一次四向放置测试里约 70% 的电缆和油管都这样。现在 `rotate` / `mirror` 交给 `block/PipeSides`，按旋转、镜像转换东南西北四个面的连接（上下不变）。GameTest `dev/GasStation01GameTests` 四向 PASS，放下后状态变化 0，见 [gas_station_01_asset_v1.md](../worldgen/gas_station_01_asset_v1.md)。
