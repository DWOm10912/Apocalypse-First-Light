# Material Meshes V1（材料 3D Mesh 物品）

状态（2026-09-30）：**已实现**。物品栏里显示 2D 图标，手持、第一人称、掉落物和物品展示框显示 3D Mesh。用户实机看过 3D 版本的物品栏、手持和掉落物；改成 2D 物品栏图标之后的效果、展示框和光影都还没有在游戏里看过。

## 文件

生成器：`tools/build-material-meshes-v1.mjs`（`--check` 校验所有输出是否最新）。每个物品一套：

| 类型 | 路径 |
|---|---|
| 可编辑源 | `src/main/blockbench/<id>.bbmodel`、`src/main/blockbench/textures/<id>_mesh{,_s,_n}.png` |
| geo / Mesh | `geo/<id>.geo.json`、`meshes/<id>.aflmesh.json` |
| 贴图 | `textures/item/<id>_mesh{,_s,_n}.png`（256，LabPBR） |
| 物品栏图标 | `textures/item/<id>.png`：16×16，由生成器从 Mesh 画出（见下文"物品栏图标"） |
| 物品模型 | `models/item/<id>.json`：`forge:separate_transforms`。`perspectives.gui` 是 `item/generated` 加 2D 图标；`base` 是 `builtin/entity` 加世界视角的 `display`（第三人称、第一人称、掉落物、展示框），交给 Mesh 渲染器。外层 `gui_light: front`，2D 图标用平光。粒子用 2D 图标 |

- 单 bone，名字与 ID 相同，pivot [0,0,0]。Mesh 在 X/Z 上居中，底面在 y = 0。
- 渲染：`AflStaticMeshItemClient` 把六个物品绑定到 `AflStaticMeshItemRenderer`，和弹药同一条路。竖直偏移 = 0.5 − 高度 / 32，让 Mesh 在物品模型里居中。
- 改 3D 时删掉的旧手绘图标已不再使用：现在的 `textures/item/<id>.png` 由 Mesh 生成。`cemented_carbide_insert.png` 已删除。
- 管状零件（钨丝、螺纹钢）由 `sweepTube` 生成：沿路径扫出的多边形管，整根一条 UV 带。钢废料的板片用通用展开，放在贴图上方 232×232；螺纹钢的 UV 带放在下方。

- **物品栏**：只显示 2D 图标（见下节），不再渲染 Mesh。
- **世界视角**（手持、第一人称、掉落物、展示框）：最长边统一按 12 px 换算，每个材料拿在手里一样大。

## 物品栏图标

材料页全部是 2D 像素图标，和原版、其余材料统一（原版三叉戟、望远镜也是物品栏 2D、手里 3D）。图标从同一个 Mesh 画出，保证拿在手里和放进背包是同一个东西：

- **视角**：默认 [30,225,0]，即原版方块物品的角度，不带侧倾；钢坯、铅砖（凹口朝前）、电解镍、硬质合金坯件都用它。
  - 钨丝用接近正面的 [15,180,0]，否则五圈线圈在 16×16 里分辨不出来。
  - 钢废料用更俯视的 [45,225,0]，否则扁平的一堆只剩一条窄带。
- **缩放**：投影后的包围盒缩放到 14/16 格并居中（与 Mesh 在物品栏里的位置相同，按高度的一半居中）。
- **画法**：每个面一种平涂色调（顶面最亮，画面左侧面比右侧面亮，同原版方块图标）；每个像素取覆盖最多的面，不做抗锯齿；一个零件压在另一个零件前面的地方，后面那件的边缘像素压暗一档；最后是原版式描边（下、右轮廓更暗）。
- **覆盖阈值**：一个像素至少被覆盖一半才画，钨丝放宽到 0.3，否则细线会断。
- **图标专用颜色**：钢废料各块之间加大色差（裸钢更亮、氧化皮更暗、锈更暖），螺纹钢的肋并进锈色，避免出现单像素噪点。

## 需要实机验证

1. 物品栏 2D 图标：清晰度、亮度（平光）是否和其它材料一致；钨丝线圈和钢废料能否一眼认出。拿起、放下时物品栏是 2D、手上是 3D。
2. 手持和第一人称：位置和大小（按原版方块物品的变换估的，最可能需要调）。
3. 掉落物是否浮在地面上方，展示框里的朝向。
4. 光影（LabPBR）：钢坯氧化皮与断面的对比、镍和硬质合金是否过亮；钢废料的裸钢、氧化皮和薄锈三种状态是否分得开，又不至于像几种不同材料。
