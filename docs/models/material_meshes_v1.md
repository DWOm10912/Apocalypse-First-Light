# Material Meshes V1（材料 3D Mesh 物品）

状态（2026-09-30）：**已实现，未实机验证**。`compileJava --offline` 一次 PASS。GUI 构图只用离线预览（按物品模型的 `display.gui` 做正交投影）看过；手持、第一人称、掉落物、物品展示框和光影效果都没有在游戏里看过。

## 范围

| Registry ID | 中文 | 形状 |
|---|---|---|
| `steel_billet` | 钢坯 | 连铸方坯：13 × 3.6 × 3.6 px，圆角方截面（R 0.55），两端是气割断面 |
| `lead_brick` | 铅砖 | 1 : 2 : 4 互锁屏蔽砖：12 × 6 × 3 px，一端 V 形凸出、另一端同角度的 V 形凹口，倒角 0.25 |
| `electrolytic_nickel` | 电解镍 | 一块剪切的阴极方片：6 × 6 × 1.8 px，小圆角，倒角 0.2 |
| `tungsten_filament` | 钨丝 | 5 圈螺旋线圈，挂在两根支架上；整根是一条连续的线（6 边管，直径 0.84 px） |
| `cemented_carbide_blank` | 硬质合金坯件 | 烧结圆棒坯：12 × Ø3.6 px，两端倒角，端面有两个冷却孔 |

`cemented_carbide_blank` 原来叫硬质合金刀片（`cemented_carbide_insert`），本轮改名，旧 ID 已删除。锂辉石精矿仍是 16×16 的 2D 图标。

物品按图标大小建模（最长边 9–13 px），不是真实尺寸，所以手里拿着和其它物品一样大。钨丝故意做粗，否则在物品栏里看不见。

## 文件

生成器：`tools/build-material-meshes-v1.mjs`（`--check` 校验所有输出是否最新）。每个物品一套：

| 类型 | 路径 |
|---|---|
| 可编辑源 | `src/main/blockbench/<id>.bbmodel`、`src/main/blockbench/textures/<id>_mesh{,_s,_n}.png` |
| geo / Mesh | `geo/<id>.geo.json`、`meshes/<id>.aflmesh.json` |
| 贴图 | `textures/item/<id>_mesh{,_s,_n}.png`（256，LabPBR） |
| 物品模型 | `models/item/<id>.json`：`builtin/entity`，粒子用 `item/<id>_mesh`，`display` 由生成器算出 |

- 单 bone，名字与 ID 相同，pivot [0,0,0]。Mesh 在 X/Z 上居中，底面在 y = 0。
- 渲染：`AflStaticMeshItemClient` 把五个物品绑定到 `AflStaticMeshItemRenderer`，和弹药同一条路。竖直偏移 = 0.5 − 高度 / 32，让 Mesh 在物品模型里居中。
- 原来的 2D 图标 `textures/item/{steel_billet,lead_brick,electrolytic_nickel,tungsten_filament,cemented_carbide_insert}.png` 已删除。

| ID | 三角面 | 贴图密度（texel/px） | 竖直偏移 |
|---|---:|---:|---:|
| `steel_billet` | 124 | 12.75 | 0.3875 |
| `lead_brick` | 44 | 11.25 | 0.40625 |
| `electrolytic_nickel` | 92 | 22 | 0.44375 |
| `tungsten_filament` | 804 | —（整根线一条 UV 带，颜色均匀） | 0.263462 |
| `cemented_carbide_blank` | 292 | 10.75 | 0.388885 |

五个 Mesh 都没有共面重叠，也没有凹四边形。

## 材质

| 物品 | 材质 | Base Color | 光滑度 / F0（LabPBR `_s` R / G） |
|---|---|---|---|
| 钢坯 | 氧化铁皮（外表面） | [60,63,69] | 72 / 30（非金属，哑光） |
| 钢坯 | 断面和端部倒角 | [146,144,140] | 128 / 230（预设金属：铁） |
| 铅砖 | 铅 | [112,115,121]，中性灰，不再用旧铅块的紫色 | 58 / 235（预设金属：铅） |
| 电解镍 | 镍 | [160,161,158] | 104 / 255 |
| 钨丝 | 钨丝 / 钼支架 | [178,179,184] / [150,150,147] | 150 / 255、128 / 255 |
| 硬质合金坯件 | WC-Co | [104,106,112] | 84 / 255 |

- 金属只用在确实是裸金属的地方，光滑度都偏低，避免在光影下大面积反光发白。钢坯大面是氧化皮，按非金属处理。
- `_n` 是平直法线，B 通道为 AO（冷却孔内壁更暗）。
- 没有涂装、文字、锈迹或噪点。

## 显示变换

- **GUI**：五个物品统一用原版方块物品的视角 [30,225,0]，不带侧倾，长条类物品在格子里朝同一个斜向。投影后的包围盒缩放到 14/16 格并居中。铅砖的凹口朝向观察者。
- **其它视角**：最长边统一按 12 px 换算，每个材料拿在手里一样大。

| 视角 | 旋转 | 位移 | 缩放 |
|---|---|---|---|
| 第三人称右手 | [75,45,0] | [0,2.5,0] | 0.42 × k |
| 第一人称右手 | [0,45,0] | [0,1,0] | 0.5 × k |
| 掉落物 | [0,0,0] | [0,3,0] | 0.4 × k |
| 物品展示框 | [0,0,0] | [0,0,0] | 0.7 × k |

其中 k = 12 / 最长边。左手沿用右手（原版会镜像）。这些值都没有在游戏里看过，是最需要实机调整的部分。

## 需要实机验证

1. 物品栏：大小、角度、光照；钨丝线圈是否清楚，铅砖的 V 口是否看得出来。
2. 手持和第一人称：位置和大小（按原版方块物品的变换估的，最可能需要调）。
3. 掉落物是否浮在地面上方，展示框里的朝向。
4. 光影（LabPBR）：钢坯氧化皮与断面的对比、镍和硬质合金是否过亮。
