# Intake Pump V1（取液泵）

状态（2026-10-05）：**已实现，用户实机 PASS**。用户的截图里能看到：泵放在岸边，绿灯亮着，水经过竖管、横管被推进立式储罐。截图没覆盖到的还没单独确认，包括：拆除掉落、无限水、燃油、Jade 和提示文字、声音。同一次实机还发现管内液体的流动方向画反了，已在管道渲染里修好（见 [fluid_pipe_v2.md](fluid_pipe_v2.md)"流动方向"），修好后还没有实机验证。

## 是什么

岸边的取液泵：把液体源方块抽进流体管道 V2。它是淘汰原版桶的第一步——以后液体靠泵、管道和容器来搬，不再用桶。

用户 2026-10-05 定下：
- **2 格长**：后格在岸上，装电机、起动箱，两个接口都在这一格；前格伸到液面上方。这样电缆不会接在水里。
- **只抽正下方**：只抽前格正下方那一格的液体。
- **开关**：做成可以直接点的开关，不用红石。
- **外观**：深绿漆的工业离心泵。
- **电源接口**：放在后格右面。
- **放置**：前格下面没有液体也允许放，指示灯亮黄。
- **不做岩浆**：岩浆和以后的高温液体用另外的泵和管道。

| 注册 ID | 名称 |
|---|---|
| `apocalypse_firstlight:intake_pump` | 取液泵 / Intake Pump |

代码：
- `block/IntakePumpBlock`
- `blockentity/IntakePumpBlockEntity`（方块实体类型 `intake_pump`）
- `item/IntakePumpItem`

物品放在创造标签页 `industry` 里，储液罐之后，堆叠 1。

## 方块和放置

- **方块状态**：
  - `facing`：从后格指向前格，也就是指向液面；
  - `part`：`bank` 是后格，`front` 是前格；
  - `on`：开关，只有后格用；
  - `lamp`：指示灯，`off` / `idle` / `run`，只有后格用。
- **后格**：
  - 是主格，持有方块实体，管掉落；
  - 画整台泵，包括前格的部分和插进下方液体的吸水管。
- **前格**：
  - 不渲染（`RenderShape.INVISIBLE`），模型是只有粒子贴图的 `intake_pump/cell`；
  - 只有碰撞箱。
- **放置**：站在岸边面朝液面，对准岸上要放泵的那格点。点到的位置是后格，前格朝玩家视线的水平方向伸出一格。
  - 两格都必须可替换、没有液体、没有实体挡着。
  - 前格下面没有液体也能放，指示灯显示黄色。
- **拆除**：拆任意一格，两格一起消失，只掉一个物品。
  - 拆后格时走掉落表。
  - 拆前格时，生存模式玩家用对的工具才掉。
  - 缓冲里的液体和电量都会丢失。
- **完整性检查**：另一格不在了，剩下那格自己消失（形状更新时安排一次 tick 检查）。
- **挖掘**：工业机器，所以：
  - `minecraft:mineable/pickaxe` + `minecraft:needs_diamond_tool`，`requiresCorrectToolForDrops()`；
  - 硬度 / 抗性 5.0 / 6.0，`SoundType.METAL`；
  - 活塞推不动（`PushReaction.BLOCK`）。
- **碰撞箱**：用盒子近似（`IntakePumpBlock.BOXES`，模型坐标）：
  - 底座（两格）；
  - 泵壳加电机；
  - 起动箱加电源接口；
  - 出口颈管、出口接口；
  - 吸水管；
  - 弯头和下管，到前格底面为止。

  插进下方液体格的那段吸水管没有碰撞箱。
- **重量**：`item_mass` 45 kg（估计），`carry/oversized`。

## 接口（站在岸上、面朝液面看）

| 格 | 面 | 是什么 |
|---|---|---|
| 后格 | 顶面正中 | **流体出口**：标准流体接口（[fluid_pipe_v2.md](fluid_pipe_v2.md) "流体接口规格"），`hasFluidPort(state, UP)` |
| 后格 | 右面正中（`FACING.getClockWise()`） | **电源接口**：标准电源接口（[power_cable_v2.md](power_cable_v2.md)），装在起动箱外侧，`hasPowerPort` |
| 后格 | 背面 | 电机风扇罩，没有接口 |
| 后格 | 左面、底面 | 没有接口 |
| 前格 | 底面 | 吸水管插进下方液体，**不是接口**，不能接管道 |
| 前格 | 其它面 | 没有接口 |

**为什么电源接口不放背面**：多格设备的电源接口原本约定放在背面底部某一格。但泵的背面是电机风扇罩，挡在那里不合适。后格右面同样在岸上，电缆碰不到水。用户 2026-10-05 同意放右面。

## 工作方式

数值在 `machine_balance/intake_pump.json`，读取见 `MachineBalanceManager.intakePump()`：

| 项 | 值 |
|---|---:|
| 抽液速度 `pump_mb_per_tick` | 5 mB/t（每秒 100 升） |
| 抽液时耗电 `work_fe_per_tick` | 8 FE/t，只在真正抽到液体的 tick 扣，待机不耗电 |
| 电量缓冲 `capacity_fe` | 2,000 FE |
| 最大输入 `max_receive_fe_per_tick` | 32 FE/t |
| 出口缓冲（代码常量 `BUFFER_MB`） | 250 mB |
| 水（和以后的岩浆）的液池 | 至少 3 × 3 × 1 格同种液体源（`fluid/PumpSourceRules.POOL_SIZE`），抽不完 |
| 其它液体用掉一格源方块（`PumpSourceRules.SOURCE_MB`） | 每抽 1,000 mB |
| 高温液体（超过 400 K，`fluid/FluidHeat`） | 普通泵：开着、有电时遇到会被烧毁（2026-10-05 起，原来是拒抽）；耐热取液泵照常抽，见 [heat_resistant_fluid_set_v1.md](heat_resistant_fluid_set_v1.md) |

每个服务端 tick，后格的方块实体做这些事：

1. **先往外送**：缓冲里有液体时，从顶面出口推进管道网络（`FluidPipeTransfer`，每 tick 最多 25 mB）。关着开关也会把剩下的推完。
2. **再抽**：同时满足下面几条才抽：
   - 开关开着；
   - 电量够这一 tick；
   - 前格正下方是**液体源**，流动的液体不算；
   - 普通泵：液体不超过 400 K（更热的液体，开着有电时直接烧毁这台泵）；
   - 水（和岩浆）要在够大的液池里，见第 3 条；
   - 缓冲装得下 5 mB：缓冲没满，并且是空的或装的是同一种液体。

   满足时，抽 5 mB 进缓冲，扣 8 FE。
3. **液池和用掉源方块**（用户 2026-10-05 定，为了游戏性；规则在 `fluid/PumpSourceRules`，以后的高温泵共用）：
   - **水、岩浆**：前格正下方那格必须在一个至少 **3 × 3 × 1** 的同种液体源方阵里，才抽；抽了**不会用掉**。
     - 只要求这格落在任意一个全是源的 3 × 3 方阵里，不要求它在正中。泵放在岸边，前格压着液池的第一排，也算。
     - 液池不够大就不抽，灯亮黄，Jade 显示"液池太小"。
     - 这条规则替代了之前跟原版无限水走的做法：四周两格水源、受游戏规则 `waterSourceConversion` 影响、小水坑会被抽干。
   - **其它液体**（汽油、柴油、工业废液、别的模组的液体）：不要求液池，任何一格源都能抽；同一格累计抽满 1,000 mB，就用掉这格源。
     - 液体方块变成空气；
     - 含液方块交出它的液体。
4. **缓冲不接收管道灌进来的液体**：出口对管道来说只能往外抽，所以泵不会被当成别的设备的出口目标。

能抽的液体：原版水（3 × 3 以上的水池）、汽油、柴油、工业废液，以及别的模组里不超过 400 K 的液体。岩浆的液池规则已经写好，但这台泵不抽岩浆，要等高温泵。

## 开关和指示灯

- **开关**：空手右键泵的任意一格，切换起动箱上的旋转隔离开关（`on`）。
  - 红色把手竖着是开，横着是关；
  - 播放原版拉杆声，音量较小、音调较低；
  - 手里拿着东西时右键不响应开关，这样可以照常在出口上接管道。
  - 不用红石。
- **指示灯**（`lamp`）：每 10 tick 更新一次，不会一闪一闪：
  - **绿**：这 10 tick 内抽到过液体；
  - **黄**：开着、有电，但抽不了，比如下方没有液体源、液池不够 3 × 3、液体太热、出口没接管或下游满了；
  - **灭**：关着，或者没电。

  亮着的灯：
  - 在 LabPBR 光影下是自发光（`_s` alpha 254）；
  - 在原版下是全亮（MTL 写了 `Ka 1 1 1`）。

  灯很小，不发方块光。
- **准星提示**（`client/WorldInteractionHint`）：空手对着泵，在把手位置显示"开启取液泵" / "关闭取液泵"。
- **声音**（2026-10-05，`tools/build-intake-pump-sounds-v1.mjs`，源录音是用户生成的五条 WAV，已做响度标准化，基准是工业电箱开门声）：
  - `intake_pump_switch`：拨开关，比基准低 3 LU，关的时候音调低一点；
  - `intake_pump_start`：灯变绿时播放，接触器"嗒"一声加电机启动；
  - `intake_pump_loop`：抽液期间循环，比基准低 11 LU；源录音高频嘶声重，做了 6 kHz 低通；客户端在灯变绿后等 26 tick，再用 12 tick 淡入（`IntakePumpBlockEntity.LOOP_FADE_IN`），接上启动音的尾巴；
  - `intake_pump_stop`：灯不再是绿色时播放（包括关开关），由循环音本身降速、淡出做成，后面叠一层降低了音量的水回落声；
  - 不做水流声（用户定）。没有实机验证。

## Jade

由 `compat/jade/IntakePumpJadeProvider` 提供。对着泵的任何一格，都显示：
- **状态**：运行中（绿）；已关闭（灰）；以下几种为橙色：
  - 无电力；
  - 下方没有液体源；
  - 液体温度过高：开泵会烧毁普通泵（普通泵关着、下面是高温液体时显示）；
  - 液池太小（至少 3×3 格同种液体源）；
  - 出口未接管道或已满。
- **取液**：前格正下方的液体源，没有时显示"无"。
- **电量条**：和其它机器一样。
- **出口缓冲**：液体、存量 / 容量和液体条，和立式储罐一样。

只有后格有方块实体，所以用 Jade 的射线回调，把对着前格的目标换成后格。Jade 设置里单独一个开关"AFL 取液泵"。

## 已知问题 / 以后
