## 2. 网格和贴图

| 项 | 炉身（cabin 拼块） | 炉膛（cabin 拼块，耐火砖 + 灰床） | 炉门（动画网格） |
|---|---|---|---|
| 三角形 | 15692（上限 16384） | 5484 | 9008 |
| 贴图 | 1024 × 1024 LabPBR | 512 × 512 LabPBR | 256 × 256 LabPBR |
| 密度 | 外表面约 283 texel / m（规则 240） | 约 257 texel / m | 约 301 texel / m |

- 炉膛单独成一个拼块，炉身的面数才放得下；炉身自己的内壁只在开门时看得到，UV 密度减半。
- 材质在 Blender 里程序化做，再烘焙：铸铁底色 + 轻微斑驳，凸边按"内侧 AO"磨亮磨滑，低处零星锈点，炉顶有加热色和锅推出来的光滑区，铸造颗粒进法线；镍件是金属；耐火砖带铁斑点和烟熏。
- 没有画上去的装饰，细节都来自形体（凸线、螺栓、炉盖、风门孔）。
- 贴图格式同 P9：`_s` R = 1 − 粗糙度、G = F0（铁 10，镍 255）；`_n` RG 是 DirectX 切线法线，B = AO。

## 3. 文件

- 脚本：`tools/stove/box_stove_v2/model.py`（建模和材质）、`build.py`（合并、展 UV、烘焙、合成贴图）、`render.py`（审图渲染）、`export.py`（导出游戏拼块，见第 4 节）。
- 门打开时伸进旁边那格 34 cm（V1 是 25 cm），高 0.24–0.58 m，那格这段要空着。
- 运行（后台 Blender，不碰正在开的 Blender）：
  - `blender -b --factory-startup --python tools/stove/box_stove_v2/build.py`
  - `blender -b --factory-startup --python tools/stove/box_stove_v2/render.py`
- 产出：`design/furniture/box_stove_v2/textures/`、`source/box_stove_v2.blend`、`renders/`（`box_stove_v2_review.png`、`box_stove_v2_firebox.png`、`v2_vs_v1.png` 等）。
- 渲染用的锅：`design/items/cooking_v1/preview/`（K0 生成器的预览输出）。

## 4. 进游戏（2026-10-26）

流程（改了模型就按顺序重跑）：

```
blender -b --factory-startup --python tools/stove/box_stove_v2/build.py     # 烘焙
blender -b --factory-startup --python tools/stove/box_stove_v2/export.py    # 导出拼块
node tools/build-box-stove-v1.mjs                                           # 拷进资源、做炉门动画网格
node tools/build-box-stove-v1.mjs --check
```

- **导出**（`export.py`）：三个物体按 cabin 拼块格式写到 `design/furniture/box_stove_v2/export/{body,firebox,door}.json`，每个角带 Weighted Normal 的法线，UV 落在各自的烘焙贴图里（左上原点）。四边形原样写，其余按三角形写（最后一个角重复）。同时打印灰床高度（y 0.21–0.22）。
- **生成器**（`tools/build-box-stove-v1.mjs`）：
  - 不再自己生成炉身和炉门；三块拷成 `cabin_mesh/stove/body.json`、`firebox.json`（新增）、`door_closed.json`（物品模型和选中框用）；
  - 贴图拷成 `textures/block/stove/box_stove_body*`（1024）、`box_stove_firebox*`（512），`_s` / `_n` 一起；
  - 炉门动画网格 `box_stove_door` 用 `door.json` 的多边形和烘焙贴图（`tools/furniture/furniture-mesh.mjs` 新增 `atlas` 选项：直接用一张烘焙贴图，不再拼材质格子），铰链轴 x 0.050、z 0.555，`open` 绕竖轴转 90°、10 tick，开向墙那边；
  - 劈柴 `load_1..3` 重摆在灰床上：两根并排（z 0.33、0.43），第三根架在上面（z 0.38），长约 40 cm；
  - 隔热钢板、石板、劈柴贴图都没变。V1 的 `soot` / `nickel` / `firebrick` / `ash` 贴图还照样生成，现在没有网格用。
- **Java**：
  - `BoxStove`：`TOP` 0.661（炉盖顶面），`SPOTS` 两个炉盖 (0.20, 0.38)、(0.80, 0.38)，`spotAt` 炉顶左半边对第 1 个、右半边对第 2 个（烟圈更高，点不到）；碰撞箱炉身 x 0.044..0.976、y 0..0.661、z 0.114..0.646，短节 x / z 0.424..0.576、y 0.661..1.0；`doorPoint` (0.03, 0.41, 0.38)；`cabinPieces` 加 `stove/firebox`；拆掉时炉顶东西从 y 0.7 掉出来；
  - `BoxStoveFire`：三团火焰跟着新劈柴；开门时灰床的光移到 (0.42, 0.226, 0.38)、半径 0.3，地上的光在门前 (-0.25, 0.38)；关门时风门六个孔的光在风门板前 x 0.034、环半径 0.034，偏 9°（风门半开，孔错开 18°）；火星从门口 x 0.05 落到炉台。
- **第一轮实机**（2026-10-26）：用户："基本上没问题"，只有单放时短节管顶是透的（单面管壁，背面剔除）。补了管内壁、管口、调风板和管底，炉身重新烘焙；离线开背面剔除从上面渲染确认。
- **面数**：炉门 9008（动画网格，Vextris 上限每个网格 16384）；炉身 15860、炉膛 5484 是区块拼块，这条路径本身没有上限，按 16384 定预算。
- **已知**：动画网格只支持平面着色，炉门上的小圆柱（门闩弹簧、风门旋钮、铰链）在游戏里是一个面一个面的，和渲染图比会有棱。
- 老宅的烟管不动，短节已经接到 y 1.0。老宅脚本不用重跑：方块没变，换资源后直接显示新炉子。
- Wiki 等实机通过再写。

### 实机要看的

1. 老宅客厅的炉子：外形、贴图、光影下和不开光影都看；和隔热钢板、烟管的接缝。
2. 开关门：门绕靠墙的铰链转出去，不穿墙、不穿炉身；关上时门贴在开口凸边上。
3. 开门看炉膛：耐火砖、灰床、劈柴（加 1、2、3 根）、火焰、灰床的光。
4. 关门点火：风门六个孔发光的位置。
5. 炉顶放两样东西：分别落在两个炉盖上，提示点、取放都对。
6. 选中框和碰撞：走近不卡、能站上去（点着会烫）。
