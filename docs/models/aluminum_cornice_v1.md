状态（2026-10-07）：**已实现，用户实机 PASS**（底部漏光修复、改成金属铝材质之后）。挖掘掉落没有单独的检查记录。
- `compileJava --offline` 通过；生成器 `--check` 通过。
- 外观只看过概念图（离线三维渲染）。
- 2026-10-07 用户实机（开、关光影截图）：外观、灯带切换正常。悬空放着从正下方看时，檐口底部有几条断续的白缝，能透过去看到天空。
  - 原因：阴影缝没有底面，墙体朝外的那一面也被省掉了，从下面能看穿整格。
  - 已修：阴影缝补了底面；墙体朝外那一面补成深色面（转角两面都补）。
  - 补完后检查过：同一平面上的面互不重叠。
  - 只改了模型 JSON，用户复看后 PASS。外转角、挖掘掉落没有单独的检查记录。

## 为什么做

[AFL Fuel Stop A1](../worldgen/fuel_stop_a1_design_v1.md) 的外墙 P0 资产：女儿墙顶的金属檐口。

## 用户 2026-10-07 定下的方向

概念图对比了三个方案：
- A：平板拉丝铝；
- B：阶梯式；
- C：只做薄压顶。

用户的选择：
- **选 A**。
- **檐口占满墙顶一整格（5–6 m）**。原设计是 5.4–6.0 m 的 0.6 m 铝带，墙顶那一格要半截砖、半截铝，方块不好做。参考 QuikTrip G3：砌体顶 16'（4.9 m）、檐口顶 20'（6.1 m），檐口本来就约 1.2 m 高，改成 1 m 更接近参考。
- **红色发光带现在就做进檐口**，嵌在檐口底边，QuikTrip 就是这么做的。

## 方块

| 项 | 内容 |
|---|---|
| ID | `apocalypse_firstlight:aluminum_cornice`（铝檐口 / Aluminum Cornice），堆叠 64 |
| 代码 | `block/AluminumCorniceBlock`；注册在 `AflBlocks` / `AflItems` |
| 创造栏 | 建筑方块，排在磨面砌块后面 |
| 属性 | 复制铁块，硬度 / 抗性 3.0 / 6.0，金属音效。整格碰撞，外挑的 1–1.6 px 不算碰撞 |
| 挖掘 | AGENTS 规定铝制商业结构是钻石级：`minecraft:mineable/pickaxe` + `minecraft:needs_diamond_tool`，`requiresCorrectToolForDrops()`。掉落表掉自身，带 `survives_explosion`。没有实机检查 |
| 噪音 | `noise_metal_blocks` |
| 重量 | `item_mass` 1.2 kg（估计，和顶棚边檐同一档） |

### 方块状态

| 属性 | 含义 |
|---|---|
| `facing` | 朝外的一面。放置时朝向玩家，也就是站在墙外面放 |
| `shape` | `straight` / `outer_left` / `outer_right`，规则和顶棚边檐、勒脚压顶一样：身后那格是铝檐口、并且转向了自己的左侧或右侧时，是外转角，铝面板、阴影缝和压顶都绕过转角。复用 `FuelCanopyFasciaBlock.Shape` |
| `band` | 红色灯带，默认关 |

- **切换灯带**：空手潜行右键；潜行看着檐口时有准星提示"加上 / 去掉红色灯带"。
- 只有外转角，没有内转角。
- 旋转只转 `facing`；镜像时交换外转角的左右。

## 几何（px，一格；朝外在 −Z，即 `facing=north`）

| 部件 | 尺寸 |
|---|---|
| 铝面板 | y 0.5..15.5，比墙面凸出 1 px（约 6 cm） |
| 阴影缝 | y 0..0.5，深色，凸出 0.25 px，在面板底下形成一条暗线 |
| 压顶 | y 15.5..16，盖住整个墙顶，朝外再多凸出 0.6 px（共 1.6 px）。压顶上面不设 cullface |
| 屋面一侧 | 朝屋面那一面是防水卷材翻上来的浅灰色。站在屋顶上看，女儿墙内侧是真实做法 |
| 两端 | 铝色，旁边是同一种方块时被剔除 |
| 底面 | 坐在砖上，被剔除 |
| 灯带（`band=true`） | y 0.6..2.2（约 10 cm），贴在铝面板外面再凸出 0.05 px；外转角时也绕过转角 |

## 材质

- **生成器**：`tools/build-aluminum-cornice-v1.mjs`，`--check` 校验输出。原版 JSON 元素模型，能用平滑光照，靠 blockstate 旋转到四个朝向。不需要 Blockbench 源，生成器就是可编辑源。
- **贴图**：四张，每张 240 px，都带 `_s` / `_n`：
  - `textures/block/facade_cornice/aluminum_cornice`
  - `cornice_membrane`
  - `cornice_reveal`
  - `cornice_band`

  | 材质 | 颜色 | 光滑度 | F0 | 说明 |
  |---|---|---|---|---|
  | 铝面板 | 银 [176,180,183] | 150 | 232（LabPBR 金属铝预设） | 只在底色里有很淡的横向拉丝纹（每行色调差 ≤ 3%） |
  | 屋面卷材 | [196,198,196] | — | — | 带很淡的斑驳 |
  | 阴影缝 | [40,42,45] | — | — | — |
  | 灯带 | 红色亚克力 [168,50,42] | 170 | — | 不发光 |

  - 法线全是平的。
  - 铝面板的材质改过一次：
    - 第一版按"涂装铝"做（F0 24、光滑度 110），想避免光影下整片金属发白刺眼（玻璃框第一版出过这个问题）。
    - 2026-10-07 用户实机问"为什么铝不反光"：涂装铝看起来像银灰色哑光漆，不像金属。
    - 改成 LabPBR 金属铝预设 232、光滑度 150（介于缎面和镜面之间）。只改了 `_s`，用户复看后 PASS。
    - 如果开光影后发白刺眼，就把光滑度往回调。
- **运行时文件**：
  - `models/block/facade_cornice/{cornice_straight,cornice_outer,band_straight,band_outer}.json`（父模型 `block/block`，所以物品栏里有正常的立体视角）
  - `blockstates/aluminum_cornice.json`（multipart：檐口按 `facing` / `shape` 转好；`band=true` 时叠加灯带）
  - `models/item/aluminum_cornice.json`

## 在 A1 的哪里

- 墙顶一整格（5–6 m），绕建筑一圈。
- 砖砌到 5.0 m（原来到 5.25 / 5.4）。店面上方的砖带变成 4–5 m，MARKET 字还在上面。
- 灯带只在店面那一段打开（A1 设计稿已同步）。
- 入口门框的顶部（到 7 m）是另外的金属板，不用这个方块。

## 已知问题 / 以后

- 灯带不发光。以后接电（建筑电力或城市电网）时，再加点亮状态和 LabPBR 自发光。
- 没有内转角。
- 真实铝檐口每 3 m 左右有一道接缝盖板，这里为了不出现"每格一条线"的网格感，没有做。
