# Lead Chest V3（铅箱 V3，不锈钢包覆铅屏蔽箱）

状态（2026-09-30）：**已实现，未实机验证**。`compileJava --offline` 一次 PASS。外观只看过离线预览（生成器的 `--preview` 输出），游戏里的效果、光影下的 PBR、四个朝向和开合动画都还没看过。

V3 只换外观：模型、贴图和 PBR，以及跟着外形调整的 Mesh Shape 数值。方块、方块实体、交互、搜索和辐射规则都与 V2 相同。V2 是紫灰色铅体加深色钢框，V3 改为参考市售铅屏蔽箱的不锈钢包覆样式。

## 模型

生成器：`tools/build-lead-chest-v3.mjs`。
- `--check`：校验输出是否最新。
- `--preview DIR`：只把 geo、Mesh 和贴图写到 DIR，用于离线预览，不碰游戏文件。

V2 的生成器 `tools/build-lead-chest-v2.mjs` 已删除：它写的是同一批文件，留着会被误跑覆盖。

可编辑源：
- `src/main/blockbench/lead_chest.bbmodel`
- `src/main/blockbench/textures/lead_chest{,_s,_n}.png`

运行时文件：
- `geo/lead_chest.geo.json`
- `meshes/lead_chest.aflmesh.json`
- `block_mesh_profiles/lead_chest.json`
- `textures/block/lead_chest{,_s,_n}.png`
- `data/apocalypse_firstlight/mesh_shapes/lead_chest.json`

坐标：单位 px，原点在方块底面中心，正面朝 -Z，+X 是站在正面时的左手边。

**1760 个三角面**，22 个 Mesh part，没有共面重叠。各 bone 面数：body 1120、lid 528、两个搭扣各 56。箱体贴图密度 5.5 texel/px（512 atlas）；警示牌正面单独一块 44×44 的高密度区域，约 10.5 texel/px。

| 部位 | 几何 |
|---|---|
| 底座 | 不锈钢，13.6 × 11.6 px，高 1，倒角 0.15 |
| 外壳 | 拉丝不锈钢，13 × 11 px，竖向圆角 R 0.9，高到箱口 y 10.2；钢皮厚 0.4 |
| 铅内胆 | 钢皮里面 1.7 px 厚的铅层，加铅底板，内腔 8.8 × 6.8 × 7.2 px。箱口一圈能看到"钢皮 + 铅"的夹层截面 |
| 盖子 | 不锈钢盖 y 10.52–12.52，倒角 0.2；下面有一圈 0.6 px 宽的黑色橡胶密封条，压在铅层上；还有铅塞，每边比内腔小 0.15，关盖时塞进箱口 |
| 合页 | 背面通长合页：7 节，箱体和盖子交替，轴心 [0, 10.37, 5.95]，加两片合页板 |
| 搭扣 | 正面两个快速搭扣（x = ±3.8）：箱体上是底座板，盖子上是扣座，扳杆可动，下端转轴 [y 8.3, z −5.85] |
| 提手 | 盖顶一个平放的 U 形折叠提手，带两个转轴座；左右两侧各一个下垂的 U 形提手，各带两个支架 |
| 警示牌 | 正面中心，4.2 × 4.2 px，四颗铆钉。黄底、黑边，黑色三叶按 ISO 361 的比例（中心圆 r，叶片 1.5r–5r，60° 宽，一片朝下），边缘按距离做抗锯齿，没有文字 |

**Render bounds**（NORTH 方向，方块局部坐标）：`[0.047, -0.016, -0.127, 0.953, 1.406, 1.142]`。打开的盖子会伸到上方和背后。

## 材质与 PBR（LabPBR）

| 材质 | Base Color | `_s` 光滑度 R / F0 G |
|---|---|---|
| `stainless` 外壳、盖子 | [152,155,159] | 100 / 255（金属；光滑度压低，避免在光影下大面积反光发白） |
| `plinth` 底座 | [112,115,119] | 88 / 255 |
| `hardware` 合页、搭扣、提手、铆钉 | [140,143,147] | 120 / 255 |
| `lead` 铅内胆、铅塞 | 箱口截面 [122,125,131]；内壁、底板 [86,89,95]，往下更暗；铅塞底面 [116,119,124] | 58 / 235（LabPBR 预设金属"铅"，很粗糙） |
| `rubber` 密封条 | [30,30,32] | 40 / 20（非金属，哑光） |
| `placard` 警示牌 | 黄 [212,168,44]、黑 [26,26,28] | 110 / 24（非金属，半光漆面） |

- 倒角边有统一色调的高光，没有逐像素的边缘描线。
- `_n` 是平直法线，B 通道为 AO：铅内壁和盖子底面更暗。
- 除警示牌外，没有涂装、文字、锈迹或噪点。
- 铅改用中性灰，和材料体系里的铅砖、铅屏蔽砖一致，不再是紫色。

## 形状与交互（Mesh Shape Runtime）

以下坐标都是 NORTH 朝向的模型坐标，单位 px。

| 状态 | Physical（碰撞） | Selection（选中/轮廓） | 交互区域 → 锚点 |
|---|---|---|---|
| closed | 整个箱子 [-7,0,-6.13 → 7,12.52,6.37] | 箱子 + 盖顶提手 | `lid`：整个箱子 → `latch` [0,11.42,-5.9]（两个搭扣中间） |
| open | 箱体（到箱口 y 10.2）+ 竖起来的盖子 [-6.55,9.93,5.28 → 6.55,21.87,10.03] | 同 physical | `interior`：箱体和箱口 → `opening` [0,10.5,-3]；`lid`：竖起来的盖子 → `lid_edge` [0,21.5,9.08] |

| 区域 + 状态 | 提示 | 右键 |
|---|---|---|
| `lid` + 关 | 打开 / Open | `open=true`，播放开盖动画；上方是实心方块时打不开 |
| `lid` + 开 | 盖上 / Close | `open=false`；正在查看的界面全部关闭 |
| `interior` + 开，还有未揭示的格子 | 搜索 / Search | 逐格搜索界面（3 行） |
| `interior` + 开，已全部揭示或是玩家放置的 | 查看 / View | 普通 3 行界面 |

- 开盖时发出 3 格的 `INTERACTION` 噪音（感染者听到的游戏内噪音，与音效无关，没有改）。
- 世界内提示由 `meshshape/AflMeshInteractionBlock` 提供。

## 搜索

- 按 [progressive_container_search_v1.md](../gameplay/progressive_container_search_v1.md) 接入：40 ticks/格，±15%，不发翻找噪音。
- 玩家放置的铅箱不需要搜索；带 `LootTable` 的世界铅箱第一次接触时进入搜索。

## 音效（2026-09-30）

**可听半径**（2026-10-01）：在 `sounds.json` 里用 `attenuation_distance` 设定（原来是原版默认的 16 格），声音随距离线性变小，到半径处听不到；播放音量都不超过 1，所以半径就是实际范围。开盖、合盖 12 格。

**方块音效**：挖掘、破坏、放置、脚步、摔落改用原版 `SoundType.NETHERITE_BLOCK`（原来是 `METAL`）。钢皮包铅芯应该是沉闷、厚重、不怎么回响的金属声，原版的下界合金块最接近。没有新文件。

**开合音效**：`lead_chest_open` → `sounds/lead_chest/open.ogg`（0.84 s），`lead_chest_close` → `sounds/lead_chest/close.ogg`（1.03 s）。
- 播放：`LeadChestBlock.setOpen` 在服务端播放，音量 0.8（与储物柜相同）。音高只在 0.98–1.02 之间随机，±2% 不会让对好的时间点明显漂移。
- 字幕："铅箱打开 / 铅箱关上"（`subtitles.apocalypse_firstlight.lead_chest_*`）。

生成器：`tools/build-lead-chest-sounds-v1.mjs [源目录]`（默认 `E:/Download`，需要 ffmpeg）。响度和混音的函数已于 2026-09-30 移到共享库 `tools/sound-mix-lib.mjs`（配电箱音效也用它），参数没变；当时源素材已不在 `E:/Download`，所以没能重新生成做逐字节比对，现有的两段成品没有改动。要重新生成，需要把六段源素材放回源目录。源素材是用户生成的六段单一事件录音（1 秒，立体声，48 kHz），生成器会按 SHA-256 前 16 位校验：

| 源文件 | SHA-256 前 16 位 | 内容 |
|---|---|---|
| `latch_open.wav` | 1718100843eb1854 | 一个搭扣弹开 |
| `latch_close.wav` | 3abb5473c5f62843 | 一个搭扣扣上 |
| `seal_release.wav` | 31e1a9647df813ac | 密封条脱开 |
| `seal_compress.wav` | 8192757625dfd453 | 密封条压紧 |
| `lid_open.wav` | 60eddcd5c22b571b | 盖子抬起时的合页摩擦 |
| `lid_close.wav` | dea922d3d3903652 | 盖子落下 |

**响度标准化**（K 加权，ITU-R BS.1770）：
1. 双声道取左右平均混成单声道。左右相关度都在 0.98 以上，不会相互抵消。注意 ffmpeg 默认的 `-ac 1` 会多出约 +3 dB，所以没有用它。
2. 每段裁掉起音前的静音（保留 5 ms）和尾部静音。按 100 ms 窗口的最大响度把每段统一到 -20 LUFS，这样清脆的咔嗒声和低沉的撞击声在同一起点上。原始素材之间差得很多：撞击 -11.7，搭扣打开 -23.9。
3. 再按角色给混音增益：主体（盖子）0 dB，搭扣 -4 ~ -6 dB，密封条 -8 ~ -10 dB（点缀）。
4. 每段成品按 400 ms 最大瞬时响度对齐储物柜开、关门成品（开 -22.3、关 -20.2 LUFS），峰值不超过 -1 dBFS。两段都是峰值先到上限，所以成品略轻：开盖 -22.6、关盖 -21.0 LUFS，峰值 -1.1 / -1.0 dBFS。
5. 编码为单声道 48 kHz Ogg Vorbis（q6）。

**对齐动画关键帧**：开、关动画都是 14 ticks（0.7 s），smoothstep 缓动；关盖时盖子在 0.70 s 落到底。下表是每个事件的峰值位置，在成品里逐个测过，误差小于 1 ms：

| 声音 | 事件 | 峰值位置 | 混音增益（标准化后） |
|---|---|---|---|
| 开 | 搭扣 1 | 0.030 s | -4 dB |
| 开 | 搭扣 2（同一素材音高 +4%，避免两声完全一样） | 0.090 s | -5 dB |
| 开 | 密封条脱开（盖子刚开始抬） | 0.120 s | -8 dB |
| 开 | 盖子摩擦（裁掉素材前 0.1 s 的铺垫，主峰对在盖子转得最快的 0.35 s 附近，0.62–0.86 s 淡出） | 0.360 s | 0 dB |
| 关 | 盖子撞击（前面是 0.66 s 静音，盖子在落下途中不出声） | 0.700 s | 0 dB |
| 关 | 密封条压紧 | 0.71 s | -10 dB |
| 关 | 搭扣 1 | 0.760 s | -5 dB |
| 关 | 搭扣 2（音高 -3%） | 0.830 s | -6 dB |

成品中各事件 50 ms 窗口的响度：
- 开盖：盖子摩擦 -18.9，搭扣 -20.4 / -22.9，密封条 -23.1 LUFS。
- 关盖：撞击 -15.0，搭扣 -17.5 / -20.2 LUFS。

声音在服务端状态改变时播放，客户端在收到同一次方块更新后才开始动画，两者的起点一致。没有实机试听。

## 需要实机验证

1. 四个朝向下，合页在背面、搭扣和警示牌在正面，开盖方向正确。
2. 开盖动画：盖子和搭扣不穿过箱体；竖起来的盖子有碰撞。
3. 警示牌在常规距离下是否清晰。
4. 光影（LabPBR）：不锈钢是否发白、过亮；铅的箱口截面和内胆是否看得出是另一种金属；密封条是否可见。
5. 音效：开、关是否和动画对上（尤其关盖撞击是否正好在盖子落到底时）；音量与储物柜是否一致；关盖前 0.66 s 没有声音会不会显得迟钝。
6. 物品栏和手持的大小（display 沿用 V2）。
