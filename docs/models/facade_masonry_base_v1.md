# Facade Masonry Base V1（磨面砌块勒脚 + 浅色石材压顶）

状态（2026-10-07）：**已实现，用户实机 PASS。**
- `compileJava --offline` 通过；生成器 `--check` 通过。编译前单独确认过游戏已关闭。
- 外观只看过概念图（离线三维渲染，用的是同一套贴图参数）。
- 2026-10-07 用户实机（开、关光影截图）：U 形一段勒脚，压顶自动出现、外转角包边正常，用户确认 PASS。三种墙材颜色不同是刻意的分层（见"颜色分层"），用户确认保持现状。挖掘掉落没有单独的检查记录。

## 为什么做

[AFL Fuel Stop A1](../worldgen/fuel_stop_a1_design_v1.md) 的外墙 P0 资产：建筑一圈离地 0–1 m 的深色基座。真实便利店用比砖更耐磨的砌块做这一段，因为墙底最容易被溅水、被车门和推车碰到。

## 用户 2026-10-07 定下的方向

概念图对比了三个方案：
- A：磨面砌块，错缝；
- B：劈裂面砌块，错缝；
- C：磨光预制块，通缝。

用户的选择：
- 选方案 A；
- 转角柱底下也做勒脚，一圈连续；
- 压顶用浅色石材。

B 不选的原因：在这个分辨率下，劈裂面的凹凸画出来像一片片碎片。

## 方块

| 项 | 内容 |
|---|---|
| ID | `apocalypse_firstlight:ground_face_block`（磨面砌块 / Ground Face Block） |
| 代码 | `block/MasonryBaseBlock`；注册在 `AflBlocks` / `AflItems` |
| 创造栏 | 建筑方块，排在深灰外墙砖后面 |
| 属性 | 复制原版砖（硬度 2.0、抗性 6.0、需要正确工具、石头音效）。整格方块，碰撞是整格，压顶外挑的 1 px 不算碰撞 |
| 挖掘 | 普通建筑材料，和原版砖一样：`minecraft:mineable/pickaxe`，不加等级标签。掉落表掉自身，带 `survives_explosion`。没有实机检查生存模式挖掘掉落 |
| 噪音 | `noise_stone_blocks` |
| 重量 | `item_mass` 0.35 kg（估计，比外墙砖略重） |

### 方块状态

| 属性 | 含义 |
|---|---|
| `facing` | 朝外的一面。放置时朝向玩家，也就是从墙外面放 |
| `shape` | `straight` / `outer_left` / `outer_right`，规则和加油站顶棚边檐一样：身后那格是磨面砌块、并且转向了自己的左侧或右侧时，是外转角，压顶绕过转角。复用 `FuelCanopyFasciaBlock.Shape` |
| `cap` | 上面那格既不是磨面砌块、也不是店面玻璃幕墙时为 true，邻居变化时自动更新。玻璃底下不加压顶，因为玻璃自带铝窗台 |

- 压顶只画在朝外那一面（转角时画两面），墙内侧没有。`facing` 和 `shape` 只在有压顶时看得出来。
- 只有外转角，没有内转角（和边檐一样）。
- 旋转只转 `facing`；镜像时交换外转角的左右。

## 贴图和模型

- **生成器**：`tools/build-facade-masonry-base-v1.mjs`，`--check` 校验输出。整格方块加 JSON 元素模型，不需要 Blockbench 源，生成器就是可编辑源。
- **砌块尺寸**：50 × 20 cm。真实标准砌块长 40 cm，但除不尽 1 m，没法每格无缝重复。所以每格 5 层、每层 2 块，错缝，砂浆缝 1 cm，做成凹圆勾缝。
- **分辨率**：每格 240 × 240 texel（一层 48、一块 120），和外墙砖一样，mip 等级 4 不受影响。
- **颜色**：砌块面 [96,93,88]，比暖灰砖深一档；砂浆 [86,83,79]，接近砌块色。
  - 每块砌块一个色调（±3.5%），加一层低频斑驳。
  - 表面有稀疏、低对比的骨料小点，几个 texel 大小，不是逐像素噪点。
  - 第一版概念图里小点太密、太跳，已调稀、调淡。
- **变体**：3 个色调变体，按位置随机选。
- **LabPBR**：

  | 贴图 | 通道 | 内容 |
  |---|---|---|
  | `_s` | R 光滑度 | 砌块面 92（磨面，比砖光一些），砂浆 30 |
  | `_s` | G F0 | 14 |
  | `_s` | B 孔隙度 | 35–50 |
  | `_s` | A | 255 |
  | `_n` | R、G、B、A | 和外墙砖同一套：DirectX、坡度按 240 循环、B 为 AO、A 为高度 |

- **压顶**：
  - 浅色预制石 [184,178,168]，光滑度 70，有很淡的斑驳，没有缝。
  - 尺寸：在方块顶部，高 2 px（约 12 cm），外挑 1 px（约 6 cm）；外转角是两段带转角方块。
  - 原版 JSON 元素模型，可以用平滑光照，没有 OBJ 那样的顶点顺序问题。
  - 不设 cullface：压顶伸出了格子，上面或旁边是整格方块时也不能被剔掉。
  - UV 都在 0–16 以内（17 px 长的那段会把整张近乎纯色的贴图拉宽一点）。
- **运行时文件**：
  - `textures/block/facade_masonry/ground_face_block_{0,1,2}{,_s,_n}.png`
  - `textures/block/facade_masonry/cast_stone_cap{,_s,_n}.png`
  - `models/block/facade_masonry/{ground_face_block_0..2,cap_straight,cap_outer}.json`
  - `blockstates/ground_face_block.json`（multipart：底座三变体随机，加上按 `facing` / `shape` 转好的压顶）
  - `models/item/ground_face_block.json`

## 颜色分层（用户 2026-10-07 确认）

三种墙材从浅到深：暖灰外墙砖 [156,141,126]（主墙）→ 磨面砌块 [96,93,88]（勒脚）→ 深灰外墙砖 [72,74,78]（柱子），中间用浅色石材压顶隔开。层次靠明暗分，不靠花纹。开光影时暖色阳光会让砌块显得偏棕，关光影看是中性偏暖的中灰。

## 在 A1 的哪里

建筑一圈 0–1 m，包括店面玻璃下的矮墙、两侧墙、后墙，以及四个转角柱、门框两侧柱和壁柱的底部。

- 柱子底下也做勒脚，是对 A1 原立面图（柱子的砖直接落地）的改动，A1 设计稿已同步。
- 入口门框处是落地玻璃门，没有勒脚。

## 已知问题 / 以后

- 只有外转角；墙体凹进去的内转角处，压顶不会自动拼。
- 玻璃幕墙的铝窗台滴水边挂在下面勒脚外皮的前面，往下伸 0.45 px（2026-10-09 起不再伸进勒脚格里面，见 [storefront_glazing_v1.md](storefront_glazing_v1.md)）。玻璃底下没有压顶，所以不冲突；如果在玻璃下面手动放了别的方块，压顶会出现，可能和滴水边重叠。
