## 为什么做

- A1 便利店的门还是原版门模板：`steel_door`（工业门）是一块平板贴图，室内用的 `poplar_door`（白杨木门）已随白杨木整套删除（[删除记录](../worldgen/poplar_wood_set_removed.md)）。
- 店要做成正式 NBT，后墙 3 扇钢门和室内 5 扇门都看得到，所以搭 NBT 之前先换掉。

## 用户 2026-10-07 定下的方向

概念图对比了三个方案：
- A：全钢平板门（外深灰、内浅灰）；
- B：外钢内木（外门深灰钢门；室内深灰钢框 + 浅色木纹门扇）；
- C：外门刷墙色，室内白钢框 + 浅灰钢门扇。

用户的决定：
- **选 B**："商业木门和这种铁门"。
- 卫生间门、窄视窗门不单独做方块，是商业木门的**样式**：只改外观，拆下来掉同一个物品，样式不跟着物品走（和雨篷的拉杆一样）。
- 建筑 NBT 要保留样式，所以样式放在方块状态里。

## 两种门

| 项 | 钢门 `steel_door` | 商业木门 `commercial_wood_door` |
|---|---|---|
| 名字 | 工业门 / Steel Door（不变） | 商业木门 / Commercial Wood Door（新） |
| 门框 | 深灰涂装钢门框 | 同一种门框 |
| 门扇 | 深灰涂装钢门扇，边缘小倒角 | 浅色枫木贴面实心门扇，缎面清漆 |
| 开门方向 | **朝放门的人那一侧往外开**，门扇转出自己那一格 | **往背离放门的人那一侧开**，门扇在自己那一格里转（和原版门一样） |
| 外侧五金 | 杠杆把手、锁芯、门镜、外露铰链、门头滴水、铝门槛 | 杠杆把手、闭门器、不锈钢踢脚板 |
| 内侧五金 | 杠杆把手、旋钮、闭门器 | 杠杆把手、铰链 |
| 样式 | 无 | `style`：`plain` 普通 / `restroom` 卫生间 / `vision` 窄视窗 |
| 挖掘 | 镐 + 钻石级，`requiresCorrectToolForDrops`（不变）；掉落表为空，只有回收工具和爆炸逻辑掉门（`SteelDoorBlock`，不变） | 斧，不要求等级，空手也掉；掉落表只在下半掉一个物品，带 `survives_explosion` |
| 重量 | 3 kg（不变） | 2.5 kg（估计） |
| 堆叠 | 64（不变） | 64 |

- **为什么开门方向不同**：
  - 外门：放在外墙上，从外面放，就往外开。真实的出口门都往外开，玻璃门 V2 也是这样。
  - 室内门：从营业区放，门扇贴着营业区那面墙，往房间里开，在自己那一格里转，不占隔壁格。营业区看过去门和墙面是平的。
- **方块状态**：两种门都还是原版门，状态 `facing` / `half` / `hinge` / `open` / `powered` 和原版一样；木门多一个 `style`。
  - 钢门的状态一个都没改，旧存档和模板里的钢门不会坏，但**要补方块实体才看得见**：以前放的钢门（这次更新之前已经在存档里的）没有方块实体，读档时 Minecraft 不会自动补上，所以**看不见**，碰撞和选中框还在。右键开关一次就好：开门会重新写一次方块，方块实体随之补上（用户 2026-10-07 实机确认）。重新放、或者把建筑重新粘贴一次也可以。新放的门、地堡这类用 `placeInWorld` 在世界里直接摆的模板都正常。开发阶段，和饮水机 V2 一样不做自动迁移。
  - 门的开启方向变了（原来往格子里开，现在往外开）；门前紧贴着东西时，开门的碰撞会和它重叠。
  - `facing` 是放门的人看的方向，`hinge` 是放门的人看到的左右；门扇挂在朝放门的人的那一面。
- **切换样式**：空手潜行右键，普通 → 卫生间 → 窄视窗 → 普通，上下两半一起变（`updateShape` 同步 `style`）。潜行看着门时准星提示下一种样式（`WorldInteractionHint`）。开关门、红石和原版木门一样。
- **样式只改外观**：碰撞、交互、掉落、重量都一样。窄视窗的玻璃能看穿，碰撞和普通门相同。

## 渲染

- **AFL Animated Block Mesh Runtime**（[说明](../rendering/animated_block_mesh_runtime_v1.md)）：
  - 方块实体只在下半：`SteelDoorBlockEntity`、`CommercialWoodDoorBlockEntity`，公共父类 `SteelFrameDoorBlockEntity`。
  - 按铰链选 profile：`<id>_right`（原始网格，铰链在 −X）、`<id>_left`（镜像）。这和收银台通道门的做法相同。
  - 网格朝放门的人那一面是 −Z，所以 `meshFacing()` 返回 `FACING.getOpposite()`。
  - 通道 `open` 跟着 `OPEN`，只转骨骼 `leaf`。
  - 木门的三种样式是 `leaf` 下面的三个子骨骼，用 `meshPartVisible` 显示或隐藏：
    - `leaf_plain`：实心门扇，普通和卫生间样式显示；
    - `leaf_lite`：带窗的门扇，窄视窗样式显示；
    - `restroom`：指示锁和门牌，卫生间样式显示。
  - 渲染范围显式写出：上下两格，四周各留一格。
- **方块模型**：只有粒子贴图，所有状态指向同一个模型（`blockstates/<id>.json`）。
- **物品**：`SteelFrameDoorBlockItem` 继承 `DoubleHighBlockItem`，和原版门物品一样放上下两半。图标是右铰链、关着的门。木门的 `leaf_lite`、`restroom` 骨骼在 geo 里标了 `neverRender`，所以物品显示的是普通门。
