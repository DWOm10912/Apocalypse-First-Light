# 声音与感染者听觉

AFL 的声音系统会将玩家行为、枪械与爆炸转换为具有位置和传播范围的噪声事件。

感染者听到噪声后会调查真实声源位置。

---

# 1. 噪声类型

当前噪声类型：

| 类型 | 用途 |
|---|---|
| `GUNSHOT` | 枪声 |
| `EXPLOSION` | 爆炸 |
| `BLOCK_BREAK` | 方块破坏 |
| `FOOTSTEP` | 脚步 |
| `LANDING` | 落地 |
| `INTERACTION` | 环境交互 |

声音系统本身：

- 不生成新的感染者
- 不直接执行寻路
- 只更新感染者的声源目标与调查状态

---

# 2. 感染者听觉

感染者位于噪声的有效传播范围内时，会记录真实声源位置并尝试调查。

当声音传播半径：

`> 10 格`

时，感染者可以进一步：

- 朝声源移动
- 搜索进入建筑的路径
- 尝试破坏允许破坏的障碍物

---

## 调查参数

| 参数 | 当前值 |
|---|---:|
| 首次寻路错峰 | 0–9 ticks |
| 成功寻路最低刷新间隔 | 20 ticks |
| 寻路失败重试 | 30–40 ticks |
| 相近声源合并距离 | 2 格 |
| 建筑入口搜索冷却 | 40 ticks |
| 建筑入口首次错峰 | 0–19 ticks |
| 每轮最大入口候选寻路数 | 8 |

距离当前调查目标不超过约 2 格的连续噪声：

- 刷新最后听到声音的时间
- 不重新建立整套调查流程
- 不重新选择几乎相同的声源位置

如果声源位置发生明显变化，则可以建立新的调查目标。

# 6. 枪声

AFL 原生枪械的枪声直接进入 AFL 自己的噪声系统。

每把枪的枪声半径由自己的枪械数据定义。

例如：

| 武器 | 枪声半径 | 枪声耳鸣 |
|---|---:|---|
| 制式手枪 | 64 格 | 否 |

只有一次真正成功射击才会产生枪声噪声。

以下情况不会产生枪声噪声：

- 空仓干击
- 被服务器拒绝的射击
- 未真正发射子弹的状态

---

## 枪声传播

枪声会：

- 以射击位置作为声源
- 吸引有效范围内的感染者
- 使用正常的方块声学衰减
- 参与感染者调查与破障逻辑

枪声不会直接生成新的感染者。

---

# 7. 枪声耳鸣

枪声噪声和枪声耳鸣是两个独立系统。

一把枪可以：

- 产生很大的感染者听觉范围
- 但不一定让玩家耳鸣

例如制式手枪：

`噪声半径 = 64 格`

但：

`枪声耳鸣 = 否`

较大口径武器后续可以单独启用枪声耳鸣。

---

## 枪声耳鸣内部参数

枪声耳鸣主要用于未来的大口径枪械。

### 基础范围

`16 格`

### 武器响度

根据枪械噪声半径 `R`：

`loudness = clamp((R - 64) / 96, 0, 1)`

因此：

- 64 格及以下基本没有枪声耳鸣响度
- 噪声半径越高，耳鸣潜力越强

### 距离衰减

玩家距离枪声 `d`：

`distanceFactor = (1 - d / 16)²`

16 格以外不产生该枪声的耳鸣暴露。

---

## 大口径倍率

| 枪声半径 | 额外倍率 |
|---|---:|
| `R ≥ 128` | ×1.25 |
| `R ≥ 160` | 再 ×1.35 |

单次暴露强度存在上限：

`0.75`

---

## 累积参数

| 参数 | 当前值 |
|---|---:|
| 累积上限 | 1.5 |
| 每 tick 衰减 | 0.008 |
| 第一阈值 | 0.35 |
| 第二阈值 | 0.60 |
| 第三阈值 | 0.90 |
| 硬冷却 | 6 ticks |
| 延长节流 | 20 ticks |
| 触发后保留累积 | 45% |

该系统主要用于：

- 大口径步枪
- 狙击枪
- 重型武器

普通 9mm 制式手枪当前不会触发。

# 8. 爆炸噪声

所有正常进入 Minecraft / Forge 爆炸流程的爆炸都会产生一次爆炸噪声。

感染者听觉半径根据实际爆炸强度动态计算。

## 公式

`rawRadius = 96 + Explosion Strength × 24`

然后：

`Noise Radius = round(rawRadius / 8) × 8`

最终限制：

`96–256 格`

---

## 爆炸噪声示例

| 爆炸强度 | 噪声半径 |
|---:|---:|
| 2.0 | 144 格 |
| 2.5 | 160 格 |
| 3.0 | 168 格 |
| 4.0 | 192 格 |
| 5.0 | 216 格 |
| 6.0 | 240 格 |
| ≥ 约 6.67 | 256 格 |

原版 TNT：

`Explosion Strength = 4`

因此：

`噪声半径 = 192 格`

---

# 9. 爆炸噪声与爆炸耳鸣

两者使用同一次爆炸事件，但属于不同系统。

## 爆炸噪声

负责：

**感染者能从多远听见爆炸。**

范围：

`96–256 格`

## 爆炸耳鸣

负责：

**玩家在近距离受到多强的听觉和视觉冲击。**

它使用自己的：

- 距离
- Severity
- 音量
- 持续时间
- Overlay

规则。

因此：

> 爆炸可以被非常远的感染者听见，但只有距离较近的玩家会出现明显耳鸣。

爆炸耳鸣的具体参数见《生存系统》。

# 10. 声音阻隔

环境方块可以削弱噪声传播。

当前已经确定：

| 方块 | 声学效果 |
|---|---|
| 羊毛 | 每穿过 1 层完整羊毛，有效传播范围 ×0.5 |

多层羊毛按乘法累计。

例如：

原始噪声：

`64 格`

穿过一层完整羊毛：

`32 格`

穿过两层：

`16 格`
