# AFL 主世界地表群系策略

本文记录当前代码中的主世界普通地表群系候选规则。这里的“普通地表”不等同于洞穴、海洋或河流分支。

## 1. 普通地表白名单

| 设计名称 | 实际 Registry ID | 角色 |
| --- | --- | --- |
| Plains | `minecraft:plains` | 唯一保留的 Vanilla 普通地表群系；用于安全区和少量安全地表区域 |
| Polluted Forest | `apocalypse_firstlight:irradiated_woodland` | AFL 污染疏林 |
| Sunken Wasteland | `apocalypse_firstlight:fallout_barrens` | AFL 沉降荒原 |
| Scorched Earth | `apocalypse_firstlight:scorched_lands` | AFL 焦土 |

除 `minecraft:plains` 外，`minecraft:forest`、`minecraft:dark_forest` 以及其他 Vanilla 普通地表群系都不得进入 AFL 主世界的普通地表候选表。它们仍保留在 Minecraft biome registry 中，不做 registry 删除。

## 2. 当前候选控制方式

- `AflVanillaBiomePolicy` 采用白名单语义：Vanilla 普通地表只允许 `minecraft:plains`。
- `OverworldBiomeBuilderMixin` 在 Vanilla `OverworldBiomeBuilder` 生成气候候选时分别过滤地表和地下分支，而不是维护一张大型 biome 黑名单。
- `AflOverworldRegion` 通过 TerraBlender 注册三种 AFL 地表群系；当前权重为 `190`，TerraBlender 默认主世界区域权重为 `10`。
- 权重只决定 Plains 区域与 AFL 区域的宏观占比，不能代替白名单。Vanilla Forest 等群系必须从候选生成阶段排除。
- `apocalypse_firstlight.mixins.json` 必须在 DEV 启动参数中注册。IntelliJ run configuration 过期时，过滤 Mixin 不会执行，TerraBlender 默认区域便会重新携带完整 Vanilla 候选表。修改 Mixin 配置后应重新运行 `gradlew genIntellijRuns`。

当前项目没有删除第三方 biome 的 registry entry。若第三方模组另行注册 TerraBlender Region，其普通地表候选不由 AFL 的 Vanilla 白名单自动管辖；需要逐项做兼容审计，不能通过全局 registry 删除处理。

## 3. 特殊群系策略

| 类型 | 当前策略 | 代码依据 |
| --- | --- | --- |
| 洞穴 | 保留 Vanilla `dripstone_caves`、`lush_caves`、`deep_dark` 候选 | `AflVanillaBiomePolicy.VANILLA_UNDERGROUND_BIOMES` |
| 海洋 | 当前 AFL 内陆无海洋策略下不作为正常地表生成 | `continents` density function 将 continentalness 下限限制到 `-0.11`，地表白名单也不保留 Vanilla ocean |
| 河流 | 当前未建立独立 Vanilla river 候选分支，按无河流普通地表策略处理 | 当前 `OverworldBiomeBuilder` 候选过滤与 AFL Region 定义 |

上述是当前 live code 的既有策略，不代表删除对应 registry entry，也不授权修改 terrain density、terrain shape 或 surface rules。

## 4. Radiation Zone 与地表群系

期望的语义对应关系为：

| Radiation Zone | `F` 范围 | 语义目标地表群系 |
| --- | --- | --- |
| `SAFE` | `F < 0.08` | `minecraft:plains` |
| `IRRADIATED` | `0.08 <= F < 0.62` | `apocalypse_firstlight:irradiated_woodland` |
| `HEAVY_FALLOUT` | `0.62 <= F < 0.84` | `apocalypse_firstlight:fallout_barrens` |
| `EXTREME` | `F >= 0.84` | `apocalypse_firstlight:scorched_lands` |

### 当前实现状态

Radiation Field 与 biome placement field 是两个不同系统：

- 辐射使用 `RadiationField`：基于世界种子的二维 value noise，宽尺度 `768`、细节尺度 `192`，按 `0.82 / 0.18` 混合。
- 地表群系放置使用 Minecraft climate sampler、TerraBlender region selection 和 `AflOverworldRegion` 的 humidity/continentalness/depth 参数。
- `BiomeRadiationResolver` 会在地表群系已经确定以后，按照该 biome 的 profile 约束辐射 `F`。这能维持群系与辐射的基本语义范围，但不是“同一个 F 直接决定 biome”的精确一一映射。

因此当前结论是：

- 普通地表白名单：已由候选层代码实现。
- Radiation 与 biome 的语义约束：已实现。
- Radiation Field 与 biome field 共用同一底层场：否。
- `F` 阈值直接、精确决定四种地表 biome：尚未实现。
- 共享阈值 authority：尚未用于 worldgen；不得复制第二套 Radiation noise 或在运行时重写已生成 chunk 来伪造对齐。

## 5. 验证边界

- biome selection 修改只影响新世界或尚未生成的 chunk；旧 chunk 可继续保留旧的 `forest`、`dark_forest` 等结果。
- 构建成功或客户端进入主菜单不等于 fresh-world biome 分布已经验证。
- 运行时验收必须在全新世界或确定未生成的主世界 chunk 中检查 F3 biome，并分别验证 Plains、三种 AFL biome、出生安全区以及 Vanilla Forest/Dark Forest 不再作为普通地表出现。
