## Gunshot Tinnitus V1

玩家枪声耳鸣使用上表经 MUZZLE `silence.distance_addend` 修正、但未应用感染者 90% cap 的独立声学输入 `R`；没有第二份枪械参数表。True suppressor 在 listener 查询前直接令整次枪声 exposure contribution 为 `0`，同时覆盖射手和附近玩家；非 Suppressor 枪口不免疫。只检测同一维度声源周围 16 格内的玩家，射手按距离 `0`，其他玩家按眼睛位置到射手世界位置计算。Creative 包含，Spectator、死亡和 removed 玩家排除。

```text
loudness = clamp((R - 64) / 96, 0, 1)
distanceFactor = clamp(1 - distance / 16, 0, 1)^2
shotExposure = clamp(loudness * distanceFactor * 0.55 * caliberBoost, 0, 0.75)
caliberBoost = 1.25 when R >= 128, then additionally * 1.35 when R >= 160
```

| 代表枪械 | R | 射手单发 exposure | V1 行为 |
| --- | ---: | ---: | --- |
| M1911 | 64 | 0.000 | 单发及连续射击均不增加 exposure |
| UMP45 | 72 | 0.046 | 近距离需要大量连续射击 |
| AKM | 96 | 0.183 | 单发不触发；近距离短 burst 可跨过轻度阈值 |
| SPAS-12 | 104 | 0.229 | 近距离数发容易累积 |
| Kar98 | 112 | 0.275 | 单发不直接触发；连续两三发可触发 |
| AWM | 128 | 0.458 | 射手单发触发轻度；连续两发可加强 |
| M107 | 160 | 0.750（单发上限） | 射手单发明显触发；约 3 格玩家也可单发触发 |

Exposure 每 tick 衰减 `0.008`，阈值为 `0.35 / 0.60 / 0.90`；触发后保留 `45%`。Packet 至少间隔 6 ticks，且后续只在 severity 增加至少 `0.15` 或距上次发送满 20 ticks、需要延长 Episode 时发送。枪声和爆炸共用一个客户端 Episode：首个有效 impulse 播放一次 one-shot；后续冲击仅 strengthen / extend 同一 Envelope 和 Overlay，不停止、重建或从头播放声音，也不重置 Overlay 帧。时间轴结束后 re-arm；时长仍为 `round(40 + 120 × severity)` ticks，上限 200 ticks，Explosion Tinnitus 数值未改。

RPG-7、M320 的发射声和弹头爆炸声仍是位置不同、类型不同的两个 Noise Event；只有弹头实际进入标准 Explosion 流程时才产生动态 `EXPLOSION` 噪声和独立计算的 Explosion Tinnitus。Suppressor 只清零 Gunshot Tinnitus，不抑制 Explosion Tinnitus；裸枪半径、枪械数值和 TaCZ 资源均未改变。
