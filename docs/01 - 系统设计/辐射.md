### 1. 基本规则

玩家出生点的周围小部分区域是安全区，默认不会有环境辐射

但是如果玩家携带了放射源，就会增加环境辐射

吸收剂量：已经被身体吸收的辐射剂量，暴露在辐射环境中持续累计；药物、医疗、特殊治疗

残留辐射：身上、装备、背包物品携带的放射性污染；洗消、换装备、丢弃污染物、清洗

### 3. 吸收的辐射

![[Pasted image 20260830044451.png]]

| 辐射累计     |  辐射效果 | 辐射病等级 |                                       |
| -------- | ----: | ----- | ------------------------------------- |
| < 2 RU   |    正常 | 0     | /                                     |
| 2–5 RU   | 轻度辐射病 | I     | 移速 -5%                                |
| 5–10 RU  | 中度辐射病 | II    | 移速 -10%，受到的治疗量：75%                    |
| 10–20 RU | 严重辐射病 | III   | 移速 -15%，受到的治疗量：50%，偶发轻微反胃，约 2–3 秒     |
| ≥20 RU   | 致死辐射病 | IV    | 移速 -20%，受到的治疗量：25%，每5秒半颗心，反胃繁，约 3–5 秒 |
>**牛奶无法解除此效果，死亡也不会！**
