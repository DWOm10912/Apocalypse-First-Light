
## 1. 核心数据与单位

| 名称                    | 代码含义                       | 单位     | 当前状态            |
| --------------------- | -------------------------- | ------ | --------------- |
| 环境场 `F`               | 由世界种子生成、再经过生物群系和安全区约束的无量纲场 | `0–1`  | 已实现             |
| 环境辐射率                 | 环境场换算出的辐射率                 | `RU/h` | 已实现             |
| `finalRadiation`      | 玩家当前位置经过屏蔽后的环境辐射，加上局部辐射    | `RU/h` | 已实现             |
| 吸收剂量 `Dose`           | 玩家累计吸收的辐射                  | `RU`   | 已实现，持久化         |
| 残留辐射 `residual`       | 玩家身上的残留污染读数                | `RU/h` | 已实现，暂不进入 Dose   |
| 局部辐射 `localRadiation` | 方块、物品或其他近距离辐射源             | `RU/h` | 接口已保留，当前固定为 `0` |

当前服务器每 `20 ticks`（1 秒）结算一次 Dose、残留辐射和辐射病。

## 2. 玩家最终辐射率计算链

当前计算顺序如下：

```text
世界种子二维辐射场
    ↓
生物群系约束
    ↓
安全锚点压制
    ↓
开局生态区辐射上限
    ↓
环境场 F → 环境辐射率 Rambient
    ↓
14 方向遮蔽采样 → 平均透射率 T
    ↓
Rshielded = Rambient × T
    ↓
Rfinal = Rshielded + Rlocal
```

公式：

```text
Rfinal = Rambient × Tshielding + Rlocal
```

当前：

```text
Rlocal = 0
```

因此现阶段通常等价于：

```text
Rfinal = Rambient × Tshielding
```

注意：

- `Rlocal` 的代码入口已经存在，但还没有接入携带物、污染物或局部辐射源。
- `RadiationZone` 根据屏蔽前的有效环境场判断；躲进建筑降低的是实际 `finalRadiation`，不会把区域枚举从 `EXTREME` 改成 `SAFE`。
- 安全锚点核心区域是例外：核心内且 `Rlocal <= 0` 时，会强制得到 `SAFE` 和 `0 RU/h`。
- 非主世界维度直接返回 `SAFE / 0 RU/h` 样本；玩家残留辐射会按 SAFE 规则衰减。

## 3. 世界辐射场

### 3.1 原始场

`RadiationField` 使用世界种子生成确定性的二维值噪声：

```text
Fraw = clamp01(broad × 0.82 + detail × 0.18)
```

| 噪声层 | 空间尺度 | 权重 |
| --- | ---: | ---: |
| Broad | 768 blocks | 0.82 |
| Detail | 192 blocks | 0.18 |

相同世界种子和相同 X/Z 坐标会得到相同结果。该场只依赖 X/Z，不直接依赖玩家高度。

### 3.2 生物群系约束

表中范围是安全锚点压制和开局区上限应用前的场值范围。

| 地表生物群系 | Profile | 约束后的 `F` | 按换算曲线对应的约辐射率 |
| --- | --- | ---: | ---: |
| 原版平原 | `SAFE` | `0–0.075` | `0 RU/h` |
| 污染疏林 | `IRRADIATED` | `0.10–0.58` | `1.33–9.33 RU/h` |
| 沉降荒原 | `HEAVY_FALLOUT` | `0.62–0.82` | `10–55.45 RU/h` |
| 焦土 | `EXTREME` | `0.86–1.00` | `82.5–240 RU/h` |
| 未识别/其他群系 | `UNKNOWN` | 保留原始场 `0–1` | `0–240 RU/h` |

Biome Profile 只约束自然世界场，不直接代表玩家最终吸收的辐射率。

### 3.3 安全锚点压制

安全锚点默认来自世界出生点；地堡生成并成功绑定后可以改为地堡中的指定安全点。

| 距离安全锚点 | 压制系数 `Sanchor` |
| --- | ---: |
| `d <= 40` | `0` |
| `40 < d < 96` | `smoothstep((d - 40) / 56)` |
| `d >= 96` | `1` |

```text
FpreStartup = Fbiome × Sanchor
```

此外，距离安全锚点不超过 40 blocks 且不存在局部辐射时，最终环境辐射会被强制设为 0，区域设为 `SAFE`。

### 3.4 开局生态区辐射上限

开局生态区以世界坐标 `(0, 0)` 为中心，并对 `FpreStartup` 施加上限：

| 区域 | 上限行为 |
| --- | --- |
| 核心平原 `d <= 160` | 上限 `0.079`，保持在 SAFE 阈值以下 |
| 核心外至噪声化平原边界 | 使用 smoothstep 从 `0` 过渡到 `0.079` |
| 平原边界至污染疏林外边界 | 上限从 `0.10` 过渡到 `0.42` |
| 疏林外边界后的 48 blocks | 从 `0.42` 平滑交接回原有效场 |
| 交接区之外 | 不施加开局上限 |

严格按当前分支判断，`d <= 160` 直接返回 `0.079`；刚越过 160 blocks 后会进入下一段从接近 `0` 开始的 smoothstep 公式，因此当前核心边界存在一次不连续跳变。本文记录的是现状，不将其描述成已经连续平滑。

最终用于区域和辐射率计算的场为：

```text
Feffective = min(FpreStartup, startupCap)  // 仅 startupCap 存在时
```

## 4. 环境场到辐射率的换算

```text
F < 0.08:
R(F) = 0

0.08 <= F < 0.62:
R(F) = 1 + 9 × (F - 0.08) / 0.54

0.62 <= F < 0.84:
R(F) = 10 + 50 × (F - 0.62) / 0.22

F >= 0.84:
R(F) = 60 + 180 × (F - 0.84) / 0.16
```

`F` 在换算前限制到 `0–1`，所以自然环境辐射率范围为 `0–240 RU/h`。

| `RadiationZone` | 有效场范围 | 换算后的理论辐射率范围 |
| --- | ---: | ---: |
| `SAFE` | `F < 0.08` | `0 RU/h` |
| `IRRADIATED` | `0.08 <= F < 0.62` | `1–10 RU/h` |
| `HEAVY_FALLOUT` | `0.62 <= F < 0.84` | `10–60 RU/h` |
| `EXTREME` | `F >= 0.84` | `60–240 RU/h` |

区间端点以代码比较规则为准，例如 `F = 0.62` 属于 `HEAVY_FALLOUT`。

## 5. 建筑屏蔽

### 5.1 采样方式

玩家位置会向 14 个方向采样：

- 6 个正交方向：东、西、上、下、南、北。
- 8 个空间对角方向。
- 每条射线最多检查 8 个采样位置。
- 每条射线初始透射率为 `1.0`。
- 每遇到一个 `radiation_shielding` Tag 内的方块，该射线透射率乘以 `0.35`。
- 当单条射线透射率低于或等于 `0.01` 时，停止继续检查该射线。
- 14 条射线的透射率取平均，得到最终 `Tshielding`。

```text
Tray = 0.35 ^ N
Tshielding = sum(Tray1 ... Tray14) / 14
shieldingPercent = 1 - Tshielding
```

这里的 `N` 是该射线上实际命中的屏蔽方块数。同一条射线命中多层材料会继续叠乘，不是只计算第一层。

### 5.2 当前屏蔽材料

| 方块 | Registry ID | 单层透射率 | 单层削弱 |
| --- | --- | ---: | ---: |
| 钢筋混凝土 | `apocalypse_firstlight:reinforced_concrete` | `0.35` | `65%` |

当前 Tag：`apocalypse_firstlight:radiation_shielding`。

屏蔽采样结果按玩家 BlockPos 缓存 10 ticks，以减少重复射线计算。

## 6. 吸收剂量

服务器每秒结算一次：

```text
Dnew = Dold + Rfinal / 3600
```

因为 `Rfinal` 的单位是 `RU/h`，所以恒定暴露一小时会累计对应数值的 RU。

| 恒定 `Rfinal` | 每秒增加 Dose | 达到 2 RU | 达到 20 RU |
| ---: | ---: | ---: | ---: |
| `1 RU/h` | `0.000278 RU` | 2 小时 | 20 小时 |
| `10 RU/h` | `0.002778 RU` | 12 分钟 | 2 小时 |
| `20 RU/h` | `0.005556 RU` | 6 分钟 | 1 小时 |
| `60 RU/h` | `0.016667 RU` | 2 分钟 | 20 分钟 |
| `240 RU/h` | `0.066667 RU` | 30 秒 | 5 分钟 |

当前边界：

- Dose 只使用 `sample.finalRadiation()`。
- 残留辐射当前不计入 Dose。
- Dose 不会自然下降。
- 玩家死亡后 Dose 仍然保留。
- 当前没有正式的医疗或洗消玩法用于降低 Dose；管理员命令可以重置或修改。

## 7. 残留辐射

### 7.1 非 SAFE 区域

环境目标：

```text
targetResidual = min(12, finalRadiation × 0.05)
```

每秒向目标双向逼近一次：

```text
residualNew = residualOld + (targetResidual - residualOld) × 0.002
```

| `finalRadiation` | `targetResidual` |
| ---: | ---: |
| `20 RU/h` | `1 RU/h` |
| `60 RU/h` | `3 RU/h` |
| `120 RU/h` | `6 RU/h` |
| `240 RU/h` | `12 RU/h` |
| `>240 RU/h` | 仍封顶为 `12 RU/h` |

这是双向公式：当玩家从更高辐射区进入较低但仍非 SAFE 的区域时，残留辐射也会缓慢向较低目标下降。

### 7.2 SAFE 区域

SAFE 不使用 `0.002` 逼近公式，而是每秒独立衰减：

```text
residualNew = residualOld × 0.9995
```

```text
residual < 0.01 RU/h → residual = 0
```

### 7.3 持久化与死亡

| 情况 | Dose | Residual |
| --- | --- | --- |
| 正常存档/重新登录 | 保留 | 保留 |
| 非死亡实体 Clone | 保留 | 保留 |
| 玩家死亡后重生 | 保留 | 清零 |

当前残留辐射更接近独立污染读数：它会显示在 Geiger 上，但暂不作为玩家吸收剂量的额外辐射源。

## 8. 辐射病

辐射病等级完全由累计 Dose 决定，由服务器权威计算。

|        Dose | Stage |   移速修正 |   治疗倍率 | 反胃                       | 周期伤害                 |
| ----------: | ----: | -----: | -----: | ------------------------ | -------------------- |
|    `< 2 RU` |     0 |      无 | `100%` | 无                        | 无                    |
|   `2–<5 RU` |     I |  `-5%` | `100%` | 无                        | 无                    |
|  `5–<10 RU` |    II | `-10%` |  `75%` | 无                        | 无                    |
| `10–<20 RU` |   III | `-15%` |  `50%` | 持续 10–12 秒；结束后冷却 45–75 秒 | 无                    |
|  `>= 20 RU` |    IV | `-20%` |  `25%` | 持续 16–24 秒；结束后冷却 25–45 秒 | 每 5 秒受到 1 点魔法伤害（半颗心） |

实现细节：

- 移速使用 `MULTIPLY_TOTAL` 临时 Attribute Modifier。
- 治疗削弱作用于 `LivingHealEvent`，修改实际收到的治疗量。
- III/IV 反胃持续时间和冷却都以 1 秒为随机步长。
- 下一次反胃冷却从上一次反胃结束后开始计算，不从反胃开始时计算。
- IV 的周期伤害与反胃调度相互独立。
- 自定义 `radiation_sickness` Effect 主要负责阶段显示；实际惩罚由服务器管理器执行。
- Effect 没有任何可用的 curative item，因此牛奶不能解除。
- 死亡会清除临时状态，但 Dose 会复制到新玩家实体，辐射病随后按原 Dose 恢复。

> 牛奶无法解除辐射病；死亡也不会清除累计 Dose。

## 9. 辐射心形覆盖

心形覆盖只替换当前已经填充的原版生命心，不改变真实生命值。

| Stage | 覆盖比例 | 使用外观 |
| ---: | ---: | --- |
| 0 | `0%` | 原版心形 |
| I | `0%` | 原版心形 |
| II | 约 `30%` 的已填充心 | Mild |
| III | 约 `60%` 的已填充心 | Severe |
| IV | `100%` 的已填充心 | Critical |

被覆盖的心根据玩家 UUID 和心形索引稳定选择，不会每帧随机跳动。半颗心使用对应阶段的 half 纹理。

## 10. 盖革计数器

### 10.1 HUD 读数规则

只有玩家主手或副手持有 **盖革计数器** 时，服务器才同步完整 Geiger 数据并显示 HUD。

| 当前区域     | HUD/声音使用的辐射率            |
| -------- | ----------------------- |
| `SAFE`   | `residualRadiationRate` |
| 非 `SAFE` | `finalRadiation`        |

HUD 同时显示：

- 当前环境辐射或残留辐射。
- 累计吸收剂量。
- 当前区域。

数据每 10 server ticks（0.5 秒）同步一次；超过 40 ticks 没有更新时，客户端快照视为 stale。

### 10.2 量程

| 实际测量值 | HUD |
| ---: | --- |
| `< 20 RU/h` | 显示两位小数的实际读数 |
| `>= 20 RU/h` | 显示“超量程” |

`20 RU/h` 只是仪器 HUD 和点击声的量程上限：

- 不会把真实 `finalRadiation` 裁剪到 20。
- 不会把 Dose 计算裁剪到 20。
- 不会把残留辐射目标规则改成 20。

### 10.3 声音曲线

| 测量值 `RU/h` | 目标点击率 `CPS` |
| ---: | ---: |
| 0.00 | 0.00 |
| 0.10 | 0.25 |
| 0.50 | 0.75 |
| 1.50 | 2.00 |
| 3.00 | 4.00 |
| 6.00 | 7.00 |
| 9.00 | 10.00 |
| 12.00 | 12.00 |
| 20.00 或更高 | 20.00 |

控制点之间线性插值。客户端每 tick 以 `CPS / 20` 的概率播放一次独立点击，因此最大 20 CPS。

## 11. 辐射环境视觉

环境雾效使用同步后的 `finalRadiation`，在 `10 RU/h` 达到最大目标强度：

```text
x = min(1, finalRadiation / 10)
intensity = x² × (3 - 2x)
```

客户端每 tick 向目标强度逼近 10%。最大强度时：

- 雾颜色以 `0.48` 强度向 RGB `(0.43, 0.46, 0.34)` 混合。
- 远裁剪面最多缩短到原来的 `70%`。
- 玩家位于液体雾中时，不应用这套空气雾修改。

视觉强度封顶不代表真实辐射率封顶。

## 12. 管理员调试命令

所有命令前缀为 `/afl radiation`，需要权限等级 2。

| 命令 | 用途 |
| --- | --- |
| `/afl radiation here` | 输出当前位置世界场、生物群系约束、区域、屏蔽、final、开局区限制等完整诊断 |
| `/afl radiation dose` | 查看当前辐射率和累计 Dose |
| `/afl radiation dose add <amount>` | 增加 Dose |
| `/afl radiation dose set <amount>` | 设置 Dose |
| `/afl radiation dose reset` | 清空 Dose |
| `/afl radiation residual` | 查看 residual |
| `/afl radiation residual set <amount>` | 设置 residual |
| `/afl radiation residual reset` | 清空 residual |
| `/afl radiation locate natural_safe [maxRadius]` | 搜索自然 SAFE 区域 |
| `/afl radiation locate irradiated [maxRadius]` | 搜索自然轻度辐射区 |
| `/afl radiation locate heavy_fallout [maxRadius]` | 搜索自然重度沉降区 |
| `/afl radiation locate extreme [maxRadius]` | 搜索自然极危辐射区 |
