# 声音与感染者听觉

## 1. 系统概述

声音系统把服务器上的玩家行为和爆炸转换为带世界坐标、类型及传播半径的 `NoiseEvent`。感染者位于经方块声学衰减后的有效范围内时，会把调查位置更新为真正的声源位置。

当前事件类型包括 `GUNSHOT`、`EXPLOSION`、`BLOCK_BREAK`、`FOOTSTEP`、`LANDING` 和 `INTERACTION`。系统不额外生成感染者、不改变寻路、目标选择或听觉记忆时长。

如果声音的传播半径超过 10，感染者会尝试朝声源所在位置移动，并尝试破坏路上的易碎阻碍。

## 3. 枪声：Noise System V2

枪声由 TaCZ 服务端射击事件产生，声源位置保持为射击玩家的世界位置。基础半径按以下优先级解析：

1. `GunId` 显式覆盖；
2. 未覆盖枪械使用当前 TaCZ 枪械类别 fallback；
3. 未知类别或无法取得枪械索引时使用通用 fallback `80` 格。

当前共有 **45** 把现实枪械使用显式裸枪半径，完整表见 [[枪械]]。原有五个锚点保持不变：M1911 `64`、UMP45 `72`、AK-47/AKM `96`、Kar98 `112`、M107 `160`。

显式值只表示裸枪基础半径。最终有效半径继续读取当前 MUZZLE attachment 的 `silence.distance_addend`：

```text
effectiveRadius = max(8, baseRadius + silence.distance_addend)
```

本轮没有更改消音器数值或算法，也没有实现 Gunshot Tinnitus。RPG-7 和 M320 的显式值只表示发射器发射声；弹头爆炸会在命中位置另行产生 `EXPLOSION` 事件。

## 4. 爆炸：Noise System V2

所有进入 Forge `ExplosionEvent.Detonate` 的真实服务端爆炸都会产生一次 `EXPLOSION` Noise Event。事件位置直接使用 `Explosion.getPosition()`；强度读取 live `Explosion` 的实际 radius/strength 字段，不按 TNT、手雷或弹头类型建立硬编码表。

动态半径公式：

```text
rawRadius = 96 + explosionStrength * 24
roundedRadius = round(rawRadius / 8) * 8
noiseRadius = clamp(roundedRadius, 96, 256)
```

| Explosion strength | Noise radius（格） |
| ---: | ---: |
| 2.0 | 144 |
| 2.5 | 160 |
| 3.0 | 168 |
| 4.0（原版 TNT） | 192 |
| 5.0 | 216 |
| 6.0 | 240 |
| 约 6.67 或更高 | 256（上限） |

仅监听 `Detonate`，因此同一实际爆炸不会因同时处理 `Start` 和 `Detonate` 而重复产生噪声。未来爆炸物只要进入标准 Minecraft/Forge Explosion 流程，就会自动使用同一公式。

Explosion Noise 与 Explosion Tinnitus 是两个独立消费者：前者决定感染者听觉范围 `96–256` 格；后者继续使用自己的玩家距离、严重度、音频与 Overlay 计算。两者可以响应同一个 `Detonate`，但互不借用半径或状态。
