# 枪械

AFL 使用自研枪械框架。

TaCZ 不再参与 AFL 枪械逻辑，仅作为开发环境中的运行时对比模组。

本页只记录当前正式枪械数据、通用规则和必要的内部参数，不记录开发历史。

---

# 2. 制式手枪

Registry ID：

`apocalypse_firstlight:service_pistol`

AFL 第一把原生枪械，同时作为后续手枪类武器的基础参考。

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 使用弹药 | 9mm 手枪弹 |
| 弹匣容量 | 17 发 |
| 开火模式 | 半自动 |
| 最短开火间隔 | 3 ticks / 0.15 秒 |
| 基础伤害 | 7.0 |
| 头部倍率 | 3.0×（已预留，当前未启用头部判定） |
| 伤害衰减起点 | 24 格 |
| 标称有效射程 | 48 格 |
| 最大射程 | 64 格 |
| 最大射程最低伤害倍率 | 65% |
| 最大射程伤害 | 4.55 |
| 基础散布 | 1.2° |
| 噪声半径 | 64 格 |
| 枪声耳鸣 | 否 |

---

## 伤害规则

### 0–24 格

造成完整伤害：

`7.0`

### 24–64 格

伤害线性下降。

### 64 格

最低伤害：

`7 × 0.65 = 4.55`

### 64 格以外

不再命中。

当前：

- 无子弹穿透
- 无方块穿透
- 无跳弹
- 无护甲穿透

子弹伤害仍然正常受到：

- 护甲
- 盾牌
- 抗性效果
- 原版 PvP 规则

影响。

为了允许当前 0.15 秒的合法连续射击，原版受伤无敌帧不会阻止正常枪械伤害。

# 4. 换弹

## 制式手枪换弹数据

| 属性 | 当前值 |
|---|---:|
| 普通换弹总时长 | 26 ticks / 1.30 秒 |
| 空仓换弹总时长 | 33 ticks / 1.65 秒 |
| 空仓拉滑套音效 | 25 ticks / 1.25 秒 |
| 抽出弹匣 | 约 8 ticks / 0.40 秒 |
| 新弹匣装入 | 约 19 ticks / 0.95 秒 |
| 实际弹药结算 | 新弹匣装入时 |

换弹会从玩家背包消耗 9mm 手枪弹。

例如：

`当前 5 / 17，备用 40`

换弹后：

`17 / 17，备用 28`

如果备用弹药不足，则只装入实际拥有的数量。

例如：

`5 / 17，备用 4`

换弹后：

`9 / 17，备用 0`

---

## 换弹限制

以下情况不会正常开始换弹：

- 弹匣已经满
- 没有备用弹药
- 当前正在换弹

换弹过程中切走当前枪械会取消未完成的装填。

已经完成弹药结算的弹药不会退回。

# 5. 空仓状态

当弹匣：

`1 → 0`

最后一发仍然属于正常成功射击。

随后进入：

**空仓挂机**

滑套保持在最后方。

## 空仓规则

| 项目 | 当前行为 |
|---|---|
| 滑套 | 后锁 |
| 枪械剪影 | 红色 |
| 当前弹量 | 红色 `0` |
| 备用弹药 | 保持正常颜色 |
| 左键 | 播放空仓声音 |
| 正常枪声 | 不播放 |
| Hitscan | 不产生 |
| 伤害 | 不产生 |
| 噪声 | 不产生 |
| 枪口焰 | 不产生 |
| 抛壳 | 不产生 |

空仓声音拥有约：

`6 ticks`

的播放限制，避免连续点击产生大量重叠声音。

# 6. 空仓换弹

空仓换弹使用独立的手动拉滑套动画：

- 换弹开始时滑套保持后锁
- 新弹匣正常装入
- 左手在 1.12–1.27 秒斜移至滑套后部侧面，1.38 秒开始释放；滑套追加后拉仍为 0.20 模型单位
- 1.43–1.46 秒释放复进，1.65 秒回到 Ready
- 原始 `slide_action.ogg` 在 1.25 秒播放一次
- 不会因为 0.95 秒时弹药变为非零而瞬间跳回
- 空仓类型在动作开始时锁定；19 ticks 装弹后仍禁止开火，直到 33 ticks 动作结束

当前尚未制作完整的：

- 独立 Slide Release 手势
- 膛内弹系统

左手以枪械局部空间同侧后部防滑纹为接触目标，直接接近后只随滑套前后轴运动；不以屏幕中线作为主要约束。掌心同侧与路径检查通过，修正后的运行时视觉验收尚待完成。普通换弹不拉滑套，仍为 1.30 秒；取消前后的弹药结算规则不变。

# 7. 枪械 HUD

玩家手持 AFL 原生枪械时，右下角显示对应枪械 HUD。

制式手枪显示：

- 枪械剪影
- 当前弹匣
- 备用弹药

例如：

`17 | 353`

其中：

- `17` = 当前弹匣
- `353` = 玩家背包中的 9mm 手枪弹

---

## 射击反馈

每次成功开火：

当前弹匣数字短暂变为红色。

持续时间：

`5 ticks`

之后恢复正常颜色。

---

## 空仓反馈

弹匣为 0 时：

- 当前弹量持续显示红色
- 枪械剪影持续显示红色
- 备用弹药保持正常颜色

重新装入弹药后恢复正常。

---

# 8. 枪械噪声

制式手枪成功开火会产生：

`64 格`

枪声噪声。

该噪声直接进入 AFL 自己的噪声系统，并能够吸引附近感染者。

制式手枪当前：

`枪声耳鸣 = 否`

因此普通 9mm 手枪开火不会触发枪声耳鸣。

爆炸耳鸣属于独立系统。

# 10. 9mm 抛壳

制式手枪成功射击后会从真实抛壳口产生一个客户端视觉弹壳。

使用：

`9mm_casing`

模型。

弹壳不属于服务端实体：

- 不可拾取
- 不保存
- 不参与碰撞伤害
- 不增加服务器实体数量

---

| 属性 | 当前值 |
|---|---:|
| 视觉尺寸 | 0.072 |
| 主要方向 | 枪械右侧 + 上方 |
| 横向初速 | 0.24–0.30 block/tick |
| 向上初速 | 0.12–0.16 block/tick |
| 前后随机 | ±0.04 block/tick |

# 11. 第一人称枪械规则

当前制式手枪第一人称采用：

- 右手主握
- 左手辅助支撑
- 换弹时左手负责弹匣操作
- Reload 时枪械可从右手中心构图转向右前臂侧面

实际玩家皮肤手臂由 AFL 自己渲染。

支持：

- Classic 手臂
- Slim 手臂
- 玩家皮肤
- 袖层

Blockbench 中的手臂参考模型仅用于制作姿势。

# 12. TaCZ 边界

TaCZ 已经不是 AFL 的生产依赖。

当前用途仅为：

**开发环境中的视觉、动画和手感对比。**

AFL 不再通过 TaCZ 获取：

- 开火事件
- 弹药状态
- 枪械伤害
- 枪声噪声
- 枪声耳鸣
- 消音器信息
- HUD
- 抛壳
- 枪焰

Native Gun Framework 是 AFL 后续枪械唯一正式路线。

# 后坐力

每把原生枪在武器定义中持有自己的后坐力参数。成功射击（含最后一发）先按当前方向完成服务端命中，再向射手施加视角和枪模后坐。

| 制式手枪参数 | 当前值 |
|---|---:|
| 垂直视角后坐 | 每发向上 0.80°–1.10° |
| 水平视角后坐 | 每发 −0.12°–+0.12° |
| 最大纵向 / 横向累积 | 4.5° / ±1.0° |
| 视角恢复延迟 | 0.05 s（1 tick） |
| 视角恢复 | 指数衰减，时间常数 0.18 s；恢复开始后 0.18 s 消退约 63% |
| 枪模上扬 / 后移 | 每发 5° / 0.04 渲染单位 |
| 枪模 yaw / roll | 每发各 ±0.75° |
| 枪模恢复 | 指数衰减，时间常数 0.10 s |
| 枪模累积上限 | 各通道单发幅度的 3 倍 |

视角后坐实际改变玩家朝向，后续服务端射线受其影响；散布仍为 1.2°。恢复只叠加增量，不保存或拉回旧瞄准点，玩家可主动向下压枪。
枪和双臂共享视觉后坐。干击不后坐；换弹禁止新射击，已有后坐继续平滑衰减。换枪、死亡或换世界清理残留，不将旧后坐带给新物品。
当前后坐力基线已通过实机手感确认。

# 子弹轨迹

普通 9mm 使用微弱高速短轨迹，只提供视觉反馈；命中仍由服务端瞬时判定。每发轨迹使用同一次射击经过后坐力与散布后的实际命中点或射程终点，不重新随机方向。

| 制式手枪参数 | 当前值 |
|---|---:|
| 轨迹模式 | 微弱轨迹（SUBTLE） |
| 速度 | 18 格/tick |
| 最大短段长度 | 3 格 |
| 核心 / 外层宽度 | 0.015 / 0.032 格 |
| 核心颜色 / 透明度 | 暖白 RGB 255,245,205 / 0.65 |
| 外层颜色 / 透明度 | 淡黄橙 RGB 255,190,80 / 0.12 |
| 枪口隐藏距离 | 0.40 格 |
| 到达终点后淡出 | 0.15 tick（约 7.5 ms） |
| 安全寿命上限 | 6 ticks |
| 同时存在上限 | 128 条，超出淘汰最旧轨迹 |

轨迹从实际枪口向服务端终点收束，用无贴图细带绘制；不是连接枪口与目标的整条光束。近距离截短，到达终点后不继续前进。第一、第三人称都等待实际枪口位置，未绘制枪口时不从眼睛补发。
干击没有轨迹，最后一发正常产生轨迹。真正曳光弹尚未实现；当前微弱轨迹的明暗与可读性已通过实机确认。
