# 弹药

原生枪械的弹药和弹匣状态由服务端管理；当前正式支持 9×19mm 与 7.62×51mm。

| 项目 | 当前规则 |
| --- | --- |
| 弹药 ID | P9-01：`apocalypse_firstlight:9x19mm_round`；BR51-01：`apocalypse_firstlight:762x51mm_round` |
| 使用武器 | P9-01 制式手枪 / BR51-01 战斗步枪，不互通口径 |
| 弹匣容量 | P9-01 为17，BR51-01 为20；保存在枪 ItemStack 的 `AflGunAmmo.ammoInMagazine` |
| 储备 | 玩家物品栏与副手中的对应口径；弹壳不可装填 |
| 换弹 | P9-01 第19tick结算，BR51-01普通/空仓第52/57tick结算；满匣或无对应储备不启动 |
| 空弹壳 | `9x19mm_casing` / `762x51mm_casing` 已注册普通物品；射击抛壳仍是不可拾取客户端视觉，不生成掉落实体 |

四项物品均64堆叠；只有两种实弹位于“AFL 武器与弹药”，弹壳不进入创造标签，仅保留开发检查注册。旧 `9mm_round` 存档注册缺失映射到新9mm物品，不转换为步枪弹。资产、命令与验证见 [正式弹药资产 V1](../../native_guns/native_ammo_assets_v1.md)。

完整射击与换弹规则见 [枪械](枪械.md)。
