# 弹药

原生枪械的弹药和弹匣状态由服务端管理；当前只有普通 9mm。

| 项目 | 当前规则 |
| --- | --- |
| 弹药 ID | `apocalypse_firstlight:9mm_round` |
| 使用武器 | P9-01 Service Pistol |
| 弹匣容量 | 17，保存在枪 ItemStack 的 `AflGunAmmo.ammoInMagazine` |
| 储备 | 玩家物品栏与副手中的 `9mm_round` |
| 换弹 | 第 19 tick 消耗储备并补足，满匣或无储备不启动 |
| 空弹壳 | `9mm_casing` 仅作客户端视觉，不注册为可拾取抛壳实体 |

完整射击与换弹规则见 [枪械系统](枪械系统.md)。
