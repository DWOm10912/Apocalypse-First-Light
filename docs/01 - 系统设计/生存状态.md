### 5. 爆炸耳鸣 / Explosion Tinnitus V1

状态：实现已接入。用户已反馈 V1 声音播放、近距离更响/更久、Overlay 渲染和连续爆炸不叠音正常，但 3–4 格视觉过弱；当前已进行仅视觉曲线修正，修正后的画面仍待固定距离实机验收。不是疾病、Potion Effect 或永久听力损伤；上方其它生存状态名称仍为规划，不代表已实现。

#### 触发与距离

- 服务器监听 Forge `ExplosionEvent.Detonate`，只遍历爆炸所在 `ServerLevel` 的存活、非旁观 `ServerPlayer`；创造玩家也可以体验反馈。
- 不依赖掉血、护甲、受影响实体列表或可见度，不进行墙体遮挡、材质吸音或 raycast。隔墙但距离足够近也会触发，这是 V1 的已知简化。
- Forge 47.4.22 / Mojmap 1.20.1 的 `Explosion` 没有公开 `getRadius()`；`ExplosionAccessor` 只读原有 `radius`（SRG `f_46017_`），没有写字段或注入伤害方法。
- Vanilla 已通过取消 `Start` 中止的爆炸不会进入 `Detonate`。当前依赖 TaCZ `8141310` 的 `EntityKineticBullet → ExplodeUtil → ProjectileExplosion` 也调用 Forge Detonate，且把同一 radius 传入父类；共用入口，不单独重复监听弹丸。不承诺覆盖绕过该事件的未知第三方爆炸。

| 参数 | 当前值 / 公式 |
| --- | --- |
| `r` | 实际 `Explosion.radius` 构造参数；不是人为固定的 TNT 半径 |
| `d` | 玩家眼睛位置到 `Explosion.getPosition()` 的三维距离，单位格 |
| 有效范围 `R` | `r × 3.0`，倍率为 AFL 表现参数，不是 Vanilla 伤害规则 |
| normalized `n` | `clamp(1 − d/R, 0, 1)`，原有计算不变 |
| audioSeverity `s` | `n²`，声音保留用户已验证的平方曲线 |
| overlaySeverity `v` | `n`，改为线性；从原 S2C 中的 `s` 通过 `sqrt(s)` 恢复，不重复检测爆炸 |
| 声音阈值 | `s ≥ 0.15`，不变；无效/非正半径、非有限数值不触发 |
| 视觉阈值 | `v ≥ 0.08`，可独立产生无声的轻微视觉冲击 |
| 网络 | 既有 AFL `main` SimpleChannel，协议仍为 `9`；声音或视觉满足阈值时发送原 S2C `s`、entity ID、dimension ID，字段格式不变、不每 tick 同步 |

#### 声音、淡出和连续爆炸

| 项目 | 当前实现 |
| --- | --- |
| SoundEvent | `apocalypse_firstlight:explosion_tinnitus`，无 subtitle / lang key |
| 素材 | 用户原始 OGG，约 10.03 秒、44,100 Hz、mono；没有转码、裁剪、normalize 或波形修改 |
| 播放 | `ExplosionTinnitusSound extends AbstractTickableSoundInstance`；`looping=false`、`relative=true`、`attenuation=NONE`、`pitch=1`，SoundSource 为 `PLAYERS` |
| 初始音量 | `0.15 + 0.55s`；仍受用户 Master / Players 音量设置影响，代码不改设置 |
| 单次时长 | `round(40 + 120s)` client ticks，即约 2–8 秒；达到阈值的最轻实际约 2.90 秒 |
| 声音外部包络 | 前 15% 保持；之后半余弦 `0.5 + 0.5 cos(πu)` 淡到 0，素材自身衰减继续保留；结束显式 stop |
| 更强新爆炸 | 保持单一 sound 引用，先 `stopNow` + `SoundManager.stop(old)`，再播放一条新 one-shot；severity 升级，时长至少保留旧剩余时长 |
| 较弱或等强爆炸 | 不 restart、不降低 severity；当前时间轴结束点延后 20 ticks（1 秒），重新拉长剩余淡出，不叠音 |
| 延长上限 | 每次实际播放从起点起最多 200 ticks（10 秒），不把单条非循环素材延长成无声状态；到上限后弱爆炸不能继续延长 |

没有世界音量压低、混音框架、耳鸣循环、多份随机素材或 HUD 状态图标。素材结束后的继续发声不通过循环伪造；需要重新增强时仅更强新爆炸替换当前 one-shot。

#### 像素 Overlay 与清理

- 使用用户原始 `256×256 RGBA` PNG，原始 alpha 为 `0..138`，保留 14,144 个全透明像素及透明中心；不 resize、重画、改色或模糊。
- 在 Forge `RenderGuiEvent.Post` 绘制世界 HUD 冲击层：通过 `GuiGraphics.blit` 将完整 `256×256` source 拉伸至当前 `guiWidth × guiHeight`，不改变 HUD 布局。
- Texture filter 为 nearest（`setFilter(false, false)`）；Java 整体 alpha 改为 `0.18 + 0.42v`，输入/结果有合法区间限制，峰值上限 `0.60`。与 PNG 自身 alpha 相乘，最强像素的合成 alpha 上限约 `0.60×138/255=0.325`；这只是数值上限，不代替实机可视性验收。
- 视觉包络仍为前 10% 保持、之后半余弦淡出，在视觉时间轴总长的 85% 时归零；使用 partial tick 连续插值。时间轴基础长度仍为 `round(40+120s)` ticks，不改近/中距离原有 fade 时间；视觉边缘新触发约 2.05 秒时间轴，在约 1.74 秒时画面归零。
- `ExplosionTinnitusClientState` 复用同一种轻量 Envelope，但音频和视觉各持有一份独立时间轴；仍只画一层。视觉更强时升级/刷新，较弱时延长但不降级，不将多张 Overlay 相加。视觉时长上限同为 200 ticks。
- 纯视觉范围的爆炸只刷新视觉，音频 `trigger` 仍在 `s<0.15` 时直接忽略，不能启动、重播、提高或延长声音。两条时间轴统一暂停和清理；在不同强度的连续爆炸后，视觉与音频不要求同时结束。
- 有任意 `mc.screen`（包括背包、容器、聊天、暂停菜单）或隐藏 HUD 时不绘制，不拦截鼠标或 slot。状态按原有客户端暂停语义推进。
- 绘制结束在 `finally` 恢复白色 shader color、blend 开关/因子、depth 开关、shader、texture binding 和 pose stack。
- `LoggingOut`、客户端 `LevelEvent.Unload`、`ClientPlayerNetworkEvent.Clone` 清理；每 client tick 同时检查 world/player 身份、死亡和旁观状态，停止声音并清空 Overlay。包携带 player/dimension ID，拒绝已切换玩家或维度的旧反馈。
- 不使用 capability、persistent NBT、跨世界保存或全世界逐 tick 扫描。
