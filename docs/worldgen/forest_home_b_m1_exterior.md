## 场地

地块 37 × 13 × 26：x = X + 10（X -10..26），y = k + 3（k -3..9），z = Z + 10（Z -10..15），正面朝南，不转。

- 搭建时先把地块里 k ≥ 0 的东西全清成空气（树、地形），一次清一排 Z，一只动物只挡住它那一排；
- 再整平：k -1 草方块，k -3..-2 泥土；
- 地块边上和原地形的高差 M1 不处理（M4 选址和地表平滑再说），所以要选比较平、没有水的地方。

## 实机搭建步骤

1. 用户开非超平坦的创造世界，站到将来客厅的位置（大约 X 8、Z 5），在聊天栏输：
   `/afl_author resume forest_home_b_m1 ~-18 ~-3 ~-15 37 26 13 3`
   （地块是空气以外的地方不能用 `authoring_create`，所以用 `resume` 指定原点；`surface_offset_y` 3 = k 0 那一层。）
   在「house test」里重搭已有的地块，用绝对原点（地块的最小角）：
   `/afl_author resume forest_home_b_m1 -785 83 -144 37 26 13 3`
   搭建会话只存在内存里，重启游戏后要重新输一次。
2. 玩家飞到地块上方（地块里不能有实体）。
3. `node tools/afl_minecraft_mcp/forest_home_b_m1.mjs build`：清场、整平、写入、`reconcile_shapes`、`audit_support`，报告写到 `build/authoring_checks/forest_home_b_m1/build_m1.json`。
4. `node tools/afl_minecraft_mcp/forest_home_b_m1.mjs fixtures`：发电机、物资箱、木桶、木橱柜、木水槽柜、木枪架。
5. 某排被实体挡住时：`node tools/afl_minecraft_mcp/forest_home_b_m1.mjs slices <Z...>` 重做那几排（先清，再写那几排的格子）。
6. 只改一块时：`node tools/afl_minecraft_mcp/forest_home_b_m1.mjs region <xa> <xb> <za> <zb>` 只重做这个 X / Z 方框（k ≥ 0 先清空，再写方框里所有层的格子，包括地面以下和整平的那几层），方框外不动——发电机、容器是放上去的东西，整排 `slices` 会把它们清掉。M1.3 地窖：`region 3 15 -10 -2`。
7. M2.1（2026-10-13）在已经搭好的房子里换家具：`node tools/afl_minecraft_mcp/forest_home_b_m1.mjs furniture`。只重写木桌、木椅那几格，把柜子和枪架的格子清空（原来的木板台面、炼药锅、活板门）再放上去，别的都不动。
