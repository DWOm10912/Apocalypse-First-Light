## 1. 设定（用户 2026-10-12）

- 默认森林开局，核战后 1–3 个月。
- 主角是战前就住在山里的长期隐居者。房子是美国常见的猎人小屋 / 林中木屋。
- 没有电网：
  - 取暖靠柴炉；
  - 要用电时开小柴油发电机。
- 串联：林中住宅 → 私家车道 → 县道 → 小镇方向。
- 风格：
  - 实用、朴素、结实、能长住，有现代痕迹；
  - 不要豪华、别墅、童话或地堡感；
  - 有长期生活和维护的痕迹，有轻度应急改造，但不是长期废弃。
- 本轮范围：
  - 不改 AFL 代码，不建世界生成结构；
  - 不直接做家具包，不一次扩展大批木材衍生方块；
  - 不扩展到全国高速落地。

## 3. 推荐 B：溪谷老宅

- **符合默认开局**：
  - "战前就住在山里"需要看得出住了很多年：自己加盖的厨房、修过的屋顶、堆满一半的柴棚、收完的菜园、车棚里的旧皮卡；
  - B 是唯一能全放下又不显得像别墅的方案（总面积约 76 m² + 阁楼）。
- **叙事、可玩性、成本的平衡**：
  - 叙事：长线天线和短波收音机是剧情入口；地窖、阁楼是可选的藏东西处；
  - 可玩：开局在一个"家"里，柴炉取暖、做饭、烧水，发电机供电，都是现有系统（温度、口渴、燃料、建筑电力）能接上的；
  - 成本：主屋和加建都是方块建筑，Mesh 只做炉子、皮卡、收音机等少数几样（6 节）。A 的资产只是 B 的子集，选 B 不浪费。
- **把玩家引向道路和小镇**：
  - 发电机油箱约 1/3（15 L 箱）+ 一桶 20 L 柴油，共约 25 L。按发电机油耗 0.4 + 0.27 × kW 升 / 游戏小时：满载约 14 游戏小时，只点灯和收音机约 2 个游戏日；
  - 食物 3–4 天，柴 1–2 天（柴棚里还有，但要劈）；
  - 收音机里有求救或广播，手绘地图标了 Millbrook 和加油站；
  - 皮卡油箱见底，车道和大门是"第一次出门"的门槛，出了门是县道和路牌。

## 7. 风险和依赖

- **树**：Mesh 森林要给住宅、院子、车道、县道让位，否则会长在车道上。树木系统已有占地索引，要接上结构占地。
- **地形**：住宅需要一块平台；车道要在坡上走得顺（地表平滑要支持碎石车道）。溪谷位置要从 Terrain V2 的水系里找。
- **出生**：森林群系里找地点、放结构、床设为重生点、物资装进容器，这是新的出生逻辑（旧地堡强制出生已退役）。
- **车辆**：没有车辆系统。V1 皮卡是静态的，所以"开车进镇"在 V1 只是叙事，实际是走路。
- **县道和镇子**：县道等级还没有定义（城市道路规格和高速 R4 之外）。镇子和加油站的位置等国家路网和城镇规划，6 节和概念图里的距离都是占位。
- **建议的第一站**：已建的 Fuel Stop A1（加油站）放在县道上，作为第一次出门的目标（柴油、物资、第一次搜刮）。

## 8. 下一步顺序（建议）
