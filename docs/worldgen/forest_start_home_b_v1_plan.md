## 0. 原型的标准

"可实机测试的 B 版原型"指新建世界后：

1. 出生在老宅卧室床边；~~死亡后在床上重生~~（2026-10-14 起按幸存者 V0：死亡后换一个继任者，出生在野外，不回床，见 P4）。
2. 房子周围是森林，树不长进房子、院子、车道。
3. 柴炉能点、能取暖、能煮水做饭。
4. 屋里有开局物资（霰弹枪和子弹、几天的吃喝、斧子、撬棍等），自家的柜子不用逐格搜。
5. 发电机里约 5 L 柴油，旁边一桶 20 L。
6. 能沿碎石车道走到路口，路口有大门、信箱、牌子，外面是一段县道。2026-10-14 起：县道由 C3 修；C3 之前车道在节点 `H` 的碎石回车场收尾；牌子的模型以后做，位置用 C 的路边锚点。

按用户 2026-10-12 调整后的顺序（3 节），新世界的完整流程在 M4 才接上；M0–M3 在测试世界里用建造工具看。2026-10-14 再调：M2 收尾 → M3a → M4，M3b 等 C3.2（3 节）。

F1 柴炉 + 烟管：
- Mesh 方块实体，烧现有的原木、树枝等木材物品；

F1 概念（2026-10-13，用户定"铸铁箱式炉"，不做带烤箱的厨炉）：
