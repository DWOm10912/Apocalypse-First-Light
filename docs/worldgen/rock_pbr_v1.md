# 岩石和矿石 PBR R1（2026-10-24，C 分支 `feature/underground-u2`）

**状态：** 已实施，离线检查通过，用户 2026-10-24 实机 PASS（洞里竖井，开 Aureveil），没提交。

用户 2026-10-24 问：岩石和矿物做了 PBR 没有，为什么在 Aureveil 下反射不明显。按用户定的顺序做（"按 5 → 2 → 1 → 3 的顺序做"）：

1. 先查 Aureveil 的高光强度（第 2 节）；
2. 再加强岩壁法线，补高度和 AO（第 3、4 节）；
3. 然后做断面闪点（第 5 节）；
4. 最后加密矿石颗粒（第 6 节）。

## 1. 原因

所有岩石和矿石都有 LabPBR `_n` / `_s`，Aureveil 也在读。反射弱是数据本身的问题：

- **光滑度很低。** 花岗岩的光滑度字节 27，基岩 `stone_0..3` 24，换算粗糙度约 0.8。
- **F0 正常。** 10（约 4%），石头本来就是这个值。
- **法线很平。** 90% 的像素倾斜不超过 9–12°，B（AO）和 A（高度）通道全是 255。
- **矿石的金属颗粒少。** 金属颗粒（F0 43–110）只占约 5%，其余部分和围岩一样粗。

## 2. Aureveil 的高光（只读了 `Aureveil Shaders/shaderpack/shaders/lib/pbr.glsl`、`lib/shading.glsl`，没有改）

- **算法：** 标准 GGX 加高度相关 Smith，`alpha = max((1 - 光滑度)², 0.08)`，Schlick 菲涅尔。
- **灯光也有高光：** AFL 的灯（手电、车灯，`avAflHighlights`）走同一个波瓣，所以洞里拿手电也有高光。
- **环境反射：** 用分裂求和，乘材料 AO。
- `SPECULAR_STRENGTH` 默认 1.0，`MATERIAL_AO` 默认开，`POM` 默认开（深度 0.20 格）。

按它的公式算（F0 字节 10，手电和眼睛在同一处，峰值是漫反射（反照率 0.3）的几倍）：

| 光滑度字节 | 粗糙度 | 正对 | 偏 20° | 偏 40° |
|---|---|---|---|---|
| 24（基岩） | 0.91 | 0.05 | 0.05 | 0.05 |
| 72（风化面） | 0.72 | 0.12 | 0.08 | 0.04 |
| 129 | 0.49 | 0.55 | 0.08 | 0.02 |
| 200 | 0.22 | 5.1 | 0.02 | 0.00 |

**结论：** 着色器不是瓶颈。光滑度 200 时高光是漫反射的 5 倍；岩石现在只有 5%，而且各个角度一样，所以看不出来。这一项是离线按着色器公式算的，没有在游戏里放测试面。

## 3. 高度通道：不填，矿石的也去掉

**原因：** Aureveil 的视差（`lib/parallax.glsl`）按每个面的贴图矩形折回：

- 矩形由 `mc_midTexCoord` 和顶点 UV 算出来（`program/gbuffer.vsh`：`halfSize = abs(vTexCoord - middle)`）；
- 岩面网格（`RockRelief`、`RockCarveMesh`）是 1/8 m 的小块，每块只用贴图的一小部分，UV 也不一定是矩形；
- 视差往里走的时候，会在每个小块自己的矩形里折回，每条小块边上都会出现错位的缝。走得越深缝越宽；默认深度 0.20 格时，斜看能错开小块宽度的一大半。

**做法：**

- 天然岩石的 A 保持 255，不做视差；
- 矿石贴图原来 A 里有高度（最低 79–120，相当于往里陷 10 cm 上下），这次一起改成 255；这个问题是之前就有的，这次统一修掉。

起伏和缝隙只靠法线和 AO 表现。以后要做视差，得先让网格的 UV 覆盖整张贴图，或者让 Aureveil 按贴图格子而不是按面折回。

## 4. 法线加强和 AO（`tools/rock/rock-pbr.mjs` `relief`）

- **高度场：** 把照片的法线积分成高度场。贴图是周期的，用 FFT 最小二乘，导数按中心差分；回算的法线和原图平均点积 0.999。
- **找增益：** 二分找一个增益，让 90% 的像素倾斜不超过目标角，再用中心差分算回法线。这样单个像素的噪点不会被放大。
- **AO（`_n` 蓝通道）：** 像素比周围（半径 2 和 6 像素）低多少，0.6 / 0.4 加权，每低 1 像素（7.8 mm）暗 0.5，最暗 0.5。Aureveil 用它乘间接光、反弹光和环境反射。
- **带地衣的贴图用裸岩的增益：** 地衣下面已经压平了，不再按它自己的分布加强，免得地衣贴图上的岩石反而更糙。

目标角：

| 贴图 | 目标（90% 不超过） | 用在 |
|---|---|---|
| `rock/stone_0..3`、`minecraft:block/stone` | 24° | 基岩（原版石头），凿出来的断面 |
| `rock/rubble` | 26° | 碎石 |
| `boulder/granite*` | 24° | 花岗岩、片麻岩（`granite_fresh`）、巨石 |
| `boulder/limestone*` | 22° | 石灰岩、白云岩、岩盐 |
| `boulder/sandstone*` | 22° | 砂岩 |
| `boulder/shale*` | 26° | 页岩 |
| `boulder/*_worn` | 原来的规则（基础贴图的一半） | 泥灰岩（`limestone_worn`）、片岩（`shale_worn`）、河卵石 |

## 5. 断面闪点（`tools/rock/build-cut-textures.mjs`，`rock-pbr.mjs` `glints`）

- **断面贴图怎么来：** 镐凿出来的新断面用 `textures/block/rock/cut/<名字>`，原来 `_n`、`_s` 直接复制岩石的。
- **改成什么：** 结晶岩的断面写进矿物颗粒。每颗是一个晶面，占 1 个像素或 2 × 2：
  - 一个光滑度（0.75–0.96）；
  - 介电质 F0（11–14）；
  - 孔隙度 0；
  - 法线按解理面随机倾斜。
- **效果：** 灯光或视线一动，颗粒就一颗颗地闪。

| 断面 | 矿物 | 占比 | 光滑度字节 | 倾斜 |
|---|---|---|---|---|
| `stone_0..3`、`granite_fresh`（花岗岩、片麻岩） | 长石解理面 5%、石英 2.5%、云母 1.5% | 约 9% | 205–245 | 20–35°，随机方向 |
| `limestone_fresh`、`limestone`（石灰岩、岩盐、白云岩） | 方解石 | 3% | 200–225 | 30° |
| `sandstone_fresh` | 石英颗粒 | 2% | 190–215 | 35° |
| `shale_worn`（片岩） | 云母 | 8% | 225–242 | 15°，同一个方向（片理） |
| `shale_fresh`、`limestone_worn`（泥灰岩） | 没有 | | | |

天然岩面（没凿过的洞壁）不加闪点，只有第 4 节的起伏和 AO。

## 6. 矿石（`tools/rock/build-ore-textures.mjs`）

- **浸染颗粒（`DISSEM`）：** 在矿物块之间的围岩和脉石上（F0 低于 20 的像素）加 1 像素的颗粒：

  | 矿石 | 加的颗粒（贫矿 / 富矿） |
  |---|---|
  | 煤层 | 黄铁矿 0.6% / 1% |
  | 条带状铁矿 | 赤铁矿条带里 25% / 30% 的像素换成镜铁矿鳞片（光滑度 0.88）；磁铁矿 2% / 3% |
  | 含金石英脉 | 黄铁矿 1.5% / 2.5% |
  | 含铜石英脉 | 黄铁矿 1% / 1.5%，黄铜矿 1.5% / 2.5% |
  | 含铅石英脉 | 黄铁矿 1% / 1.5%，方铅矿 1.5% / 2.5% |
  | 含铅锌白云岩 | 方铅矿 1.5% / 2.5%，闪锌矿 1.5% / 2% |
  | 含铜角砾岩 | 黄铜矿 2% / 3%，黄铁矿 1% / 1.5% |

  黄铁矿：颜色 (0.66, 0.6, 0.38)，光滑度 0.85，F0 138（反射率约 54%）。

- **晶面（`FACET`）：** 每颗金属矿物（F0 40 以上，包括金）是一个晶面，法线每 2 × 2 像素随机倾斜，最多 25°。
- **起伏：** 和岩石一样加强（90% 不超过 22°），AO 取原来的和新算的里面更暗的那个。
- **高度：** A 改成 255（第 3 节）。
- **会变的东西：**
  - 矿石的反照率变了（多了颗粒）。
  - 原矿物品的图集和图标跟着重新生成（`build-field-stone.mjs`）：煤块、含金石英、黄铜矿、方铅矿、赤铁矿、闪锌矿。
  - 对比图 `design/world/ore_u3b/ore_u3b_candidates.png` 也更新了。

## 9. 进游戏看什么

用普通测试世界，不用正式存档；开 Aureveil。

1. **洞壁：** 拿手电照，看起伏和缝隙比以前明显，没有细线、没有一格一格的重复、没有缝。
2. **断面：** 用镐在花岗岩或基岩上凿一个面，拿手电左右晃，看颗粒一颗颗地闪，不是一片均匀的反光，也不是满屏噪点。
3. **矿石：** 看金属颗粒在手电下闪；矿石表面不再整体往里陷，网格小块边上没有错位。
4. **不开光影：** 岩石和以前一样，矿石的颗粒多了一些。
