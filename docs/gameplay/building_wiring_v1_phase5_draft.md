- 第 5 阶段是设计 [第 18 节](building_wiring_v1_design.md) 的"布线工具和透视"。
- 现在扳手怎么用见 [建筑暗线 V1](building_wiring_v1.md) 第 3、8 节。
- 这份草案代替设计第 7.2 节的老操作（起点列表、选颜色、确认框），也改了第 7.4 节的设备标记颜色。确认后把定下来的写回设计文档。

## 0. 要解决的事

验收时你会在老宅里挪一盏灯、一个开关、一个插座，再自己接上。现在做不到的有三件：
1. **线头只能是常亮**。扳手接上的灯和开关都是 0 组，开关管不了灯，只能用开发指令改组。
2. **隔着墙接线不方便**。从墙里已有的线接到新位置，要对着墙一格一格扫，看不见墙里面怎么走。
3. **看不出接没接好**：哪个设备接了哪一路、哪一组，有没有漏接，现在都看不见；别的回路也看不见。

## 1. 按键总览（扳手在主手）

| 操作 | 平时 | 选了起点以后 |
|---|---|---|
| 右键 / 按住右键扫 | 布线（和现在一样） | 预览到准星这一格 / 这个设备；再点同一个终点 = 确认 |
| 潜行 + 右键 | **起点**（新） | 途经点 |
| 左键 | 剪线（和现在一样） | 取消 |
| 潜行 + 滚轮 | 换回路（和现在一样） | 换回路（预览跟着换） |
| 中键 | 换到准星格里的别的回路（和现在一样） | — |
| 潜行 + 中键 | **显示全部 / 只看本路**（新） | 同左 |
| 右键一个灯或开关 | 布线并**选组**（新，见第 3 节） | 当终点 |

只有"选组"会弹一个小界面，别的操作都只是看着世界按键，右上角的按键提示跟着状态变。

## 2. 两点连线：起点 → 终点 → 确认

适合隔着墙、距离远的一段，比如从墙里已有的线接到新挪的灯。

1. **起点**：潜行 + 右键一格。可以是：
   - 有当前回路的线的一格；
   - 配电箱（从它背后那一格出线）；
   - 设备（从它的安装格出线）；
   - 任何一格能铺线的方块（另起一段，铺完后靠自动连接接上旁边的同一路）。
   
   起点那一格出现一个当前回路颜色的小环。
2. **预览**：对着终点右键（设备，或者一格能铺线的方块）。
   - 服务端寻路，客户端画一条当前回路颜色的虚线，透墙；
   - 提示面板的状态行写"预览 14 m · 新线 9"：一共几格，其中几格是新铺的。走已有的线不耗线；
   - 对着别处再右键，就重新预览到那里。
3. **途经点**（可选）：预览时潜行 + 右键一格能铺线的方块，路线必须经过它。按点的顺序最多 4 个，每个画成一个小菱形。想让线走墙里而不是地板下，就点一下墙。
4. **确认**：对着同一个终点再右键一次。
   - 服务端重新算一遍路线。和预览一样就铺，扣铜线；不一样（这期间有人改了方块）就只换成新的预览，不铺，再点一次才铺；
   - 铜线不够，提示"导线不够"，不铺；
   - 铺完以后和现在扫线一样：自动连邻格、给设备接线头、拐角自动接线；
   - 终点是灯或开关时，铺完接着弹选组（第 3 节）。
5. **取消**：左键，或者换下扳手。有起点时左键只取消，不剪线。

**寻路的上限**：
- 每一段（起点 → 途经点 → … → 终点）最多 96 格，包围盒外扩 8 格，最多访问 20,000 格，和开发指令 `route` 一样；
- 找不到路，提示"找不到路线"，起点保留，可以加途经点再试。

预览请求每个玩家最多每秒 4 次。

## 3. 选组

**什么时候弹**：
- 单独右键一个灯或开关：这一下铺线、接线头，接着弹选组。如果它已经接好了线，就只弹选组，所以"右键灯"就是改组；
- 两点连线的终点是灯或开关，确认后弹；
- 按住右键扫过去时经过的设备不弹，照样接成 0 组。提示面板和设备标记会显示"常亮"，回头再单独点一下改。

插座和应急灯只能是常亮，不弹。

**样子**：一个小面板，现代风格，和生存 HUD、配电箱界面同一套（深色半透明、暖色细线）。

```
  无开关瓷灯座 · 第 1 路 ●红
  ┌────────────────────────────────┐
  │  常亮                           │
  │  组 1   2 灯 1 开关    ✓        │  ← 现在的组打勾
  │  组 2   1 灯 1 开关             │
  │  新组 3                         │
  │  光控                           │  ← 只有灯有
  └────────────────────────────────┘
```

- 列出这一路已经用着的组，后面写这一组有几盏灯、几个开关；再列"新组"，取这一路还没用的最小组号，8 个都用了就没有这一项。
- 开关没有"常亮"和"光控"：常亮的开关什么也不管，光控只给灯用。
- 点一项马上生效、关掉面板；Esc 不改。没有"确定"按钮。
- 改了组以后，配电箱马上重新对一次：开关跟着组的开关状态扳过去，灯马上重新检查。
- 数字来自配电箱上一次的求解。这一路没接到配电箱的时候，只列"常亮、新组 1、光控"。

## 4. 透视

和现在一样，只在扳手或铜线拿在手上时出现，只发周围 5 × 5 个区块。改的地方：

1. **墙后变暗**：看得见的线正常画，被方块挡住的部分画成 40 % 透明。现在是全部同样亮。做法：先画一遍有深度测试的，再画一遍没有深度测试的半透明线。
2. **显示全部**（潜行 + 中键开关，换下扳手就回到关）：
   - 别的回路也画出来，细一半、暗一半，只画看得见的部分，不透墙；
   - 当前回路照常透墙；
   - 提示面板状态行后面加"· 全部"。
3. **设备标记**：周围的接线设备在设备中心画一个小环，朝着你。
   - 接上了线头：环是线头那一路的颜色。旁边一个小字：灯和开关写"组 1""组 2""常亮""光控"，插座不写。只看本路时，别的回路的设备只画环不写字；
   - 没接线头：灰色空心环，写"未接线"；
   - 配电箱、进线盒、电表箱：环外加一圈，表示接线点。
   
   **和设计第 7.4 节的不同**：原来写"绿 = 有电、黄 = 没电、红 = 没接线"，可现在线的颜色本身就有红、绿、黄，会混。所以标记只表示接线和组，有没有电看 Jade（灯、插座、配电箱的 Jade 都已经有）。
4. **两点连线的预览**（第 2 节）：虚线、起点的环、途经点的菱形，都透墙。
5. 不改的：线的粗细、颜色、锚点、屋顶上的走法；只画 48 格以内；跳过光影的阴影 pass；Sundial 下透视不显示的老问题不修（用户在开发自己的光影包）。
6. 现在每帧重画。第 5 阶段改成线变了、换了回路、开关了"显示全部"才重建顶点缓冲，第 7 阶段实测。

## 5. 按键提示（右上角面板）

每一项都只写一个动词：

| 状态 | 状态行 | 键 |
|---|---|---|
| 平时 | 第 1 路 · 红 · 53 m（开着"显示全部"时后面加 · 全部） | 右键 布线 · 潜行+右键 起点 · 左键 剪线 · 潜行+滚轮 换回路 · 中键 选第 N 路（能用时）· 潜行+中键 显示全部 / 只看本路 |
| 对着灯或开关 | 同上 | 右键 选组（已接好时）/ 布线（没接时） |
| 选了起点 | 起点 · 第 1 路 | 右键 预览 · 左键 取消 |
| 有预览 | 预览 14 m · 新线 9 | 右键 确认（对着终点）/ 预览（对着别处）· 潜行+右键 途经点 · 左键 取消 |

对着配电箱时的那一行（范围供电、互连）照旧。

## 6. 挪东西以后怎么重接（验收的三件事）

- **挪一盏灯**：
  1. 空手拆下灯，放到新位置。旧的线头留在墙里，不碍事；
  2. 拿起扳手，旧线是哪一路就换到哪一路：对着旧线按中键，或者潜行 + 滚轮；
  3. 潜行 + 右键旧线（起点），右键新灯（预览），再右键新灯（确认）；
  4. 弹出选组，点原来那个组。
- **挪一个开关**：同上，选组时点它要管的那一组。
- **挪一个插座**：同上，或者直接沿墙扫过去；不弹选组。

## 7. 不在第 5 阶段

- 剪线还是一格一格剪，没有"剪一整段"；
- 配电箱界面上不能扳组，只显示（第 3 阶段定的）；
- 没有配方、没有音效；扳手的第一、第三人称显示变换不动；
- 结构模板带线是第 6 阶段。

## 8. 要你定的（用户 2026-10-14："都同意"）

1. **选组用小面板**（第 3 节），点一项就生效。另一种做法是不弹面板，在世界里用滚轮换组。我推荐面板，看得到每组有几盏灯。
2. **起点用潜行 + 右键**，"显示全部"用潜行 + 中键。
3. **设备标记不表示有没有电**，只表示接线和组，有没有电看 Jade（第 4 节第 3 条）。
4. **右键已接好的灯或开关就是选组**。扫线经过时不弹。
