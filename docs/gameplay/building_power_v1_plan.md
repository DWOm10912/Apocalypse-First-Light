# 建筑供电与电网 V1 规划（未实现）

状态（2026-10-07）：**规划，没有任何代码**。

目标：有电、没电、拉闸后会发生什么，要合乎现实，玩家一看就懂；但不去模拟城市里的每一根电线，也不让建筑模板里到处都是电缆。

遵循 AFL 的三条原则：
- 现实逻辑优先；
- 以美式为基础，可以自由组合；
- 有哥伦比亚联邦自己的辨识度，比如联邦的电力公司标识和设备配色，不照搬美国电力公司。

## 现实里的电是怎么到一栋楼的

发电厂 → 高压输电（铁塔）→ 变电站降压 → 配电线路（电线杆或地下）→ 变压器（杆上的圆桶，或地上的绿色箱式变压器）→ 进户线 → **外墙电表和总开关（一栋楼只有这一个进户点）** → **配电盘（分路断路器）** → 墙里和天花板里的线路 → 插座、灯、设备。

## 现在 AFL 有什么

- 实体电缆网（[Power Cable V2](../models/power_cable_v2.md)）：发电机或能量单元 → 一格一格的电缆 → 设备背面的电源接口。
  - 每 tick 扫描一次，一张网最多 4096 段，不储电、没有损耗，不强制加载区块。
- 用电设备（2026-10-01 定）：
  - 冷柜、冰柜、售货机、充电站、加油机走电缆；
  - 手持工具自带电池，在充电站充；
  - 吸顶灯当时定成充电式，理由是天花板上拉电缆难看。
- 配电箱（[Industrial Electrical Box V2](../models/industrial_electrical_box_v2.md)）**不属于电力系统**，只是能开门搜刮的容器。

## 方案：两层

### 第一层：建筑（先做这一层）

**配电盘就是这栋楼的总闸**，由现有的配电箱升级而来，一栋楼一个。
- **进线口**（一个电源接口）：接外墙电表（以后的城市电网），或者用电缆接发电机、能量单元。
- **总闸**：右键拉闸、合闸，状态写在方块上；配电箱的门板上能看出合闸还是断开。
- **"这栋楼有电"**：进线有电，并且总闸合上。
- **管辖范围（暗线覆盖）**：
  - 自动生成的建筑：模板的范围（StructureDefinition 记录配电盘位置和建筑范围）；
  - 玩家自己盖的：配电盘周围连通的室内空间，只在墙和顶棚围住的范围里扩散，有上限。
  - 这样玩家不需要在墙里、天花板上拉电缆，墙里的线路默认存在，就像真实建筑。
- **总负载**：范围内所有设备的耗电加起来，不能超过进线能提供的功率。超了就**跳闸**（总闸自动断开），要玩家减负载后重新合闸。这比"电不够就全部变暗"更真实，也更好理解。
- **零件**：配电箱原来的 9 格容器可以放保险丝、断路器这类零件。配电箱被炸、坏了要换零件才能合闸（以后再做）。

**楼里的设备分三类**：

| 类别 | 例子 | 怎么取电 |
|---|---|---|
| 固定照明、内置设备（暗线） | 吸顶灯、台式电脑、显示器、招牌、灯箱 | 在某个配电盘的范围里就自动接上暗线，楼里有电就工作，没电就灭；不需要接口和电缆 |
| 插在墙上的电器 | 冷柜、冰柜、售货机、饮水机 | 电源接口贴着范围内的墙或地面时，算插在墙上的插座上，楼里有电就工作；接口不贴墙时（比如岛式设备），要从配电盘拉一段可见电缆，或从地下走线 |
| 不在楼里的设备、玩家野外的设备 | 野外的充电站、加油站外的设备 | 和现在一样，必须用电缆接发电机或能量单元 |

- **可移动的充电式设备**（手电、盖革计数器、玩家自己挂的灯）不归配电盘管，按现在的规则自带电池、去充电站充。
- **吸顶灯**两种情况都能用：在有电的楼里走暗线，同时给自带的电池充电；没电时靠电池撑一段时间，像应急灯。这样保留了 2026-10-01"天花板不拉电缆"的决定，又让停电的楼是暗的。
- **对 2026-10-01 决定的修改（需要用户确认）**：当时定的是"电器只走电缆，不做插头、插线板"。这里加了一条：电器在有配电盘的楼里贴墙放，算插在墙上的插座上。这不是插头或插线板物品，玩家也不需要放任何东西，是楼里的暗线。楼外和岛式设备仍然走电缆。

**照明开关（可选，以后再做）**：墙上的开关只管自己房间里的暗线灯，总闸管整栋楼。第一版只有总闸。

### 第二层：电网（以后做）

- **虚拟电网**：变电站 → 配电线路 → 变压器 → 各栋楼的进户点，记成世界数据里的一张图，不铺实体电缆。
- **看得见的部分只是模型和修复点**：变电站、电线杆、架空线、箱式变压器。损坏按片区记录，修复做成几个明确的修复点，不逐根模拟。
- **末日逻辑**：开局电厂停了，全城停电。玩家有三条路：
  - 每栋楼自己发电：发电机接配电盘；
  - 地块微电网：一台大发电机接箱式变压器，带同一地块的店、顶棚、价格牌；
  - 修复变电站并提供电源，恢复一整片街区。

| 变电站（围栏场地、变压器、开关柜） | 城市边上 | 第二层 |

## 对 A1 便利店的意义（现在就按这个摆）

- **设备间的配电箱** = 这家店的配电盘（总闸）；**后墙外的配电箱** = 进户点，接口文档里标的"以后接城市电网"的位置。两个都保留。
- **三台饮料冷柜**：背面朝冷库里面，接口不贴墙。需要一段可见电缆：从设备间穿过冷库隔墙，沿冷库地面接到三台冷柜背后。这段在员工后场，看得见也合理。
- **冰淇淋冰柜**：靠东墙，背面接口贴着外墙，按"插在墙上"取电，不需要电缆。
- **吸顶灯、收银机**：算暗线。
- **整体状态**：这家店是"战前完好但停电"。等配电盘有了功能，玩家把发电机接到设备间配电箱的进线口、合上总闸，冷柜、冰柜、灯就一起工作。
