# 建筑供电与电网 V1 规划

状态（2026-10-07）：**第一层定案，开始实现**（见下面"V1 定案"）。第二层电网仍是规划。
- 第一步已写完、编译通过、未实机验证：配电盘、电表箱，见 [Building Power V1](../models/building_power_v1.md)。
- 第二步 2026-10-08 写完：插座、插头电源线、小电器改插头（[Power Outlets V1](../models/power_outlets_v1.md)），吸顶灯和应急灯（[Building Lights V1](../models/building_lights_v1.md)）。

目标：有电、没电、拉闸后会发生什么，要合乎现实，玩家一看就懂；但不去模拟城市里的每一根电线，也不让建筑模板里到处都是电缆。

遵循 AFL 的三条原则：
- 现实逻辑优先；
- 以美式为基础，可以自由组合；
- 有哥伦比亚联邦自己的辨识度，比如联邦的电力公司标识和设备配色，不照搬美国电力公司。

## V1 定案（用户 2026-10-07 确认）

概念图和关系图之后，用户逐条定下的第一层规则。下文更早的段落里和它不一致的地方，以这里为准，已在原处标了"作废"。

**取电方式**：

| 设备 | 怎么取电 | 例子 |
|---|---|---|
| 吸在天花板上的灯 | 在配电盘范围内自动有电，和加油站顶棚灯一样（2026-10-08 已做：每盏 1 FE/t，接"照明"那一路） | 方形面板灯、线形灯；以后的嵌入式灯盘 |
| 小功率、能挪动的电器 | 自带电源线和三孔插头，插在墙上的插座上 | 饮料冷柜、冰柜、售货机、饮水机，以后的落地灯、台灯 |
| 大功率电器、机器 | 能源线缆：从配电盘的出线口，或者直接从发电机、能量单元 | 充电站、加工机器 |
| 固定安装、从地下接电的设备 | 底面的标准钢接口，硬接线（不插插头） | 加油机、顶棚立柱，以后的路灯 |

- **分界值**：峰值不超过 16 FE/t 的能挪动电器走插头，超过的走线缆。数值写在数值文件里，可以再改（用户说"数值等会定"）。按现有数值：冷柜 5、冰柜 7、售货机 1、饮水机 1 走插头，充电站 128 走线缆。
- **小功率电器的接口**：去掉背后的 6 × 6 钢接口，改成背后底部的 IEC C14 电源插座和可拆电源线（C13 接头 + 三孔插头）。改了之后它们不能再直接接线缆；野外用要等插线板。（2026-10-08 已做：电源线 4 格，用户要求比插线板的长，见 [Power Outlets V1](../models/power_outlets_v1.md)。）
- **插座**：新方块，**只能装在墙上**（用户 2026-10-07：地插不做，以后做插线板）。北美双联三孔插座，薄面板、无碰撞。
  - 装在地面那一格离地约 0.35 m，装在第二格约 1.35 m（柜台上方）。
  - 在配电盘范围内自动有电（暗线）。
  - 每个插座两个插孔。电源线 2.5 格，手动插拔：空手右键电器背后拿起插头，再右键插座插上。
  - 生成的建筑沿墙预留插座，间距约 3.6 m，柜台上方另有一排。插座占墙前那一格，所以一般装在电器旁边。
- **插线板**：以后做。带一个标准钢接口接线缆，上面几个插孔，给野外和离墙太远的设备用。

- **插座和插线板（2026-10-08 已实现，未实机验证）**：用户选了放大 1.5 倍、白色面板、黑色塑料插线板、只用插头、先只放地面和桌面。见 [Power Outlets V1](../models/power_outlets_v1.md)。下面是当时概念图的记录。

## 现实里的电是怎么到一栋楼的

发电厂 → 高压输电（铁塔）→ 变电站降压 → 配电线路（电线杆或地下）→ 变压器（杆上的圆桶，或地上的绿色箱式变压器）→ 进户线 → **外墙电表和总开关（一栋楼只有这一个进户点）** → **配电盘（分路断路器）** → 墙里和天花板里的线路 → 插座、灯、设备。

## 现在 AFL 有什么

- 实体电缆网（[Power Cable V2](../models/power_cable_v2.md)）：发电机或能量单元 → 一格一格的电缆 → 设备背面的电源接口。
  - 每 tick 扫描一次，一张网最多 4096 段，不储电、没有损耗，不强制加载区块。
- 用电设备（2026-10-01 定）：
  - 冷柜、冰柜、售货机、充电站、加油机走电缆；
  - 手持工具自带电池，在充电站充；
  - 吸顶灯当时定成充电式，理由是天花板上拉电缆难看。
- 配电箱（[Industrial Electrical Box V2](../models/industrial_electrical_box_v2.md)）**不属于电力系统**，只是能开门搜刮的容器。（2026-10-07 已删除。）

## 方案：两层

### 第一层：建筑（先做这一层）

**配电盘就是这栋楼的总闸**，一栋楼一个。（"由现有的配电箱升级"已作废：用户 2026-10-07 选了新做的配电盘，见"V1 定案"。）
- **进线口**（一个电源接口）：接外墙电表（以后的城市电网），或者用电缆接发电机、能量单元。
- **总闸**：右键拉闸、合闸，状态写在方块上；配电盘的门板上能看出合闸还是断开（作废：总闸在界面里拉，开门能看到拨杆）。
- **"这栋楼有电"**：进线有电，并且总闸合上。
- **管辖范围（暗线覆盖）**：
  - 自动生成的建筑：模板的范围（StructureDefinition 记录配电盘位置和建筑范围）；
  - 玩家自己盖的：配电盘周围连通的室内空间，只在墙和顶棚围住的范围里扩散，有上限。
  - 这样玩家不需要在墙里、天花板上拉电缆，墙里的线路默认存在，就像真实建筑。
- **总负载**：范围内所有设备的耗电加起来，不能超过进线能提供的功率。超了就**跳闸**（总闸自动断开），要玩家减负载后重新合闸。这比"电不够就全部变暗"更真实，也更好理解。
- ~~**零件**：配电箱原来的 9 格容器可以放保险丝、断路器这类零件。~~（作废：配电箱已删除，配电盘没有容器。要不要做坏了换零件，以后再定。）

**楼里的设备分三类**：

| 类别 | 例子 | 怎么取电 |
|---|---|---|
| 固定照明、内置设备（暗线） | 吸顶灯、台式电脑、显示器、招牌、灯箱 | 在某个配电盘的范围里就自动接上暗线，楼里有电就工作，没电就灭；不需要接口和电缆 |
| 插在墙上的电器 | 冷柜、冰柜、售货机、饮水机 | ~~电源接口贴着范围内的墙或地面时，算插在墙上的插座上~~（作废，2026-10-07 改为插头加墙上插座，见"V1 定案"） |
| 不在楼里的设备、玩家野外的设备 | 野外的充电站、加油站外的设备 | 和现在一样，必须用电缆接发电机或能量单元 |

- **可移动的充电式设备**（手电、盖革计数器、玩家自己挂的灯）不归配电盘管，按现在的规则自带电池、去充电站充。
- ~~**吸顶灯**两种情况都能用：在有电的楼里走暗线，同时给自带的电池充电；没电时靠电池撑一段时间，像应急灯。~~（作废，2026-10-08：吸顶灯只走暗线，停电就灭；带电池、停电时亮的是单独的应急灯，见 [Building Lights V1](../models/building_lights_v1.md)。"天花板不拉电缆"仍然成立。）
- **对 2026-10-01 决定的修改（用户 2026-10-07 同意，同日又被"V1 定案"取代）**：当时定的是"电器只走电缆，不做插头、插线板"。这里加了一条：电器在有配电盘的楼里贴墙放，算插在墙上的插座上。这不是插头或插线板物品，玩家也不需要放任何东西，是楼里的暗线。楼外和岛式设备仍然走电缆。

**照明开关（可选，以后再做）**：墙上的开关只管自己房间里的暗线灯，总闸管整栋楼。第一版只有总闸。

### 进户点和配电盘：两个箱子，两种作用（2026-10-07 补充）

- **外墙电表 / 总开关箱 = 进户点**：电从这里进楼。
  - 城市电网（第二层）通电的终点就是它。
  - 要看得见时，地下电缆从它正下方接上来，电源接口开在箱子**底面**，和"地下供电设备接口开在底面"的规则一样（加油站顶棚立柱、加油机已经这样做）。
  - 停电时，玩家也可以把发电机的电缆接到这里，相当于外墙的发电机接口。
- **设备间的配电盘 = 总闸**：管整栋楼的暗线和插座。它和进户点属于同一栋楼，穿墙那段按暗线算，不拉电缆。
- 两个箱子各干一件事，不重复。（作废：配电盘和电表箱各有新模型，旧配电箱已删除。）

### 已有的先例：加油站顶棚（[Fuel Canopy Kit V1](../models/fuel_canopy_kit_v1.md)）

- 只有立柱底座的**底面**一个电源接口，电缆从地下接上来；立柱、吊顶、灯板、边檐**自己带线**，连成一个网络（`FuelCanopyNetwork`，最多 4096 格）。
- 灯按网络电量决定亮不亮：每盏灯 1 FE/t；灭着时要攒够两个周期的电才亮，弱供电不闪；一个底座最多带 100 盏灯。
- 建筑配电照搬这套规则：缓存、每件设备的耗电、攒够再亮。区别只在"连在一起的顶棚方块"换成"配电盘管辖范围里的设备"。墙和地板是普通方块，不能每块都带线，所以用范围来算。

### A1 整个地块的线路（加油区那一轮落实）

```text
地块边的箱式变压器 → 地下 → 外墙进户点（店后墙）→ 设备间配电盘
  → 店里的暗线、插座；冷柜那一段电缆在冷库里
  → 前场地下电缆 → 顶棚立柱底座（底面接口）→ 顶棚灯
                 → 加油机（底面接口）
```

现实里加油站顶棚和加油机的电也来自店里的总配电盘，走前场地下的线管。接口文档 P1 里的"设备间 → 顶棚的电缆"就是这一段，铺在模块的地下层里。

### 第二层：电网（以后做）

- **虚拟电网**：变电站 → 配电线路 → 变压器 → 各栋楼的进户点，记成世界数据里的一张图，不铺实体电缆。
- **看得见的部分只是模型和修复点**：变电站、电线杆、架空线、箱式变压器。损坏按片区记录，修复做成几个明确的修复点，不逐根模拟。
- **末日逻辑**：开局电厂停了，全城停电。玩家有三条路：
  - 每栋楼自己发电：发电机接配电盘；
  - 地块微电网：一台大发电机接箱式变压器，带同一地块的店、顶棚、价格牌；
  - 修复变电站并提供电源，恢复一整片街区。
