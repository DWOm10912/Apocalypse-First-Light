## 1. 是什么

镀银的老式防风翻盖打火机：拇指翻开盖子，滚动火石轮打火，点着以后伸在身前照明，合上盖子灭火。

- 物品 `apocalypse_firstlight:flip_lighter`，不堆叠；重量 0.06 kg（估计），网格背包里 1×1。
- 中英文名：翻盖打火机 / Flip Lighter。
- 网格：`tools/build-equipment-meshes-v1.mjs flip_lighter`（见 `docs/models/equipment_meshes_v1.md` 2026-10-20 一节）。
- 代码：
  - `item/FlipLighterItem`：状态和使用逻辑，只由服务端决定；
  - `client/FlipLighterRenderer`：盖子、轮子、火苗；
  - `client/FlipLighterClient`：导演镜头、火星、动态光源；
  - `client/skeleton/SkeletonActions#lighter`：手上的动作。

## 2. 操作（主手）

| 当前状态 | 右键 | 结果（物品标签 `Act`） |
|---|---|---|
| 合着 | 翻开盖子 | `open` |
| 开着、没点着 | 滚轮打火 | 有燃油时 85% 点着（`strike`），否则只有火星（`spark`） |
| 开着、没点着 | 潜行 + 右键 | 合上（`close`） |
| 点着 | 潜行 + 右键 | 合上盖子，火灭（`close_lit`） |
| 点着 | 右键（没对准能点燃的方块） | 没有反应，火继续烧 |
| 点着 | 对准营火、蜡烛、蜡烛蛋糕 | 点燃（方块的 `lit` 设为真） |
| 点着 | 对准 TNT | 点燃 TNT |
| 点着 | 对准柴炉（有柴、没点着） | 点燃柴炉，用掉 100 tick 燃油 |

- 不能对方块放火（第一、二轮能在可燃方块的一面放火，第三轮按用户要求去掉）。对准其他方块右键，和对着空气一样：合着就翻开，开着就打火。
- 合上只用潜行 + 右键（第一轮点着时普通右键也会合上，用户说不对，第二轮改掉）。
- 一个动作做完之前，再按右键无效：翻开 10 tick、打火 10 tick、没点着 7 tick、合上 6 tick。
- 火苗在打火 0.16 s 后才出来；这之前对方块右键不会点燃。
- 准星对准没点着的营火、蜡烛、TNT 时，交互提示显示「点燃」（`hint.apocalypse_firstlight.flip_lighter.light`）。

## 3. 状态和数值

**物品标签**（`FlipLighterItem`）：

| 键 | 含义 |
|---|---|
| `Open` / `Lit` | 开着 / 点着 |
| `Used` | 已经烧掉的 tick，满量 `FUEL_TICKS` = 36000（约 30 分钟） |
| `Act` / `ActAt` | 最后一个动作和它开始的游戏刻，所有客户端的动作、盖子、火苗都按它算时间 |
| `Snd` / `SndAt` | 等着播放的音效和时刻（声音跟着动作走，例如盖子在 0.30 s 才被翻开） |

**燃油**：
- 点着时每 20 tick 扣 20；点燃方块扣 20；点燃柴炉扣 100（`STOVE_LIGHT_TICKS`）。
- 用完时火自己灭（`Act` = `out`）。
- 物品栏耐久条显示剩余燃油（琥珀色），说明里写「燃油：N%」。

**自动熄灭和合上**：
- 头没入水里：灭（`out`），播原版熄火声。下雨不灭（防风打火机）。
- 不在主手（换格子、放进背包）：直接合上、熄灭，没有声音。丢出去也一样。

**点燃油斑**（`fluid/FuelSpills`）：
- 打火（不论点没点着）：火苗位置 0.9 格内的油斑受一次火星（只有汽油会着）。
- 点着时每 10 tick：0.9 格内的油斑受 10 tick 的火（汽油立刻着，柴油要累计）。
- 火苗位置服务端按视线估算：眼前 0.29 格、右边 0.12 格、比眼睛低 0.09 格（点着姿势的火苗位置）（`FlipLighterItem#flamePoint`）。

## 4. 动作

### 4.1 时间表（和 `FlipLighterItem` 的常量对应）

| 动作 | 内容 |
|---|---|
| `item/flip_lighter` | 还没有动作时（刚拿出来）：低位拿着，淡入 0.25 s |
| `item/flip_lighter_open` | 0–0.28 s 从腹前抬到胸前；0.30–0.42 s 拇指翻开盖子（手跟着顿一下），盖子甩过头再弹回 105° |
| `item/flip_lighter_strike` | 左手 0–0.15 s 过来护火；0.10–0.22 s 拇指滚轮（手往下压一点）；0.16 s 火苗点着，先窜高再落回；0.45 s 左手离开；0.35–0.8 s 伸到身前偏右（跟视线） |
| `item/flip_lighter_spark` | 同上的护火和滚轮，没有火苗，停在胸前 |
| `item/flip_lighter_close` | 0.08–0.18 s 盖子合上；0.15–0.5 s 手放回腹前 |
| `item/flip_lighter_close_lit` | 0.08–0.18 s 盖子合上、火苗被盖灭；0.18–0.6 s 手放回腹前 |
| `item/flip_lighter_out` | 火苗 0.4 s 内变小熄灭；手从身前收回到胸前 |

- 三个姿势：
  - **低位**（合着）：胸口坐标系，腹前；第一人称平视时看不到，低头才看到。
  - **预备**（开着）：胸口坐标系，胸前偏右，手肘弯 46°；平视时盖子露在画面底部。
  - **点着**：视线坐标系，手臂几乎伸直举在胸前偏右，火苗在视线下 17°、偏右 23°（第一轮在视线高度、贴着脸，太近）；`view_pitch` [-40, 35]，抬头低头超过这个范围就不再跟。
- 只用道具关键帧和手的目标（和撬棍一样），没有骨骼片段；`first_person` 是 `body`，第一人称画身体的手臂。
- 除了 `item/flip_lighter`，所有动作 `blend.in` 都是 0：每段的开头就是上一段的结尾，切换时不会先淡回原版姿势。
- 没有动作记录但开着或点着（例如重进存档）：按 `open` / `strike` 早已做完处理，直接是预备 / 点着姿势。
- 左手玩家镜像。

### 4.2 道具 `player_props/flip_lighter.json`

- 比例 0.2：打火机高 2.3 模型像素，和 4 像素宽的拳头的比例接近真实打火机和拳头（第一轮 0.3，第一人称显得太大）。
- 点（物品单位，网格 + (0.5, 0.14375, 0.5)）：
  - `grip`：手掌，在外壳底下 1.4 像素，所以外壳底部刚好在拳头上沿里面，外壳和盖子露在拳头外；
  - `flame` 灯芯顶、`wheel` 火石轮、`thumb` 拇指推盖子的地方、`cup` 左手护火的位置（打火机左边略靠前）。
- 盖子铰链朝玩家右边，宽面朝眼睛。

### 4.3 怎么做的、怎么检查

- 动作和道具由 `tools/author-flip-lighter-actions.mjs` 生成（`--check` 检查是否过期，`--report` 打印解算结果）。
- `--report` 用 AFL Rig 插件的解算核心（`tools/blockbench/afl_rig.js`，和游戏的 Java 解算逐点对拍过）算每个动作在 0、0.15、0.3、0.45、0.8 s，俯仰 0° 和 40° 时：
  - 淡入完成以后，两只手离目标都是 0 px（所有动作、所有时刻）；
  - 右手伸展（肩到手掌 / 手臂长）：低位 0.79，预备 0.92，点着 0.94–0.96；肘弯：低位 75°，预备 46°，点着 34–40°；腕弯都在 12° 以内，前臂扭转在 12° 以内；
  - 左手护火伸展 0.98（护火点第二轮从打火机左边 4.4 改成 3.6 像素，不然够不到）；
  - 平视时火苗在视线下 27°（预备）、17°（点着），偏右 23–24°；低头 25° 打火时火苗差不多在画面中间。
  - Minecraft 的肩膀在眼睛后面 2.5 像素，手臂伸直也只能把打火机放到眼前约 0.3 格，所以第二轮主要靠缩小打火机和放低位置让它显得远。
- Blockbench（MCP，2026-10-20，第一轮的姿势；第二轮只做了离线解算）：新建 AFL 骨架工程，导入道具和打火、点着的动作，按游戏的眼睛位置截了第一人称（16:9，视野 70°）和第三人称图：
  - 点着后打火机在画面右下、正面朝镜头，铰链在右；
  - 打火时（导演镜头低头 25°、往后拉）打火机在画面中间，左手在左边护火。
  - 用户装的插件文件在 `AFL-survivor-v0`，没有改它；插件文件本身给脚本接口加了 `mergeLook`（把 .bbmodel 并进道具外观），这次截图没用到它。
- 调整过程：第一版低位、预备离肩膀太远，手臂伸直；打火机 0.4 比例在第一人称太大、外壳大半被拳头挡住；左手够不到护火点。都改过。

## 5. 第一人称镜头（导演镜头）

`client/FlipLighterClient`，`CameraDirector` 请求 `afl_flip_lighter`（优先级 `PRIORITY_MACHINE`，游戏时钟）：

- 只在自己的第一人称、骨架画手臂时（`SkeletonActions.drawsArms()`）。
- 翻盖、打火时，镜头低头到至少 25°，同时往后拉 0.1 格（第一轮 0.18）、往上 0.06 格，两只手和打火机都在画面里（在第一人称身体照常显示的范围内：水平 0.3、竖直 0.6 格）。淡入 0.2 s、淡出 0.35 s。
- 翻盖、没点着之后镜头再停 1.2 s，等着打火；点着时随打火机抬起回到视线；合上时如果镜头还低着就回来。
- 手在动的时候锁鼠标视角（另一个请求 `afl_flip_lighter_lock`，只锁 `LOOK`）：翻盖 0.45 s、打火 0.3 s、没点着 0.25 s。
- 环绕镜头（第三人称）下不开。

## 6. 画面、声音、光

- **盖子**：部件名以 `lid` 开头的绕铰链（网格 (3.7891, 7.3)，z 轴）转，开 105°；翻开时快速甩过头 10° 再弹回，合上时越来越快。
- **轮子**：绕轴 (1.8391, 10.45) 转 150°。
- **火苗**：
  - 灯芯顶上一块面片，绕打火机自己的竖轴转向镜头；高 3.5 cm（网格 7 px），加法混合、满亮度（`LiquidRenderTypes.LIGHTER_FLAME`）。
  - 贴图 `textures/effect/lighter_flame.png`（+ `_s` 自发光），`tools/build-lighter-flame-v1.mjs` 程序生成：16 帧 4×4，每帧 32×64，每秒 24 帧循环；圆底、肩部在四分之一高度、尖端摆动，底部一圈淡蓝、灯芯上方暗一点、主体黄白、边缘偏橙、尖端暗红；高度、摆动、尖端抖动都是相位的整数倍谐波，首尾相接。
  - 大小：点着时先小、0.06 s 内窜到 1.25 倍再落回；平时有两层轻微闪烁；合盖时被盖灭；`out` 时 0.4 s 变小。
  - 物品栏图标（GUI）不画火苗。
- **火星**：打火（点没点着都有）时，从火石轮甩出 3–6 道短亮线（`FireFx#flintSparks`），所有玩家都看得到。
- **光**：点着的打火机给两个半球光（向下、向上），暖色 (1.0, 0.68, 0.38)，6 格内，近处 9 级、4.2 格处 2 级，跟着火苗大小闪（`DynamicLights`）。48 格内的玩家都算。
- **声音**（`sounds.json`，现在是原版事件占位）：

| ID | 占位 | 字幕 |
|---|---|---|
| `flip_lighter_open` | 铁活板门开，音调 1.9，音量 0.35 | 打火机：翻开盖子 |
| `flip_lighter_strike` | 打火石，音调 1.4，音量 0.6 | 打火机：打火 |
| `flip_lighter_close` | 铁活板门关，音调 1.9，音量 0.35 | 打火机：合上盖子 |

  - 听得到的范围和噪声半径都是 4 格（`NoiseType.INTERACTION`）。
  - 要换成 Firefly 一次录音：翻盖的「叮」、滚轮的「擦」、合盖的「咔」，从一条录音里切。

## 7. 和其他系统

- 柴炉（`cabin/BoxStove#igniter`）：点着的打火机算点火物，点炉子时扣燃油、不播打火石声。原版改动 V1 记录的「柴炉点不着」，在有打火机以后解决了一半：还缺获取渠道（第 8 节）。
- 骨架关着时：用原版第一人称手持（模型的 `firstperson_righthand` 显示变换），盖子、火苗照样画，没有动作和镜头。
- 换手动画：标签一直在变，覆写了 `shouldCauseReequipAnimation`，只有换格子或换物品时才重新举起。
