**状态（2026-10-23）：** 用户："无光影时，尽量提供低成本中距离风动 / 先退役原版植被（P0）"。问题 2 按这句改了（第 4 节）；P0 开工，其余问题按推荐先走，P1 前再和用户确认。

**P0 已做（2026-10-23，原版退役 V1.9，只改数据，未实机）：** 见 `vanilla_survival_rework_v1.md` 4.13 节。和本文第 2 节的差别：苔藓毯、垂根、杜鹃丛归洞穴植被（地下重做）没退；以甘蔗、花为原料的配方（纸、糖、染料）不会被移除，只是原料拿不到；地堡的 6 盆原版盆栽换成了空花盆。

用户 2026-10-23 原话："我比较想做mesh植被，后面玩家可以用手采摘植被，拿去做草药什么的，然后让联邦生成真实的植被，并且有物理效果（能被压倒/被风吹）"，随后："我指的是先退役原版植被，然后再设计各类植被 / 甘蔗什么的也可以做，但是要做afl的"。

## 1. 目标和顺序

1. **先退役原版植被（P0）**：原版的草、花、蕨、甘蔗、浆果丛、睡莲、海草、小蘑菇等不再生成，也拿不到。
2. **再做 AFL 植被**：
   - 北美真实物种，用网格模型，和网格树同一套画法；
   - 按群系生成群落；
   - 会被风吹，会被人和车压倒；
   - 能用手采摘，部分植物的叶、花、根、浆果是草药或食材。
3. 甘蔗这类原版植物不照搬，换成北美湿地里真实的高大植物（宽叶香蒲、芦苇，见第 3 节）。

按原版退役 V1.x 的老办法（`docs/gameplay/vanilla_survival_rework_v1.md` 第 2、5、6 节），记作 **V1.9**。

**物品清单**：新文件 `retired/vegetation.json`，写明确的 ID，不引用原版标签，以后 AFL 植物进原版标签时不会被连带退役。接进 `unobtainable` 和 `creative_hidden`。

**效果**（三条老规则）：

- 创造栏隐藏，`/give` 照样能拿到。

**世界生成**：
- 新加群系修改器 `forge/biome_modifier/remove_vanilla_vegetation.json`（`forge:remove_features`），去掉这些地物：
  - `patch_grass_*`、`patch_tall_grass*`、`patch_large_fern`
  - `flower_*`、`forest_flowers`、`patch_berry_*`、`patch_dead_bush*`
  - `patch_sugar_cane*`、`patch_waterlily`
  - `brown_mushroom_*`、`red_mushroom_*`
  - `seagrass_*`、`kelp_*`、`patch_cactus*`、`bamboo*`、`vines`
- 20 个联邦群系 JSON（C 负责）不改。
- 只影响新区块。

**结构和代码**：
- 扫 AFL 结构 NBT：地堡的盆栽蕨，以及老宅、小镇里可能有的花。有 AFL 植物以后换成 AFL 的，P0 时先换成空花盆或去掉。
- 代码里有 5 处认原版植物（`FlattenedPlantBlock`、`SurvivorSpawns`、两处地堡放置、`AflBlocks`），只是用来识别，旧存档里还会有，所以都留着。

**旧存档**：已有的原版植物留在原地，挖掉不掉落（同 V1.1）。

**P0 之后到 P2 之前：** 新世界的地面只剩草方块的绿色，地上没有植物（问题 1）。

## 4. 画法

和网格树一致：画进 Embeddium 的区块网格，有 LOD，近处换成能动的一层。

- **模型**：每种植物用程序生成真实形状，就像网格树的 `TreeShape`：
  - 禾草是一束弯曲的叶片条带，每片分 3–4 节，节点就是弯曲点；
  - 花有茎、叶、花头；蕨是羽状叶；香蒲和芦苇是高茎加花穗。
  - 每种 8–16 个变体，按位置哈希挑选，不会排成一个样。
  - 不用原版那种十字面片。
- **贴图**：和树一样用 CC0 照片，128 px/m，带 LabPBR `_n`/`_s`（问题 4）。叶片的透明边缘用 alpha 裁切。
- **方块**：一格放一丛，按物种和变体用方块状态，不用方块实体。没有碰撞箱。
- **距离分层**：
  - **近层（相机 16 m 内，按区段算）**：不画进区块网格，由 AFL 自己的动态层画，有风和接触弯曲。网格树已经按距离重建区段做 LOD，这里沿用同一套。
  - **中层（16–64 m）**：画进区块网格。开 Sundial 时用着色器的摇摆植物 ID 随风动（同树木的 `TreeShaderIds`）。**不开光影时也要有低成本的风（用户 2026-10-23）**：P1 试在 Embeddium 的区块顶点着色器里加摇摆（资源包覆盖它的方块着色器，模型顶点里标出哪些点能摆、摆多少，加时间和区域风向的 uniform），GPU 算，不重建区段、不占 CPU；Embeddium 的着色器改不动时，退回把近层半径加大到 32 m。
  - **远层（64 m 以外）**：只画高草和灌木的简化版，矮草不画，地面颜色已经够了。Voxy 远景不收植被。
- **兼容**：按着色器支持原则，以 Sundial 为准，原版画面正确，其他光影不坏。动态层按 Oculus 的已知限制写：用自己的缓冲，在 `RenderTickEvent` 开始时烘好姿势。

## 5. 物理

- **风**：
  - 读 `weather/RegionalWeather` 的区域风场（风向、风速 m/s、阵风），下雨和树木用的也是这份数据。
  - 摆幅按植物高度和硬度算：矮草小幅高频，高草和香蒲大幅低频，阵风来时一片一片地压过去。
  - 近层两种画面都有风；中层开 Sundial 时用光影的风，不开光影时用上面的低成本区块着色器摇摆。
- **人和动物走过**：
  - 碰到的叶片被推开、压弯，人离开后 1–2 秒回弹。
  - 只在客户端算，不发包，不改方块。
  - 每个实体只影响身边一小圈植物，开销有上限。
- **车压过**：
  - 沿用 T15 现有的"被压倒的植物"（`FlattenedPlantBlock`）：顺着车走的方向倒下，20–40 秒后起一半，再过 5–10 秒立起来。
  - 改成能装 AFL 植物，原版种类留着给旧存档。
- **声音**：
  - 从高草、香蒲、灌木里穿过时有沙沙声。
  - 声音传播范围等于感染者听觉的噪声范围（已有规则）。
  - 用 Firefly 一次生成。
- **以后**（不在 V1）：
  - 反复走同一条路会踩出小径；
  - 干草能被火点着；
  - 蹲在高草里不容易被看见；
  - 风滚草被风吹着滚。

## 6. 采摘

- **操作**：对着能采的植物按使用键，交互提示一个动词"采摘"。不用工具，手采。
- **动作**：
  - 蹲下或弯腰伸手，摘一下，动作沉稳；
  - 第一人称用现在的旧视角手臂，第三人称用骨架；
  - 新的蒙皮身体做好以后再换上去（Main 在做），所以 P3 排在后面。
- **结果**：
  - 给出对应部分（叶、花、浆果、根）；
  - 植物变成"采过"的样子（没有花或浆果，叶子少），过 3–7 个游戏日长回来（问题 7）；
  - 只有挖根（蒲公英根、紫松果菊根、香蒲根茎）会拔掉整株，以后再加折刀挖根更快、出得更多。
- **挖掉整株**：属于按方块分工具的"植物"组（另一份设计），要用折刀、手锯、伐木斧，那份设计现在暂缓。
- **草药物品**：
  - 只做材料，带质量和网格尺寸数据，以及一句说明；
  - 配方重做之前不加配方；
  - 草药的用法（敷伤口、泡茶、退烧）以后和健康系统一起设计。

## 7. 生成

- 新写 `vegetation/VegetationPlan`（纯计算，和 `tree/ForestPlan` 同一套路）：
  - 每个群系一张"群落表"（物种、权重、密度）；
  - 用斑块噪声成片分布，边缘逐渐混合；
  - 按坡度、离水远近（HAND）、湿润度、树冠遮阴挑物种。林下长薹草和蕨，空地长禾草和野花，水边长香蒲和芦苇。
- 新加地物 `apocalypse_firstlight:vegetation`，放在植被步骤最后，网格树之后，这样能知道树冠位置。用群系修改器挂到所有 AFL 群系，**不改 C 的群系 JSON、噪声和地表规则**。
- 道路、小镇、地块、老宅的范围内不长（读已有的占用查询），草坪以后由小镇自己铺修剪过的早熟禾。
- 这块属于 C 负责的世界生成，开工前给 C 发通知（五项格式），请 C 审（问题 6）。
