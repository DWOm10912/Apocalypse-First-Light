## 1. 参考：《非生物因素》的工作台

只取做法，不照搬内容：

- **第一台工作台就是主力**：大部分基础物品都在它上面做，更专门的东西去别的台子（厨房、化学、制造机）。
- **配方靠"见过"解锁**：凑齐过一个配方的所有材料、捡到某些物品或资料、剧情人物告诉你、队友分享。玩家不会看到一大堆还不会的灰色条目。
- **工作台可以加装**：随着制作技能升级，工作台能装上不同的附件，比如能直接用附近箱子里的材料、给周围的人回血、取暖。

AFL 的取舍：配方知识跟着**具体的一位幸存者**，不跟玩家账号走（已定，见 V2 计划）；附件按现实来，是装在桌子上的真实工具或设备，**不和技能等级挂钩**。

## 2. 定位：工作台做什么、不做什么

**一句话规则（建议）：工作台只用手工具对现成材料做加工和组装（锯、钻、钉、拧、绑、缝、粘），不制造材料本身，不做要精度或要电的东西。**

| 能在工作台做 | 不能在工作台做（去哪） |
|---|---|
| 木工：原木锯成木板、方木、梁；做木凳、木箱、货架这类简单家具 | 冶炼、合金、提纯：钢坯、碳化钨……（合金炉、工业熔炉、化学反应器） |
| 组装：把捡到或机器做出来的零件装成成品，比如工具头装柄 | 粉碎、压缩矿石和废料（粉碎机、压缩机） |
| 修补：缝补衣服背包、修理木制品 | 枪、枪的零件、配件、弹药、精密零件（精密制造台） |
| 简单的生活用品：捆柴、夹板、简易护耳罩这一类 | 电子件、仪表：体温计、盖革计数器（以后的电工台或精密制造台） |
| 拆解：把废旧家具、杂物拆成木料、钉子、布 | 枪械保养、校枪（枪械维护台） |

判断一个配方该不该放上来：**一个手巧的人在自家车库，用手工具半天之内能不能做出来。** 能，就放工作台；需要炉子、车床、精密模具或电，就不放。

## 6. 材料从哪里来（建议）

按这个顺序扣：

1. 工作台自己的抽屉；
2. 玩家身上（AFL 网格背包、胸挂、口袋）；
3. **附近的箱子**：以工作台为中心几格之内（比如 4 格）的 AFL 储物容器，像在自己车库里从架子上拿东西。

第 3 条参考了《非生物因素》的物品传送附件，但 AFL 不用附件解锁，**直接就有**，因为现实里就是这样干活的。清单里每样材料可以标出是从哪里拿的。**用户 2026-10-20 定了：可以用附近箱子里的材料**；范围（建议 4 格）实现时再对。

> 2026-10-21 起以第 18 节为准（JSON 数据 V1）。下面是最初的设想，`tools` 工具类别、`byproducts` 副产品还没做。

AFL 自己的配方类型 `apocalypse_firstlight:workbench`，服务器校验，客户端只显示：

```json
{
  "type": "apocalypse_firstlight:workbench",
  "category": "woodwork",
  "ingredients": [
    { "tag": "apocalypse_firstlight:planks", "count": 4 },
    { "item": "apocalypse_firstlight:nail", "count": 8 }
  ],
  "tools": ["apocalypse_firstlight:tools/saw", "apocalypse_firstlight:tools/hammer"],
  "time": 400,
  "result": { "item": "apocalypse_firstlight:walnut_stool", "count": 1 },
  "byproducts": []

```

- `tools`：工具类别，查挂板上挂着的工具。

- `byproducts`：比如锯木头剩下的木屑、边角料（以后当柴炉燃料），V1 可以空着。
- ~~配方属于哪条"知识"，写在知识文件里~~（已改）：解锁条件写在配方自己的 `unlock` 里（用户 2026-10-21，第 18 节）。
- 原版配方书、JEI：工作台配方要在 JEI 里能查，但只显示当前幸存者会的（JEI 的隐藏和配方知识 V2 一起做）。

## 17. 台前干活（2026-10-21，用户实机 PASS；锯木声已接入，未实机）

用户 2026-10-21："横梁配方的工具换成手锯，在工作台上做锯木头的动画"。配方可以写明"在台前做"（`WorkbenchCrafting.Recipe.work`，界面的 `WorkbenchRecipeView.work`：玩家动作的 ID）。现在只有测试横梁这样做，动作 `tool/hand_saw_rip`。

- **开始：** 制作页选好数量，点一下"制作"，界面关掉，玩家开始在桌面上干活。要站在工作台正面、离站位 1.8 格以内，不然提示"站到工作台前面"（`message.apocalypse_firstlight.workbench.stand_front`），不开始。
- **桌面上：** 一根白栎原木（白栎原木方块的模型，截面 18 cm）顺着桌子的进深横在抽屉那一格中间，前端伸出桌沿 30 cm；锯缝从前端顺着原木顶面往里走，每做一件从前端锯到桌沿（北向坐标 z −0.27 → −0.02），端面上的锯缝跟着往下加深。做完一件，下一件从头开始。由 `WorkbenchRenderer` 每帧画（不进区块）。
- **人：** 身体走到原木前（右肩在锯的平面上，身体在锯缝前 0.42 格、平面左边 0.36 格，朝锯的方向右偏 15°：左肩靠近原木，右肩在锯后面），胸口前倾 25°、右转 18°，低头看锯缝（视角下压 40°）。先 0.7 秒把锯从右胯边提到锯缝（`tool/hand_saw_set`），然后循环锯（`tool/hand_saw_rip`，0.8 秒一个来回：锯齿线往前下斜 20°，前推 22 cm 是切削，0.4 秒，再拉回；推的时候胸口再前倾 5°）。右手握锯柄，左手扶在原木左侧锯缝后面。手里原来拿的东西这时不画（动作新字段 `held_item: "hidden"`），锯从自己的物品画。第一人称是身体视角（同发电机拉绳），镜头跟着身体走过去。
- **锯末：** 每次往前推时，从伸出部分的锯缝下面落下锯末（`falling_dust`，白栎原木的颜色），偶尔从顶上的锯缝冒出来。
- **面板：** 快捷栏上方：成品图标、"正在做：白栎横梁 1/3"、进度条、"[左键] 停止"。干活时建筑锤的面板不画。
- **停下：** 走动、跳、左键、打开任何界面、离开工作台（5.5 格）、身体被推开 0.25 格以上、死亡、观察者模式、身上没有手锯。做完数量，或者剩下的材料不够下一件，也停。干活时右键不起作用（不会误放、误用东西）。
- **服务端：** 点制作时客户端发 `BuildingPackets.Work(bench, recipe, true)`；服务端检查工作台在 5.5 格内、身上有工具，记下这个玩家在做什么，再发 `WorkOf` 给看得到他的玩家；停下时发 `Work(..., false)`。每件做满时照旧发 `Craft`，服务端只接受正在这张台子上做这条配方的玩家（`WorkbenchCrafting.WORKING`），防刷规则不变（第 16.8 节）。玩家下线、换维度、死亡时服务端自己清掉；别的玩家开始追踪这个玩家时补发一次。
- **别的玩家：** 看到同样的动作、原木、锯缝和锯末。他们那边不知道每件的进度，锯缝按配方时间从第一锯开始循环走。
- **数值来源：** 站位、扶手位置、锯的角度和行程都在 `tools/author-hand-saw-actions.mjs`（写出 `player_props/hand_saw.json`、`player_actions/tool/hand_saw_set.json`、`hand_saw_rip.json`；`--check` 检查是否最新，`--report` 用 Blockbench 插件同一套骨骼求解离线核对）；胸口动作在 `tools/author-player-actions.mjs`（`tool.hand_saw_set`、`tool.hand_saw_rip`）；`client/workbench/WorkbenchWork.java` 的锚点常量和脚本的 `WORK` 一致。

## 18. 配方数据 V1：JSON（2026-10-21，代码，编译通过，未实机）

用户 2026-10-21："每个类别一个文件夹，里面塞配方，需要的时间和材料，解锁条件（后面可以在游戏里面生成各种真的能看的书籍/求生指南什么的）"。第一步做了数据格式、加载、同步，测试配方搬进 JSON，学会记录单独存档。

### 18.1 文件位置

- `data/<命名空间>/workbench_recipes/<分类>/<名字>.json`，配方 ID 是 `<命名空间>:<分类>/<名字>`。
- 分类文件夹（和制作页左边的分类同序）：`woodwork` 木工、`furniture` 家具、`tools` 工具、`building` 建造、`living` 生活、`repair` 维修、`salvage` 拆解。文件只能直接放在这 7 个文件夹里，放错位置的拒绝加载。
- 每个文件单独检查。写错的文件只在日志里留一行 `[AFL WORKBENCH] Rejected recipe file <id>: <原因>`，其他文件照常加载。加载完写 `[AFL WORKBENCH] N workbench recipes`。数据包可以加配方，也可以用同一路径覆盖；`/reload` 后生效。

### 18.2 格式

```json
{
  "format_version": 1,
  "result": { "item": "apocalypse_firstlight:white_oak_beam", "count": 1 },
  "materials": [
    { "item": "apocalypse_firstlight:white_oak_log", "count": 1 }
  ],
  "tool": "apocalypse_firstlight:hand_saw",
  "seconds": 5,
  "work": "tool/hand_saw_rip",
  "unlock": [
    { "type": "everyone" }
  ]
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `format_version` | 是 | 现在只认 `1` |
| `result` | 是 | `item` 成品；`count` 1–64，默认 1 |
| `materials` | 是 | 每行一种材料：`item`（一个物品）、`items`（几个都行）或 `tag`（物品标签），`count` 至少 1，默认 1。标签在第一次用到时才展开（等标签绑定好）；标签里一个物品都没有时整条配方不加载 |
| `tool` | 否 | 身上要带的工具 |
| `seconds` | 是 | 做一件的时间，大于 0、最多 3600 秒，换成 tick（× 20 四舍五入） |
| `work` | 否 | 在桌面上做的循环动作（第 17 节）。不写就在界面上等圆圈走满 |
| `unlock` | 是 | 怎么学会，至少一条（18.3） |

物品不存在时整个文件拒绝加载；`book` / `blueprint` 写的物品可以暂时不存在（书还没做）。

### 18.3 解锁条件 `unlock`

| `type` | 其他字段 | 意思 | V1 |
|---|---|---|---|
| `everyone` | | 谁都会（生活经验） | 生效 |
| `background` | `background`（如 `forest_resident`，不写命名空间时补 `afl:`） | 这个出身的幸存者会 | 生效 |
| `materials` | | 手上拿到材料时自己琢磨出来（动手摸索） | 只解析，还不会触发 |
| `after` | `recipe` | 做过另一条配方以后会 | 只解析；指向不存在的配方时日志警告 |
| `book` | `item` | 读了这本书会：在书里教这条配方的那一节停约 3 秒（2026-10-22 起生效，见 [野外求生指南设计稿](field_survival_guide_v1_design.md) 第 7.4 节） | 生效（分支 AFL-Workbench，未实机） |
| `blueprint` | `item` | 看了这张图纸会 | 只解析 |

一条配方可以写几条解锁条件，满足任意一条就会。

### 18.4 谁会哪条配方

服务端 `cabin/WorkbenchKnowledge` 按下面的顺序判断：

1. 创造模式：全会，来源"创造模式"。
2. `unlock` 里有 `everyone`，或 `background` 和当前幸存者的出身相同：会，来源"生活经验"。
3. 当前幸存者的学会记录里有：会，来源是记录里的（动手摸索、书、图纸、开发命令）。
4. 其他：不会。没有幸存者（还没选人）时只看第 1、2 条里的 `everyone`。

- **学会记录单独存档**：世界数据 `data/apocalypse_firstlight_workbench_knowledge.dat`，按幸存者 ID 存，每条记来源、书或图纸物品、学会时的游戏时间。不动幸存者记录的存档格式。学会的配方跟着这个幸存者走，继任者从头学。配方文件删掉以后记录还留着，配方回来，学会的也回来。
- **同步**：服务端只发这个玩家会的配方（不会的不发，客户端看不到），每条带完整的材料、时间、动作和来源。数据加载 / `/reload`、登录、学会或忘掉、换幸存者、换游戏模式时重发（每秒比较一次）。客户端退出世界时清空。
- 登录后的第一份清单不标"新"；以后新多出来的配方标"新"，在详情里看过一次就去掉。
- 制作和台前干活时服务端再查一次：不会的配方拒绝，动作栏提示"还不会这个配方"。
- 别人在台前干活时，动作名和每件时间跟着 `WorkOf` 包发过来，看的人不会这条配方也能看到动作。
- 详情里的来源：书、图纸显示物品名；其他显示"生活经验 / 动手摸索 / 书 / 图纸 / 创造模式 / 开发命令"。
- 建筑构件目录"会做的"也改看这份清单。
