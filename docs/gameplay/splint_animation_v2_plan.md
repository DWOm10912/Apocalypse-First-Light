# 打夹板动作 V2 + 坐下键

2026-10-20 用户：「接下来给打夹板设计动画 / 你可以用内置浏览器搜YouTube视频，寻找非生物因素的夹板，看看这个游戏是怎么打的 / 也可以参照现实生活中，如果你的腿骨折了，会怎么自己打夹板 / 可以先出一般概念动画给我，我批准了再去blockbench做」。做概念时又加了一条：「如果需要坐下才能打夹板，可以顺便加一个坐下的按键+动画，并且真的可以休息 / 只能坐在方块上（mesh也算）」。

**状态：已实现，用户 2026-10-20 实机 PASS（「都没问题」：腿和前臂夹板、坐下键、镜像），D 分支 `feature/survival-health-v1a`，2026-10-21 由 Main 合并进 master。** 同一轮按用户意见把打了夹板的腿的疾跑放早到愈合 30%（[fracture_splint_v1_plan.md](fracture_splint_v1_plan.md) 第 3 节，编译通过，没进游戏）。 用户 2026-10-20 批准概念：「概念通过，第 4 节都按推荐，去 Blockbench 正式做，并接上坐下键」。正式的动作由 `tools/medical-actions-v1a/author_splint_v2.cjs` 按概念的关键姿势生成，已用 AFL Rig 插件导进 Blockbench、逐个解算过；游戏里的样子、手感、镜头都还要用户实机看。第 6 节是实现说明。

## 1. 参考

- **Abiotic Factor**：用夹板时站着把它捧在腰前、低头，是通用的"使用"姿势，没有专门的打夹板动作。可借鉴的只有"打完会显示在身上"。
- **现实**（急救员给前臂上 SAM 夹板的短片；自救要点）：
  - 腿：先坐下，伤腿伸直不动；硬板放在小腿内外两侧，跨过上下两个关节；布条从腿下自然的空隙（膝窝、踝上）穿过去，绑在骨折处的上下，不压在骨折处；结打在夹板外侧；最后动动脚趾，看血运。
  - 前臂：两块板一块贴手心一侧、一块贴手背一侧；一只手干不了的地方用牙咬住布条一头，另一只手拉紧；打完动动手指。
- 和 V1 的差别：V1 的腿是一只手扶、另一只手拿纱布卷在腿上绕圈（卷从腿下面"推"过去，看不见）；V2 改成**布条从腿下穿、两只手在外侧打结拉紧**，更像真人，动作也更好看懂。

## 3. 坐下键（设计）

实现见 6.1、6.2；眼睛高度、时长按实现。

- **按键**：AFL 按键分类里加"坐下 / 站起"（推荐默认 `N`，现在 AFL 用了 B、C、F、G、H、K、R、V、X、Y、Z 和方向键），按一下坐下，再按一下站起；坐着时按跳跃也站起。
- **只能坐在方块上**：脚下要有方块的碰撞面（站在地上），网格方块（`aflmesh` 地形、家具网格等自定义碰撞）也算；在空中、水里、梯子上、坐车或骑乘时不能坐。坐下的高度贴着脚下碰撞面的顶。
- **真的休息**：做成和家具椅子一样的"坐在不驾驶的座位上"（座位实体放在脚下的碰撞面上），这样 `PlayerHealth#resting` 直接算休息：生命恢复走 `rest_per_minute`，骨折愈合 × `rest`（现在 1.5）。不另加规则。
- **动作**：坐下 = 概念里的 A 段，站起 = E 段，坐着时是坐地的循环姿势（伤腿伸直、好腿屈膝；没受伤时两腿随意）。坐着不能走、跳（跳 = 站起）、潜行；可以转头看、可以用物品（吃喝、绷带、夹板）。
- **和夹板的关系**（推荐）：腿的夹板只能坐着打；站着对腿用夹板时先自动坐下（播 A 段）再打；打完**继续坐着**（休息），自己按坐下键或跳跃站起。这样夹板动作里只剩 B–D（约 6 s，`USE_TICKS` 改成 120），坐下和站起是坐下键自己的动作。手臂的夹板站着、坐着都能打。

## 4. 用户定的（2026-10-20，都按推荐）

## 6. 实现（2026-10-20）

### 6.1 坐下键

- 按键 `key.apocalypse_firstlight.sit`（"坐下 / 站起"，AFL 分类，默认 `N`），`client/skeleton/GroundSitClient`：没坐时按一下坐下，坐着时按一下站起；坐着时跳跃或潜行也是站起（打腿夹板时不行）。坐着时移动键无效，潜行也不会被服务端当成下车。
- 请求包 `GroundSit.Request`（客户端 → 服务端，`sit/GroundSit#register`，挂在 `HealthPackets` 后面；网络协议仍是本分支的 60，合并时 master 59 → 60 一起改）。
- 服务端 `sit/GroundSit#canSit`：活着、不是旁观、没睡觉、没在骑乘、站在地上（`onGround`）、不在水里 / 岩浆里、不在梯子上、没在滑翔 / 游泳 / 飞行、没在用物品，并且脚下 0.06 格内有方块碰撞面（`GroundSit#supported`，任何方块的碰撞形状都算，网格方块也算）。坐不下时动作栏"这里不能坐下"。
- 坐下：在脚下放一个看不见的座位实体 `sit/GroundSeat`（注册名 `apocalypse_firstlight:ground_seat`，不存档、不能召唤，`NoopRenderer`），朝向身体的方向，玩家强制坐上去（潜行中、刚下车也能坐）。脚还在原来的高度（`RIDING_OFFSET` 0.35 抵消玩家的 −0.35）。
- 座位状态同步给客户端：坐下中（`GroundSit.SIT_TICKS` 25 = 1.25 s）→ 坐着 → 起身中（`STAND_TICKS` 20 = 1.0 s，结束时把玩家放回原地）。坐下动作没播完就按站起，会等坐好再起。脚下的碰撞面没了、座位或玩家进水时立刻起来（没有起身动作，坐姿 0.3 s 内淡掉）。
- 身体朝向固定在坐下时的方向，头左右最多转 100°。
- 坐着时眼睛高 1.03 格（`GroundSit.EYE`，坐姿片段里摆好姿势的眼睛位置），碰撞箱高 1.3 格（`EntityEvent.Size`；座位上下车时刷新）。
- **休息**：座位不由玩家驾驶，`PlayerHealth#resting` 直接算休息（回血走 `rest_per_minute`，骨折愈合 × `rest` 1.5），没加新规则。
- 坐好后动作栏提示"按 N 站起"（按键名跟着玩家设置）。

### 6.2 坐下 / 坐着 / 站起的身体

- 片段 `body.sit_down`（1.25 s）、`body.sit`（静止坐姿）、`body.stand_up`（1.0 s），在 `animations/player/body.animation.json`；对应的动作文件 `player_actions/body/sit_down.json`、`sit.json`、`stand_up.json`（`layer: stance`，只给 AFL Rig 插件导入用，游戏里由 `GroundSitClient` 直接取片段）。
- 坐姿：左腿伸直、脚尖朝上，右膝立起，右前臂搭在右膝上，左手放在左大腿上。坐下：重心放在右腿，右手往后撑地，左腿往前滑、脚跟着地，坐下后靠在右手上一下，再把前臂搭到膝上。站起：右脚收近，双手按在右膝上撑起，左腿一直伸直。
- 放在骨骼的 stance 层（`HumanoidPoser.Input#stance`），在任何物品动作下面；物品动作只管上半身（`GroundSitClient#keepLegs`：除了腿夹板自己的动作，别的动作的腿和髋都留给坐姿）。stance 层新增镜像（`StanceClip#mirror`）：右腿是断的那条（下一块夹板要打右腿，或只有右腿断）时整套镜像，坐下那一刻定；开始打腿夹板约 0.4 s 后（动作已经完全接管全身）改成伸直这条腿，两条腿都断时打完第二条也不会换腿。
- 坐着时：骨盆朝向固定在座位方向，上身最多扭 45°；视线不弯胸（只有头低下去），所以搭在膝上的手不会离开膝盖。
- 第一人称：坐下、坐着、站起时镜头放在摆好姿势的眼睛上（导演镜头 `afl_ground_sit`，优先级 `PRIORITY_BODY_EYE`，进入不淡入、因为起点就是站立时的眼睛；站起后 0.35 s 淡回原版镜头），期间画第一人称身体（`FirstPersonBody#shown`）。
- 骨骼关掉时：只有眼睛变低，身体照原版站着画。

### 6.3 夹板动作

- 动作新字段 `hold_body`（`PlayerAction#holdBody`、`ActionPose#body`，AFL Rig 插件导入导出、核心解算都认）：动作期间胸口只按片段扭和弯，玩家的视线不再叠加。V2 两个夹板动作的手都按关键姿势用 IK 解出来、烘焙成 FK 写进片段，打开这个字段后，不管玩家往哪看手都落在腿 / 前臂上。
- **腿** `item/splint_leg`：6 s（`SplintItem.LEG_USE_TICKS` 120；物品本身的使用时长还是 160，腿在 `onUseTick` 第 120 tick 提前完成），全身，淡入 0.3 s、淡出 0.4 s，第一人称低头至少 70°，相机在摆好姿势的眼睛上。
  - 必须坐着：站着对腿用夹板时先坐下（`GroundSit#sit`），坐好以后才开始（按住右键会每几 tick 再试一次；客户端比服务端多等 2 tick，免得客户端先开始）。打的时候离开座位就中断。
  - 0–0.9 s 右手把夹板放到小腿上，左手扶住；0.9 s 起身上画出两条木条；1.45 / 2.7 / 3.95 s 起三道布条（脚踝、小腿中间、膝下）：右手从内侧把布条塞到腿下，左手在外侧接住，两头拉到外侧上方交叉拉紧；5.3–5.75 s 手放回大腿，脚尖动两下；6 s 回到坐姿。打完继续坐着。
- **前臂** `item/splint_arm`：8 s（`USE_TICKS` 160），上半身（站着、坐着都能打），第一人称低头至少 45°。0–1.3 s 右手把夹板放到前臂上；1.3 s 起画木条；2.0 / 3.4 / 4.8 s 起三道布条（手腕、中间、肘下）：从下面绕过来、外侧拉上来、上面压住，然后前臂抬到嘴边，牙咬住一头，右手拉另一头打紧，再放回；6.2–6.8 s 手腕弯两下（动手指）；7.3 s 托着前臂贴近身体，8 s 放下。
- 右腿 / 右前臂整套镜像（`SkeletonActions`，和 V1 一样）。
- 身上的木条和布条（`client/BandageWrapRenderer`）：腿 0.9 s、前臂 1.3 s 起出现木条；每道布条从开始的时间起，腿 0.65 s、前臂 0.55 s 内绕满一圈（`LEG_TIE_FROM` / `ARM_TIE_FROM`、`LEG_TIE_TURN` / `ARM_TIE_TURN`）。V2 不拿纱布卷，所以不再画从卷上拉出来的那条布。
- 声音（`SplintItem` 的 `LEG_CUES` / `ARM_CUES`，借用绷带的分段）：腿 0 s 拿起，0.7 / 0.9 s 按，每道布条开始 `wrap_1/2/3`，开始后 0.9 s 撕 / 拉紧，5.3 s 拍一下；前臂 0 s 拿起，1.0 / 1.3 s 按，三道 `wrap_1/2/3`（2.0 / 3.4 / 4.8 s），各自 0.9 s 后拉紧，7.3 s 拍，7.5 s 放下。
- 原来让玩家站着打腿时不动的 `client/SplintSitInput` 删掉了（坐在座位上本来就走不了）。
