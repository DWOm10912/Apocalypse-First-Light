## 2. 100 HP

- 所有玩家 `generic.max_health` 的基础值 = `max_health`（100）。机能、成长、特质都不再改最大生命：体质好去掉 +2（只剩自然回血 ×1.2），体弱去掉 −2（只剩耐力恢复 ×0.9）。
- **旧存档**：登录、重生、每秒检查一次，基础值不是 100 的玩家把基础值改成 100，当前生命按同一比例放大（20 点制的 18/20 → 90/100）。旧"体质好"玩家：先按 22 放大，`SurvivorModifiers.apply` 去掉 +2 后钳到 100；旧"体弱"满血玩家 18 → 90/100，要自己回满（按基础值换算，不是按旧上限）。
- **死亡**：新身体由原版建成 20 点，下一秒升到 100 再满血（重生时原版已经设满）。
- **离开末地 / 跨维度**：原版把生命复制到 20 点的新玩家上会被截断，所以 `Clone` 里先把基础值升到 100 再设回原生命；伤口和 `afl_health` 一起复制。
- 吸收（金心）仍按原版单位抵伤，HUD 显示时 × `default_scale`。

## 3. 伤害换算

在 `LivingDamageEvent`（`LOWEST` 优先级）里换算。Forge 的 `Player.actuallyHurt` 顺序：`onLivingHurt` → 护甲 → 魔法减免（抗性、保护）→ 吸收 → `onLivingDamage` → 扣血，所以护甲、吸收都按原版单位生效，只有真正扣到生命上的部分换算，一次。只处理 `ServerPlayer`：生物和 NPC 不变，**枪械打感染者的伤害不变**。

规则（`health_v1.json` → `damage.rules`，按顺序第一条匹配的生效；都不匹配时 × `default_scale` = 5）：

| 规则 | 换算 | 实际 |
|---|---|---|
| `minecraft:mob_attack`，攻击者是感染者（`InfectedEntityRules.isInfected`） | × 4 | 原版僵尸普通难度 3 → **12**（简单 2.5 → 10，困难 4.5 → 18） |
| `apocalypse_firstlight:native_bullet` | 分段线性曲线 `[0,0] [7,30] [18,62] [26,90] [40,125] [100,250]`，超出按最后一段斜率外推 | P9-01 7 → **30**，BR-51 18 → **62**，HR-55 26 → **90**（护甲后的值，命中部位倍率之后） |
| `minecraft:lightning_bolt` | × 1 | `LightningStrikes.LETHAL_DAMAGE` 1000，照样必死 |
| `minecraft:fall` | × 5 | 原版"落差 − 3"：4 格 → **5**，6 格 → **15**，10 格 → **35** |
| 其它（火、岩浆、溺水、仙人掌、口渴 / 体温 3 期每次 1 点、辐射病等） | × 5 | 持续伤害的生存时间和原来一样（口渴 0 时每 10 s 失去 5 点，100 点约 200 s） |

- `never_below_one`：`minecraft:starve`（原版饥饿在普通难度下停在 1 点）换算后仍最多扣到 1。
- `/kill`（`Float.MAX_VALUE`）等 ≥ 3e37 的伤害不换算。
- 只有扣了生命的伤害会重置"受伤后多久开始回血"的计时，也只有它会判定抓伤。

## 4. 自然恢复

原版饱食回血全部关闭（两种都关，也不再消耗饱和度）。`PlayerHealth` 每秒结算一次：

| 状态 | 条件 | 每分钟 |
|---|---|---|
| 等待 | 最后一次扣血后 `delay_seconds`（15 s）内 | 0 |
| 清醒 | 其余时间 | `awake_per_minute` 3 |
| 休息 | 睡觉，或坐在不由自己驾驶的座位上（家具椅、办公椅、皮卡乘客位、按坐下键坐在地上；骑马之类的生物不算） | `rest_per_minute` 8 |
| 阻断 | 饥饿 < `min_food`（7，即"饥饿"徽章 ≤ 6 的那一档）、脱水（`PlayerThirst.blocksNaturalRegen`）、冷 2 / 热 2 及以上（`PlayerTemperature.blocksNaturalRegen`）、游戏规则 `naturalRegeneration` 关闭 | 0 |

- 倍率：`natural_regen`（幸存者属性，体质好 ×1.2）× 伤口倍率（化脓 0.85，恢复期间渐变回 1）。辐射病对所有回血的倍率照旧（`RadiationSicknessEvents`）。
- 轻微饥饿、轻微口渴（口渴 1 期）不阻断。所有条件都在服务端判定，客户端只显示。
- 回血最多补到 `HealthCap.cap`（目前没有来源，等于上限）。
- **跳夜**：`SleepFinishedTimeEvent` 时，每个正在睡觉、满足回血条件的玩家按跳过的游戏时间结算一次：跳过的 tick ÷ 1200 × `sleep_per_minute`（8）× 倍率，最多 `sleep_max`（30）。跳过的目标时间记在 `afl_health.last_sleep`，同一次跳夜不会结算两次。
- 时间换算：1 游戏日 = 24000 tick = 现实 20 分钟。从 0 回满约 33 分钟（清醒）或 12.5 分钟（休息）。

## 5. 伤口

独立于生命值的可存档状态（玩家 persistentData `afl_wounds {v:1, list}`），最多 `max_wounds` 3 处，每处三阶段：抓伤 → 局部感染 → 化脓。所有天数是游戏日，只在玩家在线时计时（离线不跳阶段）；数字都是游戏平衡参数，不是医学数据。

**来源**：感染者近战（`mob_attack` 且攻击者是感染者）每次扣血的命中有 `scratch_chance` 35% 留下抓伤。伤口已满时，最年轻的一处抓伤再次被抓：严重度 +1（最多 3），清洁 / 包扎清空，计时归零；没有抓伤可加重时不变。`Wounds.scratch(ServerPlayer)` 是以后其他来源调用的接口。

| 阶段 | 影响 | 发展 |
|---|---|---|
| 抓伤 | 不扣血，无惩罚 | `check_days` 1 天时判定一次感染：基础 25% × (1 + 0.25 × (严重度 − 1))，清洁 × 0.2，包扎 × 0.5，清洁且包扎不判定。愈合：未处理 1.5 天，清洁或包扎 1.25 天，两者都有 0.75 天 |
| 局部感染 | 耐力恢复 × 0.95，屏幕效果 0.5 | 未清洁：每天判定一次，化脓 40%（已包扎 20%，同时包扎作废），自愈 20%。清洁后：1 天痊愈（再包扎 0.5 天），不再判定 |
| 化脓 | 耐力恢复 × 0.90，自然回血 × 0.85，屏幕效果 1.0 | 未清洁：每天 10% 减轻为局部感染。清洁后：1 天（包扎 0.5 天）减轻为"已清洁的局部感染"，保留清洁 / 包扎，再按局部感染恢复 |

- 抓伤感染时清洁 / 包扎清空（旧敷料下的新感染，要重新处理）。
- 有多处伤口时取最差的一处的惩罚；清洁后的感染 / 化脓在恢复期内惩罚线性淡出（化脓淡到感染的值）。
- 死亡清空伤口；切维度保留。
- 动作栏提示：抓伤、开始感染、化脓、全部愈合、已清洁、已包扎。
- **部位**（2026-10-20，背包身体图 V1，[body_silhouette_v1_plan.md](../ui/body_silhouette_v1_plan.md)）：每处伤口有一个部位（`health/BodyPart`：头、胸、腹、右臂、左臂、右腿、左腿），抓伤按权重随机（手臂各 30、胸 15、腹 10、腿各 7.5、头 0）；旧存档里没有部位的伤口读档时随机给一只手臂。部位只决定伤标在哪、纱布画在哪，规则不变。

- **生命弧**：0–100，最大生命 ≥ 50 时每格 10 点（低于 50 时仍按 2 点一格）。弧下方只显示当前生命（例如 `73`，向上取整）：所有人上限都是 100，`100/100` 在两段弧之间放不下（用户 2026-10-19 "有点挤"）。低血闪动阈值从"生命 + 吸收 ≤ 4"改为 ≤ 上限的 20%。
- **徽章**（`StatusBadgeHud`）：
  - "饱腹"（绿，刀叉）删除，换成"恢复中"（绿，心形）：说明"生命值缓慢恢复"或"休息中，生命值恢复加快"，只在真正回血时显示（等待、阻断、满血都不显示）。
  - 每个伤口阶段一个徽章，三种图标（用户 2026-10-19：之前都是十字，分不出来）：抓伤 = 三道爪痕，局部感染 = 肿起的伤口（杏仁形，中间一道暗缝），化脓 = 肿起的伤口下面挂一滴脓。名称"抓伤 / 伤口感染 / 伤口化脓"，多处时"×N"；说明按这一阶段处理最少的一处：未处理 / 已清洁 / 已包扎 / 已清洁并包扎。未清洁的化脓为红色（危险），其余棕色。清洁后恢复中的感染 / 化脓外圈弧线显示剩余进度。清洁或包扎后（只是说明变了，阶段没变），标签"抓伤 · 已清洁并包扎"再滑出 4 s，不闪圈（用户 2026-10-20：之前处理完什么都看不到）；规则见 `docs/ui/hud_v2_research.md` 6.3。
  - 口渴 3 期说明改成"每 %1$s 秒失去 %2$s 点生命值"（第二个参数 = `default_scale`）；饥饿 1 期加"无法自然恢复生命值"。
- **屏幕效果 V2**（`WoundScreenEffect`，覆盖层 `wound_screen`，冻伤层之上，HUD 和准星之下，所以 HUD 不模糊）：第一版（重影、满屏噪点、跳动的边缘暗角，用户 2026-10-19 要的"噪点、晕乎乎"）用户 2026-10-20 否掉："现实中感染流脓不会搞的满屏都是噪点吧"、"尽量不要做这种屏幕边缘一闪一闪的效果"。按真实症状重做，离线预览后用户选定（`design/health/wound_screen_v2/`，第一轮被否的方案在 `round1_rejected/`）：
  - 阶段由服务端的伤口 visual 判断（感染 0.5、化脓 1.0，好转时逐渐降低），2 s 淡入、3 s 淡出；感染程度 = min(1, visual / 0.5)，发烧程度 = visual 从 0.5 到 1 的平滑过渡。客户端设置只按比例调强度，不改变发作时间。协议和服务端不变。
  - **抓伤**：没有视觉效果（只是伤口疼，视线不受影响）。
  - **感染：偶发视线模糊**。每隔 20–45 s 来一阵（第一次在感染出现后 10–35 s），持续 4–6 s：1.2 s 慢慢糊开，停一会儿，1.5 s 对回焦；模糊期间焦点轻微飘动（半径 ±20%，2.3 rad/s）。模糊半径峰值 = 屏宽的 0.71%（预览里 720 px 宽时约 5 px）。两阵之间完全清楚，不画任何东西。
  - **化脓（高烧）**：一直有：画面褪色 25%、向浅灰泛白 6%、略偏暖（红 +0.015、蓝 −0.015）；怕光：亮处（亮度 0.55–0.9 起）向四周发散，半径屏宽的 2.8%，强度 0.55；轻微发虚（模糊半径屏宽的 0.33%）。模糊发作更勤（每 12–28 s，第一次 2–18 s）、更重（峰值屏宽的 1.3%），发作时镜头缓慢晃动（头晕：横滚 0.9°、偏航 0.6°、俯仰 0.25°）。另外每 25–50 s 一阵寒战，1.2–1.6 s，镜头细碎抖动（横滚 / 偏航 0.25°、俯仰 0.2°，约 7–10 Hz）。

  - 着色器或拷贝出错时，本次会话不再画屏幕部分（日志 `[AFL HEALTH] Wound vision disabled`），晃动和寒战照旧。退出世界时清空状态。没在光影（Oculus）下看过：覆盖层在 GUI 阶段，和以前的画面拷贝一样，应该不受影响。

## 9. 开发指令

`/afl health`（权限 2，作用于执行者本人），每条都输出一行当前状态（生命、上限、吸收、回血状态、距上次受伤秒数、回血倍率、伤口列表、耐力恢复倍率、屏幕效果强度）：

| 指令 | 作用 |
|---|---|
| `/afl health` | 只看状态 |
| `/afl health hp <值>` | 设生命（最多到上限，0 直接死亡） |
| `/afl health scratch` | 按僵尸抓伤的规则加一处抓伤 |
| `/afl health wound <scratch\|infection\|suppuration> [部位]` | 直接加一处该阶段的伤口（满了替换最早的一处）；部位 `head`、`chest`、`belly`、`right_arm`、`left_arm`、`right_leg`、`left_leg`，不写按抓伤权重随机 |
| `/afl health fracture <right_arm\|left_arm\|right_leg\|left_leg> [splint\|heal]` | 骨折（已经断了就是再断）/ 固定 / 治好那一处；`/afl health fracture heal` 全部治好 |
| `/afl health clear` | 清空伤口 |
| `/afl health advance <天数>` | 所有伤口和骨折按在线逐秒推进这么多游戏日（每次判定照常掷骰） |

## 11. 已知限制

- 物品只在创造栏；没有配方和战利品。
- 手臂离第一人称镜头很近（玩家模型的手臂只有 6 + 6 px，伸出的前臂中段离眼睛最多约 11 px），所以第一人称里手臂显得大；这是共用骨骼动作的代价，游戏里由用户判断。
- 液流只是表现，不在地面留痕迹；只有骨骼画出瓶子道具时才有液流（骨骼关闭时没有）。
- 两个动作、液流、布带、新屏幕效果都没在光影下看过。
- "休息"只认服务端能判定的状态（睡觉、坐不由自己驾驶的座位）。坐在地上（坐下键 `N`，2026-10-20，[splint_animation_v2_plan.md](splint_animation_v2_plan.md)）也是坐座位，所以算休息；躺下以后再加。
- 跳夜结算只给正在睡觉的玩家；没睡的玩家照常按秒回血。
- 旧"体弱"满血玩家升级后是 90/100（见第 2 节）。
- 抓伤只来自感染者近战；感染者传染、其他来源以后接 `Wounds.scratch`。
- 留在身上的纱布：尸体（布娃娃，`SkeletonBodyRenderer`）上不画；原版第一人称空手不画；骨骼关闭时包扎只按时间缠、没有布带。
- 网络协议：分支上 58 → 60（2026-10-20 骨折和部位改了 `HealthPackets.State`、加了 `Marks`）；master 现在是 59，合并时取 60，master 再改过就取更大的下一个。
- `FirstPersonBody`、`PlayerSkeleton` 合并时会和 master `b2a62541`（"P9 低头交给身体"：`gunHandOver` / `gunDrop` / `armsShown`）冲突：两边都改了 `bodyArms`、`handDrop` 和第一人称手的取消条件。合并时把普通物品的 `itemHandOver` 和枪的 `gunHandOver` 合成一套（同一个帧计数、同样 25° / 45° / 3°），不要二选一。
