# AFL 生物规划 V0（方向，未实现）

状态：**只是方向和规划**，只有 F0 的"去掉原版生物生成"做了（见下）。 2026-10-18 用户定的方向，后面的物种表、阶段和变异规则都是草案，等用户逐项确认。

## 1. 用户的决定（2026-10-18）

- **一种原版生物都不留。** 以后所有生物都是 AFL 自己的：网格模型（Mesh）+ 骨骼动画 + 布娃娃，"后面全都精致化"。
- **参考美国真实的动物去做**（和 AFL "真实逻辑优先、北美风格"的设计原则一致）。
- 要有**变异的动物**：用户的理由是普通 / 困难难度下世界大部分地方有辐射。
- 第一个要做的是 **AFL 自己的丧尸**（感染者）：车撞上去要有布娃娃效果。

**尸体规则（用户 2026-10-26，所有生物）：** "所有生物死亡后，默认不清理尸体，和《僵尸毁灭工程》那样，可以搜索，过几个游戏日腐烂。玩家可以肢解丧尸，后面用作生物燃料什么的"。
- 生物死后不消失、不散落物品：布娃娃倒地 → 留下尸体 → 可以搜索（和现在的玩家尸体 `survivor/SurvivorCorpse` 一样）→ 过几个游戏日腐烂（1 个游戏日 = 现实 60 分钟）。
- 感染者可以肢解，肢体以后用作生物燃料原料（生物燃料系统还没有）。
- 结局（用户 2026-10-26）："最后原地留下骨头mesh（区块obj烘焙）"：腐烂完的尸体换成一个骨头方块，OBJ 模型烘焙进区块网格，和地上的家具一样不再每帧单独画。
- 不冒白烟、不闪红（用户 2026-10-26，玩家也一样）："AFL的生物死亡不能有白烟，而且受伤也不能闪红，而是靠后面的飙血、断肢效果来展现"。已做：`creature/AflCreatures.isAflBody`（玩家和 AFL 命名空间的实体）、`LivingEntityDeathPoofMixin` 取消死亡烟（实体事件 60）、`LivingEntityRendererNoHurtTintMixin` 去掉受伤红光（苦力怕的白光保留）；第一个用上的是 Z1a 感染者（`afl_infected_z0_design.md` 12.3）。
- 上限（用户 2026-10-26）："我觉得100具可以"：同时最多 100 具还没变成骨头的尸体；超过时最早的那具直接变成骨头（草案，不删除）。
- 开销估算（没实测）：旧方块身体一具大约 200–300 个四边形，100 具约 5 万个三角形，显卡没压力；实体每帧在 CPU 上重建顶点，100 具约 10 万个顶点，估计 1–2 ms，视野外的会被剔除，开光影时阴影再画一遍。尸体姿态不变，以后可以把顶点缓存起来。服务器端尸体基本不 tick，布娃娃只在倒下的那几秒算，同时最多 8 具（现有限制）。
- 还没定：腐烂几个阶段、每段多少游戏日（草案：新鲜 → 腐烂 → 骨头，约 3–5 个游戏日）。

## 2. 和现状的关系

- **原版敌对生物**：[布娃娃 V1](../dev/ragdoll_v1_plan.md) 第 1 节已经写了"原版默认不生成任何敌对生物"；感染者现在是给原版僵尸套的一层 AI 规则（`infected/`：`InfectedEntityRules`、`ai`、`perception`、`vision`、`breach`），**还没有 AFL 自己的实体**。
- **布娃娃**：D 的 `RagdollBody` 按骨架定义生成刚体，现在只接了玩家尸体；新生物的骨架可以直接接（同文档第 1 节）。
- **骨骼**：玩家骨架 V1（[player_skeleton_v1_design.md](../dev/player_skeleton_v1_design.md)）、AFL Rig Blockbench 插件（`tools/blockbench/afl_rig.js`）可以复用到生物上。
- **辐射**：**世界环境辐射 2026-10-10 起默认关闭**（[辐射系统](../项目内容/01%20-%20设计/辐射/辐射系统.md) 开头）：全岛地表默认没有环境辐射，不分难度。以后由"全局灾难与破坏系统"按核爆位置、沉降生成（还没做）。所以"辐射变异"要等那个系统；现在的世界里没有它的来源。普通 / 困难难度只区分死亡规则（[幸存者死亡与继任](survivor_death_succession_v0.md)），数值完全一样。
- **原版生物掉的东西**（皮革、羊毛、羽毛、骨头、线等）和用到它们的配方，原版生物去掉以后要换成 AFL 动物的掉落，或者换配方。要在去掉原版生物的同一步里清点。

## 4. 变异的两种做法（待用户选）

1. **辐射病变（建议，真实逻辑）**：长期受辐射的动物不是变成怪物，而是生病：消瘦、掉毛、肿块、行动迟缓或更易受惊；肉和皮带污染（接现有的随身污染和剂量系统）。高剂量区的动物更少、更病。来源要等全局灾难系统的沉降区。
2. **感染变异（建议和 1 一起做）**：让丧尸病毒也能感染部分动物（感染的野狗、浣熊、熊），行为照感染者的规则（听觉、追击、破门），外观溃烂。它和丧尸同一套设定，不依赖辐射，现在的世界里就有来源。
3. 游戏向的大体型变异怪物（巨型、多肢）**不建议**：和"真实逻辑优先"冲突。用户要的话再单独讨论。
