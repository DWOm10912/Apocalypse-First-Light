# 骨折与夹板 V1

2026-10-20 用户：「设计一个新的效果，骨折？然后玩家可以自己打夹板，类似非生物因素，然后慢慢恢复」。同一天用户看过设计稿后：「按照推荐开始做 / 这些文字都用本地化，要考虑中英文不同的长度超出边框的问题」，第 9 节的问题都按推荐定。

**状态：已实现（D 分支 `feature/survival-health-v1a`，2026-10-21 由 Main 合并进 master）。打夹板（V2 动作 + 坐下键）用户 2026-10-20 实机 PASS；同日按用户意见把打了夹板的腿的疾跑放早到愈合 30%（`sprint_from` 改成 [未固定, 固定] 一对）；摔落的手臂骨折改成只在摔倒时判定撑地那只手（[fall_landing_v1_plan.md](fall_landing_v1_plan.md)）。这两项编译通过，没进游戏。** 接在生存与健康 V1a（[survival_health_v1a.md](survival_health_v1a.md)）后面，是 V2 设计稿（[survival_health_v2_design.md](survival_health_v2_design.md) 第 3.4、7、8 节）里"骨折 + 夹板"那一行的最小版本：不做 11 个部位、疼痛系统和正骨手术，只做"腿 / 手臂骨折 → 打夹板 → 几天后愈合"这一圈。所有数字都是游戏平衡参数，不是医学数据，在 `data/apocalypse_firstlight/health/health_v1.json` 的 `fracture` 段（和 `HealthConfig.Fracture` 的默认值相同），可以调。背包里的身体图见 [body_silhouette_v1_plan.md](../ui/body_silhouette_v1_plan.md)。

## 1. 目标

- 从高处跳下来要掂量：摔断腿会让人走不快、跑不了，但不会直接死。
- 自己能处理：有夹板就能自己打上，打上以后能慢慢走回家，几天后好。
- 不处理也能活，但很难受、好得很慢，所以玩家会想去做夹板。
- 看得见：夹板绑在身上别人也看得到，徽章外圈显示愈合进度，背包身体图标出哪条腿、哪只手。

## 2. 四个部位

分左右（用户 2026-10-20 按推荐定）：右臂、左臂、右腿、左腿，每个部位最多一处骨折（`health/BodyPart`，`Fractures.View(part, splinted, progress)`）。

| | 腿骨折 | 手臂骨折 |
|---|---|---|
| 现实里像什么 | 小腿（胫腓骨）、脚踝 | 前臂、手腕 |
| 主要后果 | 走不快、不能疾跑、跳不高 | 拿枪不稳；主手那只还影响挖掘和近战 |

"主手臂"是拿枪、拿工具那只（`BodyPart#mainArm(player)`，跟随主手设置）；另一只是"托枪手"。

## 3. 怎么会骨折

只看**换算后真正扣到生命上的伤害**（V1a 第 3 节，护甲之后、摔落 ×5 之后），所以护甲、落到水里、干草块都会自然降低概率。

| 来源 | 腿骨折概率 | 手臂骨折概率（只在摔倒时） |
|---|---|---|
| 摔落（`minecraft:fall`，伤害 d） | `clamp((d − 10) / 40, 0, 0.85)`（`leg_fall`），随机一侧 | `clamp((d − 25) / 60, 0, 0.5)`（`arm_fall`），撑地的那只手 |
| 例：6 格（15 HP） | 12% | 0 |
| 例：8 格（25 HP） | 37% | 0 |
| 例：10 格（35 HP） | 62% | 17% |
| 例：12 格（45 HP） | 85% | 33% |
| 车祸、爆炸、重物压 | 以后（留了 `Fractures.roll`） | 同左 |

摔落先判腿，再判摔不摔倒（摔断了腿必摔倒）；手臂只在摔倒、手着地那一刻判定，断的是撑地那只手，不会出现"脚着地，手却断了"（2026-10-20 起，`health/FallLanding`，摔倒概率和动作见 [fall_landing_v1_plan.md](fall_landing_v1_plan.md)）。上表的手臂概率是"摔倒了"的条件概率。

- 左右随机（腿、手臂各自掷一次）。
- 感染者的抓咬不会造成骨折。
- **已经骨折再摔中**：愈合进度倒退一半（`rebreak_setback`），夹板松脱（要重新打），动作栏"右腿又断了"。

## 4. 骨折的后果

数值对是 [未固定, 已固定]。愈合到 70%（`fade_from`）以后，惩罚线性淡到 0。

### 4.1 腿骨折（`fracture.leg`）

| | 未固定 | 已固定 |
|---|---|---|
| 移动速度（属性修饰，客户端同样移动） | ×0.6 | ×0.8 |
| 疾跑 | 不能，愈合到 85%（`sprint_from[0]`）起可以 | 愈合到 30%（`sprint_from[1]`，5 天里约 1.5 天，休息更快）起可以（用户 2026-10-20：长好要 5 天，打了夹板 1–2 天后应该能疾跑；原来两边都是 85%） |
| 跳跃高度 | ×0.85 | ×0.9；无论如何不低于原版的 0.82 倍：还能跳上一格 |
| 落地 | 从 2 格起，按多摔 1 格算（约多 5 HP） | 同未固定 |
| 走动耐力消耗 | ×1.3 | ×1.15 |
| 自然回血上限（`HealthCap`） | 85 | 95 |

### 4.2 手臂骨折（`fracture.main_arm` / `fracture.support_arm`）

| | 主手臂 未固定 / 已固定 | 托枪手 未固定 / 已固定 |
|---|---|---|
| 枪：瞄准晃动 | ×1.5 / ×1.2 | ×2.0 / ×1.4 |
| 枪：后坐力回复 | ×0.6 / ×0.8 | ×0.8 / ×0.9 |
| 挖掘速度 | ×0.5 / ×0.8 | ×0.8 / ×0.9 |
| 近战伤害 | ×0.6 / ×0.85 | ×0.85 / ×0.95 |
| 爬梯子、藤蔓 | ×0.5 / ×0.8 | ×0.5 / ×0.8 |
| 自然回血上限 | 90 / 95 | 90 / 95 |

- 不禁止开镜（用户按推荐定：只是更晃）。
- **换弹不变慢**（V1 推迟）：换弹动作的时长现在在服务端、枪模型和身体动画里是固定的，放慢要三处一起改，放到以后（第 11 节）。

### 4.3 表现

- 动作栏：骨折"右腿骨折了"，再断"右腿又断了"，固定"右腿已固定"，愈合"右腿已经长好了"。
- 身上：夹板留在那条肢体上（第 5.3 节）。
- 骨折那一下的骨裂声（2026-10-20，编译通过，没进游戏）：`Fractures#breakLimb` 播放 `fracture_crack`，传 12 格，见 [fall_landing_v1_plan.md](fall_landing_v1_plan.md) 第 5 节。落地分档和摔倒（手臂只在摔倒时判定）已实现，在那份方案里，没进游戏。
- 还没做（以后）：镜头一沉、剧痛发白；跛行步态；伤臂贴身。

## 5. 夹板

### 5.1 物品

| 物品 | ID | 堆叠 | 质量 | 格子 | 作用 |
|---|---|---|---|---|---|
| 夹板 | `apocalypse_firstlight:splint` | 4 | 0.35 kg（估计） | 2×1 | 固定一处骨折 |

- 模型：两条削平的松木条（约 10 px 长）并排，中间捆一道纱布带，AFL Mesh（`tools/build-equipment-meshes-v1.mjs` 的 `SPLINT`，248 三角形），材质和绷带的纱布一致；物品渲染走 `client/AflStaticMeshItemClient`（偏移 0.475938）。
- **没有配方**：用户 2026-10-20「在我们做配方重构之前，不要擅作主张给任何东西添加配方」。设计时的"2 根木棍 + 1 卷绷带"不做；原版木棍也已被原版退役 V1.1 收回。配方重构时再定夹板怎么来（比如网格树掉的树枝 `*_branch`、以后的 AFL 木条）。
- 目前只在创造模式"生存物资"里，没有配方、没有战利品。

### 5.2 使用

- 按住右键：前臂 8 s（`SplintItem.USE_TICKS` 160），腿 6 s（`LEG_USE_TICKS` 120，坐在地上打；站着时先自动坐下，坐好才开始，打完继续坐着）。固定顺序：右腿、左腿、右臂、左臂里第一个没固定的（`Fractures#splintTarget`，两端同一规则）。没有骨折时动作栏"没有需要固定的骨折"，都固定了"骨折都已固定"。游泳、驾驶时不能用；中途松开不消耗。创造模式不消耗。
- **动作**：2026-10-20 换成 V2（用户批准的概念，`tools/medical-actions-v1a/author_splint_v2.cjs` 生成）：腿是布条从腿下穿、外侧拉紧，前臂是抬到嘴边用牙咬住布条拉紧；加了坐下键（坐着算休息）。详见 [splint_animation_v2_plan.md](splint_animation_v2_plan.md) 第 6 节。右肢整套镜像。
- V1 的动作（站着把夹板贴上、拿纱布卷绕三道、按两下；腿是动作自己坐下又站起、`client/SplintSitInput` 让玩家不动）已被 V2 取代，`author_splint.cjs` 只留作参考，不要再用它写文件（会覆盖 V2）。
- 声音和数值检查见 V2 文档 6.3、6.4。木条碰撞声还没录。

### 5.3 留在身上

- 用 `client/BandageWrapRenderer` 画（和纱布同一套：骨骼时跟着关节弯，原版身体时画在刚性部件上，第一人称视图模型的手臂也画）：手臂两条木条在前臂外侧和内侧，三道纱布；腿两条在小腿外侧和内侧，三道纱布。
- 使用过程中：木条从腿 0.9 s、前臂 1.3 s 起出现，三道布条按动作的时钟一道道绕上去（V2 时间表，见 [splint_animation_v2_plan.md](splint_animation_v2_plan.md) 6.3）。
- 同步：`HealthPackets.Marks`（`BodyMarkSync`）带上已固定和骨折的部位，发给本人和看得到他的玩家。
- 愈合后消失（不还夹板）；再断时消失，要重新打。

## 6. 愈合

时间按 V2 设计稿的"现实一周 ≈ 一个游戏日"压缩：

| | 已固定 | 未固定（×0.25，`unsplinted`） |
|---|---|---|
| 腿骨折（`leg_heal_days`） | 5 游戏日 | 20 游戏日 |
| 手臂骨折（`arm_heal_days`） | 4 游戏日 | 16 游戏日 |

- 和伤口一样，只在玩家在线时计时；**睡觉跳过的夜晚算进去**（`PlayerHealth#sleepFinished`）。
- 休息（睡觉、坐着当乘客、用坐下键坐在地上）时愈合 ×1.5（`rest`）。
- 死亡清空；从末地回来保留。存在玩家 persistentData `afl_fractures`（`v`、`list` 里每处 `part`、`splinted`、`progress`）。
- 只发给本人的完整状态在 `HealthPackets.State` 里；网络协议 59 → 60。

## 7. HUD、人物页、背包

- **徽章**（`StatusBadgeHud`，棕色 BAD，不用红色：骨折不会直接致命）：每处骨折一个，键 `fracture_<部位>`。图标：一根骨头中间一道斜裂纹；已固定时两侧多两条木条。名称"右腿骨折"等；效果：腿"移动速度和跳跃高度降低，无法疾跑"、主手臂"瞄准晃动增大，挖掘、近战和攀爬减弱"、托枪手"瞄准晃动明显增大，攀爬变慢"、已固定"已固定，正在愈合"。已固定时外圈是剩下的愈合，未固定没有外圈。
- **人物页状态面板**：四个部位共用一条说明 `hud.apocalypse_firstlight.status.fracture.detail`（2026-10-20 起写明手臂只在摔倒时撑地骨折、骨折期间生命值无法恢复到满）。
- **背包身体图**：骨折的部位标红（已固定变琥珀）、放骨折徽章；鼠标停上去推荐夹板（身上没有时变暗，下面写"先别乱动，找个安全的地方休息"）；已固定时写"大约还要 N 天长好"。不推荐现做（没有配方）。见 [body_silhouette_v1_plan.md](../ui/body_silhouette_v1_plan.md)。
- 不加 Jade。

## 8. 代码和指令

- `health/Fractures.java`：状态、判定、愈合、惩罚（移动速度属性、跳跃、落地、挖掘 `BreakSpeed`、近战 `LivingHurtEvent`、攀爬、回血上限 `HealthCap`）；客户端用同一套函数算自己的疾跑（`LocalPlayerWeightSprintMixin`）、耐力（`PlayerStamina`）、枪的晃动和后坐力回复（`NativeWeaponSway`、`NativeGunRecoil`）。
- `health/SplintItem.java`、`health/BodyPart.java`、`health/BodyMarkSync.java`、`health/HealthConfig.java`（`Fracture`）、`client/BandageWrapRenderer.java`；坐下键 `sit/GroundSit.java`、`sit/GroundSeat.java`、`client/skeleton/GroundSitClient.java`。
- 动作：`player_actions/item/splint_arm.json`、`splint_leg.json`，道具 `player_props/splint.json`，片段在 `animations/player/medical.animation.json`（`medical.splint_arm` / `medical.splint_leg`）；坐姿片段 `animations/player/body.animation.json`。
- 开发指令：`/afl health fracture <right_arm|left_arm|right_leg|left_leg>`（骨折；已经断了就是"再断"）、`… <部位> splint`（固定）、`… <部位> heal`（治好）、`/afl health fracture heal`（全部治好）、`/afl health advance <天>`（伤口和骨折一起往后推）。

## 9. 用户定的（2026-10-20，都按推荐）

1. 部位：分左右。
2. 未固定的腿：还能跳上一格。
3. 愈合：已固定腿 5 天 / 手臂 4 天，未固定 ×0.25。
4. 夹板配方：先按推荐定了 2 根木棍 + 1 卷绷带；同一天用户改口：配方重构之前不给任何东西加配方，所以 V1 没有配方，夹板只在创造模式物品栏里。
5. 手臂骨折开枪：只是更晃，不禁开镜。换弹变慢推迟（4.2 节）。

## 10. 验收（实机，由用户做）

1. `/afl health fracture right_leg`：动作栏、徽章、背包身体图右腿标红；走路变慢、不能疾跑、还能跳上一格。
2. 鼠标停在右腿上看推荐：身上没有夹板时；从创造栏拿一个夹板后再看。
3. 拿夹板右键：坐下打夹板 8 s，第一、第三人称都看；中途松开不消耗；打完夹板留在右腿上，别的玩家也看得到。
4. 手臂：`/afl health fracture right_arm`，打夹板（站着，镜像）；开枪更晃。左臂一样。
5. `/afl health advance 5`：腿愈合、夹板消失、动作栏"右腿已经长好了"。
6. 从 10 格以上跳下：大概率摔断腿。

## 11. 已知限制和以后

- 夹板放上那一刻，手里的夹板和身上的木条位置不完全一样（手臂放在外上侧，身上的木条在外侧），会跳一下。
- 腿绕布带时纱布卷绕到腿下面那几帧会被藏起来。
- 换弹变慢（4.2 节）；骨折那一下的镜头和发白（骨裂声已做）；跛行步态；伤臂贴身；木条碰撞声。
- 车祸、爆炸、重物压的骨折来源。
- 开放性骨折（出血 + 感染，等 V1b 出血）、肋骨骨折、扭伤、止痛药、正骨、拐杖、永久伤残、NPC 医疗。
