## 1. 这本书是什么

书在世界里是一本真实的出版物，玩家能拿起来、打开、一页一页地读。读到讲某样东西怎么做的那一页，就学会对应的工作台配方（配方 JSON 化见 `afl_workbench_v1_design.md` 第 18 节）。

| 项目 | 候选设定 |
|---|---|
| 书名 | 《野外求生指南》/ FIELD SURVIVAL GUIDE，修订第四版 / REVISED FOURTH EDITION |
| 作者 | 哈伦·普鲁伊特 / Harlan Pruitt（虚构），“做了二十六年林区巡护员”。游戏开头另加免责声明（用户 2026-10-21） |
| 出版社 | 林线出版社 / Timberline Press（候选，还没写进 `docs/world/federation_companies_v1.md`） |
| 规格 | 口袋平装，11.5 × 18 厘米，48 页，定价 $6.95 |
| 封面 | 物品模型和世界里摆着的书用英文封面（属于世界里的东西）；打开阅读时，封面和内页跟游戏语言 |
| 字体 | 全书只用模组自带的 AFL Sans SC（`font/afl_sans_sc.ttf`），中英文同一套（用户 2026-10-21）；粗体和游戏里一样，用同一字形加描边 |

## 2. 阅读界面

右键打开书。按键：A 上一页，D 下一页，Tab 目录，Esc 合上（Tab 是建议）。

- **A 版：2D 跨页**（已选定，第一轮实现）。跨页平铺在屏幕中间，高约 860 像素，字约 18 像素，和视野设置无关。背后的世界只压暗一半，不做模糊（游戏不暂停，模糊太贵）。
- **B 版：第一人称捧书**（没选，留作以后的可能）。双手（方块手臂，按真实尺寸）把书举到眼前约 40 厘米处，视野收窄到约 36°，书页在屏幕上和 A 版差不多大。书页亮度跟着世界光照，夜里要有灯才能读。如果用默认的 70° 视野，书拿在 35 厘米处时字只有约 8 像素，看不清，所以读书时必须收窄视野；收窄和恢复都要像其他第一人称动作一样平滑过渡。

两版共用的规则（建议）：

- 站着读，可以慢走；疾跑、受伤、开火就合上书。
- 翻页和合上有纸张声。
- 屏幕上显示页码，例如“第 18–19 页 / 48”。

## 3. 读到那页就学会配方

- 停在有配方的那一页约 3 秒才算学会，翻过去不算。
- 学会时提示一次，用 HUD 的书面语：“已学会配方”+ 配方名 +“可在工作台制作”。
- 服务端核对两件事：玩家手里拿着这本书；这一页确实教这条配方。客户端只上报“正在看哪一节”。
- 书不消耗。谁读谁学会，可以传给别人读。
- 学会记录写进现有的 `WorkbenchKnowledge`，来源是 `book`，来源名就是这本书的物品名。

## 4. 本地化和数据（怎样改内容、加删配方）

书在游戏里不存成整页图片，而是分成三层：

1. **文字进语言文件**。标题、每段正文、小标题、图注、插图上的部件名，都用 `book.apocalypse_firstlight.field_survival_guide.*` 的键，en_us 和 zh_cn 同行对齐，走 zh_cn 写作规范和单独的叙事审读。改一句话只改语言文件。
2. **书的结构文件**。哪一章有哪些节、每节由哪些段落、插图、提示框组成、教哪条配方，都写在结构文件里，只引用语言键，不写文字。建议放在 `data/<命名空间>/books/field_survival_guide.json`，由服务端发给客户端，和配方走同一条路，这样显示的内容和判定学会用的是同一份。
3. **插图不带字**。每张图是一张不分语言的线稿，部件名的标注位置写在结构文件里，文字由游戏按当前语言叠上去。改图只重画那一张。

**排版**：游戏打开书时按语言和字体现排。加一段、删一段，后面的内容自动顺延，页码和目录跟着变。

**配方挂在“节”上，不挂在页码上**，所以改动正文不会让配方对错页。

- **加配方**：新建配方 JSON，unlock 写 `{"type": "book", ...}`；在结构文件里加一节，引用这条配方；在语言文件里补中英文。
- **删配方**：从结构文件里删掉这一节；把配方 JSON 删掉，或者改它的解锁方式。
  - 配方 JSON 删掉了：已学会的记录不会再发给客户端，存档不会坏。
  - 配方还在、只是书不再教：学会的玩家保留这条配方（建议）。

**“你需要”清单从配方 JSON 读**（计划，第一轮没做：现在的弓钻清单是语言文件里手写的，那一节还没有对应的正式配方）。材料名和数量直接取自配方，按书的样式排版，不手抄。调配方时书页自动跟着变，只有讲解正文是手写的。

**加载时核对**，以下情况记日志：

- 书里引用的配方不存在；
- 写了 `unlock: book` 的配方在书里找不到；
- 某个语言键缺 en_us 或 zh_cn（第一轮只在客户端排版时发现当前语言缺键才记一次日志）。

## 7. 第一轮实现（2026-10-22，分支 AFL-Workbench，用户实机 PASS）

### 7.1 物品

- 注册 ID `apocalypse_firstlight:field_survival_guide`（`AflItems.FIELD_SURVIVAL_GUIDE`，类 `book/GuideBookItem`），不堆叠，只在“近战与装备”创造栏，排在手锯后面。没有合成配方。
- 网格占位 1×2，重量 0.12 千克（估计值）。
- Mesh 由 `tools/build-equipment-meshes-v1.mjs` 的 `fieldSurvivalGuide()` 生成：11.5 × 18 × 0.6 厘米，切口一侧圆角，书脊略圆；封面、书脊、封底贴一张整幅封面图（英文封面，世界里的东西），切口贴书页纹理。76 个三角形，图集 512，`texelsPerPx` 72（实际约 62.5 texel/px）。`tools/build-material-meshes-v1.mjs` 的 bake 为此新增 `texelsPerPx` 参数，默认 40，其他物品不变。
- 手持：第一人称右手捏住书的切口边（握点 `grip`），书朝左伸、封面朝向镜头；第三人称手提书脊一侧（`carry`），书竖着垂在手下。图标从模型渲染。
- 封面和切口的源图由 `design/items/field_survival_guide_v1/fsg_game_assets.py` 和 `fsg_game_assets.cjs` 生成（`python fsg_game_assets.py && node fsg_game_assets.cjs`），写到 `src/main/blockbench/textures/field_survival_guide_cover_src.png` 和 `field_survival_guide_edges_src.png`。

### 7.2 书的数据

- 结构文件 `data/apocalypse_firstlight/books/field_survival_guide.json`（`format_version` 1）。服务端 `book/GuideBooks` 加载、核对，登录和 `/reload` 时用 `GuideBookPackets.Books` 发给客户端。核对不过的书不加载并记日志；书里教的配方不存在、配方 unlock 写了这本书但书里没有，都记警告。
- 页面图片在 `assets/apocalypse_firstlight/textures/gui/book/field_survival_guide/`：`paper.png`（736×1152）、`cover_zh_cn.png` 和 `cover_en_us.png`（打开时的封面，跟游戏语言，其他语言用英文）、`fig_bow_drill.png`（弓钻部件图，不带字，部件名由游戏叠上去）。
- 文字键在 `book.apocalypse_firstlight.field_survival_guide.*`；界面键在 `screen.apocalypse_firstlight.book.*`，提示在 `message.apocalypse_firstlight.book.learned` 和 `learned_where`。
- 第一轮正文：目录页，第三章“火”的开头（备齐三样东西、雨天找干柴提示框）和弓钻一节（部件图和“你需要”清单）。章节号仍按完整的书写成“第三章”，但这一轮页码是自动排的，所以第三章从第 2 页开始，不是第 18 页。

### 7.3 阅读界面（A 版）

- 代码在 `client/book/`：`GuideBook`（解析结构文件）、`GuideBookLayout`（排版）、`GuideBookScreen`（界面）、`GuideBookClient`（收数据、打开、学会提示）。
- 主手拿书右键打开，先只显示合上的封面，再翻开是封二和目录，之后是正文，偶数页在左。
- 排版按当前语言现排：页面坐标是 1150 × 1800（每厘米 100），每章从新页开始，标了 `new_page` 的节也从新页开始；段落和列表逐行断页，小标题至少带一行正文，提示框和插图整块挪页。中文逐字断行，英文不拆单词，标点按避头避尾规则贴住前后的字。页码印在外侧，目录页（第 1 页）不印页码，目录的页码和跳转都由排版结果生成。
- 断页时不留孤行：一段的第一行不单独留在页底，最后一行不单独翻到下一页（这样会少于两行时整段挪页）；小标题后面至少跟两行正文。
- 字体：全书用 AFL Sans SC，另加 5 个只改清晰度的字体定义 `font/book_2`、`book_3`、`book_4`、`book_6`、`book_10`（同一个 ttf，oversample 不同），按字在屏幕上的实际像素大小挑一个，放大时不糊。
- 字号换算：游戏的 ttf 字体把 1 em 对应到 `size`（8.5 字体像素），不是上升线到下降线的高度。第一次进游戏（2026-10-22）按后者换算，字大了 1.45 倍，中文行与行叠在一起，已改正。
- 跨页和底部提示栏都放在快捷栏上方；提示栏按 0.65 倍绘制，比 HUD 的按键提示小（用户 2026-10-22）。
- 按键：A 或 ←、PageUp、滚轮上 = 上一页；D 或 →、PageDown、滚轮下 = 下一页；点左页翻回、点右页翻过；Tab 跳到目录，点目录里的一行跳到那一章；Esc 或背包键合上。底部提示栏显示“第 a–b 页 / N”和这几个按键。
- 声音：原版翻书声 `BOOK_PAGE_TURN`，打开和翻页音调 0.9–1.0、音量 0.8，合上时音调 0.75。
- 不暂停游戏。受伤（生命值下降）、疾跑、主手不再是这本书时自动合上。

### 7.4 停留学会

- 当前跨页上有某一节教的配方、玩家还不会时开始计时，翻页就重新计；停满 60 tick（3 秒）后，客户端对每个这样的节发一次 `GuideBookPackets.Read(书, 节)`，同一次打开里每节只发一次。
- 服务端核对主手拿的是这本书、这一节确实教这条配方、配方的 unlock 写的是这本书，然后用 `WorkbenchKnowledge.learn`（来源 `book`，来源名是书的物品名）学会，回 `GuideBookPackets.Learned`。
- 客户端在右上角显示“已学会配方 / 物品名 / 可在工作台制作”约 4 秒后淡出；书开着时由阅读界面画，合上后由 HUD 覆盖层 `guide_book_learned` 画。
- 创造模式本来就会所有配方，不计时，测试要用生存模式。
- 测试挂法：`workbench_recipes/building/white_oak_beam.json` 的 unlock 暂时改成 `{"type": "book", "item": "apocalypse_firstlight:field_survival_guide"}`，由弓钻一节教。这只是为了测试，书里讲的东西和白栎横梁无关；第二轮换成正式配方后改回。
