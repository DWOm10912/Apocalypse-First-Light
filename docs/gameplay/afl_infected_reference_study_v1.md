## 0. 前提（用户 2026-10-26 决定）

- 玩家模型不改：继续用旧方块身体（原版比例方块 + SkinMesh 关节环 + 128 皮肤）。
- 感染者和玩家用**同一种画风**：方块身体、同样的像素密度、同样的手绘贴图风格（以购买的 zombie.png 为标准）。
- 感染者的**骨架和比例可以不同**：可以多关节、加长手臂、单独的下巴、更宽更瘦，用来做夸张动作。
- 参考写实游戏，是为了学设计思路，不是学写实建模。

## 2. 共同规律

1. **普通感染者共用一副身体，花样来自衣服。** TLOU 设定图、Days Gone 尸潮、Project Zomboid 都一样。衣服用日常衣服和职业装，颜色互相区分，远看靠色块就能认。
2. **姿态是第一识别。** 写实游戏里几乎没有站得笔直的：驼背、头前伸、膝盖弯、两只手臂不对称（一垂一抬，或手缩在胸前）。原版僵尸"双臂平举"这种姿态，这些游戏里一个都没有。
3. **特殊种类靠轮廓，不靠颜色。** 胖、瘦、长手臂、驼背、爬行，影子一看就知道。L4D 删掉 Screamer，就是因为它在尸群里认不出来。
4. **伤和血有因果。** 血集中在嘴、下巴、胸口和手上，往下流；伤口在哪里，衣服就破在哪里。不在全身随机撒血点。
5. **头部的共同特征是脱发、眼窝发黑、皮肤发灰。** 不靠夸张五官。
6. **方块风格怎么打破轮廓：** Minecraft Dungeons 的做法是让外层的东西凸出方块（藤蔓）。AFL 可以换成写实的东西：破了垂下来的衣片、背包、敞开的外套、断掉的手臂。

## 3. 用到 AFL 上

**画风（不变的部分）**
- 方块身体，关节用和玩家一样的连续环。
- 128 皮肤密度（每个模型像素 2×2 贴图像素），手绘明暗，以购买的 zombie.png 为标准。

**感染者骨架（可以和玩家不同）**
- 脊柱分两节（胸、腹），能大幅弓腰。
- 脖子单独一节，头能前伸、歪。
- 下巴单独一块，能张大，不再在脸上画张开的嘴。
- 手臂、躯干的长宽按种类调：快尸手臂长、偏瘦；重型宽、厚。

**普通感染者**
- 同一副身体，换衣服库（日常装 + 职业装：店员、护士、修车工、修路工……）。
- 姿态和步态做 3–4 套随机，配上衣服，同屏不显得重复。

**特殊种类**
- 先做轮廓明显的两种：快尸（瘦长、低姿态冲刺）和重型（宽厚、慢）。
- 以后再按需要加爬行者、断颈等，每种先用轮廓过一遍"尸群里认不认得出"。

**伤和血**
- 只画在有因果的位置：咬伤、嘴、下巴、胸口、手。
- 衣服在伤口处破洞，血顺着往下流。
