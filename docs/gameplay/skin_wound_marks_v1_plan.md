# 皮肤伤痕层 V1（2026-10-21，用户按推荐批准，已实现，用户 2026-10-21 实机 PASS，见第 5 节；V2 细节见第 6 节，用户 2026-10-21 实机 PASS）

## 1. 用户的要求

用户 2026-10-21（雷击伤第二轮实机，背包身体图截图）：「这边现在是不是只显示可治疗的部位？」「能不能给烧伤真的做成玩家皮肤的覆盖层？后面的抓伤等等也可以做」「逻辑基本上没问题」。

## 2. 身体图现在显示什么（读代码，`client/inventory/BodySilhouette`）

不是只显示可治疗的部位。**每个有伤的部位都会标出来**，不管处理没处理：

- 有伤的部位刷一层颜色：琥珀色 = 已经处理、在愈合；棕色 = 该处理了；红色 = 要尽快处理（感染、化脓没清洁，骨折没固定）。
- 每个部位只放一个徽章，是这个部位上最急的那处伤；同一部位有几处伤时，鼠标悬停会全部列出来。
- 没伤的部位只是灰的皮肤，没有任何标记。

截图里胸口和左臂各一处雷击烧伤，没包扎，所以是棕色。

## 3. 设计

### 3.1 一句话

每个玩家一张和皮肤 UV 完全一样的"伤痕层"贴图，画在皮肤本体上、皮肤第二层（外套、袖子、裤子）和装备下面。伤口在哪、是什么伤、到哪个阶段、包没包扎，都画在这张图上。第三人称、第一人称的手臂、别人看到的、背包身体图，用的是同一张图。

### 3.2 每种伤的样子

| 伤 | 样子 | 愈合时 |
|---|---|---|
| 雷击烧伤 | 入口和出口的点状烧伤：中间一个深褐的焦点，外面一圈红 | 红 → 粉 → 淡掉 |
| 金属烫伤 | 烫它的东西的形状，深褐的芯、红边：背枪是背上一条斜长条（枪身贴着背的那条线），枪套是右大腿外侧一个竖长方形，胸挂弹匣是腹部前面一两个竖着的小长方形 | 比雷击烧伤慢，最后留一点浅褐 |
| 抓伤 | 三道平行的斜线，暗红 | 结痂变深，再淡掉 |
| 局部感染 | 抓伤周围一圈红肿 | 清洁后红肿慢慢退 |
| 化脓 | 红肿中间黄白的点 | 退回感染的样子 |
| 骨折 | 不画（已经有夹板的模型） | — |

- **位置**：每处伤口在它的部位上有一个固定的位置，正面、背面、侧面都可能。雷击烧伤的入口在头顶、肩或手背，出口在小腿或脚底附近；金属烫伤按装备的位置。存档里每处伤口多存一个随机种子，位置由它定，所以痊愈一处、别的伤不会跳位置。
- **愈合**：按恢复进度慢慢变淡，痊愈时消失。
- **包扎**：四肢照旧用现在的几何纱布（`BandageWrapRenderer`），纱布盖住的伤痕不画。头、胸、腹的包扎现在没有任何显示，这次在伤痕层上画一块白纱布贴片，盖在伤口的位置。
- **衣服**：皮肤第二层、AFL 的衣服和护甲盖住的地方看不到伤痕，和现实一样。

### 3.3 画在哪里

| 地方 | 做法 |
|---|---|
| 骨骼身体（平时的第三人称、自己的第一人称身体） | `SkinMesh` 把皮肤本体再画一遍，换成伤痕贴图（顶点和皮肤完全一样，画在皮肤之后，和原版蜘蛛眼睛那类层一样靠深度相等通过；实现时没有往外推 0.02 px）；头用原版的头部 |
| 原版身体（游泳、睡觉、鞘翅飞行等骨骼不画的姿势） | 一个 RenderLayer，在四肢、身体、头上画同一张图 |
| 第一人称手臂（拿枪、油桶、撬棍时的手臂） | `NativePlayerArmRenderer` 里，和纱布一样跟着手臂画 |
| 背包身体图 | 皮肤灰掉以后，把伤痕层的正面叠上去，伤痕保持原来的颜色，所以一眼能看到伤在哪 |

- 贴图每个玩家一张，只在伤口变化时重新生成，平时不花时间。
- 别人看到：现在的 `HealthPackets.Marks`（绷带、夹板，已经发给看得到这个玩家的人）加上伤痕列表（部位、种类、阶段、包扎、恢复、种子），网络协议 +1。

## 4. 要用户决定的

1. **伤痕有多细**：A 和皮肤一样的像素（64 × 64，一个焦点就是 1 个皮肤像素，看起来像皮肤本身的一部分，推荐）；B 细一倍（128 × 128，形状更清楚，但比皮肤的像素细）；C 细四倍（256 × 256，像贴上去的贴纸）。
2. **这次做哪些**：雷击烧伤、金属烫伤、抓伤、感染、化脓、头胸腹的纱布贴片一起做（推荐，同一套东西）；还是先只做烧伤。
3. **雷击纹**（Lichtenberg 纹）：V1 因为没有皮肤贴图层没做（第一版方案 3.5"不做的"）。有了伤痕层就能做：直击和侧闪后，从入口往肩、胸散开的红色蕨叶状纹，不疼、不影响任何数值，一天之内淡掉。推荐这次一起做。不做的话，烧伤徽章上的蕨叶线也去掉，只留焦斑。

**用户决定（2026-10-21）**：「按推荐做：皮肤像素精度，烧伤、金属烫伤、抓伤、感染、化脓和头胸腹纱布贴片一起做，雷击纹也做」。也就是第 1 条选 A，第 2 条全做，第 3 条做。

## 5. 实现（2026-10-21，D 分支 `feature/lightning-injury`，用户 2026-10-21 实机 PASS）

| 部分 | 做法 |
|---|---|
| 存档 | 每处伤口多一个 `seed`（`Wounds.Wound`，新伤口随机；旧存档没有时读的时候随机一个） |
| 同步 | `HealthPackets.Marks` 多了伤痕列表 `SkinMark`（部位、来源、阶段、包扎、种子、恢复 0–15）和雷击纹 `Fern`（强度 0–15、入口部位、种子）。`BodyMarkSync` 照旧在变化时发给本人和看得到的人（每秒比较一次；恢复按十六分之一走，所以变淡不用每秒发包）；雷击后立刻发一次。协议 63 → 64 |
| 恢复 | `Wounds.skin`：新鲜烧伤按年龄 / 痊愈时间，抓伤按年龄 / 当前处理情况的愈合天数，感染、化脓清洁后按恢复进度，没清洁是 0 |
| 雷击纹 | `LightningInjury.State` 多了 `fern`（剩余 tick，在线和睡觉 × sleep 才走）、`fern_part`、`fern_seed`；直击、侧闪（`lichtenberg` true）设成 `lichtenberg_days` 1 天，入口是第一处雷击烧伤的部位 |
| 贴图 | **V1，已被第 6 节替换**：`client/WoundSkin`：每个有伤痕的玩家一张 64 × 64 `DynamicTexture`，伤痕列表、雷击纹或手臂粗细变了才重画；10 秒没用就释放 |
| 位置 | 每个部位当成一圈"带子"（皮肤 UV 上相连的西、前、东、后四个面，能绕着肢体接上）：手臂第 6–10 行、腿第 6–9 行（纱布缠的那段，离手 1.5–5.5 px、离脚 2–6 px），胸是身体第 0–5 行，腹第 6–11 行，多在前面或后面；头 8 行一圈，雷击烧伤五分之三在头顶 |
| 样子 | **V1，已被第 6 节替换**：雷击烧伤：1 px 焦点、上下左右一圈红、四角淡粉；金属烫伤：背枪是背上 6 px 的斜条，枪套是右大腿外侧 2 × 4 的竖长方形，弹匣是腹前一两个 1 × 3 的小竖条，深褐芯、红边；抓伤：三道 3 px 的平行斜线；感染：伤口外一圈、两圈红肿，清洁后按恢复变淡；化脓：中间一两个黄白点；包扎的头、胸、腹：盖住伤口外一圈的白纱布贴片（织纹、深一点的边），先画纱布再画没包扎的伤，所以纱布不会盖住旁边别的伤；包扎的四肢不画（几何纱布盖着）。雷击纹：1 px 红色主干每步走一行，两侧交替长出斜向的细枝（细枝上再长更短的），越往外越淡 |
| 愈合 | **V1，已被第 6 节替换**：雷击烧伤：焦黑 → 红褐 → 淡疤变透明；金属烫伤：深褐 → 浅褐变淡；抓伤：鲜红 → 结痂暗红 → 淡粉变透明；雷击纹整体按剩余时间变淡 |
| 画在哪里 | 骨骼身体（`PlayerSkeleton.draw`，皮肤本体和头之后、纱布之前）；原版身体（`WoundSkin.Layer`，只画头、身体、四肢的本体，加在纱布层前面，骨骼画过时跳过）；第一人称手臂（`NativePlayerArmRenderer`，手臂之后、袖子之前）；背包身体图（`BodySilhouette`，灰化和部位颜色之后叠上正面） |
| 离线检查 | `WoundSkin.canvas` 用编译好的类直接跑（scratchpad 里的 `WoundSkinCheck`）：2000 个种子 × 7 个部位 × 3 种来源 × 宽窄手臂，化脓、头胸腹包扎，每 7 个带一个雷击纹，一共 489 万个伤痕像素，**落在皮肤面以外的 0 个**（窄手臂多出的两列也算在外面）；样图核对了每种伤的位置、形状和愈合的颜色 |

- **实机**：用户 2026-10-21 进游戏看过，回复 PASS。用户没有逐项说明看了哪些场合（第三人称、第一人称手臂、别人看到的、游泳和睡觉时的原版身体、背包身体图、光影下）。
- 趴着爬的时候第一人称看到的手臂（2026-10-21 补，[lightning_injury_v1_plan.md](lightning_injury_v1_plan.md) 10.5）是骨骼身体的手臂，伤痕层跟着手臂一起往前挪（用户 2026-10-21 实机 PASS）。
- **位置改了**（2026-10-21，用户：「一个人根本不可能包扎到自己背后吧」，[medical_actions_by_part_v1.md](medical_actions_by_part_v1.md)）：胸、腹的伤痕只放在正面和两侧（身体带子的第 3–12 列，以前多在正面或背面），背面只留给背枪的烫伤（自己够不到，不能处理）；头的伤痕只在头顶四行（第 0–3 行，眉毛和头皮，正好在头上缠的纱布下面，以前是 8 行一圈）。头、胸、腹包扎后除了纱布贴片，`BandageWrapRenderer` 还在部位上缠三圈几何纱布。改完编译通过，上面的离线像素检查没重跑，游戏里没看。
- 已知限制：背包身体图只看得到正面，背上和侧面的伤要看第三人称；原版第一人称空手（不经过 `NativePlayerArmRenderer` 的时候）没接；衣服系统还没有，现在挡住伤痕的是皮肤第二层和护甲。

## 6. V2 细节（2026-10-21，D 分支 `feature/lightning-injury`，用户 2026-10-21 实机 PASS）

用户 2026-10-21（V1 实机 PASS 之后）：「接下来我想让你改一下这些效果的贴图，现在像素太低了 / 和我们其他的东西格格不入 / 也就是做更精致，更真实的效果」。第 4 节第 1 条原来选的 A（和皮肤一样的像素）因此改掉。

**第一版 V2 不用了**：先做的是一个皮肤像素 16 × 16 纹素（1024 × 1024，线性过滤 + mipmap，透明纹素填色）。用户进游戏看过：「你是不是把贴图的分辨率调太高了？一般大家皮肤的分辨率都没有那么高吧……看起来有点违和」（皮肤库 62 张都是 64 × 64），雷击纹「看起来有点像肺的血管」。用户决定：「伤痕层改成每个皮肤像素 4 × 4、最近邻过滤，雷击纹按真实的样子一起重做，先发离线样图」，抓伤「看起来还行」。下面是改完的样子。

| 部分 | 做法 |
|---|---|
| 精度 | 一个皮肤像素 4 × 4 纹素（`WoundSkin.K = 4`），整张 256 × 256：比皮肤细一档，但还是看得出像素，不会像一张高清贴纸贴在 64 × 64 的皮肤上。四条画的路径都按比例取皮肤 UV，所以不用改它们 |
| 过滤 | 最近邻，没有 mipmap（`DynamicTexture` 默认，`entityTranslucent` 本来就这样），和皮肤一样。边缘是硬的：每个纹素要么是伤痕要么不是，淡出靠颜色和透明度，不靠模糊 |
| 画法 | 每处伤是一个距离场加噪声（`Paint` / `Sdf`，单位是皮肤像素，从伤口中心算），按纹素中心取色，带子横向绕圈，竖向到头为止；头顶的面单独一块，不绕 |
| 雷击烧伤 | 半径约 1 px，边缘不规则、略椭圆：中间焦黑带裂纹（露出红肉）和灰白的灰，外面一圈湿红的创面带反光点，边上一圈翘起的发白表皮，外面 1 px 多的发红；愈合：深色干痂 → 有光泽的粉色新皮肤（缩小一点）→ 淡疤 → 消失 |
| 金属烫伤 | 形状同 V1（背枪斜条、右大腿外侧竖长方形、腹前一两个弹匣竖条、其他部位 2 × 2 圆角方块），边缘清楚：中间皮革样、蜡黄褐色带斑，靠边一圈深色，外面一窄条红创面和发红；愈合：深色痂 → 保持形状的疤 → 消失 |
| 抓伤 | 三道斜的爪痕，略弯，两头尖、中间宽，中间那道最长：深红的沟、几颗血珠、周围擦伤发红；愈合：暗色痂（会碎成几段）→ 细的淡色线 → 消失 |
| 感染 | 伤口下面一片红肿：靠近伤口热红，往外偏暗紫，离伤口约 1.7 px 淡出；清洁后按恢复变淡（同 V1） |
| 化脓 | 伤口最深处两三颗奶黄色脓点，黄绿的边，一点湿的高光，外圈一道发炎的暗红 |
| 纱布贴片 | 伤口外 0.55 px 的圆角贴片：两个纹素一根线的织纹、折起来的边、贴片的阴影；左右两条医用胶带；渗出来的：新伤是淡血色（按恢复变淡），感染是黄褐色 |
| 雷击纹 | 按真的 Lichtenberg 纹重做（`WoundSkin#fern` / `Pen`）：从入口散开几根主枝（扇形），每根走一段就一分为二，分出来的两枝几乎一样粗、短一点，一共分 5 次（`FORKS`），偶尔再长一根短的侧枝，所以越往外越密、越细，最后是一片羽毛样的细尖。一边走一边弯。主枝半宽约 0.2 px（入口处深红，约 1.5 纹素宽），每次分叉细两成、淡一点，比一个纹素还细的尖画成一个纹素、至少一半浓度；下面一层很淡的粉晕，离线 0.4 px 内。入口：手臂从护腕上方往上爬上臂外侧和前面，再从那边肩膀往胸前和背后散开；头从脖子往下散到胸前和背后；腿从那边髋部往上散到腹部；胸、腹从一点往四周散。整体按剩余时间变淡 |
| 开销 | 只在伤痕变化时重画：离线一张约 1 ms（1680 张 1.9 s），上传 256 KB；显存每人 256 KB，10 秒没用就释放 |
| 离线检查 | scratchpad 的 `WoundSkinCheck` 按纹素：40 个种子 × 7 个部位 × 3 种来源 × 宽窄手臂，每次两处伤（化脓 + 头胸腹包扎、感染），每 5 个带一个雷击纹，一共 1680 张、208 万个伤痕纹素，**落在皮肤面以外或胸腹伤落到背面的 0 个**；样图（发给了用户）核对了四个愈合阶段（0、5、10、13 / 15）、包扎、四个入口的雷击纹 |

- **实机**：用户 2026-10-21 进游戏看过 4 × 4 这版（伤痕精度、雷击纹、第三人称、第一人称手臂、背包身体图），回复「PASS，全部通过」。
- 已知限制：GameTest 没跑。
