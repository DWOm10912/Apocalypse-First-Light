## 数值（`stamina_v1.json`）

- 最大 100。
- 恢复每秒 15；在水里 ×0.5；饱食度 ≤ 6 时 ×0.5；口渴时再乘口渴倍率（口渴 < 30 ×0.75、< 15 ×0.5，肠胃感染 ×0.75，见 `thirst_system_v1.md`）；再乘体温倍率（C1 ×0.8，C2 起 ×0.6，H2 起 ×0.75，见 `temperature_system_v1.md`）。
- 恢复延迟：费力动作后 1.0 秒；降到 0 后 2.0 秒。
- 力竭解除：耐力回到 30。

| 动作 | 消耗 | 打断恢复 | 怎么判断 |
|---|---:|---|---|
| 走路 | 1.5 / 秒 | 否 | 地面水平移动 > 0.01 格 / tick |
| 潜行移动 | 1 / 秒 | 否 | 同上，蹲着 |
| 坐办公椅滑行 | 0.5 / 秒起，负重越高越多，≥ 60 kg 时 1.0 / 秒 | 否 | 骑在办公椅实体上且水平移动 > 0.01 格 / tick（2026-10-03） |
| 疾跑 | 8 / 秒 | 是 | 移动且疾跑 |
| 游泳 | 7 / 秒 | 是 | 游泳姿势（水中疾跑） |
| 踩水 | 2.5 / 秒 | 否 | 在水里且不着地 |
| 攀爬 | 3 / 秒 | 是 | 在梯子 / 藤蔓上且在移动 |
| 挖掘 | 2 / 秒 | 是 | 服务端每 tick 查挖掘速度（`BreakSpeed`） |
| 跳跃 | 5（疾跑中 7） | 是 | 服务端 `LivingJumpEvent` |
| 近战 | 空手 3；撬棍 8；其它 5 | 是 | `AttackEntityEvent`（打中实体才算，挥空不算；被手持枪取消的不算） |
| 开枪 | 按弹种：9mm 0.4、7.62 0.6、.50 AE 1.2、12 号 1.5、12.7 2.5；其它 0.6 | 是 | 服务端接受的每一发 |
| 换弹 | 1；HR55 2 | 是 | 服务端接受的换弹 |
| 拉起动绳 | 6（`costs.recoil_pull`） | 是 | 便携式柴油发电机的拉绳 QTE，服务端接受的每一下（2026-10-09，[portable_diesel_generator_v1.md](../machines/portable_diesel_generator_v1.md)） |

骑乘时不算移动消耗（坐骑自己出力），办公椅例外：坐着滑行是用脚蹬，算低强度活动（上表），坐着不动不扣、照常恢复，也不产生运动热。
- 滑行消耗 = `office_chair` × (1 + (负重的移动类倍率 − 1) × `office_chair_load`)，配置为 0.5 和 0.6667，即负重倍率只取超出 1 的三分之二：30 kg 约 0.6、50 kg 约 0.83、≥ 60 kg 为 1.0 / 秒。
- 它不打断恢复，坐着滑行时体力仍在净回。它和其它消耗一样计入口渴和体温的运动量，所以滑行会产生一点点运动热。
- 椅子的速度另外按玩家当前移速缩小（见 `docs/models/modern_office_chair.md`）。

传送（一 tick 内移动超过 4 格）不算移动。

### 负重倍率

按负担比例（负担 / 舒适负重，见 `weight_system_v1.md`），点之间线性：

| 负担 | 移动类 × | 其它动作 × | 恢复 × |
|---|---:|---:|---:|
| ≤ 15 kg | 1.0 | 1.0 | 1.0 |
| 30 kg | 1.3 | 1.15 | 1.0 |
| 40 kg | 1.6 | 1.3 | 0.8 |
| 50 kg | 2.0 | 1.5 | 0.6 |
| ≥ 60 kg | 2.5 | 1.75 | 0.4 |

- 移动类：走、潜行、跑、跳、游、踩水、爬。
- 其它动作：挖、近战、开枪、换弹。

## 力竭

耐力降到 0 进入力竭，回到 30 才解除。力竭时：
- 不能疾跑：客户端拦截，和超重禁跑用同一个 mixin；服务端如果还收到疾跑标记就清掉；
- 近战（`PLAYER_ATTACK` 伤害）×0.6；
- 挖掘速度 ×0.8，客户端和服务端同时乘，挖掘进度动画不会对不上；
- 重喘息声。

不额外减速，不禁止跳跃，不扣血。

## 疲劳：晃动和散布

疲劳度在耐力 50 以上是 0，到 0 时是 1，中间线性。
- 持枪晃动幅度 ×(1 + 1.5 × 疲劳度)，最多 2.5 倍。只改幅度，不改呼吸节奏（草案里写的节奏变快没做，改周期会让晃动的相位跳一下）。服务端算好倍率发给客户端。
- 散布：腰射、开镜的散布锥都 ×(1 + 0.4 × 疲劳度)，最多 +40%，在服务端算在姿态散布之后、连射扩散之前。

## 喘息声

- 两组单口鼻息，每次随机挑一口，音高随机 0.97–1.03：
  - `stamina_breath_light`：4 种，每 2.4–3.2 秒一口，耐力 < 20 时；
  - `stamina_breath_heavy`：5 种，每 1.0–1.4 秒一口，力竭时。
  从没有到有、或者从轻变重时，0.3 秒后就来第一口。
- 声音跟着人走（`EntityBoundSoundInstance`），类别 PLAYERS，衰减距离 8 格。
- 头在水里时不播。
- 自己的等级随本人状态同步。别人的等级发给追踪他的玩家：变化时发一次，之后每 20 tick 再发一次保持；50 tick 收不到就停。
- 素材（`tools/build-stamina-breath-sounds-v1.mjs`，用户生成，2026-10-03）：
  - 两段生成的鼻息每段只有一两口，所以用三口气拼出两组：
    - 轻的：接近原速，有一种放慢到 0.92；
    - 重的：用 ffmpeg atempo 把节奏压到 1.3–2 倍，不升调。
  - 去掉 120 Hz 以下的风噪。
  - 张嘴喘的那段带嗓音共鸣，没用。
  - 响度：重的和翻找声一样，轻的再低 4 LU，峰值不超过 −1 dBFS。
  - 文件：`assets/apocalypse_firstlight/sounds/stamina/breath_{light_1..4,heavy_1..5}.ogg`。
- 字幕：呼吸 / 喘气。

## 创造 / 旁观、保存

- 创造 / 旁观：耐力锁满，没有力竭、晃动、散布加成和喘息；切回生存时从满开始。
- 当前耐力每 tick 写进玩家的持久数据（`afl_stamina`），退出重进还在。
- 死亡后从满开始；从末地回来（不是死亡的克隆）保留。

## 调试

```text
/aflstamina
/aflstamina player <玩家名>
/aflstamina set <数值>
```

需权限 2。显示当前耐力、是否力竭、剩余恢复延迟、疲劳度、负重的三个倍率。`set 0` 可以直接测力竭。

## 没做的

- 开镜保持的消耗和恢复减半：服务端现在不知道玩家是否开着镜（只在开枪那一下知道），要另加客户端上报，留到以后。
- 挥空的近战不扣耐力。
- 呼吸节奏随疲劳变快。
- 感染者能不能听到喘息声，留给感染者听觉系统。
- 受伤对耐力的影响（`耐力.md` 第 13 节预留）。口渴和体温已接入。

## 验收（2026-10-03 用户测试 PASS）

用 Survival 和测试存档：
1. 疾跑：满耐力空手约跑 12.5 秒后力竭，停跑；站着约 2 秒后开始回，回到 30 后能再跑。
2. 走路：耐力慢慢回（每秒约 13.5）。
3. 负重 35 kg（70 个铁锭）时疾跑约 9 秒就力竭。
4. 跳跃每次扣 5；撬棍打一下扣 8；BR51 连射每发扣 0.6。
5. `/aflstamina set 0`：不能跑，持枪晃得明显，近战伤害变小，挖得慢，能听到重喘息。
6. 耐力环：掉耐力时出现，颜色随状态变，回满 2 秒后消失。
7. 第二个玩家在 8 格内能听到另一个人喘气。
8. 切创造：耐力满，环消失，喘息停。
9. 退出重进耐力不变；死亡后满。
