## 1. 范围

**管的：** 原版"按住左键，裂纹长满，方块掉落"这条破坏路线。比如拆家具、拆墙板、敲碎玻璃、挖放下的土块、砍树叶。

**不管的（这些系统先拿走左键或右键，照旧）：**

| 系统 | 现在的规则 | 负责 |
|---|---|---|
| 自然地面（草方块、泥土、沙、砾石、黏土、泥） | 原版破坏已被土方取消（`Earthwork.breaking`），只能用圆头铲一铲一铲挖 | C（土方已交给 C） |
| 巨石 | 只有鹤嘴锄能敲（`boulder/BoulderStrike`） | C |
| 自然岩面 | Rock R2 鹤嘴锄开凿，在 C 分支上，还没进 master | C |
| 树干 | 斧头砍树（`tree/FellingServer`），不走原版破坏 | B |
| 建筑目录件 | 建筑锤安装；拆除见第 1.1 节（不再瞬间拆） | B |
| 撬棍砸售货机、拆隧道小件 | 撬棍自己的动作 | B |

上面这些系统将来改规则时，按本文的分组对齐，不另起一套。

### 1.1 建筑锤不再瞬间拆除

用户 2026-10-23 原话："我觉得建筑锤不能再瞬间拆除某些东西了，不然就太假了 / 后面可以做砸的动画，消耗耐久，返还大部分材料"。

**现在的做法（建筑锤 B0，`docs/gameplay/building_hammer_b0.md` 第 6 节）：** 编辑模式下左键对着建筑构件，构件瞬间消失，原样还给 1 件。

**V1（随本设计一起做）：**

- 去掉编辑模式的瞬间拆除。编辑模式下左键对着构件什么都不发生，和对着别的方块一样。安装、旋转、目录不变。
- 要拆构件就退出编辑模式，按第 2 节的分组用对的工具慢慢挖。比如木横梁归"木制品和钉装件"，用羊角锤或撬棍；混凝土构件归"砖石和混凝土"，用建筑锤。挖下来按掉落表掉。
- 编辑模式的按键提示里去掉"拆除"。

**以后（建筑锤"砸"，单独一轮，等用户开工）：**

- 编辑模式下按住左键砸构件：第一人称和第三人称都有挥锤动作，动作沉稳，几下才砸开。要砸多久按构件的大小和硬度定。
- 建筑锤加耐久，每砸一下扣一点，用完就坏。旧存档里的建筑锤按满耐久算。
- 砸掉的构件不原样还回，而是按它的配方返还大部分材料（推荐 75%，向下取整，至少 1 份主料）。没有配方的构件返还什么，到时候再定。
- 砸的时候有声音、碎屑、裂纹，和挖方块一个手感。

## 2. 方块分组

一个方块只属于一个组。每组是一个方块标签 `apocalypse_firstlight:dig/<组>`，放在 `data/apocalypse_firstlight/tags/blocks/dig/`，改 JSON 就能调。原版方块尽量直接引用原版标签。

| 组 | 标签 | 包括（举例） | 主工具 | 次工具（慢） |
|---|---|---|---|---|
| 土和松散料 | `dig/soil` | 原版 `#minecraft:dirt`、沙、砾石、黏土、泥、雪；AFL `fallout_soil`、`scorched_soil`、`graded_turf`、`loose_stones` | 圆头铲 | 鹤嘴锄 |
| 岩石和矿石 | `dig/rock` | 原版 `#minecraft:base_stone_overworld`、`#forge:ores`；AFL 七种矿石、`fieldstone`、`flagstone`、`fused_ground`、`boulder_cell` | 鹤嘴锄 | — |
| 砖石和混凝土 | `dig/masonry` | 面砖、红砖、钢筋混凝土、人行道、路缘、沥青、路面、混凝土砌块墙、抹灰基础、石材压顶、瓷砖地面、抹灰隔墙和吊顶、铅屏蔽砖 | 建筑锤 | 鹤嘴锄 |
| 树木 | `dig/timber` | 原版 `#minecraft:logs`；AFL 六种原木、`tree_root`、`tree_stump`、`tree_wood` | 伐木斧 | 手锯 |
| 木制品和钉装件 | `dig/wood` | 板材、方木、圆木墙、木门窗、外墙板、门廊、全部木家具、沥青瓦屋面、油毡地面 | 羊角锤、撬棍 | 手锯、伐木斧 |
| 金属构件和设备 | `dig/metal` | 钢材全系列、金属墙板和檐口、储物柜、垃圾箱、加油站设备、机器、发电机、货架、办公家具、冰柜、售货机、金属屋面、围栏、灯杆、路牌、隧道设施 | 撬棍 | 建筑锤 |
| 电气小件 | `dig/electric` | 插座、开关、灯座、插线板、电缆、配电盘、电表箱、发电机接线箱、应急灯、墙装灯具 | 一字螺丝刀、布线扳手 | 撬棍 |
| 玻璃 | `dig/glass` | 店面玻璃、玻璃门、镜子、石英玻璃 | 撬棍、羊角锤、建筑锤 | — |
| 植物 | `dig/plant` | 原版 `#minecraft:leaves`、花、草、作物；AFL 树冠、枝叶、被压倒的植物 | 折刀、手锯、伐木斧 | 圆头铲 |
| 不能挖 | `dig/none` | 技术方块（`lamp_glow`）、液体（`diesel`、`gasoline`）、路面标线（随路面走） | — | — |

**分组依据：** 现实里拆这样东西会拿什么工具。木制品是钉起来的，用羊角锤起钉、撬棍撬开，不是用斧头劈。金属件是螺栓和铆钉，眼下没有扳手，先用撬棍撬下来（见第 9 节问题 3）。电气件是螺丝固定的，用螺丝刀。

**多格家具：** 按主要材料归组。木床、木衣柜归木制品；收银台、冰柜、办公桌归金属。

**现状核对（2026-10-23，AFL-Workbench）：** 共 288 个方块状态文件。其中 150 个在 `mineable/pickaxe`，59 个在 `mineable/axe`，4 个在 `mineable/shovel`，75 个不在任何挖掘标签里（树、标线、路牌、隧道设施、电气小件、办公小件）。`mineable/pickaxe` 里混着金属、砖石、矿石、电气件，要拆到不同的组。实施时附一个检查脚本，列出没归组的 AFL 方块，目标是 0 个。

## 4. 规则

1. **不是工具**（不在 `tools/digging` 标签里）：什么都不发生。这条是 V1.8，不变。
2. **是工具，但不是这个组的主工具或次工具**：同样什么都不发生。不开始挖，没有裂纹、声音、粒子，手不挥，没有提示。
3. **主工具**：正常挖，按第 5 节的速度，按方块原来的掉落表掉落。
4. **次工具**：能挖，但慢，掉落和主工具一样。
5. **不能挖组**：谁都挖不动。
6. **没归组的方块**：先按 V1.8，任何工具都能挖，保证新方块不会突然拆不掉。检查脚本把它们列出来，再补进组里。
7. 创造模式和旁观照旧。整套规则跟着总开关 `vanilla_retirement.enabled` 走。

## 5. 速度和掉落

AFL 工具都是普通物品，没有原版的材料等级，所以现在挖什么都和空手一样慢（伐木斧继承原版斧，是例外）。V1 改成按"工具 × 组"查表：

- 数据文件 `data/apocalypse_firstlight/dig_rules/tools_v1.json`，写每把工具对每个组的速度。
- 推荐起始值：主工具 4（相当于原版石质工具），次工具 1.5。方块硬度照旧起作用：硬度高的挖得慢，硬度 0 的一下就掉。
- 掉落：原版对"需要正确工具才掉"的方块，用 `PlayerEvent.HarvestCheck` 判定。主工具和次工具都算正确工具，所以石头、矿石、金属件按掉落表掉。这一步也让原版进度公式用 ÷30 而不是 ÷100，速度才是表里的值。
- 喘不上气时的挖掘减速（`PlayerStamina`）、骨折、成长经验都在后面继续作用，不改。

## 6. 实现

1. **共用判定：** `VanillaRetirementEvents.cannotDig(player)` 改成 `cannotDig(player, state)`。它先查方块所在的组，再查主手工具在不在这个组的主工具或次工具里。方块和物品标签服务端会同步到客户端，所以两边结果一致。
2. **客户端：** `client/NoToolDigClient` 改传入准星指着的方块，其他不变（LOWEST、取消、不挥手、中止正在挖的那一下）。
3. **服务端：** `BreakSpeed`（HIGHEST，取消；对的工具按表设速度）、`BreakEvent`（HIGHEST，兜底）、`HarvestCheck`（新加）。
4. **数据：** 10 个组标签、一个速度表、`tools/digging` 不变。
5. **检查脚本：** `tools/check-dig-groups.mjs`。列出没归组的 AFL 方块和被归进两个组的方块；工具表里的工具必须都在 `tools/digging` 里。
6. **建筑锤（1.1 节 V1）：** `client/building/BuildingHammerClient` 编辑模式下的左键只拦住、不再发拆除包；服务端的 `Remove` 包留着不调用，等"砸"那一轮改成按住砸；HUD 键位提示去掉拆除；`BuildingHammerItem` 的类注释同步。
7. **改动估计：** Java 5 个文件（另加建筑锤客户端和 HUD）（`VanillaRetirementEvents`、`NoToolDigClient`、读速度表的新类），JSON 约 11 个，脚本 1 个。不加网络包，不改协议号，不动存档格式。
