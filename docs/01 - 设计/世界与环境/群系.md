# AFL 主世界地表群系策略

本文记录当前主世界地表候选与Terrain V2 Phase 1宏观陆海gate。完整契约见[Macro Geography V1](../../worldgen/terrain_v2_macro_geography_v1.md)。本阶段编译/资源检查不代表新世界视觉验收。

## 1. 普通地表白名单

| 设计名称             | 实际 Registry ID                              | 角色                                  |
| ---------------- | ------------------------------------------- | ----------------------------------- |
| Plains           | `minecraft:plains`                          | 唯一保留的 Vanilla 普通地表群系；用于安全区和少量安全地表区域 |
| Sunken Wasteland | `apocalypse_firstlight:fallout_barrens`     | AFL 沉降荒原                            |
| Scorched Earth   | `apocalypse_firstlight:scorched_lands`      | AFL 焦土                              |

内陆仍仅保留Vanilla Plains；另允许 `minecraft:ocean`、`minecraft:deep_ocean`、`minecraft:beach` 作为宏观海域/岸线候选，由MacroGeography确定实际位置。Forest、Dark Forest等仍排除，不删除registry entry。

## 2. 当前候选控制方式

- `AflVanillaBiomePolicy` 白名单为Plains及上述三个marine候选；`MacroBiomePolicy`防止海域成为焦土，也防止marine候选落入内陆。
- `OverworldBiomeBuilderMixin` 在 Vanilla `OverworldBiomeBuilder` 生成气候候选时分别过滤地表和地下分支，而不是维护一张大型 biome 黑名单。
- `AflOverworldRegion` 通过 TerraBlender 注册两种 AFL 地表群系；当前权重为 `190`，TerraBlender 默认主世界区域权重为 `10`。
- 权重只决定 Plains 区域与 AFL 区域的宏观占比，不能代替白名单。Vanilla Forest 等群系必须从候选生成阶段排除。
- `apocalypse_firstlight.mixins.json` 必须在 DEV 启动参数中注册。IntelliJ run configuration 过期时，过滤 Mixin 不会执行，TerraBlender 默认区域便会重新携带完整 Vanilla 候选表。修改 Mixin 配置后应重新运行 `gradlew genIntellijRuns`。

当前项目没有删除第三方 biome 的 registry entry。若第三方模组另行注册 TerraBlender Region，其普通地表候选不由 AFL 的 Vanilla 白名单自动管辖；需要逐项做兼容审计，不能通过全局 registry 删除处理。

## 3. 特殊群系策略

| 类型 | 当前策略 | 代码依据 |
| --- | --- | --- |
| 洞穴 | 保留 Vanilla `dripstone_caves`、`lush_caves`、`deep_dark` 候选 | `AflVanillaBiomePolicy.VANILLA_UNDERGROUND_BIOMES` |
| 海洋/海岸 | 单一主岛国与同国附属岛之外为大洋；海域ocean/deep_ocean、干岸带beach | `MacroGeography` + `MacroBiomePolicy`；原continents节点仅保留兼容气候/地下用途，不再决定实际无限陆地 |
| 河流 | 当前未建立独立 Vanilla river 候选分支，按无河流普通地表策略处理 | 当前 `OverworldBiomeBuilder` 候选过滤与 AFL Region 定义 |

Terrain V2已接入macro density与marine SurfaceRules，海床使用sand/gravel/stone/deepslate；Scorched近地表水抑制明确跳过macro水域及干岸带。所有registry entry仍保留。

## 4. Radiation Zone 与地表群系

期望的语义对应关系为：

| Radiation Zone | `F` 范围 | 语义目标地表群系 |
| --- | --- | --- |
| `SAFE` | `F < 0.08` | `minecraft:plains` |
| `IRRADIATED` / `HEAVY_FALLOUT` | `0.08 <= F < 0.84` | `apocalypse_firstlight:fallout_barrens`；辐射等级由独立系统决定 |
| `EXTREME` | `F >= 0.84` | `apocalypse_firstlight:scorched_lands` |

V1 已移除污染疏林；如未来需要安全区到荒地的过渡景观，再作为独立设计重新评估。辐射等级、剂量、雾效和污染等级仍是独立系统，不与新增替代群系绑定。

Terrain V2水域先于Startup生态覆盖解析。出生保护384格与主陆核心3800格保证Plains/SAFE仍在真实陆地；辐射系统未改，ocean/deep_ocean/beach目前为UNKNOWN profile，继续自然场计算，不承诺海洋SAFE。未来外国生态仅预留ID，本阶段不生成外国。
