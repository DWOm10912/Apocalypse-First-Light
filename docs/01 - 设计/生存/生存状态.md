# 爆炸耳鸣 / Explosion Tinnitus

爆炸耳鸣是一种短时间的听觉与视觉反馈，不属于疾病、Potion Effect 或永久听力损伤。

爆炸越近、强度越高，耳鸣越明显、持续时间越长。

## 基础规则

|参数|当前规则|
|---|---|
|基础爆炸范围|使用爆炸实际 `radius`|
|耳鸣计算范围|`radius × 3.0`|
|距离强度|`n = clamp(1 - d/R, 0, 1)`|
|音频强度|`s = n²`|
|视觉强度|`v = n`|
|音频触发阈值|`s ≥ 0.15`|
|视觉触发阈值|`v ≥ 0.08`|
|墙体遮挡|暂不计算|
|护甲影响|无|
|是否需要实际受到伤害|否|
|创造模式|同样可以触发|

其中：

- `d` = 玩家与爆炸中心的距离
- `R` = 爆炸耳鸣最大影响范围

---

## TNT 示例

Vanilla TNT：

```
radius = 4
R = 12 blocks
```

因此：

|效果|大致最大距离|
|---|---|
|可听见耳鸣|约 7.35 格|
|可见视觉冲击|约 11.04 格|
|完全无效果|约 12 格以外|

距离只是强度的一部分；越靠近爆炸中心，反馈越明显。

# 耳鸣声音

|属性|当前值|
|---|---|
|Sound Event|`apocalypse_firstlight:explosion_tinnitus`|
|素材长度|约 10.03 秒|
|Sample Rate|44,100 Hz|
|Channels|Mono|
|Pitch|1.0|
|循环|否|
|音量来源|受 Master / Players 设置影响|

## 音量

初始音量：

```
0.15 + 0.55 × s
```

距离越近，声音越明显。

## 单次持续时间

```
40 + 120 × s ticks
```

约：

**2–8 秒**

实际达到最低音频阈值的耳鸣约从 **2.9 秒**开始。

---

# 淡出

耳鸣不会突然停止。

时间轴：

- 前 15% 保持当前强度
- 后续逐渐淡出
- 结束后完全停止

素材本身的自然衰减也会保留。

---

# 连续爆炸

AFL 不会为连续爆炸叠加多条耳鸣声音。

同一个耳鸣 Episode 内：

### 更强的新爆炸

- 不重新播放音效
- 不叠加第二份声音
- 提升当前 Severity
- 必要时延长剩余持续时间

### 较弱或相近的新爆炸

- 不重新开始
- 不降低当前 Severity
- 延长当前淡出约 **20 ticks / 1 秒**

### 最大持续时间

单个 Episode 从第一次耳鸣开始：

**最多 200 ticks / 10 秒**

达到上限后，后续爆炸不会无限延长当前耳鸣。

耳鸣完全结束后，下一次爆炸可以重新触发一个新的 Episode。

# 视觉 Overlay

爆炸同时会产生屏幕视觉冲击。

视觉强度采用线性距离曲线，因此相比声音：

> **中远距离仍能感觉到爆炸冲击，但不一定能听到明显耳鸣。**

当前规则：

|项目|当前值|
|---|---|
|视觉强度|`v = n`|
|最低视觉阈值|`0.08`|
|最大视觉范围|`radius × 3.0` 范围内按阈值决定|
|是否需要声音同时触发|否|

因此可以出现：

> **只有轻微视觉冲击，但没有耳鸣声音**

的情况。

---

# 当前 V1 限制

爆炸耳鸣 V1 暂时不考虑：

- 墙体遮挡
- 建筑隔音
- 材质吸音
- 护甲 / 头盔听力保护
- 世界声音整体压低
- 永久听力损伤
- 多种耳鸣音效随机
- 耳鸣状态 HUD 图标
