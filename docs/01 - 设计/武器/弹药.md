# 弹药

原生枪械的弹药由服务端管理；当前已注册 9×19mm、7.62×51mm、12.7×55mm 与 12 Gauge 四种弹药资源。P9-01、BR51-01、HR55 与 Silverwood 12 分别使用对应口径，不互通。Silverwood 使用现有 `AflGunAmmo.ammoInMagazine` 计数作为双膛唯一状态源，并没有实体弹匣。

| 项目 | 当前规则 |
| --- | --- |
| 弹药 ID | P9-01：`apocalypse_firstlight:9x19mm_round`；BR51-01：`apocalypse_firstlight:762x51mm_round`；HR55：`apocalypse_firstlight:12_7x55mm_round`；Silverwood 12：`apocalypse_firstlight:12_gauge_round` |
| 使用武器 | P9-01 制式手枪 / BR51-01 战斗步枪 / HR55 战斗步枪 / Silverwood 12 双管霰弹枪，不互通口径 |
| 装弹容量 | P9-01 为17，BR51-01 与 HR55 为20；Silverwood 为两独立膛室、容量2。计数保存在枪 ItemStack 的 `AflGunAmmo.ammoInMagazine` |
| 储备 | 玩家物品栏与副手中的对应口径；弹壳不可装填 |
| 换弹 | P9-01 第19tick结算，BR51-01普通/空仓第52/57tick结算；Silverwood 战术/空膛第32/43tick结算；满匣或无对应储备不启动 |
| 空弹壳 | 四种 `_casing` 均已注册普通物品；既有枪械射击抛壳仍是不可拾取客户端视觉，不生成掉落实体；Silverwood 开火不自动抛壳，只在原 reload 动画中显示空壳弹出 |

八项物品均64堆叠；四种实弹位于“AFL 武器与弹药”，弹壳不进入创造标签，仅保留开发检查注册。HR55 射击使用 12.7×55mm 并抛出对应的客户端视觉弹壳。Silverwood 消耗 12 Gauge，一次一发实弹产生八条独立弹丸追踪；射击时不生成空壳物品。旧 `9mm_round` 存档注册缺失映射到新9mm物品，不转换为步枪弹。资产、命令与验证见 [正式弹药资产 V1](../../native_guns/native_ammo_assets_v1.md)。

完整射击与换弹规则见 [枪械](枪械.md)。

## 未完成

实体弹匣尚未实现；Silverwood V1 双膛状态由装弹数派生，未实现混装弹、手动退膛或地面掉落弹壳。其他未注册口径/弹种尚未实现。Silverwood 实机射击、换弹和模型视觉待玩家验收。
