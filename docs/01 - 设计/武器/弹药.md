# 弹药

原生枪械的弹药和弹匣状态由服务端管理；当前已注册 9×19mm、7.62×51mm、12.7×55mm 与 12 Gauge 四种弹药资源。P9-01、BR51-01 与 HR55 分别使用前三种对应口径，三者不互通；12 Gauge 尚未绑定枪械。

| 项目 | 当前规则 |
| --- | --- |
| 弹药 ID | P9-01：`apocalypse_firstlight:9x19mm_round`；BR51-01：`apocalypse_firstlight:762x51mm_round`；HR55：`apocalypse_firstlight:12_7x55mm_round`；未绑定：`apocalypse_firstlight:12_gauge_round` |
| 使用武器 | P9-01 制式手枪 / BR51-01 战斗步枪 / HR55 战斗步枪，不互通口径 |
| 弹匣容量 | P9-01 为17，BR51-01 与 HR55 为20；保存在枪 ItemStack 的 `AflGunAmmo.ammoInMagazine` |
| 储备 | 玩家物品栏与副手中的对应口径；弹壳不可装填 |
| 换弹 | P9-01 第19tick结算，BR51-01普通/空仓第52/57tick结算；满匣或无对应储备不启动 |
| 空弹壳 | `9x19mm_casing` / `762x51mm_casing` / `12_7x55mm_casing` / `12_gauge_casing` 已注册普通物品；现有枪械射击抛壳仍是不可拾取客户端视觉，不生成掉落实体；12 Gauge 尚未接入抛壳 FX |

八项物品均64堆叠；四种实弹位于“AFL 武器与弹药”，弹壳不进入创造标签，仅保留开发检查注册。HR55 的射击使用 12.7×55mm 并抛出对应的客户端视觉弹壳。12 Gauge 仅为可引用物品，未接入 Silverwood 12。旧 `9mm_round` 存档注册缺失映射到新9mm物品，不转换为步枪弹。资产、命令与验证见 [正式弹药资产 V1](../../native_guns/native_ammo_assets_v1.md)。

完整射击与换弹规则见 [枪械](枪械.md)。

## 未完成

实体弹匣、Chamber 状态与 12 Gauge 枪械使用逻辑尚未实现；其他未注册口径/弹种也尚未实现。
