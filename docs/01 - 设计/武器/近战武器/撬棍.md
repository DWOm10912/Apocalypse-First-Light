# 撬棍

撬棍是前期可靠的单手近战工具。注册名：`apocalypse_firstlight:crowbar`，可在「AFL 武器与弹药」创造标签页找到，或使用 `/give @s apocalypse_firstlight:crowbar` 获取。当前没有合成配方或战利品投放。

| 属性 | 当前规则 |
| --- | --- |
| 最大堆叠 | 1 |
| 耐久 | 480 |
| 基础伤害 | 6 点（3 颗心，普通玩家满蓄力、未计护甲和暴击） |
| 攻击速度 | 20/13 次每秒，13 tick（约 0.65 秒）回满 |
| 生存攻击距离 | 原版 Forge 玩家实体触及距离 3 格，不额外延长 |
| 击退 | 原版普通近战轻击退，仍受目标抗性与疾跑影响 |
| 耐久消耗 | 成功命中实体消耗 1；挥空和挖方块不消耗 |
| 修理 | 不提供修理材料，并禁用普通物品修理 |

使用原版攻击蓄力规则：提前挥击仍然允许，但伤害降低；不是强制锁定 0.65 秒。主手提供 +5 攻击伤害和约 -2.461538 攻击速度，叠加玩家默认属性后得到上表值。副手不提供攻击属性，无剑类横扫、不额外提高挖掘效率。创造模式沿用原版距离加成及不损耗耐久规则。

世界/物品模型以 `src/main/blockbench/crowbar.bbmodel` 为编辑源。`tools/export-crowbar.mjs` 只读取该源，导出 `models/item/crowbar.json`、`geo/crowbar.geo.json` 和 `textures/item/crowbar.png`（均位于 `src/main/resources/assets/apocalypse_firstlight/`）。非第一人称继续使用原生 item JSON。物品行为位于 `src/main/java/com/antaurora/apofirstlight/item/CrowbarItem.java`。

第一人称使用独立 `src/main/blockbench/crowbar_first_person.bbmodel`：从现有模型派生工具几何，使用 Native Rig 的 canonical 单手定位点与玩家皮肤/袖子渲染。默认右手，撬棍手臂三轴恢复1:1，取消此前展示缩小与25%截面补偿；保持握持接触点、工具大小不变，不改变枪械。主手对准完整售货机前玻璃显示原配件提示样式的“破坏玻璃”；右键启动 `smash_glass`，33 tick总长，第12 tick提交破碎及粒子。最新声音实长1.027483秒，起手静音，命中确认才播放。操作期间不重复触发，左键/换物品/丢失目标可取消；普通实体攻击属性和耐久规则保持上表。该交互V1仅支持主手；不含撬锁/撬门。实现及验证见 [Crowbar First-Person V1](../../../crowbar_first_person_smash_v1.md)。
