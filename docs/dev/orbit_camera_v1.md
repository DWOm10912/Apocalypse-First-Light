# 环绕镜头 V1（替代原版 F5）

状态（2026-10-18）：**已实现，编译通过，未实机验证。** 2026-10-19 用户实机 PASS（录完雨夜开车的开发日志后确认）。

2026-10-19 第二轮（用户实机反馈的四个问题，见第 7 节）：**已修，编译通过，未实机验证。**

用户 2026-10-18 的要求：原版 F5 只能看前面和后面，想去掉，换成 GTA V 那样能 360° 绕着转的镜头；开车也一样，不然想找个角度还得来回切。为录开发日志做的三件事之一（另外两件是驾驶按键提示收起、轮胎粒子，见 [第一辆车](../vehicles/first_pickup_v0_design.md) 第 8.18 节）。

## 1. 按键

- 原版的"切换视角"键（默认 F5，在原版按键设置里改）现在只在**第一人称**和**环绕镜头**之间切换，原版的正面视角没有了。
- 实现：每个客户端 tick 开始时（`ClientTickEvent` START，在 `Minecraft#handleKeybinds` 之前）把这个键的点击全部取走，自己切换。原版按键本身没改，按键设置里也不会出现冲突。
- 检修台界面打开时不切（它自己管镜头）。

## 2. 实现方式

- `client/camera/OrbitCamera.java`：镜头导演里的一个镜头（`CameraDirector` 请求 `orbit`，优先级 **100**，比所有其他镜头都低；机器拉绳 200、身体眼睛 300、检修台 400、过场 500、死亡 600 都能盖住它）。淡入 0.25 s（从原版的背后视角平滑过渡过来），淡出 0 s。
- 内部仍然用原版的 `CameraType.THIRD_PERSON_BACK`，所以原版第三人称的画法都不变：画自己的身体、不画第一人称手；代码里各处 `isFirstPerson()` 的判断也照旧。
- 鼠标：`mixin/client/MouseHandlerLookLockMixin` 在 `MouseHandler#turnPlayer` 开头把这一帧的鼠标移动交给 `OrbitCamera.takeMouse`，用来转镜头，不再转玩家（灵敏度曲线和原版一样：`(s × 0.6 + 0.2)³ × 8 × 0.15`，支持反转 Y 轴）。
- 遮挡：和原版背后视角一样，从中心往镜头方向打 8 条偏移 0.1 的射线（`ClipContext.Block.VISUAL`），被挡住时立刻拉近；不挡了以后在约 0.3 s 内退回原来的距离。

## 3. 走路时

| 项目 | 数值 / 行为 |
|---|---|
| 中心 | 眼睛位置 |
| 距离 | 4 格（和原版一样） |
| 俯仰 | −60° 到 80°；进入时至少往下 12°，从眼睛的朝向接过来 |
| 移动 | W A S D 按镜头方向走；人物每 tick 最多转 40° 转向走的方向。移动输入换算到人物转身后的坐标里，所以按下就往那个方向走，身体再转过去。按住左键或右键时，身体改成转向镜头方向，按键变成侧移，两边不再互相拉扯 |
| 头 | 头看向小点的方向：最多偏离身体 70°，俯仰 −50° 到 60°；镜头转到身后超过 120° 时头看回前方；按 0.12 s 的时间常数平滑。只在画面上改（原版每 tick 把头设成身体朝向），不影响服务端 |
| 点击 | 左键 / 右键（包括按住不放、按住挖方块）只有在身体朝向镜头方向（偏差 5° 以内）时才生效。没对准时这次点击先扣下，身体每 tick 最多转 30°（转半圈 0.3 s），对准后再补上这次点击。生效时人物对准镜头，重新取一次瞄准目标：屏幕中心的射线正好穿过眼睛，所以挖、放、用、打中的就是中间小点对着的东西。背对着不能瞬间回身开枪或出手（用户 2026-10-19："甩枪"） |
| 枪 | 开枪走上面"点击"那一条：身体转过去以后才开第一枪。手里拿枪按住右键瞄准时，身体先转到镜头方向，再切回第一人称；松开后回到环绕镜头（第一人称持枪是打磨过的那套） |
| 界面 | 屏幕中间画一个小点（原版第三人称不画准星）；方块轮廓线不画（它对的是人物前方，不是小点） |
| 切回第一人称 | 身体先按每 tick 30° 转到镜头看的方向，再切，画面接得上；不能靠切视角瞬间回身 |

## 4. 坐车时（T15 的任何座位）

| 项目 | 数值 / 行为 |
|---|---|
| 中心 | 车的原点往上 1.7 格 |
| 距离 | 7 格；滚轮在 4–14 格之间调（坐车时滚轮本来就不切武器） |
| 跟随 | 默认在车正后方，往下看 10°；镜头朝向用 0.3 s 的时间常数追车头方向，转弯时稍微滞后 |
| 鼠标 | 绕车转一整圈，俯仰 −30° 到 70° |
| 回正 | 鼠标停 1.5 s 以后，车速超过 2 m/s 时，偏转按 0.6 s 的时间常数慢慢回到车后 |
| 上车 / 下车 | 上车时从当前看的方向接过来再慢慢回正；下车后从车上的镜头方向继续绕人转 |
| 头 | 乘员自己的朝向（`yRot`、`xRot`、头）按 0.12 s 的时间常数跟着镜头方向，限制在座位的可看范围内（`PickupTruckLayout.Seat#look`，车本身也会夹）；镜头转到超过这个范围 20° 时看回前方。俯仰 −30° 到 25°，镜头默认往下看的 10° 不算。是真实朝向，切回第一人称时视角就从这里接着 |

## 5. 和其他系统的关系

- 玩家的身体朝向（`yRot`、`yHeadRot`）在走路和点击时由环绕镜头设定，这是原版的玩家朝向，服务端照常同步；骨骼（D）只是按这个朝向画，没有改接口。走路时的头部朝向在 `RenderPlayerEvent.Pre`（最低优先级）里临时换成看向小点的角度，`Post` 里换回去，原版绘制和骨骼读到的都是换过的值。
- 枪（`NativeGunInput#attack`，最高优先级，会先把点击取消）开枪前先调用 `OrbitCamera.holdClick`，所以和其他点击走同一道"先转身"的检查。
- 死亡镜头（`DeathCamera`）只在第一人称下打开，环绕镜头时死亡和原版第三人称一样。
- 机器拉绳、加油枪视角等"只在第一人称"的演出，在环绕镜头时和原来按 F5 一样不出现。
- 坐在不靠按键移动的座位上（木椅、坐地；2026-10-25 用户录屏：按 A/D 胸和手臂来回扭）：W A S D 不再转身，也不按镜头换方向，交还原版。头照样看向小点，点击时照样先转身。办公椅靠按键开动、转向，保持"走路时"那一套（`OrbitCamera.movement`，见 [Block-Mesh V2 B](block_mesh_v2_b_ingame.md) 11.5）。
- 坐在木椅上（AFL 坐下 `cabin/ChairSit`，同日）：移动键由 `ChairSitClient` 先接走，用来起身（方向按镜头算）。镜头能绕一整圈（用户同日先要求"F5也不能往后"，看了以后改成"自由视角，但是只能头转"），身体不动：
  - 头：镜头在人物前方 ±100° 以内（`SEAT_FACE`）时看向镜头，最多偏 70°，俯仰跟镜头；再往后就朝前（`OrbitCamera#head`）；
  - 胸：跟人物自己的朝向。不点击时朝向每 tick 回正 10°（`SEAT_SETTLE`），所以胸朝正前方；
  - 点击：镜头方向在椅子朝向 ±90°（`ChairSit.LOOK`）以内时照常先转再出手；超出时点击取消、不挥手，也不开镜（`behindSeat`）；
  - 切回第一人称：超出范围时朝椅子正前方。

## 6. 已知的限制 / 以后

- 鞘翅飞行的方向由人物朝向决定，环绕镜头下只能靠移动键转向。
- 拿枪不按右键时，左键腰射前会先转向小点方向；没有第三人称的准星和后坐。
- 数值（距离、回正时间、转身速度）等用户实机反馈后再调。

## 7. 第二轮修正（2026-10-19）

用户实机反馈：

1. 人物的头不跟着小点走，走路时也不转头。原因：原版每 tick 把玩家的头设成 `yRot`（`Player#serverAiStep`），而环绕镜头下 `yRot` 是走路方向。改法：只在画面上把头转向小点（第 3 节"头"）。
2. 一直按住左键或右键再往旁边走会抽搐。原因：按住时每 tick 把身体瞬间转向镜头，走路又每 tick 把身体转向走的方向，两边来回拉。改法：按住时不再转向走的方向，按键改成侧移（第 3 节"移动"）。
3. 开车时在第一人称转到某个角度再切环绕镜头，头就卡在那里。原因：鼠标交给了镜头，乘员的真实朝向停在切换前的角度。改法：乘员朝向跟着镜头方向（第 4 节"头"）。
4. 往后走、小点朝前时能"甩枪"：背对着也能马上朝反方向开枪，再瞬间转过去。原因：点击和开镜时身体是瞬间转向镜头的。改法：先转身再出手，转身速度有限（第 3 节"点击""枪""切回第一人称"）。

实现：`client/camera/OrbitCamera.java`（`movement`、`holdClick`、`head` / `headBack`、`riderLook`），`weapon/client/NativeGunInput.java` 开枪前调用 `holdClick`。编译通过，没进游戏看过。
