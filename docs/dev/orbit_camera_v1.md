# 环绕镜头 V1（替代原版 F5）

状态（2026-10-18）：**已实现，编译通过，未实机验证。**

用户 2026-10-18 的要求：原版 F5 只能看前面和后面，想去掉，换成 GTA V 那样能 360° 绕着转的镜头；开车也一样，不然想找个角度还得来回切。为录开发日志做的三件事之一（另外两件是驾驶按键提示收起、轮胎粒子，见 [第一辆车](../vehicles/first_pickup_v0_design.md) 第 8.18 节）。

## 1. 按键

- 原版的"切换视角"键（默认 F5，在原版按键设置里改）现在只在**第一人称**和**环绕镜头**之间切换，原版的正面视角没有了。
- 实现：每个客户端 tick 开始时（`ClientTickEvent` START，在 `Minecraft#handleKeybinds` 之前）把这个键的点击全部取走，自己切换。原版按键本身没改，按键设置里也不会出现冲突。
- 检修台界面打开时不切（它自己管镜头）。

## 2. 实现方式

- `client/camera/OrbitCamera.java`：镜头导演里的一个镜头（`CameraDirector` 请求 `orbit`，优先级 **100**，比所有其他镜头都低；机器拉绳 200、身体眼睛 300、检修台 400、过场 500、死亡 600 都能盖住它）。淡入 0.25 s（从原版的背后视角平滑过渡过来），淡出 0 s。
- 内部仍然用原版的 `CameraType.THIRD_PERSON_BACK`，所以原版第三人称的画法都不变：画自己的身体、不画第一人称手；代码里各处 `isFirstPerson()` 的判断也照旧。
- 鼠标：`mixin/client/MouseHandlerLookLockMixin` 在 `MouseHandler#turnPlayer` 开头把这一帧的鼠标移动交给 `OrbitCamera.takeMouse`，用来转镜头，不再转玩家（灵敏度曲线和原版一样：`(s × 0.6 + 0.2)³ × 8 × 0.15`，支持反转 Y 轴）。
- 遮挡：和原版背后视角一样，从中心往镜头方向打 8 条偏移 0.1 的射线（`ClipContext.Block.VISUAL`），被挡住时立刻拉近；不挡了以后在约 0.3 s 内退回原来的距离。

## 3. 走路时

| 项目 | 数值 / 行为 |
|---|---|
| 中心 | 眼睛位置 |
| 距离 | 4 格（和原版一样） |
| 俯仰 | −60° 到 80°；进入时至少往下 12°，从眼睛的朝向接过来 |
| 移动 | W A S D 按镜头方向走；人物每 tick 最多转 40° 转向走的方向。移动输入换算到人物转身后的坐标里，所以按下就往那个方向走，身体再转过去 |
| 点击 | 左键 / 右键（包括按住不放）先把人物转向镜头方向，再重新取一次瞄准目标：屏幕中心的射线正好穿过眼睛，所以挖、放、用的就是中间小点对着的东西 |
| 枪 | 手里拿枪按住右键瞄准时切回第一人称，松开后回到环绕镜头（第一人称持枪是打磨过的那套） |
| 界面 | 屏幕中间画一个小点（原版第三人称不画准星）；方块轮廓线不画（它对的是人物前方，不是小点） |
| 切回第一人称 | 人物转到镜头看的方向，画面接得上 |

## 4. 坐车时（T15 的任何座位）

| 项目 | 数值 / 行为 |
|---|---|
| 中心 | 车的原点往上 1.7 格 |
| 距离 | 7 格；滚轮在 4–14 格之间调（坐车时滚轮本来就不切武器） |
| 跟随 | 默认在车正后方，往下看 10°；镜头朝向用 0.3 s 的时间常数追车头方向，转弯时稍微滞后 |
| 鼠标 | 绕车转一整圈，俯仰 −30° 到 70° |
| 回正 | 鼠标停 1.5 s 以后，车速超过 2 m/s 时，偏转按 0.6 s 的时间常数慢慢回到车后 |
| 上车 / 下车 | 上车时从当前看的方向接过来再慢慢回正；下车后从车上的镜头方向继续绕人转 |

## 5. 和其他系统的关系

- 玩家的身体朝向（`yRot`、`yHeadRot`）在走路和点击时由环绕镜头设定，这是原版的玩家朝向，服务端照常同步；骨骼（D）只是按这个朝向画，没有改接口。
- 死亡镜头（`DeathCamera`）只在第一人称下打开，环绕镜头时死亡和原版第三人称一样。
- 机器拉绳、加油枪视角等"只在第一人称"的演出，在环绕镜头时和原来按 F5 一样不出现。

## 6. 已知的限制 / 以后

- 鞘翅飞行的方向由人物朝向决定，环绕镜头下只能靠移动键转向。
- 走路时人物站着不动，头不会转向镜头方向（GTA 会）；以后可以加。
- 拿枪不按右键时，左键腰射前会先转向小点方向；没有第三人称的准星和后坐。
- 数值（距离、回正时间、转身速度）等用户实机反馈后再调。
