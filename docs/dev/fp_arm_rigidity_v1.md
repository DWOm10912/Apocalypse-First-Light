# 第一人称手臂刚性化修正方案 V1

2026-10-23，Main。只做了分析和方案，没有改游戏代码、模型和动画资源。新加了一个只读测量工具 `tools/probe-fp-rigidity.mjs`，用来量出问题，以后也用它验收。

## 0. 需求（用户 2026-10-23 纠正）

- 用户说「不要弹性的方块手臂」，意思不是不要更真实的手，而是之前的第一人称手臂动作太软：像布娃娃、橡皮泥、液体，没有骨架撑着的感觉。
- 目标：
  - 看起来是真人的手臂在持枪；
  - 上臂、前臂、手掌都是刚性段，只在肩、肘、腕处转；
  - 动作硬朗、稳定，枪和手是硬连接；
  - 受力点清楚，关键姿势有停顿和锁定；
  - 后坐和复位干脆。
- 现阶段先不做十指手。2026-10-22 那份「十指 Rig V0」审计就此暂停，结论放在第 8 节附录。手模型继续用原版皮肤的简化手，先把骨架感和力度做出来。
- 和 2026-10-22 定的「沉稳」规则不冲突，但要重新理解（第 6 节）：
  - 沉稳，指段与段之间不慌，有停顿、有看的时间；
  - 不是指每一段动作本身都慢、都软、落点都晃。

## 1. 现状（实测）

第一人称持枪的结构：
- **手臂**：每条手臂是一根直的原版手臂方块（4×12×4，按 0.62 / 0.78 / 0.62 缩放），见 `weapon/client/NativePlayerArmRenderer`。
  - 只有手这一端定位：方块的末端放在枪动画算出的 `right_hand_anchor` / `left_hand_anchor` 上，前臂沿挂点的 −Y 方向往后伸。
  - 没有肩、肘、腕。
- **右手**：`righthand` 骨骼挂在 `handling`（枪）下面，枪转多少，整条右前臂就跟着转多少。
- **左手**：`lefthand` 挂在根上，生成脚本每帧解算它，让它贴在枪上（`leftOnGun`）或者托住弹匣（`onMag`）。
- **动画来源**：
  - P9-01：换弹和检视是 Blockbench 手调的贝塞尔关键帧（`handling`、`lefthand`、`camera`）。手上的弹匣、插匣约束、掉落的旧弹匣、握把滑动是脚本解算的，最后烘焙成 60 Hz 线性关键帧（`tools/author-p9-01-v3-native-animations.mjs`）。
  - BR-51：整段都是程序生成的，用同一套运动函数（`tools/author-br51-01-v3-native-animations.mjs`）。
- **不是来源的东西**（查过）：
  - GeckoLib 片段之间的过渡时间是 0（`ConfiguredNativeGunItem`），片段切换不糊；
  - 持枪晃动（`NativeWeaponSway`）只有 0.2° 左右，换弹时再乘 0.1；
  - 60 Hz 烘焙和 Blockbench 求值逐帧一致（`tools/bb-keyframes.mjs`）。

## A. 软塌感从哪来

按影响大小排：

1. **手臂是被手拎着的，根部没有约束**（最主要的结构原因）。
   - 方块只在手那一端定位，另一端（肩）跟着手的朝向在画面边上甩。
   - 换弹时肩端走的距离是手的 1.4–2 倍：P9 右臂 11.1 对 5.6，左臂 24 对 17；BR-51 左臂 40 对 25。
   - 真人正好相反：肩几乎不动，手在动。
   - 所以看起来像一根被手攥着的棍子在晃，没有身体撑着，就是用户说的「漂浮、无支撑」。
2. **枪几乎不停，关键姿势被抹平**。
   - P9 腰射换弹里，枪静止的时间只占 14–22%，最长一次只停 0.13–0.30 s。
   - 生成脚本的注释写明了这是当初的设计：「the gun never stops: it comes up, floats toward the incoming magazine, is knocked up by the seat, swings home and settles」。
   - 手调的键几乎没有一对是同值的，默认贝塞尔手柄把所有键串成一条连续的样条，结果「抬起—对准—插入—拍实—复位」糊成一条线。
3. **弹簧式的落点和冲击**。
   - `go()`：每段到位后有 7% 的正弦回弹（周期 0.15 s、衰减 0.06 s），开始前还有一个反向预备。
   - `jolt()`：冲击是余弦振荡，冲一下会来回摆两三次。
   - 每段换弹里枪的方向反了 22–58 次。射击后越过静止位 16–21%，像弹簧弹回来，不是被手压住。
4. **持续的正弦漂移**。
   - BR-51 换弹时有「看」的漂移 `drift`，约 ±1°、周期 1 s；检视里有 ±3°。
   - 检视中弹匣的转动也叠了 `drift`。
   - 等于在本该定住的地方加了晃动。
5. **主手和枪会相对滑动**。
   - P9 换弹时握把从拳头里往外滑 3.11 单位（`GRIP_SLIDE × slip`，约 2/3 只手宽），检视时 4.3 单位。
   - 本意是「枪转起来时握把在掌心里松一点」，但方块手没有手指，看到的就是枪和手各自在动。
6. **主手没有腕**。
   - 枪为了把弹匣井转向左手，最多偏 40°、滚 −24°。右前臂整根跟着转，所以右臂根部会扫过 8–17 单位。
   - 真人这时转的是腕和前臂的旋前旋后，肘和肩基本不动。
7. **左手接触不明确**。
   - 左手是在「关键帧位置」和「贴在枪上 / 托着弹匣」之间按时间平滑混合的（`mixT` + `W`，窗口 0.06–0.2 s）。
   - 混合的时候目标本身在动，左手离握把还不到 1.5 单位就开始在枪上「游」，每段 0.15–0.8 s，不是一下按上去。
8. **镜头骨持续摇**。
   - 新手档镜头最大 14°，有经验档 7°（低头看着换是有意的设计）。
   - 但摇法是连续的平滑曲线，整个画面一直在漂，会放大前面几条。
9. **「关节过度圆滑」在持枪的第一人称里其实不存在**（手臂没有关节）。
   - 这条对应的是骨骼身体的蒙皮 `skeleton/SkinMesh`：关节处一圈 4 个顶点由上下两段共用，放在子骨骼一半的旋转上，肘和腕弯起来是一段软的圆弧。
   - 2026-10-17 被否掉的第一人称骨骼手臂就是这套；现在第一人称里只有低头 45° 以上、收枪、空手和工具动作用它。

## B. 具体是哪些骨骼、关键帧和缓动

| 位置 | 东西 | 造成的感觉 |
|---|---|---|
| `NativePlayerArmRenderer#render` | 方块只按手挂点定位，前臂方向 = 挂点 −Y | 肩端乱甩、无支撑 |
| geo：`righthand` 挂在 `handling` 下 | 主手和枪一体，没有腕 | 枪一转整条手臂一起转 |
| 两个脚本的 `go()` | `over 0.07, per 0.15, tau 0.06`，预备 `antic 0.04` | 每次到位都回弹、晃 |
| 两个脚本的 `jolt()` | 余弦振荡 `per 0.1–0.24, tau 0.04–0.09` | 冲击像弹簧 |
| P9 `shoot`、BR-51 `shoot` | `jolt(t,0,[4.6,…],{per:0.2,tau:0.05})` + 第二个小 jolt | 后坐弹回、越过静止位 |
| BR-51 换弹 `legs` | `RELOAD_MEET` 一段从 0.38 s 拉到 1.47 s；最后复位 `over 0.07, per 0.26` | 枪慢慢漂一秒多，最后弹着回位 |
| BR-51 `look`、检视 `drift` | 正弦漂移 ±0.5–3° | 该定住的地方在晃 |
| P9 `.bbmodel` 手调键 | `handling` / `lefthand` / `camera` 每 0.04–0.1 s 一个键，没有同值停顿键，默认 ±0.1 s 贝塞尔手柄 | 一条连续样条，姿势糊在一起 |
| P9 `GRIP_SLIDE`、`slip()` | 握把滑出 3.11 单位，随枪偏转变化 | 枪和手各自动 |
| P9 `reloadKeyed` 等的 `mixT(…, W(t,a,b))` | 左手在移动目标之间按时间混合 | 左手在枪上游，接触不清楚 |
| `camera` 骨骼 | 连续平滑的低头和摆动 | 画面漂 |

## C. 不重做系统怎么改

分三步。每一步都单独实机看，前一步通过再做下一步。

### R0 只改动作数据（不改 Java，不改模型）

在两个生成脚本和 P9 的 Blockbench 手调键里改「运动语言」。服务器用到的时间都不动：片段长度、`mag_in_tick` 等，`sound_effects` 的位置也不动。

1. **到位不回弹**。
   - `go()` 默认 `over` 改成 0，到位用很短的减速直接停（最后 15% 时间里速度降到 0）。
   - 只有重物撞停的地方（拍弹匣、套筒复位）允许一次 ≤ 1.5% 的过冲，不能有第二次反向。
   - 预备动作 `antic` 只留在发力明显的动作前（甩出空弹匣、拍弹匣），≤ 0.02。
2. **冲击是一下，不是一串**。
   - `jolt()` 改成单峰：0.015–0.03 s 冲上去，然后临界阻尼回到 0，不越过 0。
   - 曲线可用 `(1 + s/τ)·e^(−s/τ)`，τ 取 0.03–0.05 s。
3. **关键姿势定格**。每个受力点前后放一对同值关键帧：
   - 有经验档定 0.08–0.15 s；
   - 新手档定 0.15–0.3 s（新手慢在停顿和犹豫，不在动作发软）。
   - 腰射换弹的目标：枪静止 ≥ 35%，最长静止 ≥ 0.25 s，反向次数不超过受力点数 × 2。
4. **删掉持续漂移**。
   - `drift()` 从换弹和检视里拿掉。
   - 要表现「看一眼」，就用一次转动 + 定格。
   - 检视里翻看弹匣的「呼吸感」也删掉，转到位就停。
5. **主手不滑**。
   - `GRIP_SLIDE` 的系数从 1 降到 0.2 以下（握把最多动 0.6 单位，相当于虎口松一点）。
   - P9 脚本已有环境变量 `P9_SLIP`，可以先用它离线对比。
   - 检视的 `inspectSlip` 同样处理。
6. **左手接触要「按上去」**。
   - 接近枪的最后 1–1.5 单位在枪的坐标系里走直线压上去，用 2 帧（0.033 s）以内切到「锁在枪上」，之后相对枪的速度为 0。
   - 离开枪时同样：先在枪坐标系里离开 1 单位，再自由移动。
   - 托弹匣同理：手和弹匣用 `magOnHand` 锁死，这一点已经做到了。
7. **镜头只在受力点动**。
   - 每次单峰 ≤ 1°，拍弹匣、套筒复位这种地方才动。
   - 有意的低头保留，但改成「低头—定住—抬头」三段，中间不漂。
8. **手调键的做法**（P9）：
   - 先按第 D 节的受力点表摆关键姿势，每个姿势复制一份放在 0.1 s 后做定格；
   - 段内的贝塞尔手柄缩到 0.03–0.05 s，或者直接用线性；
   - 不靠很多小键去「做缓冲」。
   - `HAND_KEYED` 的检查要放宽：现在要求每条通道至少有一个贝塞尔键，改成「贝塞尔或线性」都可以。

R0 能消掉 A 里的第 2、3、4、5、7、8 条。第 1 条和第 6 条是结构问题，要靠 R1。

### R1 肩点约束的刚性手臂（小改 Java，不换运行时）

改 `NativePlayerArmRenderer`，枪的 JSON 加一个开关，比如 `first_person.arm: "shoulder"`。开关没打开的枪还是旧画法，HR-55、Silverwood 12 等都不受影响。

1. **虚拟肩点**：
   - 每条手臂定一个肩点，取待机姿势下方块的近端；
   - 放在枪模型的根坐标系里（`root`，不是 `handling`），所以腰射和 ADS 的位置照旧跟着 `ads.profile` 走；
   - 待机和 ADS 时腕角为 0，画面和现在一模一样。这是 2026-10-17「就要旧版握姿」的硬要求。
2. **右臂：前臂 + 手掌两段刚性**。
   - 原版手臂贴图不变，把 12 px 拆成前臂 8 px 和手 4 px 两个方块，接头处互相重叠，不共用顶点，也不做半程旋转，所以弯的是一个硬折角，不会像橡皮。
   - 手块完全跟枪的挂点走，保持硬连接。
   - 前臂方向 = 腕 → 肩点；绕前臂轴的滚转取最接近动画给的角度。
   - 实测：肩点固定时，P9 换弹需要的腕角是 23–34°，BR-51 是 19–36°，P9 检视 53°，都在真人腕的屈伸范围（约 ±70°）里。
3. **左臂：前臂 + 画面外的上臂，两段 IK**。
   - 左手要离开枪去腰上拿弹匣，只固定肩、靠腕转需要 71–123°，不够用。
   - 左臂复用 `skeleton/HumanoidPoser` 的两段 IK 数学（只算肘的位置，肘朝下外），前臂和上臂都是刚性方块，手块同右手。
   - 上臂大多在画面外；露出来的部分是硬的直段。
4. **腕的限制**：
   - 腕角超过 45° 的部分，由前臂绕自身轴的旋前旋后和肩点小幅移动（≤ 2 单位，相当于上身跟着转）分掉。
   - 不允许出现折断一样的腕。
5. **离线检查**：
   - 新旧两种画法在 `tools/preview-fp-arms.mjs` 里并排出图（待机、ADS、换弹各受力点）；
   - 读数要求：待机和 ADS 与旧画法的差 ≤ 0.1 单位；
   - 换弹时右臂根部位移 ≤ 1.5 单位，左臂根部 ≤ 3 单位；
   - 手臂方块和枪的穿插不比现在多。
   - 记忆规则「先和旧视图模型放在一起看，再改」照做。

### R2 推到其余片段和枪

P9 的 3 段样板和 BR-51 的 2 段样板通过以后，再推到：

## D. P9-01 和 BR-51 的具体改法

### P9-01

先做 3 段样板：`shoot`、`reload_tactical_experienced`、`reload_empty_experienced`。

- **射击 `shoot`**（0.3 s）：
  - 套筒曲线不动，已经是一下到底一下回来；
  - 枪口上跳改成单峰：0.018 s 冲到 4.6°，0.1 s 内回到 0，不越过静止位，越过的部分 ≤ 3%；
  - 第二个 0.078 s 的小 jolt（套筒复位的那一下）留着，但也改成单峰；
  - 目标：0.12 s 内静止，反向 ≤ 2 次。
- **战术换弹**的受力点（括号里是有经验档的定格时长）：
  1. 拇指按弹匣释放钮：枪下沉 0.5°，单次（定 0.08 s）；
  2. 旧弹匣落下：枪轻抬 0.8° 单次；左手同时已在去拿新弹匣的路上；
  3. 新弹匣对准弹匣井：枪和左手一起定住（0.12 s），这是这一段最重要的「看清楚」姿势；
  4. 推入：直线、匀速偏快，到 `PART` 深度停一下（0.05 s）；
  5. 手掌拍底：枪向上 1.5–2.5°，0.03 s 冲上，0.08 s 回位，不回弹；镜头单峰 0.6°；
  6. 左手回到握把：在枪坐标系里沿直线按上去，2 帧内锁死；
  7. 复位到待机：减速停住，不过冲。
- **空仓换弹**：
  - 前 1–5 同上；
  - 6 改成右手拇指压空仓挂机解脱杆：拇指压下前定 0.08 s，压下瞬间套筒撞回，枪口向前点 0.5°（单峰）；
  - 新手档的左手反手拉套筒是「左手锁住套筒、右手把枪往前推」：
    - 枪往前走，套筒不动；
    - 拉到底定 0.06 s；
    - 松手瞬间套筒弹回，枪口一顿；
    - 不能像左手在空中把套筒「拖」回来。
- **握把滑动**：`SLIP` 从 1 降到 0.15–0.2，检视的 `inspectSlip` 同样。
- **镜头**：有经验档的 7° 低头保留，改成「0.2 s 低下去—定住—受力点单峰—抬回」；新手档 14° 同理。
- **检视**（R2 再做）：
  - 每次转枪到位就停，不加 `drift`；
  - 定格 0.6–1.2 s（沉稳在停的时间，不在慢慢晃）。

### BR-51（4.4 kg 步枪，打在肩上）

整段都是程序生成的，改 `tools/author-br51-01-v3-native-animations.mjs` 的参数就行。先做 2 段样板：`shoot`、`reload_empty`。

- **射击**（0.25 s）：
  - 后坐 3.4° 改成单峰；
  - 枪托在肩上，后坐要往后顶，然后被肩挡住（z 向位移单峰，回位不过冲），不是往上翘再弹回；
  - 目标：越过静止位 ≤ 3%（现在 21%），0.14 s 内静止。
- **换弹的枪身路线**：
  - `RELOAD_MEET` 那一段 0.38–1.47 s 太长，拆成「0.38–0.6 s 转到换弹角度—定住到 fetch—弹匣来时 0.1 s 小幅迎上去—定住」；
  - 最后复位 `over 0.07` 改 0；

- **冲击**：
  - `T.release`（拇指推弹匣卡笋）、`T.out1`（弹匣脱钩）、`T.hook`（前钩挂上）、`T.seat`（摇进卡住）四个 `jolt` 改成单峰；

  - 每个受力点前定 0.1 s。
- **拉机柄**（`charge()`）：
  - 右手到拉机柄 `rhOn` 时定 0.06 s（抓实）；
  - `pull → pulled` 改成先快后停的硬拉，拉到底定 0.03 s，然后松手（`let`），枪机 0.035 s 撞回不动；

## E. 继续用 GeckoLib / Blockbench 时

**避免**：
- 用 Blockbench 默认贝塞尔手柄把每个键串起来。键越多越像液体，不是越精致。
- 为了让枪「活」起来加持续漂移（正弦 `drift`、片段里的呼吸摆动）。持枪晃动由 `NativeWeaponSway` 统一管，片段里不加。
- 落点正弦回弹、多次振荡的冲击（`go` 的 `over/per/tau`，`jolt` 的余弦）。
- 主手骨骼挂在枪下面，同时又在枪上滑（`GRIP_SLIDE`）。
- 用按时间的平滑混合在两个都在动的目标之间切手（`mixT` + `W` 长窗口）。
- 用镜头骨的连续摆动做「重量感」。
- 第一人称持枪用共用顶点环、半程旋转的蒙皮关节（`SkinMesh` C-min）。
- 给第一人称枪的控制器加过渡时间。现在是 0，保持 0。

**加强**：
- 先做关键姿势表：每个受力点写清楚手在哪、枪在哪、谁在用力，再补中间帧。
- 定格用同值双键；受力点用单峰冲击，回位用临界阻尼。
- 接触用约束，不用混合：
  - 手锁在枪坐标系里；
  - 弹匣锁在手上或者弹匣井里（`magOnHand`、`seatDepth` 已经是这样）；
  - 拉套筒、拉机柄时手锁在把手上（`onHandle`、`onSlide`）。
- 旋转中心放在真实的支点上：
  - 手枪绕握把（`HP` 已经是握把）；
  - 步枪换弹时绕肩窝和枪托（BR-51 的枪托基本不动，保持住）。
- 60 Hz 烘焙和 `bb-keyframes` 的求值一致性保留。
- 每次改完跑 `node tools/probe-fp-rigidity.mjs`，把读数写进验收记录。用户看实机，脚本只管数字。

## 6. 和「沉稳」规则的关系

2026-10-22 的规则是「宁愿关键帧多一点，做出缓冲效果」。今天的纠正说明那条规则被执行过头了：缓冲变成了每段都在回弹和漂。

以后这么理解：
- **沉稳**：
  - 段与段之间有停顿，看清楚再动；
  - 新手档多停、多看、会插歪；
  - 总时长和节拍不变。
- **刚性**：
  - 每段动作本身干脆，起步可以缓，到位要停住；
  - 不回弹、不漂、不拖尾。
- **缓冲**只用在起步：发力前的轻微预备、从静止加速。到位一侧用减速停住，不用弹簧。

## 8. 附录：十指 Rig 审计的结论（暂停）

2026-10-22 开始的「第一人称动画管线与真实十指 Rig V0」审计，在用户纠正后暂停。已经查清的事实留在这里，以后要做时从这里接着做：
- **Vextris 0.1.1-alpha.4**：
  - 只有刚性部件 + 骨骼层级 + 每根骨骼一个姿势钩子（`BonePoser`）；
  - 没有蒙皮、顶点权重、glTF/GLB 读取、关键帧播放和 IK；
  - 自己的文档写明骨骼动画交给 GeckoLib。
- **GeckoLib 4.7.4** 在 AFL 里管：
  - 枪的 geo / 动画 JSON、控制器、服务器触发动画同步；
  - 枪和几件工具的第一人称渲染器；
  - `GeoBone` 姿势；
  - Vextris 的 GeckoLib 桥按 GeckoLib 骨骼画网格部件。
- **AFL 自己的骨骼运行时**（`skeleton/`）：16 根骨骼的 JSON rig、两段 IK、CPU 分段蒙皮、带道具和手目标的动作 JSON。以后做手指，它是比 Vextris 更好的起点。
- **手指可以先做成刚性分节**：每节一根骨骼、一块网格，不需要蒙皮，现有 GeckoLib + Vextris 桥就能画。R1 的「刚性段 + 硬关节」和它是一个方向。
