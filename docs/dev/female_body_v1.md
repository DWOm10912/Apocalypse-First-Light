# 女性体型 V1（旧方块身体）r3 选 D，实机 PASS（2026-10-27）

## 用户的决定

- "其实可以分男女，不过我觉得除了声音以外，就不要做任何东西了"：性别只影响外观和声音，不影响任何数值和玩法。
- "然后在男性体型的基础上，设计女性体型 / 你现在用blender帮我做女性体型吧"。
- 做在旧方块身体上（现在游戏默认的身体），不是 B5。
- 头发做成单独的头发层：画在第二层的头上，以后能从发型模板里挑、选发色，皮肤只管脸、肤色和衣服。
- 贴图照 B 的感染者 r6 风格（`AFL-vanilla-rework/design/creatures/infected_z0/`，购买的 zombie.png 的笔触，"故事模式风格"）。

## 对既有动画的影响（报告，进游戏前要用户确认）

- 骨骼、长度、关节位置不变，动画数据一帧不动。
- A：就是现在给女性 roster 皮肤用的细胳膊，没有新影响。
- B：收腰只往里收，不会和手、物品穿模；手贴着腰的动作（叉腰、拍口袋）会离身体远 0.5 px。
- C：胸口往前最多 0.7 px（肩下 1–5.9 px）。手、枪托、物品靠在胸前的动作可能穿进去最多 0.7 px，要逐个检查：持枪的低位警戒、包扎胸口、抱东西、坐姿时手放在胸前的。整块在 6 px 的关节环以上，只跟胸腔走，弯腰时不会和躯干分开。
- 第二层（外套层）要跟着 B、C 的形状走。现在第二层除了头发是空的。

## 皮肤（样本）

- 画法照 B 的 r6：平涂、柔和的明暗档位、每个面边缘略暗、衣服竖向褶纹、头发一根根有深浅和发梢，不贴照片噪点。
- 两张都是 T 恤 + 牛仔裤 + 靴子，方便对比身体；男的是短发，女的是短发波波头，带侧分刘海。
- 头发全在第二层的头上（以后单独的头发层）；底层头上画头皮颜色的头发，防止外层透出皮肤。
- 这只是对比用的样本，不替换现在的 60 张 roster 皮肤。

## 进游戏（2026-10-27，用户实机："没问题了，PASS，提交"）

用户选了 D（审图第三列），接着说"把上面的男性默认皮肤做成开局捏人，男女各一套，做完今天就这样"。

- **身体**：`skeleton/SkinMesh` 新增 `female` 参数。女性躯干在原来 0、6、12 三道环之外加 4、7.5、9.5 三道，6 和 7.5 往里收（见上面 B），每道新环跟它所在那段的骨头走；胸部是 D 的高度场（0.2 px 网格，约 600 个四边形，只在第一层，外套层不加），每个点放在它上下两道环之间、跟着躯干正面弯，再往外推。UV 是 T 恤正面正投影，任何皮肤都能用。男性的网格一个顶点都没变。
- **谁用女性身体**：存档里性别是女的幸存者（开局自己选的，或抽到的女性继任者），`Identity` 包带上性别（`SurvivorIdentityClient.Body.female`）；尸体按皮肤判断（`SurvivorSkins.female`：女性开局皮肤和 roster 里的女性）。
- **开局皮肤**：`textures/entity/survivor/afl_male_v1.png`、`afl_female_v1.png`，就是上面两张样本（128×128）。`SurvivorSkins.starter(sex)` 选，男的 4 px 胳膊，女的 3 px；开局幸存者不再用账号皮肤。继任者照旧从 roster 抽。
- **捏人页**：性别两个都能点；旧身体（默认）下只选性别，肤色、发型、发色只在 B5（开发开关）下出现；中间的预览改成旧身体，画开局皮肤，女的带女性躯干。"随机"也会随机性别。
- **网络**：`Identity`、`SetupChoice` 加性别，协议 77 → 78。主机开局设置的 NBT 多一个 `Female`。
- **声音**：还没有女声素材，没接。

### 对既有动画的影响（量出来的）

动画数据一帧没动。`gradlew skeletonCheck` 的动作检查新加一行：前臂、手的中心线到"胸腔盒 + 胸前 0.7 px 那块"的距离（旧身体胳膊半宽 2 px，小于 2 px 就是皮肤贴进去了），只报告，不算失败。只因为胸部才变近的场景有 26 个，最近的：

| 场景 | 最近 | 进胸里约 |
|---|---|---|
| `thermo_held`（举着温度计看） | 右前臂 1.3 px | 0.7 px |
| `p9_idle` / `p9_idle_crouch` / `p9_sprint_*`（P9 持枪待机、蹲、跑） | 左前臂 1.4 px | 0.6 px |
| `p9_draw_44`、`p9_reload_*`（P9 拔枪、换弹几帧） | 1.4–2.0 px | 0–0.6 px |
| `pull_0`（拉发电机）、`crowbar_*`（撬棍） | 左前臂 1.7–1.9 px | 0.1–0.3 px |

P9 持枪待机最常见，第三人称看女性角色时左小臂会压进胸口一点。要不要给女性单独把左臂往外让一点，等用户实机看过再定（改动画前先报告）。

## r4 胸型：按真实人体比例重做（2026-10-27，未实机验收）

用户穿衣服进游戏看过："女性的胸部有点问题，胸罩遮不住，下面露出来了 / 你改一下模型吧，并且查一下真实的人体结构，现在形状也不圆（并且可能有点太小了，正面看不出来）"。

**问题：** 原来的形状是一条侧面曲线乘一个横向衰减，最厚只有 0.7 px，下缘被拉到 5.9 px；胸罩只画在肩下 2–5 px，形状比胸罩低，所以下面露出来。

**依据（成年女性人体测量，换算 1 px ≈ 5.6 cm，身高 1.8 m = 32 px）：**
- 胸骨上窝到乳头约 18.5 ± 1.7 cm，乳头到乳房下皱襞约 6.8 ± 1.2 cm；
- 两乳头间距约 20 cm，乳房底宽 12–14 cm，突出 4 ± 1.3 cm；
- 上半部分是一段长而缓的斜坡（从第二肋附近开始），下半部分短而圆，到皱襞处收回胸壁。
- 来源：[PMC9516749](https://pmc.ncbi.nlm.nih.gov/articles/PMC9516749)、[PMC6756646](https://pmc.ncbi.nlm.nih.gov/articles/PMC6756646)、[PMC3995377](https://pmc.ncbi.nlm.nih.gov/articles/PMC3995377)、[USM 乳房人体测量](https://erepo.usm.my/entities/publication/fcfa10e4-6f3e-40d0-9016-74da8887859f/full)。

**新形状（`SkinMesh#chestDepth`）：** 左右各一个圆顶，取两者中较厚的：
- 乳头在中线两侧各 1.75 px、肩下 3.5 px；往中间伸 1.2 px，往外 1.35 px，往上 2.1 px，往下 1.15 px（皱襞在 4.65 px）；
- 厚度 = 1.05 px ×（1 − r²）^e，e 从正上方 1.25（缓缓并进胸口）、两侧 0.75，到正下方 0.5（圆，到皱襞处收回）；
- 1.05 px ≈ 5.9 cm，取正常范围的上端，让正面能看出来；
- 网格 x ±3.3 px、肩下 1.2–5.2 px，0.2 px 一格。

**衣服盖在上面（`CHEST_CLOTH`）：** 不再贴着身体走：
- 两胸中间的布料至少保持乳头高度的 0.92，不陷进乳沟；
- 从最厚处往下垂，每往下 1 px 最多收回 0.7 px，不贴进皱襞；
- 处处不低于身体，所以不会穿模。衬衫、夹克各自再加自己的离身距离。

**胸罩（`tools/characters/old_body_skin_paint_v1.py`）：** 用同一个圆顶函数算：
- 罩杯盖住胸部鼓出来的每一个像素，边缘深一点当包边；
- 两杯中间的鸡心位在 3–4.5 px；
- 下围在 4.5–5.5 px，正面、侧面、背面一圈；
- 肩带接到罩杯顶。

**审图：** `design/characters/old_body_clothes_v1/old_body_clothes_v1_r2.png`，最后一行依次是：
- 只穿内衣：正面、侧面、斜下方；
- 衬衫：正面、侧面；
- 夹克：斜前。

**对动画的影响（报告，动画未改）：** 胸前比原来厚 0.35 px。`skeletonCheck` 里只因为胸部才变近的场景从 26 个变成 39 个，最近的是 `thermo_held`，右前臂 1.0 px，也就是压进胸里约 1 px（原来 1.3 px）。其他较近的是撬棍、P9 持枪待机和拉东西。

## 腰部闪烁修复（2026-10-27，未实机验收）

用户实机穿上衣服后："中间白色的线会一直左右闪烁 / 衬衫也是 / 我发现是图3的那些位置一直在抖 / 背后也有"。抖的地方在罩杯下缘两侧、肚脐、背后的下围。

**原因：**
- `SkinMesh#quad` 会按四边形自己的弯曲程度选对角线，这是 2026-10-26 修手肘闪烁时加的。
- 男性的四边形都是矩形，选哪条对角线贴图都一样。女性收腰后，正面、背面、侧面在 4–9.5 px 之间都是梯形，两条对角线贴出来的贴图会错开约 0.125 px，竖线在对角线处折一下。
- 站着时呼吸、转头让躯干轻微扭动，这些四边形几乎是平的，两条对角线的分数几乎一样，于是每帧来回切换。拉链、纽扣、内衣边、肚脐就左右跳。
- 胸部网格原来是叠在躯干正面前 0.01 px 的一层，边缘和正面几乎重合，罩杯边缘也会抖。

**改法：**
- **对角线只在明显弯曲时切换**（`FLAT`）：两个三角形的夹角超过约 2.6° 才换对角线，否则固定用原版的。这条对所有身体部位都生效；只差 2.6° 以内的四边形用哪条对角线，形状上看不出差别。
- **女性躯干改成一整张面**（`SkinMesh#torso`），胸部不再叠一层：
  - 正面就是胸部网格本身；
  - 正面和背面都按胸部网格的列（0.2 px）切，侧面每 1 px 一列；顶面、底面按同样的列切；
  - 每条共用的边两边顶点完全一样，没有缝，也没有 T 形接点；
  - 列很窄，收腰的梯形不会再把贴图折出来，就算对角线换了也看不出。
- 一层躯干的四边形从约 700 个（大部分是胸部网格）变成 2230 个，穿衬衫和夹克的女性躯干共约 6700 个。玩家几个人时没影响；女性尸体也按这个画，尸体很多时要留意帧数。

**离线测量**（`gradlew skinJointCompare -Pfemale`，60 fps 逐帧数躯干上换了对角线的四边形）：

| 动作 | 只穿内衣 | 衬衫 | 夹克 |
|---|---|---|---|
| 站立待机（240 帧） | 0 | 0 | 0 |
| 蹲着待机（240 帧） | 0 | 0 | 0 |
| 走路（60 帧） | 186 | 222 | 230 |

走路时腰部的扭转超过了 2.6°，对角线会换，但每一列只有 0.2 px 宽，换了也看不出。审图 `design/characters/old_body_clothes_v1/old_body_clothes_v1_r3.png`：外形和 r2 一样，拉链是直的，没有裂缝。
