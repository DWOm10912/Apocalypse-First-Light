## 3. 数据

- 三项：`afl:firearms_pistol`（`WeaponClass.PISTOL`）、`afl:firearms_long`（`RIFLE`、`PRECISION_RIFLE`、`MACHINE_GUN`、`SMG`、`SPECIAL`）、`afl:firearms_shotgun`（`SHOTGUN`）。
- 存在 `SurvivorRecord` 的 `Growth: {"afl:firearms_pistol": {Lv: int, Xp: int}, ...}`（2026-10-17 前叫 `Skills`），即加点文档第 11 节的契约：键不认识就保留但不生效，没有的键按该项的 `default`（0 级），等级夹到 0–该项的 `max`（10）。力量、体能的成长存在 `Body` 里，不在这个表。
- 分档（`SurvivorGrowth.tier`）：0–3 级新手，4–6 级有经验，7–10 级熟练（2026-10-18 起；5 级时是 0–1 / 2–3 / 4–5）。在数据里是节点：`survivor_growth/firearms_*.json` 的 `perks` `{"0": "reload_novice", "4": "reload_trained", "5": "reload_ads", "7": "reload_practised"}`（5 级瞄准换弹 2026-10-18 加，图标是准星），成长页在这几格画换弹图标，升到这一级提示"学会了…"。
- 每一级（普通格子）：瞄准晃动 ×(1.25 − 0.05 × 等级)，后坐力回复（视角回落）速度 ×(0.8 + 0.04 × 等级)，都在客户端（`SurvivorGrowth.adsSway` / `recoilRecovery`）。0 级比以前晃 25%、回得慢 20%，5 级和以前一样，10 级晃动少 25%、回得快 20%。腰射晃动、枪模型的抖动不按等级改。
- 查询：统一一个 `GunProficiency.level(player, weaponClass)` / `tier(...)`；实际做的是 `SurvivorGrowth.gunTier(player, weaponClass)`（服务器）：创造、旁观按熟练档，没有记录、选择中按新手档。客户端读人物表（`SurvivorSheetClient.gunAdsSway` / `gunRecoilRecovery`），创造模式不改。
- 同步：本人的三项等级在登录、接手、升级时发给自己，新包，协议 56 → 57。别的玩家不需要等级：服务器选好的片段名已经广播（第三人称按片段名选动作）。

## 4. 换弹怎么按档区分

- 片段命名（枪的第一人称片段和第三人称动作同名）：
  - 熟练：`reload_tactical`、`reload_empty`（已有），瞄准时 `_ads`（已有）；
  - 有经验：`reload_tactical_experienced`、`reload_empty_experienced`（2026-10-18 做的时候从 `_basic` 改名，和档名一致）；
  - 新手：`reload_tactical_novice`、`reload_empty_novice`，出错版 `reload_tactical_novice_fumble`、`reload_empty_novice_fumble`。
- 服务器在 `NativeGunActions#request` 里选：按档换成对应片段；枪没有这一档的片段时用熟练片段、熟练时长（旧枪不受影响）。
- 时长：熟练 = 枪定义的 `reload.tactical_seconds` / `empty_seconds`；有经验 ×1.35；新手 ×1.8；出错版再加 0.6–0.8 s（P9 定 0.7 s）。弹匣附件覆盖的时长同样乘。子弹入枪刻同比后移（出错版按动画里插到底的时刻）。精确时长跟着动画的节拍定，倍数是目标。
- 新手出错：服务器在开始换弹时掷骰，0 级 25%、1 级 18%、2 级 12%、3 级 6%，4 级（有经验）起 0（10 级制的草案，F3 时定）；出错 = 弹匣顶在弹匣井边上（或找不到卡笋）要再来一次，不会掉弹匣、不会换弹失败。种子用服务器随机，不能靠重按刷。
- 动作内容（P9 试点，按参考第 6.1 节）：
  - 有经验：枪拉到胸前低处，看着换，不停顿；空仓用左手反手拉套筒（不用拇指按解脱杆）。
  - 新手：全程低头看；枪拿得离身体近、肘张开；插弹匣要对一下才进去，插完再看一眼；空仓反手拉套筒，拉得慢。出错版在插入时顶住、退出来、对准再插。
- **P9 已做（2026-10-18，D 分支 `feature/gun-reload-tiers`，未提交，没进游戏）**：六个片段 / 动作、服务器按档选片段（`NativeReloadTiers`）、掷骰、时长和入枪刻跟片段走；创造模式按 10 级（熟练）。实现和长度见 [p9_reload_inspect_v1.md](p9_reload_inspect_v1.md) 第 8 节。
- **P9 手调关键帧版（2026-10-22，master，用户 2026-10-22 实机 PASS）**：两套分级换弹按熟练档 PASS 的标准重做（贝塞尔手调帧、沉稳有缓冲、速度不超过 PASS 片段）：镜头骨骼低头（有经验约 −6.5°，新手约 −13°），新手插歪重来 +0.9 s（取代 0.7 s），有经验档多一套瞄准换弹 `_experienced_ads`（Lv 5–6），没弹匣的换弹也分档，共 16 段；服务器先判断瞄准、再按档选（`NativeReloadTiers.choose` 带 `_ads` 后缀）。长度：有经验 2.3 / 2.8 s（瞄准 2.3 / 2.7 s），新手 3.1 / 3.8 s，插歪 4.0 / 4.7 s。见 [p9_reload_inspect_v1.md](p9_reload_inspect_v1.md) 第 5.1 节。
- 检视不分档（检视本身是展示动作）。掏枪、收枪、持枪姿势、晃动按档区分放到后面的阶段（第 7 节）。

## 5. 成长（2026-10-18 随加点文档 P3 先做了，F4 提前）

**已做**（加点文档第 7 节"P3 已做"，D 分支，GameTest 通过；成长页用户 2026-10-18 实机 PASS，瞄准晃动、后坐力回复、瞄准换弹按档的手感还没专门试）：命中活的目标每个目标前 3 次各 3 点、打死再 3 点、真的装进子弹的换弹 2 点（60 s 内重复递减）；0→1 30 点，之后每级多三到五成，9→10 520 点；**没有每天上限**（用户 2026-10-18：「玩家可以一直练，没有限制」）；"怕开枪"封顶 6。枪械等级影响瞄准晃动和后坐力回复（第 3 节）；瞄准时换弹 5 级起（`NativeGunActions` 选 `_ads` 片段前看 `gunLevel ≥ SurvivorGrowth.ADS_RELOAD_LEVEL`；2026-10-18 前是熟练档）；新手、有经验两档的片段和时长 2026-10-18 做了（F2、F3，第 4 节），还没进游戏。查询没有单独做 `GunProficiency`：服务器读记录（`SurvivorSetup.growthLevel`），客户端读人物表（`SurvivorSheetClient.growthLevel`）。同步没有用单独的包：等级在人物表里，升级另有 `LevelUp` 提示包，协议 58。原来的方向：

- 经验来源（按枪类记）：完成一次真的换弹（插进去的弹匣比原来多子弹，或枪原来是空的）；命中活的目标。对着空气开枪、满弹匣重换、刚换完又换不给。
- 同类动作 60 s 内连续做，收益按次递减（第 2 次 50%，第 3 次 25%，之后 0）。
- 打靶命中也给（用户 2026-10-17：「一直开枪杀敌、打靶就能加枪械的成长」），比实战少给；要等靶子做出来。
- 升级所需经验逐级增加，学习速度乘在经验上，"怕开枪"封顶 6 级（加点文档第 7 节）。
- 不会因为长期不用而下降（V1）。

## 6. 第三人称、多人

- 第三人称动作 `gun/<枪>_<片段>` 跟片段走，档位和出错都随片段名自动对上。
- 别的玩家看到的档位 = 服务器选的片段，不用另外同步。
