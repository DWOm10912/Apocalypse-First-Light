## 3. 数据

- 三项：`afl:firearms_pistol`（`WeaponClass.PISTOL`）、`afl:firearms_long`（`RIFLE`、`PRECISION_RIFLE`、`MACHINE_GUN`、`SMG`、`SPECIAL`）、`afl:firearms_shotgun`（`SHOTGUN`）。
- 存在 `SurvivorRecord` 的 `Growth: {"afl:firearms_pistol": {Lv: int, Xp: int}, ...}`（2026-10-17 前叫 `Skills`），即加点文档第 11 节的契约：键不认识就保留但不生效，没有的键按 1 级，等级夹到 0–5。力量、体能的成长存在 `Body` 里，不在这个表。
- 分档：0–1 级新手，2–3 级有基础，4–5 级熟练。
- 查询：统一一个 `GunProficiency.level(player, weaponClass)` / `tier(...)`；创造、旁观、没有记录、选择中按普通人（1 级）。客户端有一份本人的镜像（晃动要用）。
- 同步：本人的三项等级在登录、接手、升级时发给自己，新包，协议 56 → 57。别的玩家不需要等级：服务器选好的片段名已经广播（第三人称按片段名选动作）。

## 4. 换弹怎么按档区分

- 片段命名（枪的第一人称片段和第三人称动作同名）：
  - 熟练：`reload_tactical`、`reload_empty`（已有），瞄准时 `_ads`（已有）；
  - 有基础：`reload_tactical_basic`、`reload_empty_basic`；
  - 新手：`reload_tactical_novice`、`reload_empty_novice`，出错版 `reload_tactical_novice_fumble`、`reload_empty_novice_fumble`。
- 服务器在 `NativeGunActions#request` 里选：按档换成对应片段；枪没有这一档的片段时用熟练片段、熟练时长（旧枪不受影响）。
- 时长：熟练 = 枪定义的 `reload.tactical_seconds` / `empty_seconds`；有基础 ×1.35；新手 ×1.8；出错版再加 0.6–0.8 s（P9 定 0.7 s）。弹匣附件覆盖的时长同样乘。子弹入枪刻同比后移（出错版按动画里插到底的时刻）。精确时长跟着动画的节拍定，倍数是目标。
- 新手出错：服务器在开始换弹时掷骰，0 级 25%、1 级 12%，2 级起 0；出错 = 弹匣顶在弹匣井边上（或找不到卡笋）要再来一次，不会掉弹匣、不会换弹失败。种子用服务器随机，不能靠重按刷。
- 动作内容（P9 试点，按参考第 6.1 节）：
  - 有基础：枪拉到胸前低处，看着换，不停顿；空仓用左手反手拉套筒（不用拇指按解脱杆）。
  - 新手：全程低头看；枪拿得离身体近、肘张开；插弹匣要对一下才进去，插完再看一眼；空仓反手拉套筒，拉得慢。出错版在插入时顶住、退出来、对准再插。
- 检视不分档（检视本身是展示动作）。掏枪、收枪、持枪姿势、晃动按档区分放到后面的阶段（第 7 节）。

## 5. 成长（F4 再做，规则先定方向）

- 经验来源（按枪类记）：完成一次真的换弹（插进去的弹匣比原来多子弹，或枪原来是空的）；命中活的目标。对着空气开枪、满弹匣重换、刚换完又换不给。
- 同类动作 60 s 内连续做，收益按次递减（第 2 次 50%，第 3 次 25%，之后 0）。
- 打靶命中也给（用户 2026-10-17：「一直开枪杀敌、打靶就能加枪械的成长」），但每个游戏日有上限，比实战低；要等靶子做出来。
- 升级所需经验逐级翻倍，每天有上限，学习速度乘在经验上，"怕开枪"封顶 3 级（加点文档第 7 节）。具体数值实现时测了再定。
- 不会因为长期不用而下降（V1）。

## 6. 第三人称、多人

- 第三人称动作 `gun/<枪>_<片段>` 跟片段走，档位和出错都随片段名自动对上。
- 别的玩家看到的档位 = 服务器选的片段，不用另外同步。

## 7. 分期

- **F1**：数据（`Growth` 三项）、查询、同步、协议 57；服务器按档选片段和时长（缺片段回退熟练）；开发命令 `/afl survivor proficiency <pistol|long|shotgun> <0-5>`；GameTest。不加新动画时游戏里看不出区别。
- **F2**：P9 有基础档：第一人称两段、第三人称两个动作，用户实机看。
- **F3**：P9 新手档和两个出错版，掷骰；用户实机看。
- **F4**：成长和防刷。
- 以后：其他枪重做时带三档；掏枪、收枪、持枪姿势、晃动按档区分；开局系统接上后按特质给初始值。
