## 2. 重定向方法（`design/characters/survivor_male_v1/source/anim_tp_v1.py`，numpy 离线，不经过 Blender）

1. **源数据低通。** 关节局部旋转（四元数）和根骨骼路径先做零相位高斯低通，idle 3 Hz、run 10 Hz。CMU 原始数据没有滤过波：77_02 的根骨骼欧拉角在万向锁附近（ry ≈ −86°），每帧抖 1–2°，脚的固定和腿部 IK 又会把抖动放大到髋部和腿上。这一条在 Blender 里看到"人一直在抽搐"之后补上。
2. **坐标：** CMU 是 Y 朝上、面向 +Z，转成 Blender 的 Z 朝上、面向 −Y；再加一个偏航角，让跑步的行进方向（idle 是骨盆的平均朝向）对准 −Y。
3. **躯干、颈、头、锁骨、脚、脚趾：** 把源骨段相对静止的世界转动，叠到 AFL 的静止姿势上。颈部取下颈和上颈的中间值。
4. **上臂、前臂：** 骨骼对准源骨骼方向，铰链轴取"方向 × 前方"。AFL 的 A 字静止姿势能正确接上源数据的 T 字姿势。
5. **大腿、小腿：** 按 AFL 腿长 / 源腿长缩放源脚踝位置，再用两骨 IK 求解；膝盖平面取源股骨铰链，膝盖最小弯曲 4°。
6. **手、手指：** 手跟随前臂，`forearm_twist` 不动，手指用放松弯曲。
7. **原地化：** run 减去根骨骼的直线行进，游戏里按"实际速度 / 参考速度"播放，支撑脚就停在地上；idle 减去根骨骼的平均位置。
8. **着地：**
   - 整体抬高，让支撑脚的鞋底落在 z = 0（源地面是脚趾关节中心，不是鞋底）；
   - 支撑期用一个小的踝部位移，固定前脚掌的水平位置和最低鞋底点的高度，前后各 8 帧余弦淡出，淡出时鞋底不会被压到地下；
   - idle 再抬高髋部，让膝盖中位弯曲 8°（CMU 站姿读数是 15–30°）。
9. **头部回正：** 去掉整个循环里颈和头的平均世界转动，头平均是正的，游戏里的视角转动再叠在上面。
10. **循环接缝：** 按位置和速度挑首尾最接近的循环段；剩下的差在输入端线性摊开（自由骨骼的世界转动、髋、踝目标、膝铰链），再算一遍。
11. **输出：** 重采样到 60 fps。`<name>.blend.json` 给 Blender 看，`<name>.clip.json` 给游戏用。

`anim_tp_blender_v1.py` 只在 Blender 里新建或替换 `tp_*` 动作（假用户），不碰 `fp_*` 动作、54 根骨骼和静止姿势。查看时关掉手臂 IK，`restore()` 恢复成 `fp_hip`、IK 开、REST，保存前必须调用。

### 方法改动（`anim_tp_v1.py`）

- 片段类型：`move`（根骨骼在走）、`idle`、`sit`（坐稳那一段，髋关节放到坐垫上方，脚固定在地上）。风格按片段名配（`STYLE`），选项写在 `CLIPS`。
- `stride`：脚踝相对髋关节的前后轨迹，绕它的循环平均值放大或缩小，参考速度跟着变。`lift`：脚踝高出循环最低点的部分放大。`hips_drop`：移动类和待机类都能用，降低髋部，腿弯下去够到原来的脚位。
- 走路类（`slow_stance`：走、快走、蹲走、疾跑）：
  - 着地除了"离最低点 3.5 cm 以内"，还要求前脚掌相对地面慢。走路摆动脚只离地 1–2 cm，原来的判据会把整个摆动期当成着地，固定位移达到 85 cm。
  - 循环接缝修正之后再固定一次支撑脚：接缝把脚踝目标线性摊开，会把支撑脚带离地面 0.5–0.9 cm。
  - 整圈不许鞋底低于地面。
  - 跑步保持 PASS 版的判定，加速度判据会让右脚着地变短。
- 所有移动片段把第一个样本转到左脚着地（下降到地面且慢）。游戏里各步态共用一个相位，混合时左右脚对得上。
- 跑步和 PASS 版比：只差了相位转动，以及髋部定位改用带风格的转动（四元数分量最多差 0.0003，髋部 0.15 mm）。待机逐字节不变。

一条腿在支撑、另一条在摆动时，转动按权重平均后腿的竖直长度会变。所以跨步态混合只放在短暂经过的速度段：起步 / 停步 0.06–0.25 m/s，走转跑 2.05–2.25 m/s（真人约 2.1 m/s 换步态）。游戏里的贴地修正把入地的脚抬回地面。离线移植验证：最深 −7.74 cm 修正后 0.000 cm，髋关节移动 0 mm，脚掌朝向变化 0°。

## 3.3 坐姿抽搐和手形修正（2026-10-25，用户看录像："坐在凳子上一直抖来抖去"、"潜行和坐下，手都是五只摊开"）

- **坐姿抽搐：** 原坐姿是 75_18 坐稳部分的 1.27 s 循环，两只上臂在循环里来回约 20°，最快约 100°/s。改成 `still` 选项：取这段的平均姿势，只加呼吸（spine 0.5°、chest 0.8°，绕骨骼自身 X 轴，4 s 一次）。实测：chest 范围 1.6°、spine 1.0°，最快 9.7°/s，髋部不动。木椅、办公椅两段都改，时长 4.0 s。
- **手形：** 原放松手形是静止姿势的扇形张开、手指几乎伸直，看着像五指摊开。新 `HAND_RELAXED`：手指收拢到静止扇形的 0.85，各指三节按食指 → 小指逐渐多弯（食指 22 / 32 / 18°……小指 34 / 46 / 24°），拇指向食指靠 20°；左手镜像。用在走、快走、蹲着待机、蹲走、两段坐姿。
- 待机、跑、慢跑、疾跑四段不变（逐字节相同；跑步的虚握拳是已 PASS 的样子）。
- 2026-10-25 用户同意后，6 段改过的片段从临时目录复制进资源；游戏骨链公式核对差 ≤ 0.0024 mm。**游戏内未运行。**

## 4. 游戏片段格式 `afl_skin_clip` v1

- `bones` / `parents` / `pivots`：54 根变形骨骼，渲染模型坐标（Blender (x, y, z) → (x, z, −y)），单位是方块。
- `tracks[bone]`：每个样本一个 xyzw 四元数，是绕静止枢轴的转动；没有这一项表示静止，只有一个样本表示常量。
- `hips_offset`：每个样本髋部的平移。
- 游戏骨链：`D_b = D_parent · T(pivot) · Q_b · T(−pivot)`，髋部在前面再乘 `T(offset)`。样本均匀分布，循环播放，相邻样本之间做四元数归一化插值。
- 资源：`assets/apocalypse_firstlight/skins/dev/survivor_male_v1_tp_<名称>_v1.clip.json`，十段（idle 269 KB、crouch_idle 270 KB，其余 30–55 KB），从临时目录复制过来，是独立的资源标识。

## 5. 游戏内播放（`client/dev/MeshBodyTpTest.java`，只在开发环境）

- `pose auto`（默认）：
  - 站着手持 P9-01 仍是静态姿势 H（腿不动，持枪移动留到以后）；手持 P9-01 时潜行或坐下，退回原版模型。
  - 其他情况按平滑后的地面速度和潜行权重混合各步态；坐在木椅 / 办公椅上播坐姿。
- 速度：每个客户端刻测一次水平位移，平滑速度每刻向实测值靠近 35%，潜行权重同样（约 0.15 s）。
- 站立分段（m/s，起 / 满）：
  - 待机 → 走：0.06 / 0.25
  - 走 → 快走：1.3 / 1.8
  - 快走 → 慢跑：2.05 / 2.25
  - 慢跑 → 跑：2.6 / 4.0
  - 跑 → 疾跑：4.5 / 5.4
  - 潜行：蹲着待机 → 蹲走，0.06 / 0.25
- 相位：所有移动片段共用一个步态相位，按沿身体朝向走过的距离除以混合步幅（各移动片段"参考速度 × 时长"按权重平均）推进，主要向后走时倒放。待机类按 `tickCount` 推进；待机和蹲着待机来自同一段源数据、同一个循环，相位一致。
- 混合：每根骨骼对参与的片段做加权四元数和（同一半球）再归一化，髋部位移加权平均。
- 贴地修正：混合时（两段以上），哪只脚的最低鞋底点低于地面，就用两骨 IK 把脚踝竖直抬到地面：先绕髋转大腿，再绕新膝转小腿，最后绕脚踝把脚转回原来的朝向。单段播放不做修正。
- 坐姿：座位实体的位置就是椅子的地面，身体整体平移（座位 y − 玩家 y，按帧插值），片段的地面对上椅子的地面。木椅身体朝椅子方向，办公椅跟着视角转（座位自己的规则）。
- 退回原版模型的状态：游泳、爬行 / 趴下、鞘翅、睡觉、死亡、激流，骑乘椅子以外的东西（皮卡、地上坐的 GroundSeat 等），以及手持 P9-01 时潜行或坐着。
- 空中（不在地上、不在水里）：相位和速度保持不动；潜行权重照常变化。坐下时速度清零，站起来从待机开始。
- 单次移动超过 2 格算传送，不计步。
- 头按视角转动（偏航 ±70°、俯仰 ±60°），绕当前姿势的头部枢轴，叠在片段上面。
- 每个身体每帧只算一次姿势；主通道、阴影通道和 crowd 副本共用。`stats` 报"动作计算"耗时、自己的地面速度（实测 / 平滑）、潜行权重和当前混合（如 `walk_fast 0.50 + jog 0.50`）、坐着时的坐姿片段。
- 调试命令：`pose tp_<名称>` 固定播放一段（移动片段原地按自身节奏），如 `pose tp_walk`、`pose tp_crouch_idle`。固定坐姿不做座位平移。
- 缺 idle 或 run 片段时回退到静态站姿 A；缺其他片段时播它的替代（快走 → 走 → 跑，慢跑 / 疾跑 → 跑，蹲着待机 → 待机，蹲走 → 走，办公椅 → 木椅）；缺 Mesh 或姿势文件时回退到原版模型（同 M2.5）。
- 已知限制：
  - 起步、停步、转身只有混合 + 贴地修正，没有专门的过渡动作，过渡那几刻脚会滑。
  - 坐下 / 站起是瞬间切换（和原版一样）。
  - 坐姿是平均姿势加呼吸（第 3.3 节），不会自己换姿势。
  - 坐姿的前后位置按木椅算（髋关节在座面中心后 0.05 m），办公椅的座面形状不同，要实机看。
