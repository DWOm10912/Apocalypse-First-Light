## 2. 做法：正式枪动作上叠身体

- 枪每帧的位置：`G(t) = G_hip @ handling(t)`。`handling` 来自正式片段（`source/p9_formal_fp_channels.json`，由 `extract_p9_formal_fp.mjs` 从 P9 V3 bbmodel 导出），时间轴、显隐标记、镜头骨骼、声音都照用。
- 新弹匣：`G_hip @ parts['mag_out']`，0.6–1.2 秒和正式 `reload_magazine` 一致，最后落在已上膛的 `magazine` 上。旧弹匣：`G_hip @ parts['empty_old_mag']`，0.35–0.85 秒向左下滑出。
- 右手：游戏里枪刚性挂在 `hand_r` 上，所以右手 IK 每帧都要精确（误差 ≤ 0.1 mm、0°）。换弹中右手拇指按弹匣释放钮（0.18–0.42 秒）。
- 左手：前臂只由腕点决定（IK 链 2 + 肘极向，手的旋转从 `ik_hand` 复制再过腕部限位），所以长距离移动在**腕点空间插值**（弧线位置 + 腕部欧拉角线性过渡），不用四元数插值，避免腕部扭到 87° 这种情况。
- 代码：`design/characters/survivor_base_h1p1/source/fp_reload_h1p1.py`（`Reload` 类、检查、预览渲染），握弹匣数据 `source/mag_grip_h1p2.json`。`fp_pose_h1p1.py` 的 `pose()` 加了 `right=` 参数（替换射击手手指欧拉角，用于拇指按释放钮），`export_fp()` 会烘焙 `ACTIONS` 并执行 `AFTER_EXPORT`（写 props 边车）。

## 3. 左手怎么拿弹匣

参考真实射手的做法：食指贴着弹匣前面，底板坐在掌心里。

| 握法 | 用在 | 内容 |
|---|---|---|
| carry（拿着走） | 弹匣包 → 弹匣井 | 底板在掌心，食指沿弹匣前面，中指在尺侧，无名指和小指收拢，拇指在桡侧 |
| push（推到位） | 插入后半段 → 上膛 | 掌心平托在底板下面，四指向前 |
| press_r | 右手拇指 | 压弹匣释放钮 |

## 4. 时间轴（有经验档战术换弹，秒）

| 节拍 | 时间 | 说明 |
|---|---|---|
| release / away | 0.06 / 0.11 | 左手离开握把（相对枪移动） |
| press | 0.18–0.42 | 右手拇指按释放钮 |
| pouch / grab / out | 0.34 / 0.39 / 0.46 | 左手到弹匣包、握住、拔出 9 cm |
| join | 0.62–0.70 | 从枪后下方并入正式新弹匣路径（避开下落的旧弹匣） |
| flip | 0.86–1.04 | carry 换成 push |
| seat / leave | 1.20 / 1.26 | 推到位，离开底板 |
| regrip | 1.50 | 从底板直接转回握把（R3；R2 是 back 1.46 / regrip 1.62，中间绕到 AWAY） |

R3 起 release → pouch 是一个连续动作：整段一条 smoothstep，按两段路径长度在 0.129 秒处从“相对枪剥离”切到“腕点弧线下行”，中间不停（第 10 节）。表里的 away 只用来算剥离的终点。

弹匣包：左腰，`POUCH = a 0.165, b 0.105, cy 0.045, z 1.02, theta 55°, gap 0.0148, cant −20°`；左臂取弹时 `ARM_POUCH = swivel 0, elevate 10°, protract 8°`。

## 11. 第二段：有经验档空仓换弹 R4（2026-10-24）

### 11.1 内容

`fp_reload_empty_experienced`，2.8 秒（169 帧），叠在正式 `reload_empty_experienced` 上：前半段和战术换弹同一套（退弹匣、取弹、插入、掌心推到位；正式片段在弹匣井口停一下，所以翻手、推到位晚一点：`flip0 0.90`、`flip1 1.08`、`seat 1.25`），然后左手反手拉套筒：

| 秒 | 动作 |
|---|---|
| 1.30–1.65 | 离开底板，先往下脱开，沿枪左侧立着往上（掌心朝枪、手指朝上），越过右手拇指，从上面翻到套筒上 |
| 1.65–1.73 | 手指合拢，掌心压住套筒后部，四指扣在套筒右侧，掌根和拇指在左侧 |
| 1.77–1.87 | 跟正式套筒一起往后拉，离开空仓挂机 |
| 1.935 | 放开（套筒复进声），手指一下弹开，套筒两帧回到位 |
| 1.935–2.35 | 往上、往前抬离套筒，沿左侧下来，拇指收在食指旁边，从左侧略低处进到握把，握住 |

- 握套筒的姿势用 r2 的找法（`r4_slide.py`，scratch）：手不动，把锁在后面的套筒放到手下面，往下压到接触，手指逐根合拢到接触，再看正式拉套筒那几帧够不够得着、腕部负荷多少。数据在 `mag_grip_h1p2.json` 的 `slide`：掌心在套筒后端面前 35 mm，负荷 0.40。拉套筒时手臂外旋 40°、肩前伸 30°（`ARM_SLIDE`）。
- 套筒和托弹板在 props 边车里也有轨道（`slide`、`follower`）：套筒照正式片段（锁在后面 35.7 mm，拉到 37.2 mm，放开两帧回位）；托弹板跟着显示的弹匣。游戏里 `GUN_POSER` 按名字摆所有部件，不用改 Java。

### 11.2 绕枪的路径（第一版穿过了枪）

第一版只用一个中间点（直线中点往左偏 7 cm），检查出左手 9.5 mm 进握把、11 mm 进右手。改成按正式片段左手的路线（`formal_ref/hands.json`）走多个关键点：

- 路径：`spline()`，三次 Hermite 曲线，Catmull-Rom 切线，关键点按弦长分布（速度均匀），手腕角度跟着同一条曲线插值。关键点在 `RACK_KEYS`、`HOME_KEYS`（枪的坐标，mm）。
- 手的朝向：中间关键点直接指定手指方向和掌心方向（枪的坐标）。原来在两端之间插值，手是平着的、小指一侧朝枪，小指根部离手腕约 55 mm，正好扫过右手拇指（右手拇指高高地搭在枪左侧，x ≈ −41 mm、z ≈ 85–90 mm）。指定的朝向如果超出手腕活动范围，就压在范围的 85% 以内（`WRIST_KEEP`）；手指略向拇指一侧偏，否则尺偏会超过 20°。
- 手指：离开底板时先张开（弯着的手指会扫过右手手指），快到套筒时再变成落上去的手形；回握把时拇指收在食指旁边（`TUCKED`，拇指根部 `(-10, -35, 30)`，在 f131–134 扫出来的）。原来拇指离掌面 23 mm，下来时扫过右手拇指。
- 回握把时从左侧略低 12 mm 处进来：最终握姿里左拇指在右拇指下面。
