# AFL Mesh 人物 V1：方块人动作映射技术验证（离线）

2026-10-25，Main。问题：现有方块人动作链（PlayerSkeleton / HumanoidPoser / ActionPose / SeatPose 和已 PASS 的动作）能不能在运行时直接驱动 Mesh 人的 54 根骨骼，从而不用逐个动作重做。**只做了离线对比，游戏没改、没编译、没进游戏。**

**结论（用户 2026-10-25 定）：不走映射。Mesh 人的动作按人体工学重新设计**（"那就重新做算了，按照人体工学重新设计，不用看了"）。本页只留作记录：映射为什么不够、数据里有哪些可以给重做用。

**后续（用户 2026-10-25，看了 Mesh 人和方块人坐同一把办公椅的截图）：** Mesh 人整体不做了，改为把原版方块人"Mesh 化"：加骨骼和关节、加长四肢让脚能着地、用 IK。后来用户定了统一身体 + 官方高清皮肤库，四种原型的对比见 `docs/dev/block_mesh_v2_prototypes.md`（离线，等用户选）。

## 1. 做了什么

脚本都在临时目录（`scratchpad/vx/map/`），不进仓库：

| 文件 | 作用 |
|---|---|
| `MeshMapExport.java` | 用游戏自己的 HumanoidPoser / ActionPose / SeatPose（纯 JOML，不启动游戏）把全部 50 个动作、坐地 3 段、趴下 4 段、走跑蹲 5 种、T15 三个座位逐帧解出来，导出 16 根骨骼的蒙皮矩阵、IK 目标、道具矩阵，共 1202 帧 |
| `meshmap.py` | 16 → 54 骨骼映射（世界旋转逐骨复制；A 姿势手臂对齐到方块人下垂静止姿势；胸部分到 spine + chest，头分到 neck + head；肩部位移转成锁骨摆动；前臂扭转 1/3 给 forearm、其余给 twist 骨），加 IK 修正、接触测量、软件光栅出图 |
| `genrig.py` | 生成"Mesh 比例"的 16 骨骨架（关节放在 Mesh 人的关节位置）和按身体部位的静止空间换算表 |
| `stagec.py` / `pics.py` | 在 Mesh 比例骨架上重跑真实求解器，再映射到 54 骨，测接触、出对比图 |

## 2. 比例差异（根本原因）

| | 方块人 | Mesh 人 1.80 m |
|---|---|---|
| 髋关节高 | 0.70 m | 0.935 m（腿长 ×1.33） |
| 躯干（髋到肩） | 0.70 m | 0.50 m（−28%） |
| 肩关节间距 | 0.59 m | 0.36 m（−38%） |
| 头 | 0.47 m 立方 | 0.19 × 0.26 × 0.24 m |
| 上臂 + 前臂 | 0.47 m | 0.55 m |

座位里方块人要压缩躯干到 0.72、整体缩到 0.82 才放得进 T15 驾驶室，就是这个比例造成的。

## 3. 结果

- **关节角度能直接套。** 16 → 54 的旋转映射结构上没问题，每帧在 Python 里 0.06 s，Java 里只是几十个矩阵加 4 个两骨 IK。
- **只复制旋转（第一阶段）：** 手离 IK 目标 0.12–0.98 m，因为比例不同。
- **在 Mesh 比例骨架上直接跑现有求解器，道具和插座坐标按身体部位统一换算（第三阶段）：**
  - 工具类（撬棍、斧、镐、铲、锯）、打火机开合、P9 待机 / 疾跑、腋下体温计、拉发电机、油桶、加油枪：手位比方块人多偏 ≤ 3 cm，图上看着对。
  - P9 换弹 16 段、检视 4 段、拔枪 / 入套、装弹匣、BR51：手多偏 4–15 cm（要调枪的站姿参数）。
  - 酒精消毒 5 段多偏约 7 cm；手臂夹板、腿夹板多偏 26–27 cm（坏了）。
  - 坐地 / 趴下：Mesh 人整体悬空 10–14 cm；整体降到地面后，因为腿更长，脚变成最低点、臀部仍悬空，要按"哪个部位着地"重新解。
  - 步枪待机图上不像端枪。
  - 座位：Mesh 人按真实尺寸坐进 T15，眼高比现在的座位相机高约 15 cm，头顶离车顶只剩约 1 cm；SeatPose 的压缩 / 缩放逻辑是方块人专用的。
- 道具几何和 Mesh 身体的穿插没测；动作连续播放（抖动）没测；多人没测。

## 4. 给重做留下的东西

- 比例表（第 2 节）和"Mesh 比例 16 骨骨架"的关节位置：重做时的动作设计以 Mesh 人真实比例和关节活动范围为准，不再从方块人的数值出发。
- 方块人动作清单（50 个动作 + 坐地 / 趴下 / 座位）可以当作"要做哪些动作"的清单，但姿势本身重新设计。
- 已有的离线工具（导出、映射、蒙皮光栅出图）可以复用为 Mesh 人动作的离线检查。
