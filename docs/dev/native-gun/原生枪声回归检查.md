# 原生枪声回归检查

> 当前正式型号：P9-01 制式手枪（p9_01）；BR51-01 战斗步枪（br51_01）。旧称仅作历史背景，当前映射与验证边界见 docs/native_guns/native_weapon_renaming_report.md。

入口审计：`P901Actions.request` 验证并扣除一发后调用 `NativeGunShot.execute`。后者在 hit/miss 分支之外，以服务器眼睛位置发送 `GUNSHOT`。当前由 `NativeGunNoise.resolve` 解析真实枪附件：P9 裸枪64格，安装有效 pistol_suppressor_01 后 max(1,round(64×0.05))=3格；P9 tinnitus=false。`NoiseSystem` 转交 `InfectedHearingSystem`，精确匹配普通 Zombie，再经声学传播检查写入调查状态。以下20/40/60/68格历史回归均指裸枪，消音状态不沿用裸枪听觉半径。抑音音频独立选择，不把播放音量/传播距离乘0.05。

真实寻路复现：20 格正常调查；40/60 格听到但完整路径不可达，旧调查 Goal 丢弃局部路径，因而不移动。68 格听觉边界不接受。用户报告的 20 格不移动尚未在隔离夹具复现，不能宣称已定位该场景的所有原因。

修正规则：仅枪声调查允许有明确距离进展的局部路径，保留原声源、预算、刷新和失败冷却。爆炸、搜索、建筑入口、破障及增援规则不改。

开发诊断通过 `src/dev/native-noise-validation.init.gradle` 启用 `afl.dev.nativeNoise`，仅开发环境记录枪声半径、位置、候选数、有效半径、接受数。测试夹具位于 `NativeNoiseRegressionTests`：命中类型矩阵和固定距离真实导航分批运行，避免并行测试的难度与爆炸污染。图形客户端验收仍单独进行。

服务端 GameTest 已验证六种成功射击均产生枪声，冷却拒绝及干击不产生枪声。固定距离夹具在一次枪声后，20/40/60 格僵尸分别向声源前进约 10.59/10.94/10.59 格，均发起 5 次路径请求；68 格无听觉状态、无路径请求、无位移。该结果来自真实实体导航，不是距离公式推算。整套 54 项中仅既有流体测试 `singleSourceFlowsAndDrains` 失败；不可据此宣称全套测试通过。原用户场景的图形客户端验收仍待确认。

最终 `compileJava`、`processResources`、`build` 和 `git diff --check` 通过。图形客户端已完成启动，操作系统确认 Minecraft 窗口可见；这只证明启动，不代表原场景枪声验收通过。
