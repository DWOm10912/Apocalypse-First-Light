# 子弹轨迹技术契约

服务端 `NativeGunShot.executeWithTrajectories` 保留代表性 `Hit.point` 用于既有命中效果，并同时收集每颗弹丸的实际停止点。共享网络协议当前为 30；`NativeShotS2CPacket` / `NativeShotFxS2CPacket` 在原代表性终点和 hit-effect 后附加有界的 1–64 个服务端终点，分别发给射手和追踪射手的玩家。协议不兼容旧客户端。Silverwood 12 每发传 8 个终点；其它现有枪传 1 个。客户端不重算散布，不改变命中、伤害或视角。

NativeBulletTrails 按当前枪 ID 读取 NativeGunDefinition.trail。等待对应视角下实际 muzzle_anchor 的矩阵；第一人称采用现有枪口/弹壳的投影转换，使出生点对齐屏幕枪口。静态物品与非持枪渲染不提供起点。最多等待 3 ticks，缺失枪口即丢弃，无眼睛或固定偏移替代。

每颗弹丸的视觉路径为同一发的 muzzle→对应 server endpoint 的收束线，解决眼睛物理射线与枪口视觉位置的视差；并非从枪口平移一条永不相交的平行射线。实际终点不变，head 不超过终点，tail 不早于该 profile 的枪口隐藏距离；核心与外层共享短段。长度不足时截短。Silverwood 使用短而淡的 `subtle_buckshot` profile，8 条轨迹共用枪口而随距离分离；其隐藏距离为 0，冻结第一人称轨迹的额外起点前移也为 0，使轨迹近端与枪口火焰起点重合。其它枪的近端隐藏配置保持原样。

使用世界时间加渲染部分 tick 推进，不按帧数推进。到达终点后 0.15 tick 淡出，安全寿命 6 ticks。待定队列与活动队列各限 128，换世界清空；非有限坐标与枪口至终点超过 128 格的异常路径丢弃。

细带宽轴由射线方向与朝向相机向量叉积得到，平行退化时选不平行的固定辅助轴。宽度不依赖 GUI Scale。POSITION_COLOR 无贴图、无世界光照衰减；RenderType 管理 additive、双面、深度测试及仅颜色写入，结束批次后恢复状态。不创建实体、粒子或逐 tick 网络包。

NONE 不生成轨迹；SUBTLE 已实现；TRACER 仅保留枚举，不生成特殊弹药或独立效果。新增枪械需接入同一持枪 muzzle_anchor 回调。
