# 后坐力技术契约

通用后坐力读取 NativeGunDefinition.recoil，客户端只维护本地玩家的一份状态。

## 真实朝向与时序

1. 射击输入在同一连接上先发送 Vanilla ServerboundMovePlayerPacket.Rot，再发送已有枪械请求。
2. 原版包处理更新玩家真实旋转；自定义请求继续由服务端检查弹量、状态、射速，再从眼睛与 getLookAngle 求射线。
3. 成功回包触发本地后坐；当前发不受它自己产生的后坐影响，下一次请求携带更新后的原版旋转。

不新增隐藏 Aim、不接受客户端命中坐标、不增加枪械协议字段。网络延迟意味着反馈在确认后出现，不预测未确认射击。
过期回包必须匹配当前玩家、槽位和枪 ID 才产生后坐。观察者只收现有 FX，不修改视角。

## 增量恢复

NativeRecoilState 只保存自身纵/横累积量，不保存绝对玩家朝向。恢复每帧取新旧状态之差叠加到当前 yaw/pitch。
恢复为 exp(−dt/时间常数)，视角有独立延迟，枪模立即开始衰减。帧 dt 最多 0.05 s，暂停时冻结，避免卡顿后的瞬间跳回。
仰角限制处只计入真实可施加的向上幅度。切枪/死亡/世界切换丢弃状态，不回写过去朝向。

## 枪与手共同变换

NativeGunRecoil.applyViewmodel 在第一人称完整 rig 入口、Display 之前施加平移和旋转，位于 gun 和两个 hand anchor 的共同祖先。
后移沿相机 +Z，上扬绕 +X；不引入 scale，不修改 source 动画、静态 locator 或 B_skin。第三人称保留源 Fire。
现有 muzzle/ejection anchor 消费最终绘制矩阵，因此跟随父变换；特效自己的尺寸、寿命、弹壳物理不变。

参数单位：角度为度，时间为秒，后移为渲染单位。恢复时间是指数时间常数，不是强制归零期限。
