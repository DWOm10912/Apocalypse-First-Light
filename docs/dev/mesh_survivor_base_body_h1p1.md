## 4. P9-01 双手握姿

用户 2026-10-23 定为 H1-P1 **基础静态握姿 V1**：后面不为静态图大量微调，不回到全局求解器；游戏镜头里有明显问题时只做局部修正，不整体重摆。单手持枪以后单独做，不复用这套双手姿态。

### 4.1 坐标

P9-01 V3 geo 像素，1 px = 19 mm；+x 是枪的右边，+y 是枪口，+z 向上，枪左右对称。手的 H 坐标是 mm，X 指向桡侧，Y 指向远端，Z 指向掌侧，原点在腕部。左手是镜像枪上摆的右手：rig 矩阵 = S4 · root · Mh⁻¹（S4 = diag(-1, 1, 1, 1)），换回真实左手用 S4 · root · S4、欧拉角 (x, −y, −z)。

### 4.2 参考

- USMC《Pistol Marksmanship》双手等腰握法（Gutenberg 75995），加上现在通行的 thumbs-forward 握法：
  - 射击手握得高，握把尾部的护手卡在虎口；枪管大致和前臂平行；食指伸直放在扳机护圈外；拇指在枪左侧朝前，压在辅助手拇指上，不碰套筒和空仓挂机柄。
  - 辅助手的大鱼际贴在握把露出来的左侧；四指包住射击手的手指，食指在扳机护圈下面；手腕向下转；拇指沿机匣朝前，在套筒下方。
- 用户给的录屏 `E:\Download\AFL\参考视频`：
  - MWII X12：检视时能看到射击手拇指沿机匣左侧、在套筒下面朝前贴住，三指叠着包住握把前侧；
  - 50 GS：待机时从正后方看，两只手的手背在握把后面并成紧凑的 V 形，两根拇指都贴着枪身左侧朝前。
  - 只看手的结构，不照搬游戏动画。

### 4.3 方法（v8 之后改的）

不再用全局优化器反复搜。按真实握法手摆：

1. **主手**（辅助手先隐藏）：用解剖标志点做刚体对齐，包括腕、虎口、食指 / 中指 / 小指掌指关节；虎口放到护手下面，掌指关节一列排在握把右前方，食指掌指关节和扳机同高。然后沿掌心法线推到掌面软组织压进约 4–5 mm。
2. 手指用自然的角度组合，三节一起按比例收，指腹压进不超过 1 mm 就停；食指伸直。
3. **辅助手**：以大鱼际、食指和小指掌指关节为标志点对齐，压在射击手手指上；四指同样按比例收。拇指沿机匣朝前，避开空仓挂机柄。
4. **射击手拇指**最后摆：
   - 目标是压在辅助手拇指上方、沿枪身朝前；
   - 掌骨中轴离护手至少 5 mm，按骨头算，皮肤允许压缩；
   - 指骨皮肤离枪至少 1.5 mm；
   - 在正常关节范围里，让三个关节点靠近目标。
5. 程序只用来量：关节角范围、骨骼胶囊互穿、蒙皮顶点进枪深度、手对手穿插。

### 4.6 和 v8 相比修了什么

- 主手拇指外钩：v8 的掌骨穿过护手 ≥ 9.5 mm。现在虎口卡在护手下，掌骨从护手左后角绕过去，拇指沿枪身朝前，压在辅助手拇指上。
- 辅助手掌离握把 7 mm、四指没包住：现在大鱼际贴着握把左侧露出的部分，四指包住射击手的手指。
- 右手无名指 / 小指插进左手 2–3.5 mm：现在没有。
- 手指扭转、交叉：现在手指只做单轴屈曲，三节按比例。

### 4.7 剩下的问题和原因

- 掌面只有一根刚性骨骼，没有掌骨弓，掌面贴合面积有上限。要改得给 H1-P0 手加掌骨弓（骨架改动，先提方案）。
- 射击手拇指 CMC 扭转 −34°，接近正常范围上限。根部朝向不变，拇指要朝前只能靠这个扭转。如果再抬高主手腕，让前臂和枪管更平行，扭转能小一些，但要整体重摆主手。
- 射击手拇指掌骨中轴离护手只有约 3.5 mm（按骨头半径 4–5 mm 算，可能有约 1 mm 骨接触）。**NOT VERIFIED**：骨头半径是估计值。
- 主手单独看时，拇指在套筒高度向左伸出约 3 cm。这是 thumbs-forward 握法本来的样子，拇指是压在辅助手拇指上的；只用单手握持时要另做一套拇指姿态。
- H1-P0 手掌宽 78 mm，ANSUR 男性约 88 mm，偏窄。
- 辅助手掌心离枪 ≥ 9.5 mm：解剖上它压在射击手手指上，是几何上的限制，不是空隙。

只在开发客户端：

- `body fov <20–70>`：把手部视野固定在这个值。`body fov auto`：回到跟随姿态（皮肤文件里的 fp_view，第三轮是腰射 42° → ADS 34°，和举枪同一条 smoothstep；提示里显示实际读到的值）。原版手部通道固定 70°，所以把视图的 x、y 按 tan(35°) / tan(fov / 2) 放大（z 不变，光照按不放大算），只影响这个测试的画面。

- `body fire`：开一枪（举枪途中不开）。

做法：
- GeckoLib 只负责采样，渲染器不画东西，只把每根骨骼的变形矩阵存进预先分配的数组。
- 举枪进度 0–1 按时间线性走，0.2 s 走完；开枪时冻结。
- `SeekController` 重写 `adjustTick`：RUNNING 和 PAUSED（停在末帧）状态下返回进度对应的帧，切片段那一帧和转场仍用 GeckoLib 自己的值；所有切换都不过渡（transition 0）。
- GeckoLib 切片段时会把新片段的第一帧显示一次，所以每次切换都落在身体当前的姿势上：
  - 腰射开枪后回到 `fp_raise`（第一帧是腰射）；
  - ADS 开枪后回到 `fp_lower`（第一帧是 ADS），之后两个方向都靠 seek。
- 相机放在这一帧头骨上的眼睛点，朝向水平。
- CPU 线性混合蒙皮只算第一人称三角形（三个顶点的手臂权重都 ≥ 0.5）用到的顶点。
- P9-01 V3 用 hand_r 的矩阵乘导出的枪矩阵画，换弹弹匣和掉落弹匣隐藏。
- 我们的代码每帧不分配对象。
