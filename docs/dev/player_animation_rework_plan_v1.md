# 玩家动画重做规划 V1

状态（2026-10-09）：**规划，没有实现**，等用户定方案。

## 用户的想法（2026-10-09）

- 以后用 GeckoLib 重做玩家的所有动画，优化持枪逻辑，把现有动画都改一遍，更真实。
- 特殊动作（比如便携发电机的拉绳）要让手臂能弯曲。
- 参考：Epic Fight（史诗战斗）的自定义动作，YSM（Yes Steve Model）。

## 现状

- **第一人称**已经是自己的一套：
  - 枪、撬棍、油桶各有独立的视图模型，在手持物品那一遍画；
  - GeckoLib 的骨骼和动画，加上 AFL 网格；
  - 手臂是 `weapon/client/NativePlayerArmRenderer`：原版皮肤的整条直臂，挂在手的锚点上，末端伸出画面；
  - 动画在 Blockbench 里做，用 `tools/author-*-first-person.mjs` 导出；
  - 有相机骨骼。
- **第三人称**是原版的 `PlayerModel`：
  - 枪靠原版持物姿势，测温计、拉绳靠 mixin 在原版姿势之后改手臂角度；
  - 原版手臂没有肘。
- 便携发电机的拉绳先用了临时做法：第一人称手画在世界里，第三人称直臂指向拉手（[portable_diesel_generator_v1.md](../machines/portable_diesel_generator_v1.md)"拉绳动画"）。

## 几条路

| 方案 | 怎么做 | 好处 | 代价 |
|---|---|---|---|
| A. PlayerAnimator + bendy-lib（建议） | 在原版 `PlayerModel` 上播放关键帧动画；bendy-lib 让手臂和腿能在中间弯曲（肘、膝） | 还是原版模型：皮肤外层、盔甲、披风、别的模组挂在玩家身上的东西都照常；动画可以分层叠在走路上；Better Combat、Emotecraft 这类模组都用它 | 多两个依赖模组；弯曲是网格变形，不是真骨骼；动画格式要按它的来；要验证和 Sundial / Oculus 的兼容 |
| B. GeckoLib 替换玩家渲染 | 自己做一个玩家 geo（上臂、前臂分开），用 GeckoLib 的替换渲染器画玩家 | 骨骼随便定，肘是真关节 | 盔甲、皮肤外层、披风、别的模组的玩家层都要自己重做或会失效，兼容代价最大 |
| C. 依赖 Epic Fight | 用它的骨架和动画系统 | 动作很成熟 | 它是一整套战斗系统，会和 AFL 自己的枪械逻辑打架，体量太大 |
| D. YSM | 只能当参考 | 自定义模型和动画做得好 | 闭源，不适合集成 |

## 建议

- **第三人称用 A。** 动画在 Blockbench 里做：用标准 Steve 骨架，带弯曲参数。持枪瞄准这类要跟着视角走的姿势，用程序控制的动画层，每帧算手臂角度。
- **第一人称继续用现在的视图模型。** 把手臂换成两段（上臂 + 前臂，按原版皮肤的 UV 切开），这样拉绳、换弹、检视时肘能弯。第一人称很少看到上臂，两段就够。
- **两边用同一个"动作状态"驱动。** 第一人称和第三人称的动画都从同一个状态开始、用同一条时间线，状态在网络上同步给别的玩家。动作状态比如：空闲、瞄准、换弹、检视、拉绳、倒油。

## 先验证的事（第一步，做一个小样）

- PlayerAnimator 和 bendy-lib 在 Forge 1.20.1 上的版本、依赖关系、动画 JSON 格式和弯曲写法。2026-10-09 只查到第三方页面，要看它们自己的 README。有用户报告装了两份 PlayerAnimator 会崩，要确认 bendy-lib 是不是自带一份。
- 在 Sundial 光影下手臂弯曲处的样子；盔甲、皮肤外层跟不跟着弯。
- 先只做一个动作：便携发电机拉绳的第三人称版本。拿它和现在的直臂比。

## 之后的顺序（草案）

1. 小样：依赖 + 拉绳一个动作。
2. 第一人称两段手臂。
3. 枪：腰射、瞄准、换弹、检视的第三人称姿势，第一人称动画重做。
4. 其他交互：倒油、撬棍、拉绳的正式版。
