# 《非生物因素》参考研究 V1（美术、人物动画、玩法）

2026-10-24，Main。用户要求：研究《非生物因素》（Abiotic Factor，下称 AF），给 AFL 定一套美术和动画标准，研究完先交报告，等用户决定。本轮没改代码、Vextris、Blender 工程。

同一天用户定了角色美术方向（下称“用户方向”）：风格化低多边形生存者；贴图分辨率不高，细节靠手绘贴图；末日荒野气质，不是实验室喜剧；轮廓清楚；服装模块化；脸用预设，不做捏脸；男女各一套体型，统一骨骼和动作接口；比 AF 更成熟、更脏旧，但不走高写实路线。本报告按这个方向写结论。

可信度标记：**高** = 官方页面或亲眼看到的视频帧；**中** = 媒体报道、Wiki 或从视频顺序推断；**低 / 未知** = 资料里没有。

## 1. 执行摘要

1. AF 的人物不是“差一点像真人”，而是一眼就看得出的风格化：低面数、五官夸张的人物头像，皱纹和褶皱都画在贴图上，衣服盖住全身。它不进恐怖谷，靠的就是这一点（高）。
2. AF 第一人称的手很简化：几种固定握形，手指基本不单独动，换弹匣很多时候发生在画面下沿以外（高，见第 4、6 节）。
3. AF 的换弹熟练度：官方 Wiki 写着换弹技能会逐级加快换弹、减少笨拙，10 级再减一次笨拙（中）。粉丝 Hoider 按这个思路重做了全部换弹，做成三档；美术总监在评论里公开称赞（中）。AFL 的 P9-01 分档换弹已经是同一思路，而且做得更细。
4. 对 AFL 最有用的不是某个机制，而是一个取舍原则：**玩家能看清的地方要可信，看不清的地方大胆简化**。
5. 建议近期做三件事（第 13 节）：
   - 默认角色 V1，低多边形 + 手绘贴图，沿用冻结的 54 骨骼；
   - 手形库 + 换弹验收标准；
   - P9 第一人称按物品逐个切换到 Mesh 身体。

## 3. 人物模型与美术风格

资料：[捏人界面全选项视频（Tales of Lumin）](https://www.youtube.com/watch?v=-97Yk2dTiX8)、[Wiki 角色外观](https://abioticfactor.wiki.gg/wiki/Character_Appearance)、[多人实况（The Co-Op Bros）](https://www.youtube.com/watch?v=p_gDztk6xPg)。

**实际观察**
- **整体比例**（捏人视频 5:10、6:27，全身站姿）：
  - 头和手偏大，肩窄，腿粗壮，接近真实比例但明显“玩具化”；
  - 这个相机离得近，透视会放大头部，所以我量不出准确的头身比（约 5 头身是画面读数，不是模型比例）（中）。
- **脸和头**（1:40 特写）：
  - 头的面数低，轮廓上看得出折角；
  - 五官夸张（大鼻子、下垂的眼、深法令纹），皱纹、眉毛、胡茬都画在贴图上，不是雕刻出来的（高）；
  - 16 个预设头，加发型、发色、胡子、眼镜，没有捏脸滑块（Wiki，高）。
- **服装**：上衣、衬衫颜色、面料图案、裤子、腰带、鞋、工牌分开选（Wiki，高）。衣褶和缝线基本靠贴图；靴子、口袋等少数结构做在模型上（视频，高）。
- **多人里的远距离**（多人实况 0:45、7:27）：队友背着方块形背包、穿防护服，剪影一眼能分出来；轮廓主要靠装备，不靠脸（高）。
- **第一人称**：只看得到前臂和手，袖口（白大褂、手表）占画面不小，是“我是谁”的主要线索（高，见第 4 节）。

**为什么 AF 的人物不恐怖谷**（推论，中）
- 风格化方向一致：脸、衣服、场景都是同一种“低面数 + 手绘贴图”，没有一个部分在模仿照片；
- 五官夸张：人脑不拿它当真人比，就不会去找缺了什么；
- 人体几乎都被衣服盖住，解剖细节不需要对。

**用户截图里的 AFL 灰模为什么有点恐怖**（对照）
- 身体是高面数、平滑的写实解剖：锁骨、膝盖、脚趾、小腿肌肉都有，大脑把它当真人看；
- 但脸是空白的蛋形头，没有眼、嘴、头发，全身同一种灰，没穿衣服。像真人又缺关键特征，就是人体模特、假人效应；
- 截图里是第一人称专用的姿势（耸肩、头前探、膝盖弯），是为摄像机摆的，从外面看必然别扭；
- 结论：这不是比例错了，是“写实的身体 + 没做完的脸和表面”。按用户方向改成低面数、手绘贴图、穿衣、有预设脸，这个问题就会消失。

**AFL 保留什么、不保留什么**

| AF 的做法 | AFL | 理由 |
|---|---|---|
| 低面数 + 手绘贴图，细节画在贴图上 | 保留（用户方向） | 便宜、统一、远处也读得清 |
| 预设头 + 发型配件，不捏脸 | 保留（用户方向） | 制作量可控 |
| 服装分件搭配 | 保留，按 AFL 装备分：上衣、裤、鞋、外套、胸挂、背包、护具 | AFL 已有胸挂、背包、背带等装备格 |
| 剪影靠装备区分 | 保留 | 第三人称识别 |
| 五官夸张到漫画感、干净鲜艳的配色 | 不保留，改成更克制的五官、脏旧做旧的贴图 | 用户方向：更成熟、更有末日感 |
| 科研喜剧的服装主题（白大褂、领带图案、节日服） | 不保留 | 世界观不同 |

## 4. 第一人称动画

资料：[官方换弹合集（snyplays，2025-10-13，1.0 后）](https://www.youtube.com/watch?v=nvoU510dKW4)、[多人实况](https://www.youtube.com/watch?v=p_gDztk6xPg)。只看了枪和近战武器，工具、抓取物品、走路、疾跑没有逐帧看，下面不写这些。

**实际观察**（高）
- **枪的位置**：手枪腰射在画面中下偏右，枪身很大；步枪类主要露右手和枪身后半，左手平时常常不在画面里（官方合集 2:31.5，Gutnic Rifle）。
- **手的比例**：手和前臂在画面里很大，袖口清楚。
- **手指**：几乎都是固定握形，握把拳、托弹匣的整手握、张开的平掌。换弹过程中手指很少单独动（官方合集 0:02.5–0:07.5）。
- **两手接触**：手枪腰射双手合握；步枪平时只看到右手。“始终紧贴”不是 AF 的规则。
- **近战**：右手单手握武器，前臂从画面右下伸进来（多人实况 2:59、5:13）。

**哪些是玩家看得清的**
- 枪的轮廓和朝向；
- 手的整体位置；
- 弹匣进出的那一下；
- 拉套筒、拉机柄的动作方向；
- 袖口和手表。

**哪些可以简化**
- 单根手指的弯曲；
- 画面下沿以外的弹匣交接；
- 旧弹匣掉下去的路线。

**未知**：AF 的第一人称视场角、手臂是不是和第三人称共用骨骼。

## 5. 第三人称人体动作

**能确认的只有**（多人实况 0:45、7:27，高）
- 队友站着时是放松的站姿；
- 剪影主要靠背包和防护服。

**没看到、不能下结论的**：行走、奔跑、冲刺、蹲伏、双手持枪、射击、换弹、工具、搬运、受伤、坐下、死亡倒地。
- AF 没有官方第三人称视角，只有第三方 UE4SS 视角模组（[Nexus Mods](https://www.nexusmods.com/abioticfactor/mods/224)，页面拒绝抓取，内容来自搜索摘要，低）。
- 所以 AF 的第三人称动作主要是给队友看的，不太可能是 AF 打磨的重点（推论，中）。

**结论**：AFL 的第三人称标准不能照 AF 抄，要按现实人体资料自己定（第 12.3 节）。第一人称和第三人称本来就该是两套片段，可以用同一副骨骼。

- 手大，五指分得开，但没有关节细节；
- 握弹匣都是整手握住下半截，指尖对准不追求；
- 袖口、手表一直清楚。

- 每一档的差别都在**节奏和犹豫**上，不在手指精度上；
- 机械动作的方向（插、拍、拉）大而清楚；
- 镜头和枪一起动，动作有重量。

### 6.C 给 AFL 的建议

AFL 的 P9-01 已经有三档 + 新手插歪 + 瞄准换弹 + 没弹匣版本，比 Hoider 和原版都细。下一步不是再加细节，是**定标准、降成本**：

| 环节 | 要求 |
|---|---|
| 必须真实接触 | 握把上的手；推弹匣入井那一下；拉 / 放套筒；拍底 |
| 可以靠遮挡省掉 | 画面下沿以外的取弹匣、旧弹匣掉落路线、弹匣袋里的动作 |
| 不需要逐指动画 | 移动中的手。用固定手形，只在接触前后切换 |
| 新手和熟练的差别 | 停顿、看一眼、对不准再对一次、动作分段；熟练档是一个连贯动作。不要靠手指抖动表现生疏 |
| 机械同步 | 声音、枪身震动、镜头小幅冲击落在同一帧：插到底、套筒复位 |

## 7. 生存与成长系统（AF 官方 Wiki，中）

**需求**（[Statuses](https://abioticfactor.wiki.gg/wiki/Statuses)、[Mechanics](https://abioticfactor.wiki.gg/wiki/Mechanics)）
- 饥饿、口渴、便意、疲劳四条；
- 见底后开始倒计时，饥饿、疲劳倒计时结束直接死亡，便意结束是当场排泄、得到“臭”状态；
- 温度分冷热阶段，晚上降温，取暖器或工作台“暖凳”升级能取暖。

**身体**
- 分部位生命值，护甲只护所在部位；
- 负重分三档减速和耐力惩罚，快捷栏物品按约 75% 重量算。

**成长**（[Skills](https://abioticfactor.wiki.gg/wiki/Skills)）
- 17 个技能，满级 20，做什么练什么；
- 每隔几级给一个“特长”，例如：
  - 力量 8 级能用重型近战；
  - 建造 10 级家具轻 40%；
  - 烹饪 5 级看到队友饥渴。

**职业和特质**（[Character Creation](https://abioticfactor.wiki.gg/wiki/Character_Creation)）：开局选职业、分特质点，同一存档里不能改。

**昼夜**：一天约 30 分钟；晚 9 点到早 6 点断电，灯灭、降温、安保机器人巡逻。

## 8. 搜刮、制作和基地建设（AF 官方 Wiki，中）

**配方**（[Research Minigame](https://abioticfactor.wiki.gg/wiki/Research_Minigame)、[Recipe](https://abioticfactor.wiki.gg/wiki/Recipe)）
- 大多数配方在拿到材料时学会，然后在工作台做一个“研究”小游戏才能做；
- 配方能分享，捡到别人做的成品也能学会。

**拆解与维修**
- 维修回收站能把物品拆成材料；
- 锤子拆非玩家家具，掉零件；
- 耐久每次使用有概率掉 1 点；
- 胶带在背包里就能修，但只修 5 点。

**家具打包**
- 按住 F 把家具、部署物打包成物品，成功率看建造技能；
- 失败等于拆掉，掉零件。

**基地**
- 通电的工作台能压住附近敌人刷新；
- 有些夜晚会有敌人围攻工作台（“袭击事件”）。

**搬家**：手推车、叉车、保安车、SUV、固定线路电车（Steam 页也写到用这些搬东西）。

**电力**
- 插座无限供电，插线板分配；
- 电池在插座上充电、断电时放电；
- 串联比并联掉电快；
- 后期有激光无线传电。

**为什么玩家肯花时间整理基地**（推论，中；没找到开发者原话）
- 开局就在一个现成的办公楼里，到处有家具可以搬，第一天就有“家”的样子；
- 打包搬家很便宜，换地方不用从零开始；
- 工作台压刷新，给“在这里安家”一个机制上的理由；
- 职业、技能、外观让每个人在小队里有分工。

**容易繁琐的地方**（推论，中）
- 四条需求加上排泄、倒计时直接死亡，比较依赖喜剧语气才不让人烦；
- 只有一篇评测提到战斗前期笨拙（[digitrendz](https://digitrendz.blog/?p=29363)，低）；
- 没找到系统性的玩家抱怨统计（未知）。

## 10. AFL 与 AF 的设计差异

## 12. AFL 动画质量标准建议

### 12.1 通用（第一、第三人称）

1. **正常速度下可信**：按 1 倍速看，动作的意图一眼看懂（拿什么、往哪放、为什么停）。
2. **关节在人体活动范围内**：沿用已定的资料（Ryu 1991 手腕、Morrey 1981 前臂、Bain 2015 手指）。这是硬标准。
3. **起止和待机一致**：每段第一帧、最后一帧等于待机姿势，不跳变。
4. **看得见的穿模要修，看不见的不追**：
   - 画面内、正常速度下能看出来的手进枪、手进手要修；
   - 画面外或单帧 1–2 mm 的接触不算验收项，只记录。
5. **干脆，不软**：动作利落、停得住，不过冲（已有规则）。

### 12.2 第一人称

- **手形库**：先定 6–8 个固定手形，例如：
  - 握把、张开托底、整手握弹匣、捏、平掌推、反手抓套筒、放松；
  - 动作里手形之间插值；
  - 只在接触的那几帧精调手指；
  - 新枪先套手形库，减少逐指关键帧。
- **画面优先**：先看画面构图（已有规则），镜头里看不到的段落可以只保证路线合理。
- **机械同步**：声音、枪身反馈、镜头冲击对在同一帧。

### 12.3 第三人称（还没做，先定原则）

- 和第一人称分开做片段，共用骨骼。
- 走、跑、疾跑先查步态资料（步频、步幅、骨盆转动、手臂反向摆动），再对齐游戏里的移动速度。
  - 要注意：原版走路速度约 4.3 格/秒，远快于真人步行（约 1.3–1.4 m/s）。
  - AFL 现在的移动速度我没核对。动画步幅必须和实际移动速度匹配，不然脚会滑。
- 持枪、换弹在第三人称只要节奏和大动作对，手指可以更简化。

### 12.4 换弹验收清单（P9 以后的枪通用）

| 项 | 标准 |
|---|---|
| 节拍 | 释放 → 旧弹匣出 → 新弹匣入 → （空仓）放套筒，每拍在画面里能读出来 |
| 接触 | 握把手全程在；推弹匣、拉套筒那一刻手真的在零件上 |
| 分档 | 新手：停顿、看一眼、对一次；熟练：一个连贯动作；时间按设计表 |
| 关节 | 全部在活动范围内 |
| 穿模 | 画面内正常速度看不出 |
| 结尾 | 回到待机姿势，误差 0 |

## 13. 近期最值得做的三项

1. **默认角色 V1（男）**：解决恐怖谷，也是第三人称的前提。
   - 用户方向：低多边形，手绘贴图，脏旧的末日幸存者，预设脸，分件服装。
   - **沿用冻结的 54 骨骼（名字、静止姿势、比例都不动）**，已 PASS 的 39 段第一人称片段就能直接用；头和手稍微放大，只改模型，不改骨长。
   - 第一人称看到的袖口、手套、手表要单独设计，它是第一人称里最显眼的“人设”。
   - 女性体型第二步做：骨骼名字和层级相同、比例不同，第三人称片段按比例重定向；第一人称手臂可以男女共用一套（很多游戏这样做）。这一点要用户定。
2. **手形库 + 换弹验收标准**（第 12.2、12.4 节）：先用 BR-51 试一遍，看能省多少关键帧。
3. **P9 第一人称正式接入（要用户批准）**：
   - 按物品开关，P9 用 Mesh 身体；
   - 别的枪、撬棍、油桶、加油枪、发电机拉绳、开车等继续用旧手臂；
   - 一样一样迁移；
   - 前提是 Vextris 蒙皮部件，不然开光影会卡。
