# 坐姿与上下车 V1（骨骼人物 P3 的第一块）

状态（2026-10-16）：代码完成，在 `feature/external-grid-v0`（D 的 worktree `AFL-survivor-v0`）提交。`compileJava`、`skeletonCheck` 的坐姿部分、`cameraCheck` 都通过。用户同日实机试过，评价「还不错」，本轮到此为止，有两个已知问题（见第 9 节）。**之后坐姿和上下车整体交给 Main**（见第 10 节）。

来源：
- Main 2026-10-16 转来用户的实机问题：骨架开着时，T15 司机坐得笔直，手垂进座椅，第一人称看下去腿在坐垫下面。用户要求第一人称低头能看到大腿和放在方向盘上的手。
- 用户同日要求：「做上下车动画、坐姿，然后告诉 main 改计时器」，「手默认扶着方向盘」。
- 分工：车和车门归 Main，人的身体、大小、上下车动作归 D（本文）。

## 1. 尺寸：为什么要缩小，怎么缩

原版比例的人放不进真实尺寸的驾驶室：
- 头有 8 px 高（缩放 1 时 0.47 m）；
- 坐垫到车顶内衬只有 0.85 m（坐垫顶 0.845，内衬约 1.69）；
- 腿只有 12 px（0.70 m）；
- 坐垫有 0.35 m 深。

所以坐着的人整体画小，再单独调躯干和腿：

| 项 | 值 | 原因 |
|---|---|---|
| 整体缩放 `SeatPose.SCALE` | **0.72** | 头顶（带帽子层）离车顶留出余量。之前说的 0.75 / 0.8 头会碰顶，见第 6 节 |
| 眼高 `EYE_OVER_SEAT` | 坐垫顶以上 **0.59 m**（驾驶室 1.435） | 车顶下抬头 12° 时帽子层最高到 1.679 |
| 眼的前移 `EYE_AHEAD` | 坐垫点以前 **0.09 m** | 坐在方向盘前，画出来的眼睛在胯点稍前。镜头放到那里，第一人称的镜头就在画出来的头里 |
| 躯干压缩 | 自动解，现在约 **0.68** | 眼睛要落到镜头高度：胸和头各往下 6 px ×（1 − t），胸的上端按 t 压扁（皮肤网格的顶圈），肩膀跟着往下。量的是颈部，低头抬头不改变躯干 |
| 大腿 `THIGH` | ×1/0.72（**原尺寸**） | 膝盖要到坐垫前沿 |
| 小腿 `SHIN` | **×1.6** | 小腿要够到地板，同时膝盖大致和胯一样高 |
| 胯高 `HIP_LIFT` | 骨盆轴心在坐垫顶以上 2.2 px | 大腿下面贴着坐垫 |
| 驾驶座后仰 | 0°（乘客 −8°，货斗 +4° 前倾） | 手要够到方向盘 |
| 车顶下抬头 | 身体最多后仰 12° | 镜头照样能往上看 |

大小在 `PlayerSkeleton.begin` 里绕渲染原点缩放；求解用的模型坐标包含这个缩放，所以座位、方向盘、车门的世界坐标都落在对的地方。物品、护甲、名牌跟着一起缩小。

## 2. 接口（Main ↔ D）

都在通用包 `skeleton/seat`，服务器和客户端都能用。

- `SeatedRiderHost`（载具实现）：
  - `int riderSeatIndex(Entity passenger)`：乘客坐在哪个座位，−1 表示没坐（或者座位还没同步过来）；
  - `RiderSeat riderSeat(int seat, float partialTick)`：客户端每帧调用，按编号取。人下车以后还会接着问：下车动作要看车门怎么转。
- `RiderSeat`（世界坐标，用载具的完整朝向，包括俯仰和侧倾）：
  - `kind`：DRIVER（手扶方向盘）、PASSENGER（手放腿上）、BENCH（货斗这种开放座位，没有门）；
  - `cushion`：坐垫顶，取臀部正中；
  - `frame`：座位坐标系到世界的旋转，+X 是乘客的右边，+Y 向上，−Z 是乘客面朝的方向；
  - `doorSide`：−1 左、+1 右、0 没有门；
  - `door`：车门开了多少，0 关上，1 全开；
  - `anchors`：手脚要去的点，都可以不给：
    - `grip_l` / `grip_r`：握方向盘的位置，**要跟着方向盘一起转**；
    - `floor_l` / `floor_r`：脚底踩的地方；
    - `door_pull`：车门内侧的拉手，**跟着门转**（T15 用扶手上的拉手：左门 rig (−0.76, 0.95, −0.12)，右门是镜像）；
    - `door_outer`：车门外把手，跟着门转；
    - `entry`：车门外站人的位置；
    - 计划中（P3，换挡）：`shift_knob`、`pedal_clutch`、`pedal_brake`、`pedal_accel`。
- 过渡做法：`PickupTruckEntity` 实现 `SeatedRiderHost` 之前，D 用 `client/skeleton/T15Seats` 临时包一层：
  - 用的是 rig 数字，只算航向；
  - 实体本身实现了接口时，`SeatedRiders.host` 先用实体自己的；
  - Main 实现以后，`T15Seats` 删掉。

## 3. 坐姿

### 3.1 求解器新增（`HumanoidPoser.Input`）

| 字段 | 作用 |
|---|---|
| `rootTurn` | 根骨骼在模型空间的完整旋转（座位朝向、车身倾斜） |
| `hipTarget` | 骨盆轴心要去的位置，整个根骨骼移过去 |
| `eyeLevel` / `torsoMin` / `torsoDirect` | 躯干压缩（第 1 节） |
| `legIkWeight`、`ankleRight/Left`、`kneePoleRight/Left`、`footRest` | 腿的两段 IK：膝盖朝 pole 方向，小腿往后折，脚掌贴地（在关节限制内） |
| `thighStretch` / `shinStretch` | 腿的拉长：骨骼偏移加长，皮肤环跟着拉 |

另外：
- `SkeletonPose.squash` 和 `shoulderDrop` 给出压扁量和肩膀下移量，`SkinMesh` 把部件第一根骨骼的顶圈往轴心收。
- 站着时这些都是 1 或 0，计算结果不变。

### 3.2 姿势（`SeatPose.body` / `hands`）

- 身体：骨盆在座位上，身体朝座位方向。
- 胸：司机的胸随视线转 10%，最多 ±6°；乘客转 35%，最多 ±30°。
- 双脚踩在 `floor_*` 上，膝盖朝前上方。
- 手：
  - 司机：手掌贴在 `grip_l` / `grip_r` 上。手的方向用 IK 得到的前臂方向（不弯手腕、不扭前臂），手腕在接触点往回 1 px；肘部朝外下方，肩膀可以前伸 2 px。
  - 乘客、货斗：手放在大腿上，大约胯到膝盖的 60% 处。
- 手上拿着东西：
  - 第三人称：身体照样坐着，手照样在方向盘或腿上。
  - 第一人称：还是原来的第一人称手（和站着时一样）。

## 4. 上下车

每个客户端自己看每个玩家：
- 有了座位，开始上车，起点是他上一刻站的位置；
- 离开座位，开始下车，终点是他现在站的位置。

所以所有客户端看到的一样，不需要新的网络包。下车途中走动，下车动作立刻结束。进世界时已经坐着（5 tick 内没有站立记录），直接是坐着的样子。

### 4.1 上车（有门，约 1.7 s）

| 时间 | 身体 | 手 | 车门（Main） |
|---|---|---|---|
| 0–0.75 s | 从车门外站的位置进到座位上：里侧的腿先进，转向座位方向，从 1 缩到 0.72，腿伸长 | 垂着 | 开着 |
| 0.45–0.7 s | 坐下 | 靠门的手（司机左手）伸向门内拉手，胸往门那边转 20° | 开着（门全开时拉手够不到，手先伸过去） |
| **14 tick（0.7 s）** | | 手抓着拉手，跟着门走 | **开始关**（`SHUT_IN` 12 → **14**） |
| 门快关上（开度 < 0.2） | | 松开，去方向盘或腿上 | 约 1.4 s 关好 |
| 1.7 s | 坐好 | 双手在方向盘上 | |

### 4.2 下车（有门，约 1.5 s）

| 时间 | 身体 | 手 | 车门（Main） |
|---|---|---|---|
| 0 s | 在座位上；人已经被放到车外 | 靠门的手抓着门内拉手，跟着门推开；另一只手离开方向盘 | 开始开（Main 现在的做法） |
| 0.25–1.0 s | 从座位出来站好，从 0.72 变回 1 | 0.55 s 左右松开拉手 | 0.7 s 全开 |
| 0.8 s 起 | 站着 | 离车门外把手近的那只手抓着把手 | |
| **20 tick（1.0 s）** | | 跟着门推 | **开始关**（`SHUT_OUT` 24 → **20**） |
| 门关到开度 < 0.4 | | 松开，门自己关上 | |
| 约 1.5 s | 结束；门一直不关的话 2.0 s 结束 | | |

### 4.3 时间对不上时

拉手、推门都跟着门的实际开度走：门早关、晚关或者不关，手都不会停在半空。上面写的 tick 数是看起来最顺的时间。

### 4.4 没有门的座位（货斗）

只动身体，0.5 s。

## 5. 镜头和第一人称

- 自己在第一人称上下车：`CameraDirector` 的请求 `afl_seat_move`（优先级 BODY_EYE，淡入 0 s，淡出 0.1 s）。镜头从离开的眼睛位置跟着身体的进度移到现在的眼睛；视角还是玩家自己的。
- 过程中镜头离开了实体眼睛，`FirstPersonBody.shown` 通过 `SeatedRiders.cameraOnBody` 继续画第一人称身体。
- 坐着时镜头就是 Main 放的眼睛位置。躯干按镜头高度自动压缩，所以 Main 用别的眼高，身体也对得上（压缩下限 0.62）。

## 6. 离线检查（`./gradlew skeletonCheck`，`SeatCheck`；出图：`AFL_SNAP_SEAT=<目录>`）

驾驶室，T15 rig 数据，眼高 1.435：

| 座位 | 躯干 | 头顶 / 帽子层 | 车顶下抬头时帽子层最高 | 手 | 腿 | 大腿对坐垫 | 画的眼睛离镜头 |
|---|---|---|---|---|---|---|---|
| 司机 | 0.68 | 1.619 / 1.640 | 1.679（车顶 1.69） | 到方向盘的距离是臂长的 1.01 倍（用了肩膀前伸），手腕偏 0.06 px；左右看 ±60° 时偏 < 0.6 px | 够得到，脚底贴地 | 最深陷进 6.5 cm（坐垫往前升高，当作压陷） | 1.5 cm |
| 乘客 | 0.68 | 同上 | 1.679 | 在腿上 | 同上 | 同上 | 0.9 cm |
| 货斗 | 0.68 | 1.664 / 1.685 | 没有车顶 | 在腿上 | 够得到 | +1 至 +5.6 cm | 2.7 cm |

上下车：
- 上车时手抓着拉手，最近 4.6 cm（司机）/ 6.6 cm（乘客）；
- 下车时拉手 4.2 cm，推门时外把手 5.9 cm。

试过的方案：
- 0.75 缩放：抬头时帽子层到 1.713，超过车顶；
- 腿不拉长：大腿陷进坐垫 10 cm，膝盖到不了坐垫前沿。

`skeletonCheck` 还有 6 项失败，都是 BR51 / P9 拿枪的检查（换弹时手够不到、肩膀进画面、ADS 时皮肤离眼睛太近）。枪械是第 1 轮，用户 NOT PASS，已暂停等重做。这次的改动在站姿下计算结果不变，**但没有跑改动前的基准对比**。

## 7. Main 要改的（已经发通知）

1. `PickupTruckEntity` 实现 `SeatedRiderHost`：
   - `riderSeatIndex` 用 `seatOf`；
   - `riderSeat` 用 `point()` / `orientation(partialTick)` 和 rig 锚点；
   - 方向盘握点跟着 `steerAngle` 转；
   - 门上的点按 `doorAngle` 转（左门 `rotY(−angle)`，右门 `rotY(+angle)`，转轴是车门铰链）。
2. 乘客位置：`riderY = 坐垫顶 + SeatPose.EYE_OVER_SEAT − eyeHeight`，水平往座位前方移 `SeatPose.EYE_AHEAD`。坐垫顶：驾驶室 0.845，货斗轮罩 0.89。
3. 车门：`SHUT_IN` 12 → `SeatPose.SHUT_IN_TICKS`（14），`SHUT_OUT` 24 → `SeatPose.SHUT_OUT_TICKS`（20）。下车时先开门的做法不变。
4. 删掉：
   - `VehicleRiderScale`：D 已在 D 的分支上让它跳过骨架画的乘客，合并时如果 Main 删了这个文件，冲突就按删除处理；
   - `PickupTruckLayout.riderScale`、`cabHip` 和 `/afl dev vehicle seat` 的缩放部分。
   - 骨架关着时，原版模型坐在车里还是太大。要不要保留一个骨架关闭时的缩放，由 Main 决定。
5. 换挡和离合（Main 2026-10-16 提的 P3 需求）：右手跟着挡杆、左脚踩离合，等 Main 的换挡信号接口草案。

## 9. 没做 / 已知限制

- **头在某些角度看起来被压扁**（用户 2026-10-16 实机录像，第三人称绕车看司机）。从车头斜前方看最明显，头显得又宽又矮。原因**没有查清**，有两种可能：
  - 头顶被挡风玻璃上沿或车顶边框挡住了。缩到 0.72 以后帽子顶在 1.64 m，离顶棚 1.69 m 很近，低角度从外面看，上半截头会藏在窗框后面；
  - 躯干压缩（`compress`）或顶圈压扁（`squash`）连带影响了头。
  下一步应该先在出问题的角度把窗框遮挡和头的实际尺寸分开量，再决定改哪边。
- **上下车时缩放看得出来**（用户 2026-10-16）。人从 1.0 倍缩到 0.72 倍，跟着上车进度变化，从外面看很明显。可选的改法（都没做）：
  - 车外就先缩小；
  - 只在车门遮住身体时缩放；
  - 把驾驶室按原尺寸的人做大，不再缩放。最后这条牵涉车身模型。
- 脚踩不到踏板：踏板在胯前 0.8 m，要把腿拉得更长才够得到，所以脚踩在踏板后面的地板上。踩离合和刹车放到换挡那一块（第 7 节第 5 条）。
- 方向盘转动、车身俯仰侧倾：要 Main 的宿主提供（`T15Seats` 只算航向，不转方向盘）。
- 腿比身体按比例长（大腿 1.39 倍，小腿 1.6 倍），主要藏在仪表台下。车门开着时从外面看得出来。
- 大腿压进坐垫前部最多 6.5 cm。
- 第一人称往下看时，方块风格的粗胳膊占了画面下方两角。
- 坐着拿枪不处理（还是枪的姿势）。
- 骨架关着时还是 Main 的原版缩放。

## 10. 交接：之后归 Main

用户 2026-10-16 决定：本轮到此为止，载具（包括坐姿、上下车、手扶方向盘、换挡和离合）以后**全部由 Main 做**，D 去做布娃娃系统。理由：一个功能不能分在两个会话里做。

所以第 2 节"车和车门归 Main，人的身体归 D"的分工到此作废。
- 本文、`skeleton/seat/*`、`SeatedRiders`、`T15Seats` 和 `SeatCheck` 归 Main 改。
- 第 7 节的待办由 Main 自己决定做不做、怎么做；第 9 节的两个已知问题也一样。
- `HumanoidPoser` 里坐姿用到的输入（`rootTurn`、`hipTarget`、躯干压缩、腿 IK、拉长）是骨架求解器的公共部分。Main 可以改，但要保证站姿结果不变（`skeletonCheck`）。
- 合并时外部网格的协议号要用 50（Main 已经占了 49）。
