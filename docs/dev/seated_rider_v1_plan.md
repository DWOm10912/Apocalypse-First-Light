## 1. 尺寸：为什么要缩小，怎么缩

原版比例的人放不进真实尺寸的驾驶室：
- 头有 8 px 高（缩放 1 时 0.47 m）；
- 坐垫到车顶内衬只有 0.85 m（坐垫顶 0.845，内衬约 1.69）；
- 腿只有 12 px（0.70 m）；
- 坐垫有 0.35 m 深。

所以坐着的人整体画小，再单独调躯干和腿：

| 项 | 值 | 原因 |
|---|---|---|
| 整体缩放 `SeatPose.SCALE` | **0.72**（第二轮 **0.82**，第 11 节） | 头顶（带帽子层）离车顶留出余量。之前说的 0.75 / 0.8 头会碰顶，见第 6 节 |
| 眼高 `EYE_OVER_SEAT` | 坐垫顶以上 **0.59 m**（驾驶室 1.435；第二轮 0.8194 × SCALE = 0.672 m，驾驶室 1.487） | 车顶下抬头 12° 时帽子层最高到 1.679 |
| 眼的前移 `EYE_AHEAD` | 坐垫点以前 **0.09 m**（第二轮 0.125 × SCALE = 0.1025 m） | 坐在方向盘前，画出来的眼睛在胯点稍前。镜头放到那里，第一人称的镜头就在画出来的头里 |
| 躯干压缩 | 自动解，现在约 **0.68** | 眼睛要落到镜头高度：胸和头各往下 6 px ×（1 − t），胸的上端按 t 压扁（皮肤网格的顶圈），肩膀跟着往下。量的是颈部，低头抬头不改变躯干 |
| 大腿 `THIGH` | ×1/0.72（**原尺寸**） | 膝盖要到坐垫前沿 |
| 小腿 `SHIN` | **×1.6** | 小腿要够到地板，同时膝盖大致和胯一样高 |
| 胯高 `HIP_LIFT` | 骨盆轴心在坐垫顶以上 2.2 px | 大腿下面贴着坐垫 |
| 驾驶座后仰 | 0°（乘客 −8°，货斗 +4° 前倾） | 手要够到方向盘 |
| 车顶下抬头 | 身体最多后仰 12° | 镜头照样能往上看 |

大小在 `PlayerSkeleton.begin` 里绕渲染原点缩放；求解用的模型坐标包含这个缩放，所以座位、方向盘、车门的世界坐标都落在对的地方。物品、护甲、名牌跟着一起缩小。

## 2. 接口（Main ↔ D）

都在通用包 `skeleton/seat`，服务器和客户端都能用。

- `SeatedRiderHost`（载具实现）：
  - `int riderSeatIndex(Entity passenger)`：乘客坐在哪个座位，−1 表示没坐（或者座位还没同步过来）；
  - `RiderSeat riderSeat(int seat, float partialTick)`：客户端每帧调用，按编号取。人下车以后还会接着问：下车动作要看车门怎么转。
- `RiderSeat`（世界坐标，用载具的完整朝向，包括俯仰和侧倾）：
  - `kind`：DRIVER（手扶方向盘）、PASSENGER（手放腿上）、BENCH（货斗这种开放座位，没有门）；
  - `cushion`：坐垫顶，取臀部正中；
  - `frame`：座位坐标系到世界的旋转，+X 是乘客的右边，+Y 向上，−Z 是乘客面朝的方向；
  - `doorSide`：−1 左、+1 右、0 没有门；
  - `door`：车门开了多少，0 关上，1 全开；
  - `anchors`：手脚要去的点，都可以不给：
    - `grip_l` / `grip_r`：握方向盘的位置，**要跟着方向盘一起转**；
    - `floor_l` / `floor_r`：脚底踩的地方；
    - `door_pull`：车门内侧的拉手，**跟着门转**（T15 用扶手上的拉手：左门 rig (−0.76, 0.95, −0.12)，右门是镜像）；
    - `door_outer`：车门外把手，跟着门转；
    - `entry`：车门外站人的位置；
    - `wheel_hub` / `wheel_axis`：方向盘中心和转向柱轴上的一点（第 12 节，手腕跟着轮缘拧）；
    - `wheel_rim`：轮缘上的一点（第 13 节：握点离开轮缘时手腕不再跟着拧）；
    - `shift_knob`：挡杆球头，跟着挡杆动（第 13 节；司机的 `grip_r` 换挡时由宿主移到这里）；
    - 计划中：`pedal_clutch`、`pedal_brake`、`pedal_accel`（脚够不到，第 13 节）。
- 过渡做法（**已结束**：2026-10-16 `PickupTruckEntity` 实现了接口，`T15Seats` 已删，`SeatedRiders.host` 只认实体自己的接口）：`PickupTruckEntity` 实现 `SeatedRiderHost` 之前，D 用 `client/skeleton/T15Seats` 临时包一层：
  - 用的是 rig 数字，只算航向；
  - 实体本身实现了接口时，`SeatedRiders.host` 先用实体自己的；
  - Main 实现以后，`T15Seats` 删掉。

## 3. 坐姿

### 3.1 求解器新增（`HumanoidPoser.Input`）

| 字段 | 作用 |
|---|---|
| `rootTurn` | 根骨骼在模型空间的完整旋转（座位朝向、车身倾斜） |
| `hipTarget` | 骨盆轴心要去的位置，整个根骨骼移过去 |
| `eyeLevel` / `torsoMin` / `torsoDirect` | 躯干压缩（第 1 节） |
| `legIkWeight`、`ankleRight/Left`、`kneePoleRight/Left`、`footRest` | 腿的两段 IK：膝盖朝 pole 方向，小腿往后折，脚掌贴地（在关节限制内） |
| `thighStretch` / `shinStretch` | 腿的拉长：骨骼偏移加长，皮肤环跟着拉 |

另外：
- `SkeletonPose.squash` 和 `shoulderDrop` 给出压扁量和肩膀下移量，`SkinMesh` 把部件第一根骨骼的顶圈往轴心收。
- 站着时这些都是 1 或 0，计算结果不变。

### 3.2 姿势（`SeatPose.body` / `hands`）

- 身体：骨盆在座位上，身体朝座位方向。
- 胸：司机的胸随视线转 10%，最多 ±6°；乘客转 35%，最多 ±30°。
- 双脚踩在 `floor_*` 上，膝盖朝前上方。
- 手：
  - 司机：手掌贴在 `grip_l` / `grip_r` 上。手的方向用 IK 得到的前臂方向（不弯手腕、不扭前臂），手腕在接触点往回 1 px；肘部朝外下方，肩膀可以前伸 2 px。
  - 乘客、货斗：手放在大腿上，大约胯到膝盖的 60% 处。
- 手上拿着东西：
  - 第三人称：身体照样坐着，手照样在方向盘或腿上。
  - 第一人称：还是原来的第一人称手（和站着时一样）。

## 4. 上下车

每个客户端自己看每个玩家：
- 有了座位，开始上车，起点是他上一刻站的位置；
- 离开座位，开始下车，终点是他现在站的位置。

所以所有客户端看到的一样，不需要新的网络包。下车途中走动，下车动作立刻结束。进世界时已经坐着（5 tick 内没有站立记录），直接是坐着的样子。

### 4.1 上车（有门，约 1.7 s）

| 时间 | 身体 | 手 | 车门（Main） |
|---|---|---|---|
| 0–0.75 s | 从车门外站的位置进到座位上：里侧的腿先进，转向座位方向，从 1 缩到 0.72，腿伸长 | 垂着 | 开着 |
| 0.45–0.7 s | 坐下 | 靠门的手（司机左手）伸向门内拉手，胸往门那边转 20° | 开着（门全开时拉手够不到，手先伸过去） |
| **14 tick（0.7 s）** | | 手抓着拉手，跟着门走 | **开始关**（`SHUT_IN` 12 → **14**） |
| 门快关上（开度 < 0.2） | | 松开，去方向盘或腿上 | 约 1.4 s 关好 |
| 1.7 s | 坐好 | 双手在方向盘上 | |

### 4.2 下车（有门，约 1.5 s）

| 时间 | 身体 | 手 | 车门（Main） |
|---|---|---|---|
| 0 s | 在座位上；人已经被放到车外 | 靠门的手抓着门内拉手，跟着门推开；另一只手离开方向盘 | 开始开（Main 现在的做法） |
| 0.25–1.0 s | 从座位出来站好，从 0.72 变回 1 | 0.55 s 左右松开拉手 | 0.7 s 全开 |
| 0.8 s 起 | 站着 | 离车门外把手近的那只手抓着把手 | |
| **20 tick（1.0 s）** | | 跟着门推 | **开始关**（`SHUT_OUT` 24 → **20**） |
| 门关到开度 < 0.4 | | 松开，门自己关上 | |
| 约 1.5 s | 结束；门一直不关的话 2.0 s 结束 | | |

### 4.3 时间对不上时

拉手、推门都跟着门的实际开度走：门早关、晚关或者不关，手都不会停在半空。上面写的 tick 数是看起来最顺的时间。

### 4.4 没有门的座位（货斗）

只动身体，0.5 s。

## 5. 镜头和第一人称

- 自己在第一人称上下车：`CameraDirector` 的请求 `afl_seat_move`（优先级 BODY_EYE，淡入 0 s，淡出 0.1 s）。镜头从离开的眼睛位置跟着身体的进度移到现在的眼睛；视角还是玩家自己的。
- 过程中镜头离开了实体眼睛，`FirstPersonBody.shown` 通过 `SeatedRiders.cameraOnBody` 继续画第一人称身体。
- 坐着时镜头就是 Main 放的眼睛位置。躯干按镜头高度自动压缩，所以 Main 用别的眼高，身体也对得上（压缩下限 0.62）。

- 上车时手抓着拉手，最近 4.6 cm（司机）/ 6.6 cm（乘客）；

## 9. 没做 / 已知限制

- **已修（2026-10-16 第二轮，第 11.1 节）**：原因是头翻倒，下面两种猜测都不对。**头在某些角度看起来被压扁**（用户 2026-10-16 实机录像，第三人称绕车看司机）。从车头斜前方看最明显，头显得又宽又矮。原因**没有查清**，有两种可能：
  - 头顶被挡风玻璃上沿或车顶边框挡住了。缩到 0.72 以后帽子顶在 1.64 m，离顶棚 1.69 m 很近，低角度从外面看，上半截头会藏在窗框后面；
  - 躯干压缩（`compress`）或顶圈压扁（`squash`）连带影响了头。
  下一步应该先在出问题的角度把窗框遮挡和头的实际尺寸分开量，再决定改哪边。
- **已改（2026-10-16 第二轮，第 11.2 节）**：缩放改成 0.82，而且只在钻车门的那一段变大小。**上下车时缩放看得出来**（用户 2026-10-16）。人从 1.0 倍缩到 0.72 倍，跟着上车进度变化，从外面看很明显。可选的改法（都没做）：

  - 只在车门遮住身体时缩放；

- 脚踩不到踏板：踏板在胯前 0.8 m，要把腿拉得更长才够得到，所以脚踩在踏板后面的地板上。踩离合和刹车放到换挡那一块（第 7 节第 5 条）。

- 腿比身体按比例长（大腿 1.39 倍，小腿 1.6 倍），主要藏在仪表台下。车门开着时从外面看得出来。

## 10. 交接：之后归 Main

### 11.1 头翻倒（以前看成"压扁"）

- 用户的 OBS 录像：头扭到极限时往下翻。
- 原因：
  - 坐着时视角能转 120°，司机的胸只转 6°，头相对胸要转约 114°；
  - `HumanoidPoser` 原来用 `clampEuler`，按 Z-Y-X 拆角度，中间那个角（左右转）只能拆在 ±90° 以内；
  - 超过 90° 时，同一个旋转被拆成"左右转 180° − a，俯仰和侧倾各翻 180°"；
  - 再按限位夹（俯仰 −70…+60，侧倾不限），头就侧倒或者朝下。
- 修法：头单独用 `clampHead`，按 Y-X-Z 拆（先左右转，再俯仰，再侧倾；JOML `getEulerAnglesYXZ` / `rotationYXZ`）。左右转可以拆到 ±180°，夹到 ±70° 时脸停在边上，不再翻。
- 司机：
  - 胸转到限位以后，视角再多转的部分（超过 `NECK_TURN` 64° 的那段），胸最多再跟 `DRIVER_LOOK_BACK` 8°，手还在方向盘上；
  - 脸最多转到 ±84°；
  - 乘客和货斗能转到 ±100°。

### 11.2 大小

- 车顶加高 10 cm，内衬 1.69 → 1.79；坐垫降 3 cm，0.845 → 0.815。坐垫到内衬从 0.85 m 变成 0.975 m。
- `SeatPose.SCALE` 0.72 → **0.82**：
  - `EYE_OVER_SEAT` = 0.8194 × SCALE = 0.672 m，驾驶室眼高 1.487；
  - `EYE_AHEAD` = 0.125 × SCALE = 0.1025 m。

  - 上下车的进度"坐进去多少"在 0.3–0.75 之间时才变（`SIZE_FROM` / `SIZE_TO`，`SeatPose.Moment.size`，平滑曲线）；
  - 门外站着时是原大小，过门以后就是坐着的大小；
  - 货斗没有门，跟着坐下的进度变。
- 试过 0.80：头和车顶之间还有余量，所以加到 0.82。

## 12. 第三轮：倒手转方向盘（Main，2026-10-16，离线检查通过，未实机验证）

用户 2026-10-16 实机：打方向盘时手不够流畅，要求用 D 的骨骼动作接口做精致一点。

- 用法和 D 的玩家动作（`skeleton/action`）一样：手的 IK 目标（掌心位置 + 前臂的未拧方向）、肘的朝向、绕前臂的拧转（`roll`）。
- 为什么不用动画片段：方向盘的位置每帧都由车给，手要跟着它走，所以握点在 `vehicle/SteeringHands` 里按规则算，再交给座位姿势的 IK。

### 12.1 规则（`vehicle/SteeringHands`，每辆车一份，客户端按帧更新）

- 角度：每只手在轮缘上离自己静止位置（左 9 点、右 3 点）的角度，正方向和方向盘一样（司机看是顺时针）。所以右手的 + 往下，左手的 + 往上。
- 握着的手跟着方向盘转，但只在自己那半边转：
  - 往 12 点最多 `UP` 50°，往 6 点最多 `DOWN` 70°（离线检查：坐着的手臂够得到的范围）；
  - 超过就让方向盘从手里滑过。
- 转进去（方向盘离开中间、每秒超过 30°）时倒手：
  - 剩余空间少的那只手先松开；
  - 松开的时机：到了自己的限位，或者另一只手剩下的空间刚好够在这只手越过去的时间里握住方向盘（不让方向盘滑的最晚时机，留 10% 余量）；
  - 越过去：落到静止位置另一侧 `BACK` 30°，用时 0.16 s + 每 90° 0.14 s，平滑曲线，中途离开轮缘最多 2.5 cm（`LIFT`，往司机这边）；
  - 同一时间只有一只手离开方向盘。
- 回中间：手松着，方向盘在限位处从手里滑过。
- 方向盘静止（每秒小于 30°）0.3 s 以后，离静止位置超过 12° 的手一只一只回到 9 点和 3 点。
- 换了司机，或者两帧之间隔了 0.5 s 以上，两只手直接回到静止位置。

### 12.2 手腕

- `SeatPose` 用锚点 `wheel_hub` / `wheel_axis` 求出握点从静止位置绕转向柱转了多少；
- 把这个转动里沿前臂方向的那部分，取 `WHEEL_ROLL` 80%，作为手绕前臂的拧转；
- 没有这两个锚点时不拧（别的宿主不受影响）。

### 12.3 离线检查（`SeatCheck`，2026-10-16）

- 每只手在整个够得到的范围里（贴着轮缘和抬起 2.5 cm 都试了）：手腕最多偏 0.26 px（右手往 12 点 50° 时）。
- 模拟开车（1/60 s 一帧，用真实的转向速度）：
  - 打满舵：方向盘每秒 928°，转到 540°；
  - 松开回中：每秒 1266°；
  - 静止；
  - 慢慢往另一边转：每秒 280°，转到 −300°；
  - 再回中、静止。
- 结果：
  - 一共倒手 15 次，两只手同时离开方向盘的帧数 0；
  - 慢速转弯时方向盘滑过 2°（倒手改成提前松开之前是 31°）；
  - 打满舵时滑过 172°（转了 540°，手倒不过来）；
  - 手每帧最多移动 0.068 m；
  - 手腕最多偏 0.26 px；
  - 最后停下时两只手都回到 9 点和 3 点。
- 看不出来的：拧转的方向和多少是否好看、倒手节奏是否自然。这些只能实机看。
