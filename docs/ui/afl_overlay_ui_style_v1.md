# AFL 界面现代化与统一样式 V1

状态（2026-10-06）：**第 9 节 1–6 步已实现**（用户要求"按 5 步一次性实现"，并要求快捷栏把原版的和 AFL 改枪的都换掉、做上顶效果），`compileJava`、`compileDevJava`（`--offline`）通过；**用户 2026-10-06 实机 PASS**（负重条常驻也一起验收）。实现细节见第 10 节。第 2.2 节路线图未做。

改版记录：
- 第一稿（2026-10-06）：像素圆角（按 GUI 像素逐行缩进、不抗锯齿）、斜面高光、1 px 硬投影，理由是"和像素风一致"。
- **第二稿（2026-10-06，当前）**：用户说"我们的 UI 都需要做得现代一点，生存栏虽然只是占位，但风格已经很现代化了，不是 RPG 游戏里那种奇幻 UI"。改成和生存 HUD 同一种视觉语言：平滑抗锯齿的形状、暖白细描边、深色半透明底、柔和投影。像素圆角、斜面高光、硬投影都去掉。

## 1. 为什么做

- 用户 2026-10-06：即时改装界面（Z）要加按键提示，放右上角，像 PUBG 那样，要跟着玩家改过的键位显示；以后载具也能用。
- 盘点后发现，深灰半透明这一类浮层已经有三种不一致的画法（第 2 节），再加按键提示面板就是四种。
- 用户希望做成圆角方形、精致一点，可以有动画，整体要现代（第二稿）。

## 3. 视觉规范

### 3.1 视觉语言：跟生存 HUD 走

生存 HUD（[survival_hud_v1.md](survival_hud_v1.md)）已经定下的做法，这里照搬：
- 形状按**真实屏幕像素**画，边缘抗锯齿（距离场），不是按 GUI 像素画方块；
- 深色半透明底；
- 暖白细描边 `#E8E4DC`，透明度 0.28，约 1 个屏幕像素宽，暗处也看得清轮廓；
- 数字和文字仍用原版字体，落在屏幕像素网格上，不发虚。

### 3.2 颜色

| 名字 | 值 | 用途 |
|---|---|---|
| 底色 | `#101010`，不透明度 0.62 | 所有面板、标签、格子的底（HUD 环底是 0.56；面板上要放文字，略深一点） |
| 底色（悬停） | `#1E2124`，不透明度 0.72 | 格子、按钮悬停 |
| 描边 | `#E8E4DC`，透明度 0.28 | 约 1 屏幕像素，和 HUD 描边同一个值 |
| 描边（悬停） | `#E8E4DC`，透明度 0.55 | 悬停时描边变亮，不改底色以外的东西 |
| 柔和投影 | 黑色，透明度 0.22，外扩约 3 GUI 像素、羽化 | 压在亮天空上也分得清，替代第一稿的 1 px 硬投影 |
| 主文字 | `#E8E4DC` | 和描边同色系的暖白 |
| 次文字 | `#A8A49C` | 说明、"当前：…"、"退出" |
| 禁用文字 | `#6C6A66` | 处理中、不可用 |
| 强调色 | `#E0A84A`（暗琥珀） | 只用于"选中 / 激活"：选中格的指示条、键帽按下 |
| 键帽 | 底 `#E8E4DC` 不透明度 0.92，字 `#16181A` | 实心浅色圆角小块，一眼看出是"键"；不画斜面底边 |

一屏只用一处强调色，其余全是暖灰阶。

### 3.3 圆角（平滑）

- 圆角矩形用距离场按屏幕像素栅格化，边缘抗锯齿；底、描边、投影都由同一个距离场算出，角上不会出现台阶或残角。
- 半径（GUI 像素）：键帽 2.5，候选格和按钮 3，标签 3，面板和操作小窗 4。
- **九宫格绘制**：每种（半径、样式、界面缩放）只栅格化一张四个角的小贴图（动态贴图，和 `AflGauge` 一样缓存），四条边和中间用拉伸 / 纯色填充。任意宽高的面板都只要一张贴图，每个面板每帧 9 次以内的绘制，不按尺寸生成新贴图。
- 界面缩放变化时重新栅格化（和 `AflGauge` 一样按需重画）。

### 3.4 尺寸和排版

- 原版字体，行高 11 GUI 像素；面板内边距左右 6、上下 4。
- 按键提示面板：右上角，距屏幕边 8；每行 14 高，**右对齐**，"键帽 + 说明"，间隔 5。
- 按键提示面板的底从右往左渐变到透明（右侧 0.62 → 左端 0），不画左边描边，像 PUBG 那样；其余面板是完整圆角矩形。
- 键帽宽度按键名自适应（至少 11），改键后的长名字（"Left Shift"、"Mouse 4"）也装得下；超过 60 截断加省略号。
- 以后可选：给 UI 单独配一套 TTF 无衬线字体（Minecraft 字体 JSON 支持 `ttf`），现代感提升最大；但中文字体要做子集、注意授权和 jar 体积，生存 HUD 也要一起换才统一。V1 不做。

### 3.5 键位显示

- 键盘键：读 `KeyMapping#getTranslatedKeyMessage()`，玩家在控制设置里改键，提示立刻跟着变。
- 鼠标操作（不能改键）：键帽里画小鼠标图标（同样按屏幕像素抗锯齿画），用到的那个键（左、中、右）涂亮；滚轮画成中间一条竖线加上下箭头。
- 新增键位"重置检视视角"（默认 R，`KeyConflictContext.GUI`），替换 `FieldAttachmentScreen` 里写死的 `GLFW_KEY_R`。只在界面里生效，不和游戏里的换弹（IN_GAME）冲突，也出现在控制设置里。

## 4. 动画

原则：
- 短（80–150 ms），按真实时间（`System.nanoTime`），不按帧数。
- 位移对齐到**屏幕像素**（不是 GUI 像素）：界面缩放 3–4 时一个 GUI 像素是 3–4 个屏幕像素，所以滑动是平滑的，又不会出现半像素发虚。
- 文字和物品图标不做缩放（像素字体和 16×16 图标一缩放就糊）；只有纯形状（指示条、键帽底）可以伸缩。

| 元素 | 动画 | 时长 | 曲线 |
|---|---|---|---|
| 按键提示面板进场 / 退场 | 渐入 + 从右侧滑入 8；退场只渐出 | 150 / 100 ms | ease-out |
| 面板内容随状态切换 | 旧行渐出、新行渐入，面板高度平滑过渡 | 120 ms | ease-in-out |
| 键帽按下反馈 | 按下这个键或鼠标键时，键帽底变强调色、下移 1 | 按住期间 + 松开后 80 ms 回弹 | ease-out |
| 悬停标签、交互提示 | 现有 150 ms 渐变 + 上浮 2 | 150 ms | ease-out |
| 操作小窗打开 | 渐入 + 从锚点方向滑 3 | 120 ms | ease-out |
| 候选格出现 | 9 格依次渐入并上移 4，每格错开 20 ms | 120 ms + 160 ms 错开 | ease-out |
| 候选格悬停 | 描边透明度过渡（0.28 → 0.55） | 80 ms | linear |
| 按钮按下 | 底色变深、下移 1 | 80 ms | — |

键帽按下反馈是最有用的一个：玩家按一下就知道"这个键在这里起作用"，也能发现自己改过的键。

### 4.1 选中物品上顶（用户 2026-10-06 提出，参考 Windows 11 任务栏）

- 选中格里的物品图标（连同数量、耐久条）上移 3：先快速冲到 4（60 ms，ease-out），再回落到 3（60 ms），这点过冲就是 Windows 那种"弹一下"；取消选中时 120 ms 落回。
- 格子底部的琥珀色指示条（圆角小胶囊）跟着选中项**滑到**新格子，滑动时先拉长再收短（Windows 11 任务栏指示条那样），120 ms。
- 快速连续切换（滚轮狂滚）时，每格各自按自己的进度回落，不排队。
- 位移对齐屏幕像素，图标不缩放。

适用范围：
- **配件候选格**：直接做（上顶 + 指示条）。
- **原版快捷栏**：用户 2026-10-06 决定整条换成 AFL 样式（不只加上顶），上顶和指示条都做。做法见第 10 节：不改原版贴图、不用 mixin，取消原版的 HOTBAR overlay、自己画一条。

## 5. 不做毛玻璃

用户问过要不要毛玻璃 + 渐变。结论：只做半透明、渐变和柔和投影，不做真模糊。
- 1.20.1 原版没有界面模糊，要自己读屏幕画面再模糊。开 Oculus 光影时帧缓冲由光影包管理，这一步兼容风险最大。开光影掏枪的开销刚降下来（[hybrid_mesh_runtime_v1.md](../native_guns/hybrid_mesh_runtime_v1.md) 实机结果），不值得为浮层冒险。
- 面板后面多半是天空或远景，模糊了看不出区别；深色底 + 柔和投影已经保证可读。
- （第一稿的另一条理由"和像素风不搭"已作废：第二稿改成了现代平滑风格。）

## 6. 世界交互提示加键帽

现在的世界交互提示只有文字（"打开""搜索"）。统一后在文字前加键帽，键位跟着改键变：
- 默认用"使用物品 / 放置方块"键（`keyUse`，默认右键）；
- 破坏玻璃这类靠攻击触发的提示用攻击键（`keyAttack`）；
- 每个 `Target` 多带一个键位来源，不改判定逻辑。

## 7. 代码结构（计划）

| 新类 | 作用 |
|---|---|
| `client/ui/AflUiStyle` | 第 3.2 节颜色、第 3.3 节半径、第 3.4 节尺寸常量 |
| `client/ui/AflUiShapes` | 距离场圆角矩形的栅格化和九宫格绘制（底、描边、柔和投影），按（半径、样式、界面缩放）缓存角贴图；小鼠标图标、指示条胶囊 |

| `client/ui/AflKeyHintPanel` | 通用按键提示面板：传入"键位来源 + 说明"的列表；处理进场、内容切换、按下反馈。即时改装界面先用，以后载具、机器、油壶倾倒都能复用 |

## 10. 实现（2026-10-06）

代码在 `client/ui/`：

| 类 | 作用 |
|---|---|
| `AflUiStyle` | 颜色、透明度、圆角半径（第 3.2、3.3 节的值） |
| `AflUiTween` | 按真实时间的缓动值（`LINEAR` / `OUT` 三次 / `IN_OUT` smoothstep），从当前值改目标；`snap` 把 GUI 长度取整到屏幕像素 |
| `AflUiShapes` | 圆角盒子：投影、底、内描边三层，同一个距离场按屏幕像素算抗锯齿覆盖。九宫格：每种（半径、描边宽、投影外扩，都按屏幕像素）一张动态贴图，三层的角并排放，中间一个像素拉伸；每个盒子一次绘制、最多 27 个四边形，颜色按顶点给，所以动画改颜色、透明度不用重画贴图。描边宽 = 0.3 GUI 像素取整（至少 1 个屏幕像素），和 HUD 一样。界面缩放变了就释放旧贴图重建。`fadeTo` 让整块从左边透明渐变到不透明（按键提示面板） |
| `AflUiDraw` | 面板、标签、按钮、文字（文字位置取整到屏幕像素；透明度低于 2% 不画，原版字体会把极低透明度当不透明） |
| `AflKeyHint` | 键帽：键位映射按当前绑定显示（改键即变）；绑定在鼠标左 / 右 / 中键上、或者固定的鼠标操作（左、右、中键、滚轮），画一个 5×8 的小鼠标，用到的键涂实；其它按键画键名（超过 54 GUI 像素截断）。按下检测直接读 GLFW（界面打开时 KeyMapping 收不到按键），按住时标记变琥珀色、键帽下沉 1，松开后再保持 80 ms；滚轮由界面调用 `scrolled()` 点亮 150 ms。每个映射只建一个实例（`of` 缓存），松开计时才不会每帧丢 |
| `AflKeyHintPanel` | 按键提示面板：右上角离边 8，每行 14，右对齐"键帽 + 说明"，左侧 26 GUI 像素渐变到透明、不画投影。首次出现 150 ms 渐入并从右滑入 8；行内容变了 120 ms 交叉淡化，宽高平滑过渡；隐藏时 100 ms 渐出 |
| `AflItemStrip` | 物品格一排：第 4.1 节的上顶（60 ms 冲到 4，再 60 ms 回到 3；失去选中 120 ms 落回，各格各自计时）、琥珀指示条（前端 90 ms、后端 160 ms，拉长再收短）、格子亮起（80 ms）、出现时错开（每格 20 ms，120 ms，上升 4）。有长底板时（快捷栏）格子只是淡色，选中才出描边；单独的格子（候选格、维护台）各自带底、描边、投影 |
| `AflHotbarOverlay` | 新快捷栏 |

### 10.1 快捷栏

- `AflHudEvents` 在非旁观模式下取消原版 `HOTBAR` overlay；`AflHotbarOverlay` 注册为 overlay `apocalypse_firstlight:hotbar`（在 `HOTBAR` 之上）自己画。旁观模式不取消，原版的旁观快捷栏照旧。即时改装视图里它和原版一样被藏起来（加进 `FIELD_VIEW_HIDDEN`）。
- 占位和原版一样：底板 182×22，底边离屏幕底 1，物品横向位置和原版相同（中线 −88 + 20 i），纵向比原版高 1 GUI 像素。所以生存仪表组、负重条（经验条位置）、物品名的位置都不受影响。选中物品上顶 3 后仍在底板里。
- 选中的格子亮起、物品上顶、琥珀指示条滑过去（`AflItemStrip`）。
- 副手：有东西时在副手一侧单独一个 22×22 小底板，物品位置和原版相同。
- 攻击冷却指示器设成"快捷栏"时：原版画剑的位置改画一个小环形进度（用生存 HUD 的 `AflGauge`，半径 7、宽 1.6、暖白）。
- 捡起物品时的"弹一下"（原版 pop 动画）保留，照抄原版 `Gui#renderSlot`。
- 不改原版贴图、不用 mixin；资源包对原版快捷栏贴图的修改不再生效（快捷栏不再用那张贴图）。

### 10.2 即时改装界面、维护台

- 悬停标签：`AttachmentHintStyle` 改成圆角标签，渐入时上浮 2（接口不变，世界交互提示同步变化）。
- 配件槽操作小窗：圆角面板，120 ms 渐入并上浮 3；按钮圆角，悬停描边变亮，按下变深下沉 1。点击区域不随动画移动。
- 配件候选格：`AflItemStrip`，打开时错开出现，鼠标下的候选上顶并带指示条；处理中整排变淡。原来的整排渐显遮罩删掉了。

### 10.3 世界交互提示

`WorldInteractionHint` 按提示的语言键决定键帽：所有动作用"使用"键（默认右键，画小鼠标）；拿起油壶 / 油桶是"潜行"+"使用"两个键帽；只说明情况的提示（无法充电、需要撬棍、需要接油的容器）不带键帽。破坏售货机玻璃也是右键触发（服务端 `use`），用"使用"键。

原来把按键写进文字的三条提示改短（键帽已经说明了按键）：

| 语言键 | 原来 | 现在 |
|---|---|---|
| `hint.apocalypse_firstlight.fuel_container.fill` | 按住右键加油 | 按住加油 |
| `hint.apocalypse_firstlight.fuel_container.crank` | 按住右键摇油泵 | 按住摇油泵 |
| `hint.apocalypse_firstlight.fuel_container.pick_up` | 潜行 + 右键拿起 / Sneak + use to pick up | 拿起 / Pick up |

新增语言键：`key.apocalypse_firstlight.reset_inspection`、`gui.apocalypse_firstlight.key_hint.*`（rotate、pan、zoom、reset、exit、select_slot、confirm、back、install、page、place_gun），中英文都有。
