## 1. 东西存在哪里

| 部分 | 存在哪里 | 说明 |
|---|---|---|
| 武器位 1–3、手上 | 原版物品栏 0–3 格 | 0 主武器（要背带）、1 手枪（要枪套）、2 近战、3 “手上”（快捷绑定或“手上”框拿出来的东西）；4–8 不用、锁定。见第 10 节 |
| 原版物品栏 9–35 | 原版，继续锁定 | 和现在一样只是旧物品的“溢出”：能取出，不能放入。网格背包不用它们 |
| 口袋（4 个 1×1） | 玩家身上的数据（能力 `afl:pockets`） | 基础衣服自带，一直都有 |
| 胸挂、背包的内部网格 | 物品自己的数据（物品 NBT 的 `Items` 列表，每件另记所在小格、位置、是否旋转） | 穿在 Curios 栏位上（背包用现有的 `back`，胸挂新加 `rig`）。脱下、扔掉、进尸体时东西都还在里面，像塔科夫 |

- 网格里的每一格放“一叠物品”，占这件物品的尺寸（第 2 节）；同种物品照原版规则叠在一起。
- **所有网格操作都在服务器上执行**：客户端只报告“点了哪个容器的哪一格、有没有旋转”，服务器检查能不能放再执行，结果同步回来。所以单人、多人是同一套逻辑。
- 拿起来的物品就是原版“鼠标上拿着的物品”，所以网格、快捷栏、装备栏之间可以直接拖来拖去，关界面时手上的东西按原版放回去（放不下按拾取顺序进网格，再放不下掉在地上）。

## 2. 物品尺寸数据 `item_size`

- 数据文件 `data/<命名空间>/item_size/*.json`，写法照 `item_mass`：按物品 ID，也可以按物品标签。服务器读，进游戏时和 `/reload` 后同步给客户端。
- 没写的物品默认 1×1。枪按类别给默认值（步枪、霰弹枪、机枪、精确步枪 5×2，冲锋枪 3×2，手枪 2×1），单把枪可以另写。
- 物品可以旋转 90°（拖着的时候按 R）。
- 提示框加一行占格，和质量写在一起：`1.00 kg · 1×1`。

## 3. 拾取顺序

玩家拿起的地上的东西（第 12 节：E 界面“附近”栏 Shift 点击、对准地上物品按使用键）、`/give`、关界面时手上的东西、其它系统“还给玩家”的东西，都走原版的“加进物品栏”。生存、冒险模式下走过地上的东西**不会自动吸起**（第 12 节）。

0. 装备（胸挂、背包、枪套、耳罩、手腕）：对应的 AFL 装备栏空着就直接穿上（第 11 节用户实机检查）；
1. 武器进它的空武器位：装了背带的长枪进 1，穿了枪套时手枪进 2，近战进 3（第 10 节）；
2. 其它东西不进快捷栏，也不会叠到手上拿着的那叠里；
3. 按口袋 → 胸挂 → 背包的顺序：先叠到同种物品上，再找第一个放得下的位置（先不转，再转 90°）；
4. 都放不下就留在地上（原版行为）；从地上拿时还会放进空着的“手上”（第 12 节）。

创造、旁观模式不走网格（原版物品栏全开，和现在一样）。

## 4. 和其它系统的接入

| 系统 | 怎么接 |
|---|---|
| 负重 | 口袋里的东西作为新的来源计入；胸挂、背包里的东西跟着那件装备一起算（负重计算本来就会读物品里的 `Items` 列表） |
| 尸体（幸存者 V0） | 口袋里的东西进尸体；胸挂、背包整件进尸体，里面的东西还在里面 |
| 换弹找弹匣 / 弹药 | 先找快捷栏，再找口袋、胸挂、背包 |
| 电池供电、物品污染 | 网格里的东西也算 |
| 锁定栏位 | 规则换成“按格子和物品判断”：武器栏只收对应武器；已经在武器栏里的非武器（旧存档）算溢出，能取不能放 |
| 创造模式 | 创造模式物品栏不改；网格里的东西照样保存，只是在创造模式里看不到 |
| 网络协议 | 新增网格包，体温包加舒适温度下限：协议 43 → 44 |

## 5. E 背包层

按概念图的布局，用自己的整数缩放（1080p 4 倍，1440p 5 倍），不跟原版 GUI 缩放走。

- 左栏：人物 + 装备栏位，下面是 5 个武器栏，最下一行负重和舒适温度。
- 右栏：口袋、胸挂栏位（穿上后出现它的小格）、背包栏位（穿上后出现它的网格），最下面是绑定行 4–9（第 10 节，阶段 1 是快捷格 6–9）；放不下时上下滚动。
- 拖动：绿色 / 红色占格框，半透明的拖动物品，按 R 旋转；鼠标停住显示提示框（名称、质量、占格）。
- 左键拿整叠 / 放下，右键拿一半 / 放一个，Shift 点击在快捷栏和网格之间移动，Q 丢出鼠标下的物品；点到界面外面丢出手上的东西（原版行为）。
- 拖放（第 12 节）：按住拿起、在别处松开就放下（整叠），和“点一下拿、再点一下放”并存。
- 右上角按键提示：`E 关闭`，拖动时加 `R 旋转`。

- 画布 480×270，按窗口像素取最大整数倍（1920×1080 是 4 倍）。GUI 缩放和这个倍数不同时，整体会再缩放一次，字和圆角会略软，正常 4 倍时一一对应。

## 10. 武器位和快捷栏重做（2026-10-14 代码完成；2026-10-15 合并前检查用户实机 PASS）

### 我的方案（用户 2026-10-14 回复“行”确认：先出概念图，再写代码）

**武器位：键 1 / 2 / 3，不是格子，也不算快捷栏**

| 键 | 位置 | 条件 | 没有条件时 |
|---|---|---|---|
| 1 主武器 | 背在背上，只能 1 把 | 枪上装了背带（枪的配件） | 只能拿在手上；切走时自动放进背包格子，放不下就不让切（提示“没有背带”），可以按 Q 扔掉 |
| 2 手枪 | 腰间枪套 | 装备栏穿了手枪套（新栏位） | 同上，放进口袋 / 胸挂 / 背包 |
| 3 近战 | 腰间 | 不需要（默认不做刀鞘，以后可加） | — |

- 背上的枪、腰间的枪套画在人物身上；和背包穿模时，像枪架那样每把枪单独调位置。
- 捡到第二把长枪：先进背包格子（5×2），放不下就留在地上。

## 12. 地上的物品（2026-10-15，用户实机 PASS）

用户决定见第 11 节最后。只对生存、冒险模式；创造、旁观照旧走过就吸（原版）。

### 做了什么

- **不自动吸**：生存、冒险玩家走过地上的东西不会捡起（取消 Forge 的 `EntityItemPickupEvent`）。箭照旧（原版另一条路），漏斗照旧。
- **E 界面“附近”栏**：右栏合成 / 溢出下面一直显示，到左栏底边为止。列出玩家身边能拿的地上物品，近的在前，一行一件：图标、名称、数量；多了用滚轮翻。
  - 范围：玩家碰撞箱水平向外 2.5 格、向上 1 格、向下 1.5 格；要看得见（眼睛到物品中间或顶部之间没有方块挡着）。展示用物品（永不可拾取）和指定给别人的物品不列。
  - 左键：整叠拿到光标；右键：拿一半；Shift 点击：直接按拾取顺序收进来（第 3 节）。
  - 光标上有东西时点“附近”栏（或拖进去松开）：放在脚下（右键只放一个）。栏会亮绿框。
  - 拖放：在格子、装备栏、附近栏之间按住拖、松开放下（整叠）。松开时服务器还没把拿起的东西同步回来的话，最多等 0.6 秒再放。
- **对准地上物品的提示**：准星对着地上的东西（3 格内，比看着的方块近；用物品躺着时占的框判断，枪按真实长度），世界提示显示动作和物品名：
  - 使用键：按拾取顺序拿，提示说它会做什么：`穿上`（对应装备栏空着）、`装备`（对应武器位空着并收它）、否则 `拾取`；
  - 潜行 + 使用键：在“穿上 / 装备”的东西上改成 `收进背包`（只放进网格）；
  - 手上拿着枪时使用键是瞄准，所以要潜行 + 使用键，按普通拾取顺序拿。
  - 都放不下时动作栏显示“放不下”。从地上拿时，拾取顺序都放不下的东西会放进空着的“手上”（比如没装背带的长枪、网格满了的大件）。
- **地上的样子**：所有掉落物不再上下浮动、不再旋转，每件按自己的 UUID 固定一个朝向。
  - 平面物品（普通贴图物品）平躺在地上；其它所有物品（方块、网格的弹药 / 材料 / 装备、GeckoLib 的弹匣 / 瞄具等）每件先录一次地面显示量出包围盒，再把底面放到地上、水平居中在影子上方（2026-10-15 改，见下面“用户实机检查”）。是不是平面物品按地面显示真正画的那个模型判断（`GroundItemRenderer.groundModel`）。
  - 枪：按真实长度、和枪架一样的绑定姿势（弹匣、瞄具、配件照装），左侧贴地躺着。每把地上的枪只录制一次（复用枪架的录制器 `WoodGunRackChunking.record`），之后每帧回放顶点，不再每帧走一遍骨骼。
  - 东西多时：枪只在相机 32 格内画，同时超过 16 把时只画最近的 16 把（每 10 tick 重新选一次）；其它物品照原版（同种叠加合并、5 分钟消失、原版实体渲染距离）。

### 没做 / 已知限制

- 地上的枪仍是实体每帧提交顶点，没有进区块网格（实体不能进），所以一大堆枪（超过 16 把）时远一点的不画。
- “附近”栏不合并同种物品（原版已经会把同种掉落物合成一叠）。
- 潜行 + 使用键拿枪时，按住的那一下枪会短暂开镜（瞄准读的是使用键按下状态）。
- 提示一次只显示一个动作：“收进背包”要按住潜行才出现。
- 没有拾取动画以外的音效；拾取用原版的捡起动画和统计。

### 用户实机检查（2026-10-15）

用户回复：“大题逻辑pass”（不自动吸、附近栏、拖放、提示都过了），另外两个问题：

1. **很多网格物品没贴地**（耳罩、胸挂、两个背包、铅砖、弹匣、弹鼓、红点瞄具都浮在影子上方，枪没问题）。改成：每件掉落物第一次画时把它的地面显示录一次（`WoodGunRackChunking.record`，新加的 `Replay.bounds()`），量出包围盒，底面放到地上，水平中心对准实体（影子）。结果按实体缓存，物品变了或网格重载才重量；光影的阴影通道里不量，量好之前不画。准星对准用的框也改用量出来的大小。
   - **第一次修没生效**（用户第二次实机检查仍然浮空）：真正的原因是这些物品的模型外面包着 Forge 的 `forge:separate_transforms`（AFL 网格物品几乎都是）。查 Forge 47.4.20 源码：这个外层模型的 `isCustomRenderer()` 固定返回 false，`getTransforms()` 返回空变换（缩放 1）。代码按外层模型判断，把它们当成方块，走了“方块底面贴地”的公式 `0.5 × 缩放 − 平移`，结果抬高 0.5 格，量包围盒那段根本没执行。第一次修时没核实这个假设。现在按地面显示真正画的那个模型判断（`model.applyTransform(GROUND)` 拿到的模型），平面物品以外的全部用实测包围盒贴地（方块也是，不再用公式）。
2. **有背包时背着的枪在最外面**：用户先选“挂在一侧肩膀”，看过后觉得侧面位置奇怪，改为**夹在背和背包之间**。现在不管有没有背包，长枪都斜挎在背上同一个位置（背带上面，离身体中心 3.05 px）；背包的包体从 2.35 px 开始，帆布包深到 5.0、登山包深到 6.35，所以交叉的那段枪身藏在包里，只露出枪口和枪托。某把枪太厚从包后面穿出来时，用 `CarriedWeaponsLayer.BACK_OFFSET` 单独调。左肩挂枪的代码已删掉。

顺带修了一个问题：地上的枪“最近 16 把”的筛选，因为起始时间用了 `Long.MIN_VALUE`，相减溢出，从来没执行过（超过 16 把时也会全画）；改成从 `-10` tick 开始。

验证：`compileJava --offline` 通过。这轮只改了客户端渲染（GameTest 服务器不加载这些类），没有重跑 GameTest。**没有进游戏验证**：网格物品和方块的贴地高度、居中，背包压住枪的样子（站、走、蹲）都要用户看。

用户问合并前还差什么，我列出的头号缺口是：容器界面里看不到口袋 / 胸挂 / 背包，背包里的东西放不进箱子。用户让我看看现有容器都怎么接，并说末影箱这类容器不用管（已经定了获取不到）。下面先是盘点和方案，用户 2026-10-15 说“开始做容器网格”，做法见本节最后“做了什么”。

### 通用做法

1. **服务器**：网格操作现在只认背包界面（`player.containerMenu == inventoryMenu`）。改成认**当前打开的、含玩家物品栏格子的任何界面**，光标用那个界面自己的。这样从网格拿起的东西能直接点进容器格，容器里拿起的东西能点进网格。新增一个动作：**Shift 点击网格里的东西放进容器**，先叠到同种物品上，再找第一个肯收它的空格（按菜单的格子顺序和每格的放入规则，熔炉的燃料格只收燃料）。容器往网格的 Shift 点击已经通了（`LockedInventoryMenuMixin`）。
2. **界面**：所有容器界面（只要菜单里有玩家物品栏的格子）在窗口**左边**加一个侧栏，画口袋、胸挂、背包三块网格，样子和操作照搬背包界面：点按拿 / 放、拖放、R 旋转、绿 / 红占格框、提示框、Q 丢出。容器自己的布局一格不动，原版、AFL、以后别的模组界面都一样。侧栏太高时滚动。
3. **JEI**：侧栏占了窗口左边，JEI 的左侧书签栏会让开（侧栏算进界面的范围）。
4. **原版物品栏的锁定格**（9–35 和快捷栏 4–8）在容器界面里照旧灰掉，不改。

### 工作量和顺序

1. 服务器动作放开 + 新的“放进容器”动作 + GameTest（箱子、熔炉、搜刮容器）；
2. 侧栏（复用背包界面的网格画法和拖放代码，先把这部分从 `AflInventoryScreen` 拆出来共用）；
3. 维护台 / 野外改装的配件从网格里找；
4. 文档、实机检查清单。

### 做了什么

**服务器**（`GridActions`）

- 网格动作在背包界面和**任何打开的、菜单里有玩家物品栏格子的容器界面**里都能用（`GridActions.gridMenu`：还要菜单 `stillValid`），光标用当前界面的。地上物品的三个动作仍只在背包界面里。
- 新动作 `TO_CONTAINER`（枚举最后加一项，包格式不变，协议仍是 44）：Shift 点网格里的东西放进容器，**按菜单自己的 Shift 规则**（熔炉只收能烧的和燃料，搜刮容器只进已经搜出来的格子，AFL 机器按各自的格子规则）。做法：把这叠临时放进一个空的锁定主栏格（9–35），调用菜单的 `quickMoveStack`（像原版那样重复到搬不动为止）；菜单留下的、搬进玩家其它格子的（比如熔炉把不能烧的东西往快捷栏搬，撬棍会进近战位），都拿回网格**原位**。这期间 `LockedInventoryMenuMixin` 不往网格塞剩余。
- `Loadout` 判断“手上的东西是不是被光标拿走了”改看当前界面的光标。

**界面**（`client/inventory/ContainerGridPanel.java`）

- 生存 / 冒险，所有容器界面（不含背包页和创造物品栏），只要菜单里有摆在屏幕上的玩家物品栏格子，窗口**左边**（配方书打开时在配方书左边）出一块侧栏：口袋、胸挂、背包三块网格，只画穿着的。和容器窗口顶边对齐；比屏幕高时滚动；窗口太窄时整体缩小（最小一半），再窄就盖住旁边。
- 操作和背包页一样：点按拿 / 放，按住拖到别处松开（拖到容器格子里也行），R 旋转手上的东西，Q 丢（Ctrl 整叠），1–3 放进武器位，4–9 绑定（口袋和胸挂），手上拿着背带点长枪装背带；**Shift 点网格里的东西放进容器**。从容器格子按住拖到侧栏松开，放进网格。
- 侧栏画在容器自己的格子和光标物品**下面**（`ContainerScreenEvent.Render.Background`），光标上的东西总在最上面；网格物品的说明框在最上面。
