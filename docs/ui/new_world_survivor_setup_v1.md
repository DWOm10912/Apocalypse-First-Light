## 2. 两个方案

| | 方案 A | 方案 B |
|---|---|---|
| 新的世界 | 居中一张卡片：世界名称、种子、幸存者模式（普通 / 困难两张卡）、**开局场景**列表（四个场景 + 随机；2026-10-18 起 V1 测试版只显示三个、默认溪谷老宅、地堡隐藏，见加点文档第 8 节），"更多"里只有允许命令 | 左侧竖栏、右边留给大背景（以后换成场景实景或动态镜头）：世界名称、种子、幸存者模式（分段按钮）、允许命令；**场景不在这一页** |
| 幸存者 | 三栏一屏：左边背景列表（每行写固定特质和点数，选中的那行展开说明和特质徽章），中间上面身体机能两行、下面按组分的特质列表（三列，可滚动，悬停的特质在标题行写效果），右边人物、名字、开局汇总（含枪械起点）、随机 / 开始 | 人站正中（大），顶上一排出生地（场景），左栏身体机能 + 成长起点（只读）+ 汇总，右栏按组分的特质列表（两列，可滚动，底部渐隐），底部一排背景卡片（固定特质、点数） |
| 场景放在哪 | 建世界时选（世界设置，联机时所有人在这里出生） | 幸存者页顶上（先选地方再选人，联机时房主定） |

两个方案共有的：
- AFL 只有一种世界（联邦六州），没有世界类型、预设、数据包、游戏规则这些选项。
- 机能点条 7 格：白色 = 默认的 3 级，琥珀 = 自己加的，虚线的 6、7 级只能靠成长涨；读数写成"舒适负重 33 kg · 干活耗耐力 ×0.9""耐力 100 · 恢复 ×1.00"。
- 特质：六组（身体、代谢、冷热、动静、手上、成长），每个写"花 N"或"给 N"；背景给的带锁、写"背景"；选中的有亮边框，悬停的只有浅底色；互斥的变淡。
- 剩余点数在右上，旁边写来源（"背景 3 · 负面特质 +1"）。
- 名字：账号名或自定义（V0 的起名界面并进来）。
- 剩余点数在右上；"开始"后不能再改。
- 示例状态：林区住户（预算 3，固定特质耐寒、干惯粗活），力量 3 → 4（花 1），选了轻手轻脚（花 1）和怕热（给 1），剩 2 / 4；鼠标停在不显眼上。
- 背景（8 个）：普通人 6 点、林区住户 3、卡车司机 4、便利店店员 4、退伍军人 2、猎人 3、护士 4、汽修工 4；后 4 个是第二批，数值都是草案。

## 5. 游戏里和图不一样的地方（P2b）

- 代码：`client/survivor/AflNewWorldScreen`、`AflSurvivorSetupScreen`、`SetupCanvas`（480 × 270 画布）。
- 新的世界：没有"更多"，底下是"允许作弊：开 / 关"（2026-10-18 前叫"允许命令"）开关和"原版设置…"链接（打开原版界面本身，给要改世界类型、游戏规则、数据包的人）。卡片上加了一行"地区：哥伦比亚联邦"。选了还没接上的场景时写一句说明。主按钮是"下一步"，进幸存者页；幸存者页的主按钮是"创建世界"（2026-10-17 用户：加点在建世界之后、进世界之前）。
- 幸存者页：特质前面是小色点，不是徽章图标；点数写"−N"/"+N"（不写"花 N"/"给 N"）；冲突的特质是红框，不变淡；右上写"缺点给的点 n / 4"，不写点数来源；背景每行只写名字和点数，固定特质在选中展开后列出。

## 6. 中文文案（2026-10-17 用户反馈）

用户：「某些东西不符合中文语序，一般这种短句，现代人不习惯在后面加句号」「地点描述也有点太书面了」。参考 [蚂蚁设计文案规范](https://ant.design/docs/spec/copywriting-cn)：

- 标签、标题、按钮、输入框提示、悬停提示单独出现时不加句号；一条说明里有两句时用逗号连起来，结尾也不加句号。
- 用口语、常用词：不用"某处""就此""不可更改"这类书面说法（"野外某处"→"荒郊野外"，"旅程就此结束"→"死了就结束"，"不可更改"→"不能改"）。
- 中文和数字、英文之间空一格（"最多 3 人""−1"），中文和中文之间不空格（"力量开局 +1""和体弱冲突"）。
- 说明写感觉，不写内部数值（"有枪械经验"，不写"从 Lv 3 起步"）。
