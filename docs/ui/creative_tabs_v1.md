## 规则

- 除弹壳外，每个已注册的 AFL 物品恰好出现在一页（共 125 个；2026-09-28 新增 BR51 弹鼓；2026-09-30 Material System V1 删除 20 个物品、6 个材料换成新 ID、新增 1 个方块物品）。
- 五种弹壳（9×19mm、7.62×51mm、12.7×55mm、12 Gauge、.50 AE）不进任何标签页，只保留开发检查用的注册，可用 `/give` 获取。
- 三种道路标线（白色边缘线、黄色边缘线、白色车道分界线）此前不在任何标签页，现已放进建筑方块页。它们的 step connector 变体没有物品，不受影响。
- 枪械按类别排序，暂不拆成“手枪 / 步枪”独立页：每类只有 1～3 把，单独成页太空。某一类超过一整行（9 把）时再拆。
- 新增物品时，放进对应页的合适位置，并同步更新本表。
