# 生存 HUD V1

状态：**已实现（2026-10-03，2026-10-04 改为嵌套排版），`compileJava --offline` 通过，没有实机验证**（排版改版前的一排五环版本用户在游戏里看过）。

原版的红心、饱食度、护甲、氧气泡和坐骑血量全部隐藏，由一组圆形仪表代替。体温表盘保持原样，用户的原话是"现在的体温 HUD 很不错，留着"。

排版的来历：
1. 用户先选了"五环一排"（方案 A）。
2. 实机看过后，用户参考冬季救援，觉得太散、像现代扁平 UI，于是改成平滑风格的"收紧成一组"（方案 1，像素风的方案 2 没选）。
3. 按冬季救援的做法，外侧两个小仪表改成开口朝内的半环。
4. 半环两端延伸，接到大环上（用户 2026-10-04）。

## 排版

一组，居中在屏幕中线，像括号一样一层层往外套。从左到右：

| 位置（GUI 像素，相对屏幕中线） | 仪表 | 代码 |
|---|---|---|
| −34.16 | 耐力半环 "("，图标在开口里；水下时外面再套一层氧气弧 | `stamina/ClientStaminaHud`（氧气弧在 `SurvivalVitalsHud`） |
| −21.39 | 生命环：心形和生命数字在环里，顶上是护甲弧 | `client/SurvivalVitalsHud` |
| 0 | 体温表盘，外面一圈深色金属边框 | `temperature/ClientTemperatureHud` + `TemperatureDial` |
| +21.39 | 饥饿环（骑坐骑时换成坐骑血量） | `SurvivalVitalsHud` |
| +34.16 | 口渴半环 ")"，图标在开口里 | `thirst/ClientThirstHud` |

尺寸和位置都在 `client/SurvivalHudLayout`，所有数值都是原尺寸乘 `SCALE`。

**整体比例和位置**
- **整体放大**：`SCALE` = 1.15，只放大几何。表盘里和生命环里的半号数字仍按整数屏幕像素绘制、不跟着放大，以免发虚。历史：原尺寸偏小 → 第一稿 1.25 → 用户说略大、趋势箭头碰到负重条 → 1.15。
- **圆心高度**：所有仪表的圆心在屏幕底边上方 48 GUI 像素（体温 V1 时是 55）。整组最低的是表盘下方的趋势箭头（圆心下 15.2 像素，约在底边上方 32.8），离负重条（经验条位置，底边上方 24–29 像素）约 4 像素。
- **宽度**：整组宽约 ±41.5，水下加上氧气弧约 ±43.3，在快捷栏（±91）以内。

**表盘**
- 底面半径 10.925。
- 外面一圈深色金属边框，宽 1.32：上亮下暗，从 `#5A5E64` 渐到 `#2A2C2F`；外沿是 `#1A1B1D` 的暗边，再外一圈淡色描边。不亮、不反光。

**生命 / 饥饿环**
- 外半径 8.625，环宽 2.415，格间隙 0.98。
- 圆心离表盘边框 0.52，紧贴表盘。
- 环里有深色半透明底面（透明度 0.45），外沿一圈淡色描边。

**耐力 / 口渴半环**
- 外半径 7.015，环宽 1.78，圆心在图标上。
- 开口朝向中间。两端越过竖直方向 47.7°（`CRESCENT_REACH`），总共约 275°：这个角度由几何算出，恰好让半环的外角碰到大环的描边，所以改尺寸后也会自动接上。
- 填充从下端开始往上涨。
- 图标大小 5.4，下面垫一个半径 3.34、透明度 0.35 的深色圆底。
- 半环内外两条边都有淡色描边。

**护甲弧**：在生命环顶上，半径 9.66–10.75，从顶部左偏 45° 开始，跨 70°。避开了半环的尖端，也避开了腕表那段气温弧。

**氧气弧**：在耐力半环外面，半径 8.05–9.14，从左下 196° 到左上 344°，共 10 格。

**描边**：所有描边都是 `#E8E4DC`，透明度 0.28，宽 0.3，学冬季救援，让暗处也看得清轮廓。

**物品名和动作栏**：这组显示时整体上移 26 像素（`TEXT_LIFT`），落在表盘气温数字之上。

## 各仪表

**生命**
- 每颗心一格（2 点生命），从顶上顺时针填充；半颗心就是半格。
- 环里上方是心形，下方是生命数字（半号原版字体，向上取整，一直显示，用户定）。
- 颜色（环和心形同色，数字是米白 `#F0ECE4`）：
  - 正常红 `#CC4A42`；
  - 中毒绿 `#8FA83C`；
  - 凋零灰 `#5E5E5E`；
  - 冻僵冰蓝 `#9FD8F2`（优先级同原版：中毒 > 凋零 > 冻僵）。
- **吸收**（金心）：金色 `#E2BE4A` 接在生命后面。总量超过最大生命时，环会多出格子，和原版多出一行金心一样，最多 30 格。
- **受伤**：环在 0.06 秒内降到新值；掉的那部分先留一道浅色残影（`#F2E6DE`，透明度 0.8），0.45 秒后在 0.3 秒内退掉。回血在 0.15 秒内长上去。
- **低血**：生命 + 吸收 ≤ 4 时（原版红心抖动的条件），环和心形以每秒 1.6 次的节奏闪动。
- **辐射病**：II / III / IV 期把约 30% / 60% / 100% 的已填充格染成辐射色 `#A09666` / `#88805A` / `#7A7454`。挑哪几格沿用原来"辐射心"的算法：按玩家 UUID 固定，生命不变时不跳。原来的 `client/RadiationHeartOverlay` 和 `textures/gui/radiation/heart_*.png` 已删除。
- 一直显示。

**护甲**：生命环顶上的细弧，连续填充，0–20 点，银灰 `#B4BCC4`。有护甲时 0.25 秒淡入，没有时淡出；数值变化 0.15 秒过渡。

**饥饿**
- 10 格（每格 2 点饱食度），琥珀 `#D39A4C`；有饥饿效果时变成 `#92A84A`。
- 不显示数字，也不显示饱和度（用户定）。
- 一直显示。
- **骑坐骑时**（原版会把饱食行换成坐骑红心）：这个环换成坐骑血量，每颗心一格（最多 30 格），颜色 `#C28A57`，图标换成马蹄铁。

**氧气**
- 耐力半环外的分格弧，10 格（对应原版 10 个气泡），浅蓝 `#92D4F2`，从下往上填。
- 出现条件同原版气泡：眼睛在水里，或氧气不满。0.25 秒淡入淡出；数值 0.15 秒过渡。
- 氧气耗尽（开始溺水）时，空格的底色按每秒 1.6 次的节奏闪红。

**耐力**：一直显示（用户 2026-10-03：不然会缺东西；以前回满 2 秒后淡出）。颜色规则见 `../gameplay/stamina_system_v1.md`。

**口渴、体温**：行为不变，只是外形和位置跟着这组调整。见 `../gameplay/thirst_system_v1.md`、`../gameplay/temperature_system_v1.md`。

## 显示条件

- 生存 / 冒险模式显示。
- 不显示：创造、旁观、F1 隐藏 HUD、枪械附件视图。
- 原版的生命、护甲、饱食、氧气、坐骑血量覆盖层（`VanillaGuiOverlay` 的 `PLAYER_HEALTH`、`ARMOR_LEVEL`、`FOOD_LEVEL`、`AIR_LEVEL`、`MOUNT_HEALTH`）一律取消（`client/AflHudEvents`）。

## 绘制

`client/AflGauge`：
- **一张贴图一个仪表**：每个仪表的环带、圆弧、圆底和图标，按真实像素逐点计算（带抗锯齿的距离场），画进它自己的一张动态贴图，每帧贴一次。
- **按需重画**：显示内容（填充量、颜色、透明度）没变时直接复用上次的贴图，只有动画进行中才重画。
- **环带**：可以是整圆，也可以是任意起止角的弧（半环、护甲弧、氧气弧），两端有抗锯齿；可以连续，也可以分格，分格间隙按沿环的长度计算。
- **其它元素**：实心圆（大环底面、图标底），图标可以上下偏移（生命环的心形）。
- **半环**的画法统一放在 `SurvivalHudLayout.crescent()`，耐力和口渴共用。
- **数字**用 `client/AflHudText.half()`，从 `ClientTemperatureHud` 抽出来，体温读数和生命数字共用。
- **已删除的旧画法**：`AflRingIcon.draw` 逐像素调用 `fill`，已删除。`AflRingIcon` 只保留图标距离场和单独画图标的 `glyph()`，口渴提示框还在用。

`client/AflHudEvents`：
- 取消原版覆盖层。
- 抬高物品名和动作栏：在 `Pre` 里压一层位移，在 `Post` 里弹出。这一步放在最低优先级、只处理没被取消的覆盖层，保证有 `Pre` 就有对应的 `Post`。

## 以后：数值超出原版上限时

现在生命超过约 15 颗心后，格子会变得很细，超过 30 颗心就只能看比例。护甲超过 20 只显示"满"。

如果以后加了能突破上限的东西，计划改成"叠圈"：每格固定 1 颗心或 2 点护甲，一圈 20 点，超出部分在同一圈上换色叠一层，再加一个小的"×2"。生命数字已经在显示真实值。

## 需要实机验证

- 整组的大小、间距、半环和大环的衔接，在 GUI 缩放 2–6 下的效果；
- 表盘边框、描边在亮处和暗处的观感；生命数字是否清楚；
- 受伤残影、回血、低血闪动、中毒 / 凋零 / 冻僵的颜色；
- 吸收（金苹果）多出的金色格子；辐射病染色；
- 护甲弧、氧气弧的淡入淡出，溺水时闪红；
- 骑马时饥饿环换成坐骑血量；
- 物品名、动作栏抬高后的位置；
- 和其它模组的 HUD 是否冲突。
