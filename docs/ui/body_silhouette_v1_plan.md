2026-10-20 用户：「把我们背包里面的角色渲染，改成类似塔可夫的角色轮廓，然后对应的部位受伤了，玩家把鼠标放上去可以得到 hint，也就是推荐使用什么医疗物资（如果没有最好的，就推荐次要的）」。

同一天第二轮，用户看了塔可夫式的平滑轮廓：「我觉得做minecraft的风格可能会好一点，你这做的真的是塔科夫了」；选 B（玩家皮肤），「不要屁股对着屏幕」。第三轮：「按照推荐开始做 / 这些文字都用本地化，要考虑中英文不同的长度超出边框的问题」，第 5 节的问题都按推荐定。

**状态：已实现（D 分支 `feature/survival-health-v1a`，已提交，未合并进 master），编译通过，没进游戏看过。** 代码 `client/inventory/BodySilhouette.java`，接在 `AflInventoryScreen#bodyMap`。概念图 `design/ui/body_silhouette_v1/`（`concept_b_skin.png`、`concept_b_skin_hover.png`；A 纯色方块和第一轮塔可夫式轮廓被否）。和 [骨折与夹板 V1](../gameplay/fracture_splint_v1_plan.md)、V2 设计稿里"人物页加身体页签"（[survival_health_v2_design.md](../gameplay/survival_health_v2_design.md) 第 8 节）是同一件事，这里放在背包里。

## 1. 画面

- 背包左栏两列装备格中间原来的 3D 玩家模型（`renderEntityInInventoryFollowsMouse`）换成**平面的 Minecraft 人物**，从正面看（屏幕左边是身体的右边）：头 8×8、胸和腹各 8×6、手臂和腿 4×12（细手臂皮肤手臂 3 宽），一个皮肤像素 = 4 个画布单位（`BodySilhouette.U`），人物左上角在画布 (48, 29.5)，每块四周内缩 0.45 留一条暗缝。3D 模型还在人物页（`AflCharacterScreen`）。
- 画法：读玩家自己的皮肤（`getSkinTextureLocation`），每块画正面的底层和外层（64×64 皮肤的正面 UV：头 8,8 / 外层 40,8；胸 20,20 / 20,36；腹 20,26 / 20,42；右臂 44,20 / 44,36；左臂 36,52 / 52,52；右腿 4,20 / 4,36；左腿 20,52 / 4,52），着色压暗到 0.62，再盖一层灰（#7E7E7A，不透明度 0.5）：颜色基本褪掉，形状还是自己的。
- **2026-10-27 改成纯白（用户 2026-10-28 实机 PASS）：** 用户："把E这个界面的人物模型改成白色的贴图，这样就不用管衣服的状态了"。不再读皮肤，每块直接填白色（#E8E6E1，不透明度 0.9），穿什么衣服人物都一样；伤色、伤口痕迹（`WoundSkin`）、徽章、悬停框照旧画在白色上面。上面这条"读皮肤再压灰"的画法已不用。
- 有伤的部位整块叠一层颜色（不透明度 0.42），按最要紧的那处伤：
  - 红 #B8443C：要尽快处理（没清洁的感染 / 化脓、没固定的骨折）；
  - 棕 #A86A3A：需要处理但不急（没处理过的抓伤）；
  - 琥珀 #D9A441：处理过、正在好（清洁或包扎过的抓伤、清洁过的感染 / 化脓、已固定的骨折）。
- 伤在哪块就在那块上放一个徽章（`StatusBadgeHud.drawBadge`，和 HUD 徽章同一个画法、同一个图标，半径 3.6 画布单位；手臂和腿放在上半截），同一部位多处伤只放最要紧的一个。徽章在画布缩放之后按 GUI 坐标画（`BodySilhouette#badges`）。
- 鼠标停着的部位描一圈边。
- 两只脚下面"右 / 左"（英文 R / L），按腿宽缩小字号放得下；再下面一行"生命值 72 / 100"，太长时缩小字号（最宽 120 画布单位）。

## 2. 鼠标停在部位上

提示框和背包现有提示同一个样式（深色圆角框、z 400、靠鼠标右下，出屏时翻到左边或往上挪）：

1. 部位名（右腿）。没伤时下一行"没有受伤"。
2. 每处伤（最要紧的在前）：名称（要尽快处理的用红字）和处理情况 / 效果（和 HUD 徽章同一行字）。
3. 下面是建议，每项一块：左边物品图标，中间做法和一行原因（暗色），右边"身上有 / 身上没有"：
   - 身上有的最好的一项加琥珀边框；
   - 比它更好但身上没有的放在上面、变暗（图标也压暗）；
   - 更差的不列。
4. 一个都没有时最后一行"身上都没有：……"，给一句不靠物品的办法；已经处理好的伤只写还要做什么（比如"已固定，大约还要 2.5 天长好"）。

"身上有"= 物品栏（含快捷栏、手上）+ 胸挂、背包、口袋里的格子（`PlayerGrids.stacks`），不算地上和箱子。不推荐"现做"：配方重构之前不给任何东西加配方（用户 2026-10-20），以后有了配方可以加一档"能现做"。

**中英文长度**：提示框文字宽度最多 220 GUI px 或屏幕宽的 2/5（取小），超过就换行（`Font#split`）；右边"身上有"那一列的宽度先扣掉，做法和原因在剩下的宽度里换行，图标那一块的高度随行数变高。脚下的"右 / 左"和生命值按宽度缩小字号。

### 2.1 推荐表（V1，写在 `BodySilhouette#wound` / `#fracture` 里）

| 伤 | 最好 | 次选 | 都没有 |
|---|---|---|---|
| 抓伤，没处理 | 医用酒精（降低感染风险） | 绷带（愈合更快） | 抓伤自己也会好，留意别感染 |
| 抓伤，只清洁过 | 绷带（愈合更快，不包扎也行） | — | 不处理也行 |
| 抓伤，只包扎过 | 医用酒精（降低感染风险，不清洁也行） | — | 不处理也行 |
| 抓伤，清洁并包扎 | — | — | 已清洁并包扎，等它自己愈合 |
| 感染，没清洁 | 医用酒精（清洁后才会好转） | — | 先去找医用酒精 |
| 化脓，没清洁 | 医用酒精 | — | 先去找医用酒精，清洁之前没法包扎 |
| 感染 / 化脓，清洁过没包扎 | 绷带（好转更快） | — | 已清洁，正在好转 |
| 感染 / 化脓，清洁并包扎 | — | — | 已清洁，正在好转 |
| 骨折，没固定 | 夹板（愈合快 4 倍左右） | — | 先别乱动，找个安全的地方休息 |
| 骨折，已固定 | — | — | 已固定，大约还要 N 天长好（(1 − 进度) × 愈合天数） |

## 3. 和塔可夫不一样的地方（用户按推荐定）

- **不做分部位血量。** 部位只用来标伤在哪、给建议，后果还是走伤口 / 骨折各自的规则；生命值还是一个数。
- 伤有部位（`health/BodyPart`，存档和同步都带）：
  - 感染者抓伤：按权重随机（手臂各 30、胸 15、腹 10、腿各 7.5、头 0：抬手挡的多），以后有命中部位判定再改。
  - 摔落骨折：腿、手臂各自随机左右。
  - 旧存档里没有部位的伤口：读档时随机给一只手臂。
- **不做拖拽治疗**：医疗用品还是拿在手里按右键，服务端自动选部位；身体图点了没有反应。以后可以加"拖到部位上 = 对这个部位用"。
- 绷带、酒精的动作还是处理前臂：伤在头、胸、腹、腿时，动作照旧在一只前臂上做，用完后纱布出现在伤的部位（腿上画，头和躯干 V1 不画）。

## 4. 已知限制

- 只看自己：推荐在客户端算（`ClientHealth` + 身上物品），不发包。
- 部位徽章和 HUD 用同一张贴图缓存（按 `body_<部位>` 区分）。
- 头、胸、腹上的包扎不画在身上。
- 没进游戏看过：皮肤压灰的深浅、伤色、徽章大小、提示框在小窗口和英文下的换行都要实机看。

## 5. 验收（实机，由用户做）

1. 打开背包：左栏中间是自己皮肤的正面、压灰，脚下"右 / 左"，下面生命值。换细手臂皮肤看手臂宽度。
2. `/afl health wound scratch`、`/afl health fracture right_leg` 等：对应部位上色、放徽章；鼠标停上去看提示和推荐（身上有 / 都没有）。
3. 切英文看提示框换行、R / L、生命值有没有超框；GUI 缩放调大调小各看一次。
