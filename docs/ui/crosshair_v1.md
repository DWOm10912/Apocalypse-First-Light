## 1. 规则

| 情况 | 画什么 |
|---|---|
| 第一人称，空手或拿普通物品 | 一个很淡的小点（不透明度 0.3） |
| 对着能操作的东西（出现交互提示，且提示来自看着的东西，不是手上的物品：门、炉盖、开关、地上的物品、铲子 / 镐够得着的地方等） | 小点变亮（0.9），0.12 秒淡入淡出 |
| 拿枪腰射 | 圆点 + X 形四条斜线，斜线离中心的距离就是扩散估计（原来的动态准星算法不变）；疾跑时整体变淡 |
| 腰射命中 | 四条线闪白（打身体）或闪红（爆头），同时往外伸长一点，5 / 6 tick 内褪回 |
| 举枪瞄准 | 不画准星，用瞄具；命中时只画 X（从 7 收到 4 GUI 像素，白 / 红，渐隐） |
| 第三人称（环绕镜头步行） | 同样的点，亮档（这时它就是瞄准点） |
| F3 调试界面 | 原版的三轴坐标照旧 |
| 旁观模式 | 不画 |
| 攻击冷却条 | 不画（准星下和物品栏旁边两种都删），以后随冷却系统重做 |

"能操作"直接沿用 `WorldInteractionHint`：它这一帧找到的提示是从看着的方块 / 实体 / 地上物品来的（或铲子、镐的提示），就算对着；手里拿着弹匣、五金盒这种和看哪里无关的提示不算。准星画在提示之前，所以用的是上一帧的结果。

## 2. 外形（帧缓冲像素下的平滑图形，GUI 缩放不影响清晰度）

用户 2026-10-27 第一版小样：像素台阶锯齿太重，要真正平滑的线条和圆形。现在每个图形都是带抗锯齿边的矢量图形（`AflCrosshair#capsule`：圆头线段，圆点是长度为 0 的线段），边缘在 1 个像素内从实到透明，相当于按像素覆盖率淡出，不用贴图。

- 一个单位 = 1 080 行屏上的 1 个像素，按屏幕高度等比缩放（2160 行是 2，720 行是 0.75 下限）（`AflCrosshair.unit()`）。
- 点：半径 1.75 单位的圆，外面一圈 1 单位宽的深色描边（不透明度为点的 0.45），亮天空、雪地上也看得清。
- 斜线：四条 45° 的圆头直线，外面一圈 1 单位、不透明度 0.35 的深色描边。离中心的距离和长度沿用 `gui/layout/native_crosshair.json`（GUI 像素 × GUI 缩放，沿对角线量），最近不小于点外 3 单位；线宽 = thickness × GUI 缩放 × 0.6（默认值、缩放 4 时约 2 像素），夹在 1.5–5 单位之间。
- 颜色：点和线 `#E8E8E2`；命中白 `#FFFFFF`、爆头红 `#FF3B30`（和原来的命中标记一样）。

## 3. 实现

- `client/AflCrosshair`：常驻点、亮度淡入淡出，以及点和 X 的平滑画法（三角形 + 1 像素渐隐边，位置颜色着色器；枪的准星和环绕镜头共用）。
- `mixin/client/GuiCrosshairMixin`：`Gui#renderCrosshair` 开头直接取消，换成 `AflCrosshair.render`；不取消 CROSSHAIR 这一层叠加，所以挂在它 Post 上的交互提示、接线面板、发电机拉绳时间条照常画。F3 开着时让原版画三轴。
- `client/WorldInteractionHint`：新增 `aimed()`。
- `weapon/client/NativeDynamicCrosshair`：`render(g, partial, hit, head)` 画圆点 + X，`hitOnly` 画举枪瞄准时的命中 X；扩散估计、射击后的扩张和回落都没改。
- `weapon/client/NativeGunCrosshair`：命中标记并进 X（腰射时斜线本身变色、伸长；举枪瞄准时单独画 X）。拿枪时仍然整层取消 CROSSHAIR（和以前一样，拿枪时不显示交互提示）。
- `client/camera/OrbitCamera`：第三人称的点换成同一个点。
- `client/ui/AflHotbarOverlay`：删掉物品栏旁的攻击冷却环。
- 没改：`native_crosshair.json` 的数值、`NativeCrosshairConfig` 的字段和范围、`NativeCrosshairMotion`（`src/dev/tests/NativeCrosshairTest.java` 照样适用），任何命中、伤害、扩散数据。
