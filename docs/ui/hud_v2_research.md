## 2. 参考游戏怎么做（只学做法，不照搬画面）

- **《森林》（The Forest）**：一组小指标放在角落：生命红、能量蓝、护甲黄，饥饿是胃的图标，温度是温度计图标。画面中间完全不挡，没有小地图和指南针。VR 版把 2D HUD 换成手腕上的智能手表。
- **《森林之子》（Sons of the Forest）**：右下角一个圆形组件，正中是小地图。左边一道弧是生命（红），右边一道弧是耐力（蓝）。护甲是生命弧外面的分段弧，一段一件。口渴、饥饿、休息是三个带绿色圆环的小圆，排在耐力弧上方。耐力弧的外框表示"活力"，就是现在能用的耐力上限，由饥饿、口渴、休息、体温决定：又冷又湿时，耐力有一段变淡、暂时不能用。低血时画面变灰，冷、湿和拾取的消息出在左下角。交互提示用实心表示按一下、半透明表示长按。
- **《非生物因素》（Abiotic Factor）**：左下角，一条生命条加一个人物小像，每个身体部位按伤势变色（蓝 → 黄 → 红）。饥饿、口渴、疲劳是小指标；快见底时屏幕上出一个**倒计时**，告诉你必须马上吃 / 喝 / 睡。状态效果不放在主界面，在健康页里看。
- **DayZ**：右下一排小图标（口渴、饥饿、体温、血量、生命），平时白色，变差变黄，危险变红，接近危险时闪。生病、湿、流血等状态图标只在有的时候才出现在同一排。
- **Rust**：几条细横条叠在一起，每条一个图标加一个数字。状态（冷、辐射、建筑权限、舒适度）在条上面以小条目出现，有才显示。
- **Green Hell**：没有常规 HUD，需求都在左手的手表上，抬手才看。有玩家抱怨，希望能选"屏幕上也显示"。
- **趋势研究**：Meyer 和 Homsani（2026）统计了 2014–2025 年 30 款年度游戏提名作：HUD 越来越少常驻、越来越按情况显示。玩家觉得越简洁越有沉浸感；是否清楚主要取决于熟不熟悉。他们说的是"按状态选择性显示"，不是"没有 HUD"。反面意见：生存游戏把状态全藏起来，玩家就看不到饥饿、口渴这些反馈，玩法会断掉。

## 3. 从参考里得到的规则（三套方向都遵守）

1. **画面中间留空**：常驻的东西都在角上，中间只有准星和交互提示。
2. **分常驻和按需**：生命、耐力常驻；饥饿、口渴、体温、负重变小或者有事才放大；状态（冷、湿、辐射、超重、药水效果）**有才出现**，用同一种小条目。
3. **一种警告语言**：正常是暖白 / 本色，注意是琥珀，危险是红并闪；快要出事时给倒计时或者明确的字（"脱水"），不只靠颜色。
4. **数字少而准**：生命、体温、负重给数字，其余只给量。
5. **一套样式**：沿用 [AFL 浮层样式](afl_overlay_ui_style_v1.md)：深色半透明底、暖白细描边、抗锯齿圆角、琥珀只用于选中和注意、AFL 字体。没有毛玻璃、没有像素斜面、没有奇幻边框。
6. **右下归装备，左下归身体**：武器、弹药、盖革、仪表盘在右；身体状态在左。绑定栏留在底部中间但变矮。

### 6.2 需求小圆（饥饿、口渴、负重）

在组件右上方，离圆心 36.5，角度 22° / 52° / 82°（从正上方顺时针）。

- 平时：半径 5.2、环宽 1.4、透明度 0.8，只有图标。
- 变大（0.25 秒过渡）：半径 7.4、环宽 1.8，不透明，图标下面带数字。
  - 饥饿：饱食度 ≤ 6 时变大，数字是饱食度 × 5（百分比）；≤ 3 时变红。骑活的坐骑时换成坐骑血量 + 马蹄铁，不带数字。
  - 口渴：低于口渴线（30）时变大，数字是百分比；低于脱水线（15）时变红。
  - 负重：代替原来经验条位置的负重条。满圈 = 重度超载比例（`severe`），颜色跟档位（灰 / 黄 / 琥珀 / 橙 / 红），数字是 kg（一位小数）。档位不是"轻松"时一直变大；轻松时负重变化（≥ 50 g 或换档）后变大 3 秒。坐车、或者负重惩罚关掉时整个小圆藏起来。

### 6.4 Alt 状态卡片

**2026-10-17 关掉了**（用户："现在按alt会触发那个详细状态栏界面，感觉如果玩家经常误触alt会有点烦，详细状态目前最好不要显示，后面我们做一个生命监测仪（高级手表）再说"）：`client/StatusBadgeHud.DETAILS_CARD = false`，卡片不画，"状态详情"键也不注册（按键设置里没有它）。代码和下面的排版都留着，以后挪到生命监测仪上。下面描述的是关掉之前的样子。

按住"状态详情"键（`key.apocalypse_firstlight.status_details`，默认**左 Alt**，可在按键设置里改）时，徽章那一列淡出，换成一张卡片（0.12 秒淡入，左边 6，宽 158，底边在需求小圆上方）：

- 标题"状态"，右上角：气温（只有戴着能读气温的东西时，和表盘的规则一样）和湿度百分比。
- 数值行（图标、名字、细条、数值）：生命、护甲、耐力、饥饿、口渴、体温（双向条：往左冷、往右热；写感觉——寒冷 / 失温… / 偏冷 / 舒适 / 偏热——和趋势箭头 ↑↓，只有能读核心体温时才带 °C 数字）、负重（kg + 档位）。
- "效果"：所有徽章各一行，徽章 + 名字 + 一句效果 + 剩余时间；没有就写"没有"。
- 开着别的界面时不响应。

### 6.5 聊天栏上移

左下角原来是聊天栏。`StatusBadgeHud.Chat` 在 `CustomizeGuiOverlayEvent.Chat` 里把聊天栏往上推到组件和徽章列上面（随徽章数量变化，0.2 秒过渡）。只在没有打开界面时推；打开聊天框时聊天回到原版位置，点链接不受影响。

### 6.6 枪械 HUD（2026-10-17 改成 V2 B 装备区，没进游戏看过）

枪重做合并后，右下装备区按概念图 B 做了（`weapon/client/NativeGunHud`）：射击模式胶囊 + 短枪名一行，弹匣大数字 / 备弹一行；剩 1/4 以下琥珀，空仓红 + 换弹键帽和"换弹"，换弹中"换弹"字下一条琥珀进度条；剪影和竖线去掉；武器列表固定在它上方。细节、字号、配置见 `../native_guns/native_gun_hud_layout_v1.md`。

### 6.7 删掉的旧代码

- `stamina/ClientStaminaHud`（耐力半环，overlay `stamina_ring`）、`weight/ClientWeightHud`（负重条，overlay `weight_bar`）删除；`thirst/ClientThirstHud` 不再注册 HUD，只保留水滴图形、水的颜色和提示框组件。
- `temperature/ClientTemperatureHud` 不再自己注册，改成 `OVERLAY` 常量给身体组件调用。
- `client/AflHudEvents` 里给 V1 用的抬高物品名 / 动作栏、给负重条让位的逻辑删除。

### 6.8 网络

徽章要在客户端知道冷热阶段和湿度，`temperature/TemperaturePackets.State` 加了 `coldStage`、`heatStage`（各一个字节）和 `wet`（float）；阶段变化或湿度变化 ≥ 0.02 时重发。`AflNetwork.PROTOCOL` 51 → **53**（D 工作区的布娃娃未提交改动占了 52，合并时要再定一个号）。

### 6.9 没做的

- 绑定栏改成 17 格大小、用完变淡留位；
- 交互提示的长按进度圈和"做不了"变暗（`WorldInteractionHint` 现在没有长按的概念）；
- 盖革计数器面板的位置没动。

### 6.10 需要实机验证

- GUI 缩放 2–6 下组件、小圆、徽章的大小和间距，左下角会不会被别的东西挡；
- 徽章名字滑出、闪圈、限时白弧（脱水原来带倒计时，2026-10-20 起改成白弧）；
- Alt 卡片的排版、中英文长度、左 Alt 和别的按键是否冲突；
- 聊天栏上移的位置；
- 负重小圆的唤醒 / 隐藏；坐车时的样子；
- 低弹药琥珀和换弹提示的位置。

### 6.11 HUD 卡顿（2026-10-17）

用户反馈：创造模式 125 fps，切到生存模式后约 80 fps；耐力条一涨一落时掉帧更明显。原因有两个：

1. 仪表动起来的时候，每帧都要在 CPU 上逐像素重画整张贴图再上传（`client/AflGauge`，GUI 缩放 5 时生命环 7.5 ms、耐力 5.7 ms、身体底盘 7.3 ms）；
2. 体温表盘（`temperature/TemperatureDial`）一直在动（呼吸、趋势箭头），HUD 不动时也每秒在 CPU 上重画 30 次。

改法：两者都改到 GPU，每帧逐像素画，公式不变（`client/AflGaugeProgram` + 着色器 `afl_gauge`；`temperature/TemperatureDialProgram` + 着色器 `afl_temperature_dial`）。仪表的图标画成白色贴图，绘制时着色，只有形状、大小或位置变了才重画。着色器没加载时退回原来的 CPU 画法。截图对比：GPU 和 CPU 画出来的一样。

测量（测试客户端，用户存档副本，2560 × 1440，RTX 3080 Ti，`RainPerfProbe` 的 hud 模式，见 `docs/rendering/rain_v1.md` 3.1；同一次运行的四个阶段之间可以比较，不同次之间场景不同）：

| 情况 | 不开光影 | 开光影（Aureveil） |
|---|---|---|
| 生存 HUD，仪表不动（表盘照常动） | 218 fps | 115 fps |
| 所有仪表每帧都在变（新画法） | 257 fps | 112 fps |
| 所有仪表每帧都在变（旧 CPU 画法） | 28 fps | 28 fps |
| F1 隐藏 HUD | 539 fps | 138 fps |

改之前（只改了环带、表盘还在 CPU 上的那次）开光影是 74 fps（HUD 显示）对 118 fps（隐藏）。JFR：开光影、仪表不动时，渲染线程花在 GUI 上的采样从 12%（大头是 `TemperatureDial.fill`）降到 2%。剩下的 HUD 开销约 1.4 ms，主要在 GPU 一侧。

还没做：寒冷徽章的雪花图标光栅化一次约 2.3 ms，徽章滑入滑出时位置的小数部分在变，会连续重画几帧。用户 2026-10-17 实机确认：不卡了。
