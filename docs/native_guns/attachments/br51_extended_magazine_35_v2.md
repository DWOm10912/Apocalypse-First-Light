# BR51-01 35 发扩容弹匣 V2（Pure Mesh + PBR）

2026-09-28 重置。只做了离线生成、离线校验和离线渲染；这次没有改 Java，因此没有编译。**未实机验证。**

这一版只替换资产，玩法不变：Registry ID、名称、Tooltip、容量（20 → 35）、槽位、维护台装拆、换弹事务与溢出返还都沿用 [35R V1](br51_extended_magazine_35_v1.md)。

## 几何（408 triangle-equivalent：139 Quad + 130 Triangle）

| 部件 | 来源 | 三角面 |
| --- | --- | --- |
| `mag_body` | 20 个主体 cube：上段直筒、供弹口（含两块 15° 唇片）、倾斜 5° 的主体、两侧各 3 道加强筋 | 268 |
| `mag_floorplate` | 4 个底板 cube：底板块和下方拉环 | 120 |
| `mag_id_marks` | 新增：两侧识别条 | 20 |

- **规则**：与 BR51 标准弹匣（`mag_standard` / `hu2`）完全相同。弹匣倒角 0.035、底板 0.04；去台阶容差：主体 0.07、底板 0.05。
- **切块结果**：主体沿 x 切 3 层、沿 z 切 1 层（唇片）；底板沿 x 切 3 层；没有丢弃的层，也没有退化成方盒的 cube。
- **外形尺寸**：x −1.25 … 1.25，y −9.0515 … 1.7051，z −2.6093 … 1.7239（弹匣本地坐标）。
- 底板下方露出的一圈主体、拉环形状都是原作者设计，照原样保留。

## 识别件

- 两侧各一条低饱和黄褐色小条，和 P9 扩容弹匣 V2 使用同一种识别颜色。
- 位置：底板块侧面的后段（拉环后方），竖直居中。
- 尺寸：长 0.85、高 0.16；表面凸出 0.02，底部埋入 0.01，四周 0.012 倒角。
- 随底板一起倾斜 5°。

## 材质（Base Color / `_s` / `_n`）

| 材质 | Base Color | 平滑度（平面 / 倒角） | F0 | 备注 |
| --- | --- | --- | --- | --- |
| 弹匣钢材（涂层黑钢） | 39,41,43 | 82 / 132 | 24（倒角 255） | 倒角高光 +20；明暗分区沿用原作者面板布局 |
| 底板（黑色聚合物） | 25,26,27 | 62 / 72 | 10 | 单一色调，不做分区 |
| 识别件（muted tan） | 124,106,74 | 62 | 10 | 倒角高光 +8 |

- 弹匣钢材和底板两项与 BR51 V2 生成器的材质表逐项相同，校验脚本会直接比对。
- 贴图密度同为每单位 16 像素，所以面板比例、高光条宽度与枪上的标准弹匣一致。256 图集只能放下每单位 10 像素，因此用 512。
- 明暗分区：参考 V1 贴图（即 BR51 旧图集）的面板布局，只迁移明暗，不迁移色相，所以旧的黄色底板不会带进来。
- 高光条只画在沿像素轴走向的长边上，短于 0.35 的倒角条逐渐淡出，避免远看闪烁。
- 法线：平面法线，只带 AO（孔壁、下表面）。

## 挂载与动画兼容（离线校验）

| 检查 | 结果 |
| --- | --- |
| 替换骨骼 | `mag_standard`、`reload_mag_standard`、`empty_old_mag_standard`，`subtree=true`，三者共用枢轴 `[0, 9.41883, 4.52607]`；模型原点就是这个枢轴 |
| 动画 | 换弹、检视动画只驱动这三根骨骼的上级（`magazine`、`mag_out`、`empty_old_mag`），底板 `hu2` 没有任何动画，替换后不会丢动作 |
| 动态顶弹 | `7`、`3`、`reload_bullet_7`、`reload_bullet_3` 都挂在 `bullet` / `reload_bullet` 下，不在任何被替换的子树里，装上扩容匣后顶弹照常显示 |
| 供弹口 | 最高点 y 与 V2 标准匣相同（均为 1.7051）；枢轴以上部分的 x（±0.75）和 z 范围与标准匣一致（误差 < 0.03） |
| 顶弹锚点 | `7`（−0.25, 1.3226, −0.3872）与 `3`（0.3125, 1.0101, −0.3872）都在供弹口范围内 |
| 装上后的间隙 | 比标准匣长 2.125（最低点 −6.9265 → −9.0515）；待机姿态下，这段多出的长度范围内没有任何枪体几何 |
| 其他 | 共享工具库抽出后，BR51 生成器 `--check` 仍然逐字节一致（BR51 输出没有任何变化） |
