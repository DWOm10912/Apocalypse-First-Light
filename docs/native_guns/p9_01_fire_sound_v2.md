## 2. 电平

按开头 0.1 s 的 RMS 比较（短文件用 EBU 积分响度会被门限算成 −70，不能用）：

| 文件 | 峰值 | RMS（0–0.1 s） |
|---|---|---|
| 旧开火 | −2.2 dBFS | −10.7 dB |
| 旧消音 | −2.6 dBFS | −14.8 dB |
| 新开火 | −1.0 dBFS | −12.5 dB |
| 新消音 | −6.8 dBFS | −17.5 dB |

- 新录音原本消音比开火还响约 4 dB（RMS −10.9 对 −14.8），所以重新配平：消音比开火低 5 dB。
- 新开火比旧的低约 2 dB：旧文件压缩得多（峰值和 RMS 只差 8.5 dB），新录音保留了枪声的起音（差 11.5 dB）。
- 用户问"现实中消音器的声音不会小很多的吧"：对。手枪消音器在射手位置大约降 20–30 dB（约 160 dB 降到 130 dB 上下），仍然是很响的一声，不是电影里的"噗"；P9-01 用 9×19mm，常见的 115–124 gr 弹头从手枪射出约 350–370 m/s，略高于音速，弹道上的音爆也还在（2026-10-24 改正：原文误写成 Five-seveN 的 5.7×28）。所以文件里只低 5 dB，消音靠音色区分（更闷、低频余响），不靠大幅减音量。
- 传播距离和感染体听觉没改：开火声传 64 格（噪声半径）；消音枪声传 16 格（`NativeGunNoise.SUPPRESSED_SOUND_RADIUS`，用户 2026-10-09 定）、噪声 3 格（`NativeSuppressorItem` 默认系数 0.05）。按点声源距离衰减，系数 0.05 相当于降 26 dB，和现实的降幅一致。

## 4. 第二版：贴耳播放，加响（2026-10-19）

用户实机反馈两点，原因是同一个：

- **环绕声**：开火声在开枪那一刻按服务端的眼睛位置放成一个固定的 3D 声源。听的人是镜头（第一人称有走路晃动，环绕镜头离人物 4 格），声源总偏在旁边一点，一转头就在左右耳之间甩。旧文件是立体声，MC 不给立体声定位，所以以前听不出来。
- **声音小**：单声道放在正中，每只耳朵只有 −3 dB；第一版文件本身又比旧的低约 2 dB。按 50 ms 窗口的峰值 RMS，开火（单声道 −11.6，听感约 −14.6）和拉套筒（立体声 −13.2）、插弹匣（−15.5）差不多响。

改法：

- 开枪的人自己听到的开火声贴耳播放：不放进世界、不衰减（`RangedSound.play` 多一个"发声的玩家"参数，`RangedSoundS2CPacket` 多一个 `relative`，协议 58 → 59；`client/RangedSoundInstance`）。别的玩家照旧按位置和半径听。所有枪都走这条路，不只 P9。
- 贴耳播放时，如果 `sounds.json` 里有 `<id>_near` 就放它：P9 新加 `p9_01_fire_near`、`p9_01_suppressed_near`，内容和单声道版一样，左右声道各一份，两只耳朵都是满电平。字幕和原事件相同。
- 开火加响：单声道原始录音推 9 dB 后限幅到 −1 dBFS（起音 0.1 ms、释放 5 ms，只压最开头约 20 ms 的尖峰）；消音推 −4 dB，仍比开火低 5 dB。用压缩器托枪身声试过，2 ms 起音会放过尖峰、压低后面，反而更小，没用。

| 文件 | 声道 | 峰值 | 峰值 RMS（50 ms） |
|---|---|---|---|
| `p9_01_fire.ogg` / `_near` | 1 / 2 | −0.7 dBFS | −9.0 dB |
| `p9_01_suppressed.ogg` / `_near` | 1 / 2 | −4.2 dBFS | −14.0 dB |
| 旧开火（2026-09-08，立体声） | 2 | −2.2 dBFS | −10.7 dB |
| 拉套筒 `slide_action` / 插弹匣 `magazine_in`（立体声，没改） | 2 | | −13.2 / −15.5 dB |

自己开枪时，开火比旧版响约 1.7 dB，比拉套筒响约 4 dB，比插弹匣响约 6.5 dB。如果还嫌不够，下一步可以把换弹和手上动作的声音整体调低几 dB，不再把枪声压得更狠。

其他枪的开火文件还是立体声：自己开枪也会贴耳播放（不受影响），但别的玩家听到的立体声仍然不定位、不随距离变小。这是原来就有的问题，等各枪重做时一起改成单声道 + `_near`。

## 5. 滑套复位声（2026-10-19）

用户实机反馈：滑套复位声"结束得太快，听起来有点怪"。测旧文件 `p9_01_slide_release.ogg`（0.352 s，立体声，2026-09 版）：

- 0.08 s 有一下咔哒（−3 dBFS），真正的套筒撞击在 0.25 s（−2.8 dBFS）。动画的声音关键帧都放在套筒回位前约 20 ms（按"撞击在文件开头"放的），所以画面上套筒已经到位，撞击声还要再等约 0.23 s。
- 撞击后 0.1 s 文件就结束，结束时峰值还在 −26 dB，尾音是硬切的。

改法：换成同一把枪拉套筒录音 `p9_01_slide_action.ogg` 里的回位撞击（0.200–0.520 s，这一段有完整的自然衰减），开头 4 ms、结尾 50 ms 淡入淡出，重采样到 48 kHz，降 4.7 dB 和旧文件的峰值 RMS 对齐（−17.3 dB，50 ms 窗口）。

| | 长度 | 撞击位置 | 峰值 | 结尾 |
|---|---|---|---|---|
| 旧 | 0.352 s | 0.25 s | −3.0 dBFS | 峰值 −26 dB，硬切 |
| 新 | 0.320 s | 0.02 s | −4.1 dBFS | 0.1 s 后低于 −47 dB，0.3 s 静音 |

用到这个声音的所有动画关键帧都没改，新文件的撞击落在套筒回位帧 ±25 ms 内（v3 `reload_empty` / `reload_empty_ads` 1.015 → 回位 1.033；`first_draw` 0.615 → 0.65；v2 检视三下 0.845 / 1.265 / 2.135）。拉套筒 `slide_action`、退套筒 `slide_back` 没改。旧文件备份在 `scratchpad/p9snd/old_ogg/`，也能从 git 取回。没进游戏听过。

现实里：P9 这类手枪打空后套筒挂在后面，插上新弹匣套筒**不会**自己复位，要拇指按空仓挂机解脱杆，或者拉一下套筒再松手。个别枪用力拍弹匣会被震得复位，但不是设计功能，不能指望。现在的动画是新匣拍到位约 0.12 s 后拇指按解脱杆，是熟练射手的做法。
