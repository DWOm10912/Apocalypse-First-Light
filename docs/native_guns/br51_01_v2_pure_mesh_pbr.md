## 几何重建方法

每个原几何组按以下规则重建（组名沿用作者原名，mesh 部件与组同名）：

- **Slab**：沿挤出轴按厚度把 cube 分层。
  - 挤出轴：无旋转或绕 X 旋转 → X（侧面轮廓）；绕 Y → Y；绕 Z → Z（截面）。复合旋转的 cube 退化为定向盒。
  - 每层把投影足迹栅格化，然后追踪轮廓，再用 Douglas-Peucker 化简，使 cube 台阶变成直线。
  - 化简后按材质做真实倒角挤出：
    - 0.04：机匣、下机匣、护木、枪托、底板
    - 0.035：弹匣
    - 0.025：瞄具、枪机
    - 0.02：导轨
    - 0.05：握把
  - 薄件（厚度小于 0.3 或面积小于 0.12）不倒角。
  - 被更宽层完全包住的隐藏层删除。
- **Lathe**：八边形拼成的圆件改为真圆柱：
  - 枪管 20 段
  - 导气管、套环 16 段
  - 枪机面、瞄具鼓 12 段
- **消焰器**：带内孔的回转体（16 段）加 4 个齿。
- **握把区**：`bone6` 侧面轮廓中的握把区域（z 8.0–15.6，y 2.8–8.55；含握把后跟和扳机护圈）拆成独立聚合物部件 `bone6_grip`。其他方向挤出的面按面心落在同一区域也改用握把材质（修正了后跟和握把正面残留的金属色）。
- **弹匣三态**：`mag_standard` / `hu2` 各有两份逐顶点相同的副本：
  - `reload_mag_standard` / `reload_hu2`
  - `empty_old_mag_standard` / `empty_old_hu2`
  - 三态都是 Mesh，显隐沿用 Phase 1 的缩放关键帧。
- **显示弹药**：BR51 网格本身不含弹药几何。2026-09-28 起，顶弹由通用动态弹药系统在空骨骼上绘制，见下文“动态弹药（顶部两发）”。原记录如下（历史）：
  - 弹匣顶部两发、枪膛一发、换弹新匣两发全部不生成几何。
  - 骨骼 `bullet → 2 → 3 / 7`、`bullet_in_barrel`、`reload_bullet → reload_bullet_2 → reload_bullet_3 / 7` 保留为空骨骼，动画通道不变，留作将来动态弹药的挂点。
- **源中移除**（均为 `export=false`、从不导出，动画 animator 无关键帧，可从 `38b6c66` 恢复）：
  - 旧 TaCZ 参考红点 / 激光组 `sight`，含 11 个组、134 个 cube。
  - 参考前握把 `grip_default`，46 个 cube。
  - 独立步枪红点资产 `rifle_red_dot_01` 早已提取，不受影响。（2026-09-28 红点另行重置为 Pure Mesh，BR51 `sight_slot` 改为 `mount_interface rifle_optic_rail`、`mount_offset [0, 0.0625, -1.11375]`，`ads_center` 不变；见 `attachments/rifle_red_dot_01_pure_mesh_v1.md`。）

色调定位为黑钢。

- 第一版每个材质只有一个平色，在 Blockbench 里看起来像白模。
- 第二版为了去掉白模感把金属提亮到 58–81，又偏白。
- 第三版把金属压回石墨 / 黑钢范围（32–52）。
- 2026-09-28 贴图整理后（当前）：
  - 再暗一档：金属 28–49，枪机 76–81，聚合物 25–34。
  - 大面积表面全部按**涂层**处理：F0 24（约 0.09），光滑度 76–96。原因是之前这些面是 F0 255 金属，光影下大块侧板会整面反射天空而发灰发亮（用户实机反馈“枪身偏亮”）。
  - 只有枪机组是裸金属；倒角条的 F0 为金属，表现磨出金属的边缘，在光影下勾出轮廓。
  - 部件之间靠小幅明度差、倒角高光和光滑度区分。

- **分区明暗（原枪械师色调）**：
  - 每个参考 cube 面取其在 Phase 1 贴图中 UV 区域的平均亮度。新 Mesh 上每个像素取所在参考面的亮度，与本材质中位亮度相比，得到系数 `(L/Lmat)^0.5`，限制在 0.90–1.10。
  - 只迁移明暗，不迁移色相，所以原黄色底板不会带过来。
  - 只作用于金属。注塑聚合物（枪托、握把、底板）保持单一色调。
  - 原贴图的像素噪点被平均掉，每块面板保持单一干净色调。
- **边缘**：
  - 倒角条是整条统一的高光色（数值见上表），光滑度升到倒角值，F0 为金属。
  - 长度不足 0.35 的倒角条，高光按长度比例减弱；长度不足 0.35 的硬边不画高光带或压暗。原因是短而亮的小段在远处会闪成碎点。
  - 大面沿硬凸边（大于约 25°）有 2.2 px 高光带，沿硬凹边有 3 px 压暗（最多 28%，同时写 AO）。
  - 只有与贴图轴对齐的边才画高光带或压暗，斜边不画，避免锯齿。
- **孔壁**：
  - 镂空孔的侧壁压暗到 74%，AO 195，光滑度 −20。
  - 朝下的端面 AO 225。
- **变化与限制**：金属只有 ±1.2% 的低频明暗漂移和 ±5 的光滑度漂移，没有逐像素噪点，也没有画上去的反射或高光。
- **`_s`**：R 光滑度，G F0（255 金属 / 24 涂层 / 10 聚合物），B 0，A 255。当前像素占比：涂层 61%、金属 21%（枪机和倒角条）、聚合物 17%。
- **`_n`**：RG 平直法线 128/128，B 为材质 AO，A 255。
- **PBR 接入**：与 Blackridge / P9 相同，不需要代码。GeckoLib 绑定 `textures/item/br51_01.png`，Iris / Oculus 按 LabPBR 约定读取同目录的 `_s` / `_n`。Complementary 需要把材质模式设为 labPBR。
- **无黄色 / 金色**：
  - 底板在三种状态下都是黑色聚合物。
  - 原来唯一的暖色是弹药的黄铜 / 铜色，已随显示弹药一起移除。

## 检视的拉机动作与声音（2026-09-29 重做，未实机验证）

用户希望检视结尾的拉机声和空仓换弹最后的拉机声一样，所以这次改动作去配合空仓换弹的 `reload_empty_4`，而不是给原来的动作配新声音。

- **`reload_empty_4` 的结构**（1.047 s）：
  - 0–95 ms 是几下轻微咔哒：手抓住拉机柄、拉到后位；
  - 100–160 ms 是主撞击：枪机复位；
  - 240 ms 还有一下轻响，之后是低音量的手部杂音。
- **动作**：右手仍在 3.375 s 搭上拉机柄。枪照原作者的动作翻转、在 3.83–4.21 s 静止展示，其间枪机保持在前位、不再提前拉开。展示末尾一次快速拉放：
  - 4.100 → 4.225 s 拉到后位（4 单位，先慢后快，2.1475 处与原动作的缓入比例相同）；
  - 停 0.01 s；
  - 4.235 → 4.260 s 放回，枪机复位。
- **声音**：`reload_empty_4` 放在 4.149 s。服务端按 `ceil(t × 20)` 取 tick，所以它在第 83 tick（4.15 s）响起。
  - 前面的轻咔哒落在拉到后位前后，主撞击落在 4.25–4.31 s，与 4.26 s 枪机复位对齐。
  - 原作者在 4.2917 s 的枪身反冲和 4.25 → 4.2917 s 的镜头震动，正好跟在撞击后面。
- **右手**：全程跟着拉机柄，相对枪机的位置恒定，已离线逐帧核对。4.26 s 放开后，在 4.36 s 离开拉机柄（原为 4.333 s），4.458 s 回到原来的位置。
