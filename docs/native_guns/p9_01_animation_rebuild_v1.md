> 空仓动画后续已被 [P9 空仓特殊换弹重做](p9_01_empty_reload_special_rebuild.md) 替代。下文 V1 空仓抓取路径、旧/新共用骨骼、关键帧总数及几何计数为当时快照；当前为右手主导左向 snap 甩旧匣、左手另取新匣的独立动作，最新数据与验收边界见专项报告。其他动作仍沿用本页方案。

本轮重新编排第一人称动作，BR51-01 仅作动画语言参考；80% 是风格目标，不是可计算的完成度。没有复制 BR51 关键帧，也没有调整玩法平衡。

## BR51 动画语言审查

来源：当前 `src/main/blockbench/br51_01.bbmodel` 和运行时 `animations/br51_01.animation.json`。主驱动是 root；gun_and_righthand 让枪与主握手保持控制关系，mag_and_lefthand 组织操作手/弹匣，lefthand 再补局部腕部方向。以旋转组织大动作，位移控制深度和操作弧线；Catmull-Rom、抓取停顿、反向小幅回摆和分层收尾共同去除机械匀速感，关键帧数量本身不是质量来源。

| BR51 状态 | 时间与组织 | P9 借鉴方式 |
| --- | --- | --- |
| static_idle | 静态握持关系提供稳定基线 | 保留瞄线，只在左腕做极轻微循环 flex，手掌接触点固定 |
| shoot | 机械件约 .0167s 后退、.0833s 复进；root 的位置峰值约 .05s；旋转与位移回摆不同步，长尾至 .8333s | 保留 P9 .14s 射击时长，滑套先动、整体极小响应后到，避免复制步枪幅度或与 Native recoil 重叠放大 |
| reload_tactical | 左腕 .2333s 进入抓取，1.9667s 释放、2.0667s 回握，root 约 2.5333s 收稳 | 准备、接触、拔出、转弧、插入、回握分段；操作手与枪体错峰、末段小 settle |
| reload_empty | 抓取/换匣后，1.8667–2.0s 保持机械接触，2.0333s 拉动/释放；枪体有交替衰减的 roll 响应 | P9 自己的同侧套筒后部接触点；手跟随 slide 局部轴，保留 1.65s 游戏时长 |
| draw | .1–.2667s 为主抬枪，约 .3667s 旋转 overshoot，.6333–.7333s 收稳 | P9 短促抬枪与转腕，操作手微滞后，不套用长枪起始姿态 |
| put_away | 腕部位置约 .0667s 先退、旋转约 .1333s 跟随，root .1667–.3333s 主转动，.4333s 离场 | 保留原版装备时钟，用独立短收枪曲线代替直线下降 |
| inspect | 枪、弹匣/操作手、机械操作分层；后段接触/拉动/释放再回位 | P9 当前无 inspect，未虚构新检查功能 |
| static_bolt_caught | 静态保持机械后定 | P9 empty_idle 明确保留套筒、准星及照门后定位置 |

BR51 历史 shoot 中不对应现有机械骨骼的轨道未复制到 P9；两种枪的运行时、骨架和弹匣结构没有互换。

## 新源与运行时接线

- 源仍为 `src/main/blockbench/p9_01_v03_8_fire_slide_cleanup.bbmodel`。新增零姿态的 `p9_handling`，层级为 `fp_root → p9_handling → weapon_root`；枪和左右 hand_motion 仍共同挂在 weapon_root 下。原有语义名称、握持点和参考臂尺寸保留。
- 8 条重新创作的动画、4249 个新关键帧；没有复用旧关键帧 UUID。分段形状保持 Hermite 曲线烘焙成数值线性关键帧，默认 100 Hz、快速射击/装备主驱动 200 Hz。Blockbench 和 Gecko 使用同一数据，不依赖未知 Molang 曲线。
- `static_idle` 2.4s 循环；`fire` / `fire_last_round` .14s；`reload` 1.30s；`reload_empty` 1.65s；`empty_idle` 1s 静态循环。只有 idle/empty_idle 循环，其余为一次性动作。
- `draw` / `put_away` 各 .15s 是资源归一化采样区间，实际显示仍由 Minecraft 原有 equip progress 决定，不新增服务器切枪锁或实际装备时长。
- `P901Presentation` 在 P9 第一人称骨骼遍历中临时采样装备姿态，遍历后恢复，避免污染其他渲染上下文；切出时使用原版保留的旧 P9 stack，切入等待前一物品下降。普通射击/换弹仍由原 Gecko 触发控制器播放。
- `animations/p9_01.equip.json` 由同一源的 draw/put_away 导出，不在 Java 中复制关键帧。`tools/export-native-gun.mjs` 常规及 animations-only 导出均同步这份文件；客户端资源重载重新读取。
- P9 的 NativeGunItem.animationAsset 仍保持 null；没有改成步枪分支，没有改动公共射击、装弹结算或音效事件流水线。

## P9 操作节奏

| 动作 | 新设计 |
| --- | --- |
| 待机 | 左腕最大约 .11° 的微动；反算位置保持掌端原位，枪管/瞄线不随 idle 摆动 |
| 拔枪/收枪 | 共用枪+右手主驱动；平移与 pitch/yaw/roll 配合，操作手微滞后，拔枪末段轻微越位收稳 |
| 射击 | 套筒快速后退/复进、枪管轻响应、扳机动作；主驱动峰值约 .32°，仅作小辅助反馈，Native recoil 参数不变 |
| 普通换弹 | 枪体先转入操作姿态；左腕调整并抓底板，拔匣先沿插槽轴，脱离后才转弧，.95s 插入到位后分层回握 |
| 空仓换弹 | 起手明确后定；换匣后左手去同侧后部 serration，掌端随套筒局部前后轴走，释放后复进，1.65s 回 Ready |
| 空仓静态 | slide/front_sight/rear_sight/sight_anchor 保持同一后定位置；最后一发过渡到该状态 |
