# Silverwood 12 V3（左右并列双管）：模型、AFL 层级、动画

2026-09-29，已实现，离线校验通过。**未实机验证**：没有运行 runClient、GameTest，也没有在 Iris / Oculus 光影下看过。

- Java 只在第一轮（上下 → 左右改名）改过，那一轮 `compileJava --offline` 通过。
- 之后的几轮（银色机匣、木纹、膛内弹壳、动画、换弹时长）都没有改 Java，所以没有重新编译。

## 范围

- 把 Silverwood 12 从上下双管重做为**左右并列双管**（Side-by-Side，SxS）无击锤盒式枪机霰弹枪，方便开膛时看到膛内。
- **模型**：Pure Mesh、1024 Base Color 和 LabPBR `_s` / `_n`，通过 Hybrid Mesh V2 sidecar 输出。
- **层级**：AFL 原生枪械层级（Rig）。
- **待机姿势**：绑定姿态就是待机姿态。
- **膛内弹壳**：每膛一发实弹、一发空壳。
- **七条动画**：射击、拔枪、收枪、空膛换弹、单发补弹、检视，外加空的待机片段。动作参考用户给的 CoD Vanguard 双管视频，按本枪结构改编，见下文“动画”。
- **玩法**：只改换弹时长，见下文；其余不变。
  - 仍是 SEMI：每扣一次扳机只发射一管，先发右管、再发左管。
  - **单扳机（2026-10-06）**：原模型是前后两片扳机（真实并列双管常见的双扳机），但玩法是一个扳机按顺序打两管，用户把"霰弹枪有两个扳机"列为要修的问题。改成一片居中的扳机，和玩法一致。只改了模型，Java 和玩法不变；`compileJava --offline` 通过，没有实机看过。
  - ADS 参考点 `[0, 9.88, 3.5]`、eye_relief 0.4、缩放 0.45、腰射平移 `[3.6, -7.2, -12]` 都不变。新前珠顶在 y 9.885，正好落在原瞄准线上。
- **音效复用**：`silverwood_12_fire`、`_open`、`_eject`、`_shell_insert`、`_close`，时间点重新对齐到新动作。

### 设计参考

- **模型**：参考用户在 Blender 里打开的一把 SxS 猎枪（来源许可未知）。**只借鉴**比例、布局和材质划分，没有使用它的网格或贴图，模型由生成器从零建出。
- **动画**：参考用户给的 CoD Vanguard 双管视频，逐帧看过，只借鉴动作编排。

- 烤蓝钢件按 AFL 黑钢规则处理：涂层 F0 24，只有倒角是裸金属。
- **机匣为什么用银色**：机匣是用户选的例外。它是素面金属（F0 255），做成缎面：底色中灰，光滑度 135，不做镜面，避免光影包下大面积反光刺眼、发白。质感全靠 PBR 表现，不画图案。
  - 曾试过在两侧画卷草雕花，用户认为掉价，已经删掉（2026-09-29）。
- **弹壳配色**：与 12 Gauge 弹药资产一致，PBR 取值同 `tools/ammo-pbr.mjs` 的霰弹条目。
- **凸榫槽**：前伸是实心的，槽只是顶面上一块暗色区域。开膛时凸榫从这块暗区里转出来，看起来像从槽里出来。
- **没有防滑纹**：曾在握把和护木两侧画过防滑纹区，实机里看起来像一块污渍，已删掉（2026-09-29），木面保持素面。
- **UV**：
  - 车床件和放样件整块展开：一整根枪管、一整只枪托各是一块，接缝放在看不到的位置，枪托接缝在底部中线；
  - 挤出件沿用共享库的平面展开；
  - 看不到的面（埋在单体块里的管身、护木顶面、枪托两端等）只给 1/8 的像素密度；
  - 天际线装箱，所有岛统一密度 32.25 像素/单位（HR55 为 16），共 283 个岛。
- **渐变材质的接缝**：膛内和胡桃木的颜色随位置变化。它们的展开块做成矩形，岛的边界正好落在像素中心，所以接缝上的像素一定由面本身画出，不会露出填充色。其它材质按真实弧长展开，保留 V2 四边形。

## 动画

### 参考与改编

- **参考视频**（CoD Vanguard 双管）：
  - 空膛：开膛时把后膛转向镜头，往上一甩倒出两枚空壳，两发弹一起推进，甩合。按用户要求，倒壳改成先往左、再往下倒，不往上甩。
  - 单发：手指捏出那一枚空壳扔掉，塞一发，合膛。
- **本枪的区别**：本枪只有抽壳器（开膛时只把壳顶出 0.32），不会自动弹壳。
  - 空膛把枪带到左边再往下倒，让两枚空壳靠重力滑出。
  - 单发补弹用手捏：右管先发，空壳总在右膛，正好在右手一侧。

### 实现约定（`tools/silverwood-12-v3-animations.mjs`）

- **坐标与旋转**：Blockbench 源坐标；骨骼旋转 M = Rz·Ry·Rx（度）；位置是父级空间里的偏移。
- **导出**：运行时旋转的 x、y 和位置的 x 取反（同 Blackridge）。
- **显隐**：弹壳显隐用缩放 0/1 的步进键，缓动为 `afl_hold`。
- **开膛联动**：枪管绕铰链下折 36°。抽壳器随开膛角的平方后退，最多 0.32。开膛杆向右转 30°，合膛瞬间弹回。
- **分工**（按用户要求）：右手一直端枪握住握颈，所有装填操作都由左手完成。
- **右手**：挂在 `handling` 下，始终在握颈上。换弹时只跟着枪转一半的手腕角度（前臂保留 50% 的待机方向）。
- **左手**：挂在 `root` 下。
  - 握护木时，轨道按"枪管世界变换 × 待机时相对护木的位置"逐帧解出，所以开膛、倒壳、合膛时手都贴在护木上。检视时按下面的"手腕"方式握持。
  - 取弹、捏壳时，拳头放在弹壳底部的左下方（偏移 −1.7, −1.1, 0.25），弹壳从拳头右上边缘伸出去。前臂方向固定在屏幕空间：朝左下、略朝镜头 (−0.45, −0.86, 0.22)，所以手臂从画面左下方伸进来，后膛口保持可见。
  - 掌心朝向 (0.2, 0.6, −0.8) 是挑过的：让"握护木"和"托弹"两个朝向相差小于 150°，两者之间插值不会翻到另一边转。
- **新弹**：从画面外对齐到膛后 3.45，再被拇指推到底，有硬停。
- **空壳**：先沿枪膛滑出。离开时保留枪自身速度的一部分（倒壳 60%、手扔 80%），再加一个出膛速度；之后受重力下落（330 单位/秒²）并翻滚，出画后隐藏。
- **检视的手腕**：检视时两只手的位置仍跟着握把和护木，但前臂保留待机时的屏幕方向（右手 80%、左手 60%），枪在手里翻转，手臂方块不会甩进画面或被近裁剪面切掉。
- **欧拉角**：两手各选一个常量预旋转放在 `*_pos` 骨骼上，避开万向节锁；每个关键帧之间最大步进都在 6° 以内。
- **动作语言**：`go()`（预备、加速、硬停、阻尼回弹）和 `jolt()`（一两帧的机械撞击），与 Blackridge 相同。

### 膛口喷气没有接回

- 装填姿势下，膛口轴线与镜头方向只差 9°–35°，距离 0.3–0.7 格。
- 现有 Chamber Gas FX 的喷流（0.21 格/tick，行程约 0.5 格）会直接吹进镜头，所以两段换弹都没有加 `chamber_eject_fx` cue，喷气暂不触发。
- 需要另做一个更弱、会上飘的喷气样式后再接回，见 `chamber_gas_fx_v1.md`。
