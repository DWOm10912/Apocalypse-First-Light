# Suppressor Muzzle Gas FX V1

Status: follow-up outlet-alignment correction implemented in code; in-game visual acceptance is pending. The previous V1 particle was reported by the user as appearing to disperse away from the suppressor front.

Successful suppressed shots now spawn one `apocalypse_firstlight:suppressor_muzzle_smoke` particle instead of Vanilla `ParticleTypes.SMOKE`. The existing `NativeGunNoise.resolve` result selects the suppressed path, which continues to omit the ordinary muzzle flash. Unsuppressed effects are unchanged.

`AflParticles` registers the type and `AflParticleProviders` binds `SuppressorMuzzleSmokeParticle.Provider`. Its particle JSON references the existing `textures/particle/chamber_smoke_base.png`; the texture itself is unchanged. The particle uses a translucent sprite, warm light gray tint `(0.86, 0.85, 0.83)`, 0.045-block initial quad size, 0.20 initial alpha, four-tick life, 1.25× maximum size, and quadratic alpha fade. Initial velocity is 0.035 block/tick along the actual muzzle forward direction; horizontal velocity is multiplied by 0.78 per tick, while vertical velocity uses the same damping and gains 0.001 upward from the second tick. The sprite roll is fixed at zero. There is no collision physics or emissive burst. The previous larger, randomly rotated six-tick puff is obsolete.

The confirmed first-person snapshot still validates the shot, but the gas waits for the next actual gun render and is emitted from that frame's accessory exit. The earlier implementation spawned a world particle from the saved pre-shot position only after the server confirmation; normal viewmodel movement during that delay made it look detached. Third person uses the current `NativeGunFx.anchor` pose after `NativeMuzzleRendering.applyExit`. Both paths transform two points on the local negative-Z axis into world space, starting 0.008 block just ahead of the front-face locator. The legacy non-snapshot first-person path uses the same transformed-points method. A confirmed shot without a valid local snapshot retains its existing no-fabricated-FX behavior. Invalid/non-finite directions skip the particle. No suppressor length or P9-specific dimensions are hard-coded. Tracer and ordinary flash snapshot timing are unchanged.

Files: `src/main/java/com/antaurora/apofirstlight/registry/AflParticles.java`, `client/AflParticleProviders.java`, `client/SuppressorMuzzleSmokeParticle.java`, `weapon/client/NativeGunFx.java`, and `src/main/resources/assets/apocalypse_firstlight/particles/suppressor_muzzle_smoke.json`.

User visual checks remain: P9 with suppressor during hipfire and ADS bursts, different aim directions, third-person outlet alignment, Shader OFF, Oculus with Complementary, and Oculus with Sundial. Compilation cannot verify screen obstruction, particle atlas loading, or shader appearance.
