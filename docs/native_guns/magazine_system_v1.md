## 2. 规则

**弹匣是物品，子弹存在弹匣里。**
- `apocalypse_firstlight:p9_01_magazine`（P9-01 17 发弹匣，新物品）和 `p9_01_extended_magazine`（28 发扩容弹匣，原来只是配件）都能装弹。
- 弹数存在物品 NBT `AflMagazine.rounds` 里。空弹匣没有这个键，所以新弹匣和打空的弹匣是同一种堆叠，可以叠在一起。有子弹的弹匣不叠。
- 物品条显示弹数 / 容量。提示框多一行「弹数：%s / %s」。

**枪里装着一个弹匣，外加膛内一发。**
- 枪的 MAGAZINE 配件槽就是装着的弹匣。存进去的是不带弹数的那份，弹数算在枪自己的计数 `AflGunAmmo.ammoInMagazine` 里，这个计数包括膛内那一发。
- 容量 = 弹匣容量 + 1：标准弹匣 17+1 = 18，扩容弹匣 28+1 = 29。
- 槽是空的 = 没装弹匣，只能打膛内那一发，容量 1。
- 枪的数据 `native_guns/p9_01.json` 的 `magazine_slot.standard` 写着标准弹匣 `apocalypse_firstlight:p9_01_magazine`。有这个字段的枪就走这套规则（`NativeMagazines.system`）。
- 旧存档的 P9，以及刚做出来、还没在服务器上过一个 tick 的 P9：第一次 tick 时装上标准弹匣，并打标记 `AflGunAmmo.magazines`。原来枪里的子弹留在这个弹匣里。
- 开枪以后，只要还有子弹，就当作滑套把下一发推进了膛（chambered = 还有子弹）。

代码：`weapon/NativeMagazines.java`、`NativeGunAmmo#capacity / initialize`、`NativeGunActions`（开火后上膛）。

## 3. 换弹

- **只找胸挂和口袋**（`PlayerGrids` 的 RIG、POCKETS）。背包、快捷栏、主物品栏里的弹匣都不算。这是所有快速动作的通用规则（[物品栏网格](../ui/afl_inventory_grid_v0_plan.md) 3.1 两层规则，用户 2026-10-20 确认）：背包里的东西只能打开物品栏去拿。
- 找的是同一把枪能用的弹匣里子弹最多的那个，而且要比枪里这个多（同样多时先用胸挂里的）。有几只弹匣时不看格子的先后，总是挑最满的；空弹匣不会被换上。找不到就不能换弹，换弹键改为取下弹匣（第 3.1 节）。
- **背包里有更满的弹匣、身上没有时**（2026-10-20，`NativeMagazines#inBackpack`；用户截图：背包里一只满的扩容弹匣和一只空的 17 发，按 R 换不上）：按换弹键不换弹、也不取下弹匣，动作栏提示「弹匣在背包里」（`hud.apocalypse_firstlight.gun.magazine_in_backpack`，Magazine in backpack）；枪打空时 HUD 也显示这一句，不带按键图标（按键没用）。用户最早的说法就是"背包里面没有任何弹匣的时候"才取下弹匣。
- 换弹动作照旧（战术换弹 / 空仓换弹，熟练度三档）。弹匣在动作的「弹匣插入」那一刻（`presentation.mag_in_tick`，P9 是 18 tick）才交换，这时重新找一次，开始换弹时不预留。
- 换下来的弹匣**保留它剩下的子弹**：
  - 和换上去的是同一种弹匣时，放回新弹匣原来的格子；
  - 否则按捡东西的顺序放（口袋、胸挂、背包）；
  - 放不下就掉在地上。
- 膛内那一发留在枪里：枪里剩 3+1，换上 15 发的弹匣，结果是 15+1。
- 换弹时，枪的骨骼显示的是真实的弹匣：
  - 开始换弹时，枪上记下出去和进来的弹匣及各自弹数（`AflGunAmmo.swap`）；
  - 结束或中断时清掉。
- 枪里没装弹匣时换弹（取下弹匣以后再插回去）：换弹动作里旧弹匣的 `<枪>_magazine_release`、`<枪>_magazine_out` 两声不放，画面上出去的弹匣本来就不画（第 5 节）；检视时没装弹匣，四个弹匣声都不放（`NativeGunActions#magazineCues`，用户 2026-10-20："把弹匣重新插入枪械，会额外播放弹匣弹出的声音，这是不可接受的"）。
- 创造模式（2026-10-20 起）：和生存一样，只换胸挂和口袋里更满的真实弹匣，换下来的弹匣照样回到身上。以前创造模式直接把枪里的弹匣装满，所以从来没有弹匣出来。压弹在创造模式下仍然不消耗子弹（第 4 节）。

代码：`NativeMagazines#canReload / beginSwap / swap / endSwap`、`NativeGunActions#load`。

### 3.1 取下弹匣（2026-10-20）

- 条件：胸挂和口袋里没有比枪里更满的弹匣（`canReload` 为假），背包里也没有（`inBackpack` 为假，2026-10-20 起），枪里装着弹匣，而且这个弹匣没装满（`NativeMagazines#ejectable`）。这时按换弹键（默认 R）不换弹，而是把弹匣取下来。
- 取下的弹匣带着它剩下的子弹，**拿在手上**（`Loadout#toHand`）：
  - 放进「手」这一格（快捷栏第 4 格，`HotbarRoles.HAND_SLOT`），并选中它；
  - 枪留在原来的枪位（手枪在枪套位）。枪原本在「手」这一格时，先按原来的规则把枪放回去；
  - 「手」这一格原来有东西时，先把它放回原处；放不下就提示「放不下」，弹匣改为按捡东西的顺序放（口袋、胸挂、背包），再放不下就掉在地上；
  - 创造模式和旁观模式没有这些规则：放进第一个空的快捷栏格并选中，快捷栏满了就按捡东西的顺序放。
- 膛内那一发留在枪里：取下后 P9 是 0+1，还能开一枪。
- **动作**（2026-10-20 第二轮，用户："换弹完全没有动画"）：
  - 第一人称剪辑 `unload`（滑套在前）/ `unload_empty`（空仓挂机），1.3 s，`tools/author-p9-01-v3-native-animations.mjs` 的 `UNLOAD` 写进 `animations/p9_01_v3_native.animation.json` 和 `src/main/blockbench/p9_01_v3_native.bbmodel`：枪像检视弹匣那样抬起转向左手（0–0.3 s），拇指按卡笋（0.35 s），弹匣落进左手（0.38–0.52 s），左手拿着弹匣往左下出画面（0.55–0.85 s），枪随后收到下方（0.62–1.0 s）；
  - 剪辑里的 `camera` 骨骼走导演镜头的抖动层（`NativeCameraBoneConsumer`）：抬枪、按卡笋的轻顿、收枪下沉；
  - 第三人称动作 `gun/p9_01_unload` / `gun/p9_01_unload_empty`（`tools/author-p9-01-reload-actions.mjs`，1.05 s）：同样的节拍，左手接住弹匣带到腰前（`bone:pelvis`），枪回胸前预备位；逐帧检查通过（手离目标最多 0.29 px，腕弯 34°，扭转 26°，道具离躯干最少 1.23 px）；
  - 服务器开一个动作会话（`NativeGunActions#unload`），第 21 tick（1.05 s，`UNLOAD_SWAP_TICK`）弹匣才交到手上，这时枪已经出画面；这之前切枪、死亡、换维度都会中断，弹匣留在枪里；
  - 弹匣交到手上引起的换手不再触发枪的 `put_away`（剪辑里已经收过枪）；第三人称照常播放回枪套动作。
- 声音：剪辑自己的 `p9_01_magazine_release`（0.35 s）、`p9_01_magazine_out`（0.39 s）、`p9_01_put_away`（0.62 s），由服务器按剪辑时间放。`NativeMagazines#eject` 自己不再出声。没有这个剪辑的枪：立即交到手上，放 `<枪>_magazine_out`。
- 拿到手上以后右键就能压弹（第 4 节）。切到别的格子时，弹匣按「手」的规则放回网格；也可以在物品栏页面里自己放。
- 装满的弹匣不取下：没什么可压的。

代码：`NativeMagazines#ejectable / eject`、`inventory/grid/Loadout#toHand`、`NativeGunActions#request`（换弹分支）/ `#unload`；剪辑名还要在 `NativeCameraBoneConsumer`（镜头骨骼）、`NativeGunAds`（取下时放下瞄准）、`NativeMagazineRoundRendering`（拔出的弹匣按真实弹数画最上面一发）、`SkeletonGunStance`（第三人称动作）、`AflItems`（P9 的剪辑列表）里认得 `unload`。

## 4. 压弹

- 主手拿着空的或没装满的弹匣，**右键任何地方**开始压弹，再右键停止。按住右键时连发的使用包（5 tick 内）不算新的一次点击。
- 每发 1 秒（`NativeMagazineLoading.ROUND_TICKS = 20`），在每一秒的第 13 tick（`PRESS_TICK`，0.65 s）压进去。这正好是动作里拇指把子弹压进弹匣口的时刻。
- 子弹来源：身上任何地方的散装子弹（9x19mm），包括快捷栏、主物品栏、口袋、胸挂、背包。先从原版物品栏拿，再从各个格子拿。创造模式不消耗子弹。
- **能走路**。下面几种情况会停：疾跑、弹匣离开主手（换了快捷栏、丢掉）、弹匣装满、身上没有子弹了。
- 弹匣上记着开始压弹的服务器时间 `AflMagazine.loading`，跟着物品同步，所有客户端按同一个时钟播放动作。物品在其他地方留下的旧标记，下一次物品 tick 时清掉。手持提示：没在压弹时显示「压弹」，压弹时显示「停止」，按键是使用键（默认右键）。

### 4.1 压弹声（2026-10-20）

用户先试过一条录音里按编号要 7 个声音，结果漏音效（"一条出的话，会漏音效"），所以改成每次只生成一个声音。取弹声（从口袋摸出一发）用户决定先不做（"取弹先不做，这个不好做"）。

| 声音 ID | 文件 | 来源 | 处理 |
|---|---|---|---|
| `apocalypse_firstlight:p9_01_mag_load`（3 个随机） | `sounds/weapons/p9_01/p9_01_mag_load_1.ogg` | `E:/Download/压弹1.wav` | 取 0.795–1.0 s：咔哒声在 0.82 s；前面 0.06–0.17 s 那段很轻的摩擦声离得太远，没要 |
| 同上 | `p9_01_mag_load_2.ogg` | `压弹2.wav` | 取 0.34–0.62 s：这条里有两下，第一下在 0.37 s |
| 同上 | `p9_01_mag_load_3.ogg` | `压弹2.wav` | 取 0.885–1.0 s：第二下在 0.93 s |
| `apocalypse_firstlight:p9_01_mag_load_last` | `p9_01_mag_load_last.ogg` | `最后几发.wav` | 取 0.74–1.0 s：0.70–0.78 s 弹壳滑进去、0.79 s 咔哒，前面留了滑动的尾巴 |

- 每段都转成单声道，峰值归一到 −3 dBFS，开头淡入 3 ms，结尾淡出 30 ms，转成 Vorbis q5。
- 录音都是 48 kHz 立体声，每条 1.0 s。
- `sounds.json` 里 `attenuation_distance` 设为 8，比普通声音传得近。字幕「弹匣：压弹」/「Round pressed into magazine」。
- **播放时机**：服务器把一发压进弹匣的那一刻（每一秒的第 13 tick），在玩家位置播放，`SoundSource.PLAYERS`，音量 0.8（`NativeMagazineLoading#pressSound`）。每段从咔哒声前 30–50 ms 开始，所以声音和压进去的时刻对齐。
- 弹匣最后 3 发（`STIFF_ROUNDS`）放 `_mag_load_last`（弹簧更紧的那一声），其余放 `_mag_load`。
- 声音 ID 按枪的 id 拼（`<枪>_mag_load`、`<枪>_mag_load_last`），没有注册就不放，以后别的枪有录音直接加。
- 不算感染者能听见的噪声。
- 切出来的 wav 和切割脚本在会话临时目录 `claude_magsnd/`，不在仓库里。

**动作 `gun/p9_01_mag_load`**（`player_actions/gun/p9_01_mag_load.json`，Blockbench 工程 `src/main/blockbench/player_actions/p9_01_mag_load.bbmodel`）：
- 1 秒循环（`loop: time`、`length: 1`），只动上半身（`mask: upper`），所以能边走边压。优先级 45，淡入淡出各 0.25 s。第一人称画自己的身体（`first_person: body`），低头就能看见手里的弹匣。
- 文件里按左手拿弹匣做（下面按文件写）。**游戏里弹匣留在取下它的主手**（2026-10-20 第四轮）：主手是右手时整个动作镜像播放（`SkeletonActions` 里 `mirror = 主手是右手`），右手拿弹匣、左手取弹压弹；主手是左手时按文件原样播放。镜像走通用动作镜像（`ActionPose`）：手的轨道左右互换，`bone:` / `chest` 坐标系的位置 x 取反，两个道具按自己的 x 对称面反射（`symmetry: "x"`，弹匣和子弹左右一样），所以弹匣不会翻成反面。
- 左手把弹匣拿在上胸前（`chest` 坐标系）：弹匣口朝上、往后倾 20°，弹匣前端朝左转 35°。左手掌心在弹匣左侧偏下的 `hold_l` 点。0.58–0.66 s 压弹时弹匣往下沉 0.35 px，0.85 s 回到原位。
- 右手一直跟着子弹的 `pinch` 点：
  - 0–0.08 s 从弹匣口抬起；
  - 0.08–0.30 s 伸到右腰前（`bone:pelvis`）取一发，子弹 0.30 s 才出现；
  - 0.36–0.55 s 弹头朝上斜着拿到弹匣口上方；
  - 0.55–0.65 s 弹底朝下朝后压进去；
  - 0.65 s 起子弹道具藏起来，改由弹匣自己画最上面那一发；
  - 拇指停在弹匣口直到下一发。
- **第一人称进出**（2026-10-20 第二轮，用户："凡是有第一人称额外动画的，都需要做镜头渐变"）：`first_person_pitch: 55`。压弹开始时导演镜头把视角在 0.45 s 内平滑压到至少 55° 向下（鼠标还能往下看，不能往上），停止时 0.45 s 抬回玩家原来看的方向；同时手里的弹匣模型 0.15 s 滑出画面，之后身体的手才接过来，停止后身体的手放下完（0.25 s）再滑回来。不会同时出现两套手（`client/skeleton/FirstPersonActionView`，`docs/rendering/first_person_body_v1.md` 3.5）。55° 是离线算的：弹匣在眼睛下方约 60–73°，55° 时落在画面中下部。
- 运行时：`client/skeleton/SkeletonActions` 在主手是正在压弹的弹匣时播放 `gun/<枪>_mag_load`。这个改动给通用动作路径加了按时间循环：`loop: time` 的动作按长度取模（`ActionPose.loopSeconds`），以前只有枪的姿势循环会绕回。
- 两个道具：
  - `player_props/p9_01_magazine.json`：手里的弹匣，点 `top`、`grip`、`base`、`hold_l`，`symmetry: "x"`。扩容弹匣用同样的点；
  - `player_props/9x19mm_round.json`：手指间的子弹，点 `base`、`mid`、`tip`、`pinch`，`symmetry: "x"`。`pinch` 在弹底后方 1.7 px、偏上 1.5 px：手掌在这里时，子弹正好露在指尖外面（掌心离手的末端 1.5 px，`GunStance.PALM_Y`）。
- 读数：
  - 两只手离目标 0 px；
  - 肘角 85°–98°，在胸前弯着；
  - 右手到腰前取弹时伸展比 0.95；
  - 腕弯和扭转都在门槛以内。
  - 镜像播放的读数和上面相同、左右互换：骨架 `rigs/afl_humanoid_v1.json` 左右完全对称（16 根骨头、腋下插槽成对，离线检查差 0 px）。离线求解器（`tools/blockbench/afl_rig.js`）本身不做道具镜像，没有单独跑镜像的逐帧检查。

## 5. 显示

## 6. 资源

## 7. 其他系统

- **维护台装卸弹匣**：
  - 换下来的弹匣带着它的子弹回到玩家身上；
  - 装上去的弹匣带着它的子弹进枪；
  - 不再有"多出来的散装子弹"；
  - 拔掉弹匣后只剩膛内那一发。
  - 代码 `AttachmentInteractionCore`。
- **重量**：没装弹匣的 P9 不再加默认弹匣的质量。弹匣物品按自身质量加子弹质量算。
- **旧存档**：P9 第一次 tick 时装上标准弹匣，原来的子弹留在里面（第 2 节）。
- **其他枪**：BR-51、HR-55、Silverwood 12 规则不变。
