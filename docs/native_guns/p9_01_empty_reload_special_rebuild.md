# P9-01 空仓特殊换弹重做

当前 `reload_empty` 为甩出旧匣、左手取新匣、插匣、手动复位滑套的独立动作；替代动画重做 V1 中共用旧/新弹匣骨骼的空仓路径。普通换弹及其他动画未改。

## 当前动作

| 时段 | 显示行为 |
| --- | --- |
| 0–0.40s | 保持空仓后定，枪与右手明显侧转、抬至操作位置露出退匣区域；左手离开支撑位取新匣，不去拔旧匣 |
| 0.40–0.48s | 右手主导左向加速甩动；旧匣切换到同几何、同贴图的临时显示骨骼，沿弹匣井局部轴退出，完全脱离前不独立旋转 |
| 0.48–0.84s | 在左向速度峰值附近释放，旧匣继承枪体平移、转腕与退匣运动的合成速度，向左下方飞离并自转；不跟随枪回弹，也不独立指定横向发射速度 |
| 0.56–0.78s | 右手与枪体反向收稳，左手送入新匣 |
| 0.61–0.95s | 新匣随左掌进入并插入到位；0.61–0.84s 新旧匣同时存在，旧匣继续向外、新匣向插槽收拢 |
| 0.95–1.23s | 插匣确认，左手短距离移动至同侧滑套后部接触点 |
| 1.23–1.39s | 掌端沿滑套局部前后轴轻带、释放；滑套复进 |
| 1.39–1.65s | 左手回支撑位，枪体与手腕收稳回 Ready |

右甩加幅度版已被用户录像 `QQ20260908-062256-HD.mp4` 的反馈否定：右前臂正对镜头遮住退匣区域，甩动不明显。旧方案 .455s 已到转腕极值，.51s 才自由脱离，速度没有继承枪体。本版按最新要求改为右手主导的 **leftward snap / wrist flick**，替代此前右甩方向。

准备姿态为局部 yaw 45°、roll -70°，随后在 .40–.56s 进行短促左扫，终点 yaw 68°、roll -92°。释放在 .48s，位于左向速度峰值；.56s 后才反向回弹。基于实际烘焙轨道取释放位置的一阶速度，旧匣继续沿该速度飞行并向下加速，父骨骼后续运动由反变换抵消。所有运动在枪械共同局部空间定义，不使用固定世界 X。手臂尺寸、静态 anchor、枪械 Display 均未修改。

## 资源与显示边界

- 编辑源：`src/main/blockbench/p9_01_v03_8_fire_slide_cleanup.bbmodel`。
- 导出：`src/main/resources/assets/apocalypse_firstlight/geo/p9_01.geo.json`、`animations/p9_01.animation.json`。同源 `animations/p9_01.equip.json` 保持不变。
- 新增 `empty_old_magazine`，复制原弹匣 11 个 cube 及其 UV；原枪几何、原骨骼静态变换、图集、Display 均保持不变。当前共 172 个源 cube（含 4 个不导出的参考臂）、168 个运行时 cube、22 个运行时 bone。
- 临时旧匣仅在 P9 第一人称且当前控制器确实播放 `reload_empty` 时渲染。动画默认/结束时 scale 为零，0.84s 隐藏、0.85s 变换复位；非空仓换弹、切出取消、第三人称、背包和掉落显示不渲染该临时匣。
- 没有新增可拾取物品、实体、背包弹匣、弹药 NBT 或装弹结算。临时匣只是显示实例。
- 普通换弹、fire/fire_last_round、idle、draw/put_away、ADS、Native recoil、其他枪械不变。
- 空仓总时长仍 1.65s / 33 tick；插匣结算仍 tick 19，拔匣声音 tick 8，滑套声音 tick 25。Blockbench 的 1.25s `slide_action` 仅作编辑预览标记，运行时不导出重复声音事件。
