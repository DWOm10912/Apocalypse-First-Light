# Native Gun & Attachment Tooltip Cleanup V1

> 本文下述“两行正文、斜体描述、规格行”现已过时，保留为历史记录。现行布局与动态属性见 [装备 Tooltip V1](../ui/equipment_tooltip_v1.md)：非斜体灰色介绍、分割线、语义色属性、分割线。HUD 单行规则保持不变。

状态：已实现。

Native Gun 与 Native Attachment 的普通物品 Tooltip 统一为两行正文：枪械显示灰色非斜体“口径｜射击模式｜静态弹匣容量”及深灰斜体的一句定位描述；附件显示灰色非斜体“类型｜兼容类别”及深灰斜体的一句功能描述。名称继续使用 Minecraft 默认物品名称样式，AFL 不手动追加 Mod 名。所有正文来自 `zh_cn.json` / `en_us.json`，Java 不硬编码正式文案。

当前覆盖 P9-01、BR51-01、手枪微型红点、步枪红点、两种消音器、P9-01 24发扩容弹匣与 BR51-01 35发扩容弹匣。P9 静态容量规格随附件显示 17 或 24；BR51 规格行通过本地化参数读取 NativeGunAmmo.capacity，显示 20 或 35，不显示实时余量。所有枪 HUD 统一单行“当前装弹 | 备弹”，不显示容量。扩容弹匣类型行“弹匣 ｜ 手枪 ｜ 24发”，描述“一款为P9-01设计的24发扩容弹匣，可提升持续交火能力。”，英文同步。附件正文不包含 V 键或安装教学。

原清理任务仅修改正文、样式和本地化。后续容量和渲染变更见 [24R 扩容弹匣](p9_01_extended_magazine_v1.md)。

验证：中英文 JSON 解析与旧键/实时弹量代码静态扫描通过；离线构建记录于 `build/native-tooltip-cleanup-build.log`。本轮未启动图形客户端，因此实际换行宽度、JEI/创造栏显示及第三方 Mod 来源行尚未实机验收。
