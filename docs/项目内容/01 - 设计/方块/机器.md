# 1. 热力发电机

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 储能上限 | 100,000 FE |
| 发电速度 | 16 FE/t |
| 最大输出 | 16 FE/t |
| 液体燃料槽 | 200 mB（2026-10-04 起，按 1 mB = 1 升；原 4,000）；仅熔岩 |
| 流体接口 | 面向正面：左进、右出，25 mB/t；其余面不接流体 |
| 能量接口 | 背面输出 FE |
| 外观与占地 | 3D 机身配动态转子/燃料/液位，1×1 格占地；排气塔最高 1.075 格 |
| 运行粒子 | 固体火焰/少量烟火星；熔岩偶发活性粒子；顶部连续薄烟，OFF/FULL 停止生成 |
| 朝向 | 北 / 南 / 东 / 西，放置朝向玩家 |
| 碰撞 | 随朝向旋转的机身、底脚与顶部结构组合形状 |
| 选取轮廓 | 独立简化为机身与排气塔，随朝向旋转 |
| 挖掘工具 | 钻石级或更高等级的镐 |

## 燃料

| 燃料  |      总发电量 |
| --- | --------: |
| 煤炭  |    500 FE |
| 木炭  |    500 FE |
| 煤炭块 |  5,000 FE |
| 熔岩桶 | 20,000 FE |
| 熔岩（1,000 mB，一格源方块） | 20,000 FE（每 mB 20 FE，槽满 200 mB 为 4,000 FE） |

熔岩桶消耗完成后返回空桶。

每 tick 实际生成：

`min(16 FE, 当前燃料剩余能量, 剩余储能空间)`

因此燃料总能量会精确结算，不会因为无法被 16 整除而损失。

## 特殊规则

- 储能满时暂停燃烧。
- 当前燃料剩余能量不会被浪费。
- 储能重新出现空间后继续燃烧同一份燃料。
- 作为能源网络的发电端参与供电。
- 液体槽支持现有流体管道；右口只排出槽内尚未消耗的熔岩，无副产物。接口随四向朝向旋转。
- 空闲时优先燃料槽，当前已消耗燃料的剩余能量结算完才切换；固体与液体不并行消耗。
- 满电不消耗新燃料；槽内液体与已消耗液体的待转换能量随存档及正确工具掉落物保存。
- Jade 仅在槽内非空时显示液体名称、数量/容量与流体条。JEI“热力发电”展示当前燃料及对应总 FE，催化剂为热力发电机。
- GUI 左侧显示同化学反应器的流体条与悬停名称/储量提示，右侧能量条及原熔岩桶槽位用法保留；不新增手持桶灌注。世界模型显示槽内煤炭/木炭/煤块及真实液位；运行转子旋转、绿灯亮、光照 9；满电暂停转子停止、黄灯亮、光照 0；停机全灭，红灯仅预留故障用途。

| 最大输入 | 128 FE/t |

## 工作模式

### 充电模式

- 只接收 FE。
- 不主动向能源线缆网络输出。
- 作为能源网络的用电端。

### 放电模式

- 停止接收 FE。
- 最大输出 128 FE/t。

机器会保存：

- 当前 FE
- 充电 / 放电模式

正常拆除并重新放置后恢复。

# 7. 化学反应器

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 储能上限 | 60,000 FE |
| 最大输入 | 128 FE/t |
| 工作消耗 | 32 FE/t |
| 输入液槽容量 | 200 mB（2026-10-04 起，按 1 mB = 1 升；原 8,000） |
| 废液槽容量 | 200 mB（原 8,000） |
| 物品输入槽 | 1 |
| 物品输出槽 | 1 |
| 配方类型 | `apocalypse_firstlight:chemical_reacting` |

## 接口

以玩家面对机器正面为准：

| 位置 | 功能 |
|---|---|
| 左侧 | 输入液体 |
| 右侧 | 输出废液 |
| 背面 | 输入 FE |
| 正面 | 无流体接口 |
| 顶部 | 无流体接口 |
| 底部 | 无流体接口 |

### 左侧流体口

- 只能输入。
- 自动化速率最高 25 mB/t。

### 右侧废液口

- 只能输出。
- 自动化速率最高 25 mB/t。

左右两个端口拥有独立的 tick 预算。

因此理论上可以在同一 tick：

- 左侧输入 25 mB
- 右侧输出 25 mB

互不占用对方预算。

## 工作条件

只有以下条件全部满足时加工进度才会前进：

- 输入物品正确
- 输入液体足够
- 输出物品槽有空间
- 废液槽有足够空间
- 当前 FE 足够

任意条件不满足时：

- 加工暂停
- 不消耗 FE
- 当前加工进度保留

完成时再次检查全部条件，并统一结算：

- 物品输入
- 液体输入
- 物品输出
- 废液输出

化学反应器保存：

- 当前 FE
- 输入液体
- 废液
- 物品
- 加工进度

正常拆除时：

- 内部物品单独掉落
- 机器物品保留 FE
- 机器物品保留输入液体
- 机器物品保留废液

---

## Jade 显示

显示顺序：

1. 能量
2. 输入液体
3. 加工进度
4. 废液
5. 输出物品

规则：

- 能量始终显示。
- 空液槽不显示。
- 没有加工进度时不显示进度。
- 空输出槽不显示。
- 暂停加工时保留已有进度显示。

# 8. 流体储罐

2026-10-05 起是 V2：方形玻璃罐，相邻储罐拼成完整长方体时自动合并成一个大罐，见 [Fluid Tank V2](../../../models/fluid_tank_v2.md)。

流体层按自身亮度自发光，外框正常受光；熔岩储罐产生 9 级标准方块光，普通流体/空罐为 0。合并的大罐里每格按自己分到的液体发光，空的格不亮，详见 [流体光照](fluid_lighting_v1.md)。

Registry ID：

`apocalypse_firstlight:fluid_tank`

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 容量 | 800 mB / 格（2026-10-04 起，按 1 mB = 1 升；原 20,000） |
| 等效桶数 | 0.8 桶（单格装不下一整桶原版桶，合并的大罐才能倒入一桶） |
| 合并 | 相连的储罐拼成完整长方体（最大 5 × 5 × 16）且只有一种液体时合并，容量 = 格数 × 800 mB；不是完整长方体就各自独立；拆开后每格留着自己那份液体 |
| 同时存储流体种类 | 1 |
| 顶部自动输入 | 25 mB/t |
| 底部自动输出 | 25 mB/t |
| 水平侧自动接口 | 无 |

---

## 自动接口

### 顶部

只允许：

`输入流体`

最大：

`25 mB/t`

### 底部

只允许：

`输出流体`

最大：

`25 mB/t`

### 四个水平侧面

不提供自动流体能力。

---

## 手动容器

玩家使用：

- 桶
- Forge 流体容器

可以从储罐的可交互面进行输入或取出。

手动交互按照容器自身容量一次结算。

例如：

`Bucket = 1,000 mB`（原版桶的合成已禁用，见 [流体系统](../工业/流体系统.md) 第 0 节）

不受自动端口：

`25 mB/t`

限制。

---

## 储存规则

流体储罐一次只能保存一种流体（合并的大罐也一样）。装着不同液体的储罐贴在一起不会合并。

例如：

已经存有：

`工业废液`

则不能继续加入：

`水`

直到当前储液被完全清空。

---

## 状态保存

正常拆除后的储罐物品会保留：

- 当前流体类型
- 当前流体数量

Tooltip 显示：

`流体名称    当前储量 / 800 mB`

空储罐不显示流体信息。

# 9. 充电站

Registry ID：

`apocalypse_firstlight:charging_station`

第一台 Mesh 机器。模型、渲染与文件见 [Charging Station V1](../../../models/charging_station_v1.md)。

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 内部缓冲 | 10,000 FE |
| 最大输入 | 256 FE/t |
| 充电速率 | 128 FE/t（同时受物品自身接收上限限制） |
| 最大输出 | 无（不向网络放电） |
| 损耗 / 待机耗电 | 无 |
| 同时充电 | 1 个物品 |
| 外观与占地 | 钢制充电台，2 格长 × 1 格宽 × 1 格高；主格是面对正面时的左格 |
| 朝向 | 北 / 南 / 东 / 西，放置朝向玩家 |
| 放置条件 | 两格下方都是实心顶面；失去支撑时整台破坏并掉落 |
| 挖掘工具 | 钻石级或更高等级的镐 |

数值在 `machine_balance/charging_station.json`。

## 接口

以玩家面对机器正面为准：

| 位置 | 功能 |
|---|---|
| 两格背面正中 | 输入 FE（标准电源接口，共两个，都通到同一个缓冲） |
| 其余面 | 无接口 |

同一个线缆网络同时接两个接口时只算一个用电端。

## 充电规则

- 托盘上只放一个物品，不分物品种类。
- 只接受带 Forge Energy 能力、能接收电量的物品；其它物品放不上去（提示"无法充电"）。
- 每 tick 从缓冲向物品充：

`min(128 FE, 缓冲剩余, 物品本 tick 能接收的量)`

- 只给物品充电，不从物品抽电。
- 50,000 FE 的能量电池从空充满约 20 秒。

## 操作

- 没有 GUI。
- 拿着可充电物品右键：放上一个。
- 空手右键：取回物品。
- 准星提示："放上充电" / "无法充电" / "取下（当前 FE / 容量 FE）"。

## 显示

- 有电（缓冲大于 0，或最近 1 秒内收到过电）时，正面机架的十个橙色指示灯亮。
- 有电且托盘上有物品时，电量条和读数屏显示物品电量：`NN%`，充满显示 `FULL` 并变绿。没电时不亮。

## 声音

- 放上 / 取下：原版皮革装备声。
- 开始充电（有电时放上没满的物品，或来电时托盘上有没满的物品）：两声上扬的"滴-滴"。
- 充满：一次完成提示音。
- 充电中：很轻的电流嗡嗡声循环，8 格内听得到。

## 状态保存

- 托盘物品和缓冲电量随存档保存。
- 拆除时托盘物品单独掉落；缓冲电量丢失，机器物品不保留 FE。

## 基础属性

| 属性 | 当前值 |
|---|---:|
| 抽液速度 | 5 mB/t（每秒 100 升） |
| 抽液耗电 | 8 FE/t（只在抽到液体的 tick 扣，待机不耗电） |
| 内部缓冲 | 2,000 FE |
| 最大输入 | 32 FE/t |
| 出口缓冲 | 250 mB |
| 水的液池 | 至少 3 × 3 × 1 格水源才能抽，抽不完（岩浆同样规则，留给高温泵） |
| 用掉源方块 | 其它液体每抽 1,000 mB 一格 |
| 能抽的液体 | 不超过 400 K 的液体源（水、汽油、柴油、工业废液）；岩浆不能抽 |
| 外观与占地 | 深绿漆离心泵，2 格长 × 1 格宽 × 1 格高；后格在岸上，前格伸到液面上 |
| 朝向 | 北 / 南 / 东 / 西，前格朝玩家视线方向 |
| 放置条件 | 两格都可替换、没有液体；前格下面没有液体也能放 |
| 挖掘工具 | 钻石级或更高等级的镐 |

数值在 `machine_balance/intake_pump.json`（缓冲 250 mB、液池 3 × 3、1,000 mB、400 K 是代码常量）。

## 接口

以玩家站在岸上、面朝液面为准：

| 位置 | 功能 |
|---|---|
| 后格顶面正中 | 输出液体（标准流体接口，往管道推，每 tick 最多 25 mB） |
| 后格右面正中 | 输入 FE（标准电源接口，在起动箱上） |
| 前格底面 | 吸水管插进下方液体，不是接口 |
| 其余面 | 无接口 |

## 操作和显示

- 没有 GUI，不用红石。
- 空手右键任意一格：开 / 关（起动箱上的旋转开关）。准星提示"开启取液泵" / "关闭取液泵"。
- 指示灯：绿 = 正在抽；黄 = 开着有电但抽不了（下方没有液体源、液池不够 3 × 3、液体太热、出口没接管或满了）；灭 = 关着或没电。
- Jade：状态、取液、电量、出口缓冲。
- 抽液时有电机运转声（暂时借用冷柜压缩机的循环音）。

## 状态保存

- 开关、电量、出口缓冲随存档保存。
- 拆除时缓冲里的液体和电量丢失。

# 11. 机器通用规则

## 能量

加工机器的总能耗由：

`工作消耗 FE/t × 加工 ticks`

计算。

配方本身原则上只负责：

- 输入
- 输出
- 时间

机器负责自己的功率等级。

---

## 暂停加工

以下情况不会继续增加加工进度：

- FE 不足
- 输入不足
- 输出堵塞
- 必要流体不足
- 废液槽空间不足

暂停时：

- 不额外消耗 FE
- 不清空已有进度
