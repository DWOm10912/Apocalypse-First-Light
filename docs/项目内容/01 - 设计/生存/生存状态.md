# 爆炸耳鸣 / Explosion Tinnitus

> **已过时**：耳鸣 V2（2026-10-21，D 分支 feature/tinnitus-v2，用户 2026-10-21 实机 PASS，等 Main 合并，见 `docs/gameplay/tinnitus_v2_plan.md`） 取代了下面整节的爆炸耳鸣和旧的灰色暗角贴图。新的做法：每次巨响按剂量加进听力负荷，负荷够了得到负面状态"耳鸣"，状态期间时不时耳鸣、周围声音变小；近距离爆炸当场震耳。下面保留作历史记录。

爆炸耳鸣是一种短时间的听觉与视觉反馈，不属于疾病、Potion Effect 或永久听力损伤。

爆炸越近、强度越高，耳鸣越明显、持续时间越长。

以下示例数值默认未佩戴听力防护；HEAD 简易隔音耳罩保留原始 severity 的服务端触发判定，在共用耳鸣发送入口将最终 severity 乘 0.50。客户端基础音量、持续时间和旧视觉反馈由这个有效值派生，耳鸣播放实例还将音量乘 HEAD 耳鸣防护倍率（简易耳罩 0.50）；客户端各自的触发阈值仍适用。它不改变爆炸伤害或半径。

## 基础规则

|参数|当前规则|
|---|---|
|基础爆炸范围|使用爆炸实际 `radius`|
|耳鸣计算范围|`radius × 3.0`|
|距离强度|`n = clamp(1 - d/R, 0, 1)`|
|原始强度|`s_raw = n²`；用于服务端触发判定|
|客户端有效强度|`s_effective = s_raw × P`；P 为 HEAD 耳鸣防护倍率，普通状态 1.0、简易隔音耳罩 0.50|
|耳鸣播放音量|`(0.15 + 0.55 × s_effective) × P_current × 淡出包络`；简易耳罩的 `P_current = 0.50`，取当前客户端 HEAD 状态|
|视觉强度|`v = sqrt(s_effective)`；既有耳鸣 packet 同时驱动听觉冲击视觉反馈|
|音频触发阈值|服务端 `s_raw ≥ 0.15`，客户端 `s_effective ≥ 0.15`|
|视觉触发阈值|服务端 `sqrt(s_raw) ≥ 0.08`，客户端 `v ≥ 0.08`|
|墙体遮挡|暂不计算|
|护甲影响|无|
|是否需要实际受到伤害|否|
|创造模式|同样可以触发|

其中：

- `d` = 玩家与爆炸中心的距离
- `R` = 爆炸耳鸣最大影响范围

---

## TNT 示例

Vanilla TNT：

```
radius = 4
R = 12 blocks
```

因此：

下列距离为未佩戴听力防护时的参考。

|效果|大致最大距离|
|---|---|
|可听见耳鸣|约 7.35 格|
|可见视觉冲击|约 11.04 格|
|完全无效果|约 12 格以外|

距离只是强度的一部分；越靠近爆炸中心，反馈越明显。

## 音量

初始音量：

```
(0.15 + 0.55 × s_effective) × P_current
```

距离越近，声音越明显。

## 单次持续时间

```
40 + 120 × s ticks
```

约：

**2–8 秒**

实际达到最低音频阈值的耳鸣约从 **2.9 秒**开始。

# 淡出

耳鸣不会突然停止。

时间轴：

- 前 15% 保持当前强度
- 后续逐渐淡出
- 结束后完全停止

素材本身的自然衰减也会保留。

---

# 连续爆炸

AFL 不会为连续爆炸叠加多条耳鸣声音。

同一个耳鸣 Episode 内：

### 更强的新爆炸

- 不重新播放音效
- 不叠加第二份声音
- 提升当前 Severity
- 必要时延长剩余持续时间

### 较弱或相近的新爆炸

- 不重新开始
- 不降低当前 Severity
- 延长当前淡出约 **20 ticks / 1 秒**

### 最大持续时间

单个 Episode 从第一次耳鸣开始：

**最多 200 ticks / 10 秒**

达到上限后，后续爆炸不会无限延长当前耳鸣。

耳鸣完全结束后，下一次爆炸可以重新触发一个新的 Episode。

# 视觉 Overlay

爆炸同时会产生屏幕视觉冲击。当前这层由耳鸣 packet 与时间轴驱动，属于听觉冲击反馈，并非独立的爆炸物理震荡；耳罩仅通过有效耳鸣强度间接减弱它。

视觉强度采用线性距离曲线，因此相比声音：

> **中远距离仍能感觉到爆炸冲击，但不一定能听到明显耳鸣。**

当前规则：

|项目|当前值|
|---|---|
|视觉强度|`v = n`|
|最低视觉阈值|`0.08`|
|最大视觉范围|`radius × 3.0` 范围内按阈值决定|
|是否需要声音同时触发|否|

因此可以出现：

> **只有轻微视觉冲击，但没有耳鸣声音**

的情况。

# 当前 V1 限制

爆炸耳鸣 V1 暂时不考虑：

- 墙体遮挡
- 建筑隔音
- 材质吸音
- 普通护甲 / 头盔听力保护（简易隔音耳罩已经实现；2026-10-03 起戴在耳部栏，可以和头盔一起戴）
- 永久听力损伤
- 多种耳鸣音效随机
- 耳鸣状态 HUD 图标
