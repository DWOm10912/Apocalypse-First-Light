# 负重

本页记录负重系统当前的规则与数值。只记录当前有效设计，不记录开发过程、测试日志、修复历史或代码实现细节。

数值都是测试估值，还在平衡中。质量数据在 `data/apocalypse_firstlight/item_mass/`，惩罚曲线在同目录的 `core_v1.json`，改完 `/reload` 生效。技术细节见 `docs/gameplay/weight_system_v1.md`。

---

# 1. 基本概念

| 概念 | 说明 |
|---|---|
| 质量 | 物品本身的重量，Tooltip 显示的就是它 |
| 负担 | 按“怎么带着”加权后的重量，惩罚按它算（见第 2 节） |
| 舒适负重 | 30 kg。负担在 30 kg 以内没有任何惩罚 |
| 计重范围 | 背包 36 格（包括生存模式锁定的格子）、4 个盔甲槽、副手、鼠标上拿着的物品、合成格里的物品 |
| 不计重 | 打开的箱子、机器、别人的库存、地上的掉落物 |
| 超重 | 不会阻止拾取或放入物品，只会变慢 |
| 创造 / 旁观 | 照常计算，但没有任何惩罚，也不显示负重条 |

# 2. 负担

负担 = 每一堆物品的质量 × 位置系数 × 物品搬运系数。

## 位置系数

| 位置 | 系数 |
|---|---:|
| 背包、副手、鼠标上、合成格 | 1.00 |
| 穿在身上的盔甲 | 0.65 |
| 专业背包 | 约 0.90（规划中，负载分布更好，不是减轻质量） |
| 车辆货物 | 不算玩家负担（规划中，只算车辆自己的质量） |

例：全套铁甲质量 18.5 kg，穿在身上算 12 kg 负担；放在背包里算 18.5 kg。

## 物品搬运系数

大件东西抱在手里比重量本身更累：

| 类别 | 系数 | 物品 |
|---|---:|---|
| 超大件 | 1.25 | 堆叠为 1 的家具（多格或 20 kg 以上），加上充电站以外的所有机器，共 26 种 |
| 大件 | 1.10 | 单格中型家具和充电站，共 9 种 |
| 其它 | 1.00 | |

例：自动售货机质量 45 kg，抱着它的负担是 56.25 kg。

# 3. 负重档位

| 档位 | 负担 | 状态 |
|---|---|---|
| 轻松 | ≤ 30 kg | 没有惩罚 |
| 负担 | 30–40 kg | 移速快速下降 |
| 重载 | 40–50 kg | 不能疾跑，明显变慢 |
| 搬运 | 50–60 kg | 接近搬运状态，跳跃变低 |
| 极重 | ≥ 60 kg | 移速最低，跳跃最低 |

---

# 4. 惩罚

| 负担 | 移速 | 跳跃高度 | 疾跑 |
|---|---:|---:|---|
| ≤ 30 kg | 100% | 1.25 格（原版） | 可以 |
| 35 kg | 85% | 1.25 格 | 可以 |
| 40 kg | 70% | 1.25 格 | 禁止 |
| 50 kg | 50% | 约 1.13 格（90%） | 禁止 |
| ≥ 60 kg | 30% | 约 1.07 格（85%） | 禁止 |

- 两个值之间平滑过渡，60 kg 以上不再继续加重。
- **跳跃永远能上一格**：再重也只是跳得勉强，不会被一格高的坎卡住。
- **疾跑**：到 40 kg 禁止，降到 39 kg 以下才恢复，避免在 40 kg 附近捡一件东西就来回开关。
- **视野不缩小**：原版移速变慢会让视野变窄，负重造成的这部分被抵消了。
- 最低移速 30% 和原版潜行一样慢；超重时再潜行会更慢（约 9%）。
- 骑乘时不禁止疾跑，交给坐骑。
- 办公椅：负重会同样拖慢推椅子的速度，重载时坐椅子不会比走路快（2026-10-03）。
- 物品变化后约 0.25 秒内惩罚跟上。

# 5. 与耐力的关系

负担越重，耐力消耗越大、恢复越慢（详见 `耐力.md`）：

| 负担 | 移动类消耗 | 其它动作消耗 | 恢复 |
|---|---:|---:|---:|
| ≤ 15 kg | ×1.0 | ×1.0 | ×1.0 |
| 30 kg | ×1.3 | ×1.15 | ×1.0 |
| 40 kg | ×1.6 | ×1.3 | ×0.8 |
| 50 kg | ×2.0 | ×1.5 | ×0.6 |
| ≥ 60 kg | ×2.5 | ×1.75 | ×0.4 |

移动类指走、潜行、跑、跳、游泳、踩水、攀爬；其它动作指挖掘、近战、开枪、换弹。

# 6. 物品质量标准

## 原则

| 类别 | 标准 |
|---|---|
| 拿在手里的小东西（工具、材料、弹药、食物） | 接近真实质量 |
| 整格方块 | 一小份搬运单位，不按真实体积；常见方块一组 64 个约 10–16 kg |
| 家具、机器 | “搬一件”的质量，10–50 kg |
| 液体 | 按密度：1 mB = 1 升，水每 mB 1 kg（2026-10-04 起；原来一桶 1,000 mB 按 10 升算） |

- 台阶是母方块的一半，楼梯约 3/4。
- 能来回合成的保持质量不变，不能靠合成减重：例如铁块 = 9 个铁锭。
- 没有规则的物品统一按 250 g 计（现在基本只剩刷怪蛋、命令方块、末地物品、珊瑚、幽匿方块等）。

## 常见数值

| 物品 | 质量 |
|---|---:|
| 泥土、沙、砾石 | 0.15 kg |
| 石头、圆石、砖、混凝土 | 0.25 kg |
| 原木 / 木板 | 0.4 / 0.1 kg |
| 玻璃 / 羊毛 / 树叶 | 0.15 / 0.05 / 0.05 kg |
| 钢块 / 钢筋混凝土 / 铅屏蔽砖 | 1 / 1.5 / 3 kg |
| AFL 矿石方块 | 1.0–1.2 kg |
| 铁锭 / 铁块 | 0.5 / 4.5 kg |
| 钢坯 / 铅砖 | 1 / 0.75 kg |
| 9mm / 7.62 / 12.7 子弹 | 12 / 24 / 80 g |
| BR51 满弹（20 发） | 3.88 kg |
| 撬棍 / 能量电池 | 1.2 / 1 kg |
| 全套铁甲 | 18.5 kg |
| 空桶 / 水桶 / 岩浆桶 | 1 / 11 / 21 kg |
| 脏水瓶 / 煮沸水瓶 / 纯净水瓶 | 0.5 kg |
| 自动售货机 | 45 kg |
| 垃圾箱（四种颜色） | 40 kg |
| 办公桌 / 储物柜 | 25 kg |
| 垃圾桶 | 10 kg |
| 粉碎机 / 工业熔炉 | 50 kg |

枪的质量 = 枪身 + 配件 + 弹匣 + 枪里实际的子弹，开枪会变轻。

## 带着内容的物品

- 流体储罐、热力发电机、化学反应器拆下来时保留液体，液体也算重量，按密度算（1 mB = 1 升）：水每 mB 1 kg、岩浆 3 kg、工业废液 1.1 kg、汽油 0.74 kg、柴油 0.84 kg。满一格储罐的水（800 mB）有 800 kg，基本背不动，只能空罐搬（2026-10-04 起；原来每 1,000 mB 按满桶减空桶算，满罐水 200 kg）。
- 桶本身（空桶 / 水桶 / 岩浆桶）仍按上面表里的质量算：原版桶在淘汰中，不改它的质量。
- 物品里保存着标准格式的容器内容时（比如创造模式复制的带东西的箱子），里面的物品也算重量。

## 堆叠上限

| 堆叠 | 物品 |
|---|---|
| 1 | 多格或 20 kg 以上的家具、所有机器 |
| 4 | 单格 5–20 kg 的家具 |
| 16 | 5 kg 以下的桌面小件（显示器、键盘、鼠标） |
| 64 | 建材、门、灯、线缆、管道、材料 |

# 7. 显示

## 物品提示

一行显示：

| 情况 | 示例 |
|---|---|
| 单个 | `重量：45 kg` |
| 一堆 | `重量：12 g × 64 = 768 g` |
| 枪 | `整枪重量（含附件及弹药）：3.88 kg` |

按 F3+H 打开高级提示时，没有质量数据、按 250 g 计的物品多一行灰字提示。

## 负重条

- 位置：原版经验条的位置，快捷栏正上方（创造 / 旁观不显示）。
- 被动显示（2026-10-04 用户定）：平常隐藏，负担变化时淡入，停 3 秒后淡出。
- 两端圆头，满格代表 60 kg，在 30 / 40 / 50 kg 有刻度。
- 颜色随档位：轻松灰、负担黄、重载琥珀、搬运橙、极重红。
- 右边显示当前负担，例如 `42.5 kg`。
- 负担变化时长度、数字、颜色平滑过渡。
- 骑可以跳的坐骑时，原版跳跃蓄力条占用这个位置，负重条暂时隐藏。

正式的生存 HUD 等口渴、体温等系统完成后统一设计，负重条位置不变。

# 8. 管理命令

需要权限 2：

| 命令 | 作用 |
|---|---|
| `/aflweight` | 自己当前的质量、负担、档位、移速和跳跃倍率、是否禁跑 |
| `/aflweight breakdown` | 再列出各位置的质量和负担 |
| `/aflweight held` | 主手物品的质量明细（枪会拆成枪身、弹匣、子弹等） |
| `/aflweight player <玩家名>` | 查看其他玩家 |
| `/aflweight coverage [missing]` | 检查 AFL 物品是否都有质量数据 |
