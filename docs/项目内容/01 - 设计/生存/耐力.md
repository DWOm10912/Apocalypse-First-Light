# 耐力 / Stamina — 设计草案 V1

状态：**V1 已实现，用户实机测试 PASS**（2026-10-03）。实际行为、文件和数值见 `docs/gameplay/stamina_system_v1.md`；数值在 `data/apocalypse_firstlight/stamina/stamina_v1.json`，`/reload` 就能调。

和本草案不同的地方：
- 开镜保持的消耗和恢复减半没做：服务端不知道玩家是否开着镜；
- 近战只有打中实体才扣，挥空不扣；
- 持枪晃动只放大幅度，呼吸节奏不变快；
- 喘息素材只够拼出轻 4 种、重 5 种（见第 7 节和 stamina_system_v1.md）；
- 临时 HUD 不是细条，而是一个带跑步小人图标的圆环（用户要求加图标）。2026-10-03 起放在生存指标组里体温表盘的左边。

原则：
- **任何动作都消耗耐力**，但多少差很多。走路几乎不费；疾跑、游泳、挥砍费得多。
- 不做极端机制：耐力耗尽不会让人卡住、动不了或直接受伤。
- 负重越重，消耗越大、恢复越慢（接 `weight_system_v1.md` 的负担）。

## 1. 最大耐力

- 100 点。
- V1 固定 100。口渴和体温只改恢复速度和消耗，不降上限；受伤以后再定（见第 13 节）。

## 2. 恢复速度

每秒恢复（负担 ≤ 15 kg 时）：

| 状态 | 恢复 / 秒 | 从 0 到满 |
|---|---:|---:|
| 站着不动、蹲着不动 | 15 | 约 6.7 秒 |
| 走路 | 15 − 走路消耗 1.5 = 净 13.5 | 约 7.4 秒 |
| 在水里（没在游） | 一半（7.5） | |
| 饱食度 ≤ 6（原版不能疾跑的线） | 一半 | |
| 疾跑、游泳、攀爬 | 0（这些动作一直在打断恢复） | |

## 3. 恢复延迟

- 做了任何“费力动作”（疾跑、跳、游、爬、挥砍、挖掘、开枪、换弹）后，**1.0 秒**内不恢复。
- 走路、潜行移动是持续的小消耗，不打断恢复。
- 耐力降到 0 后，恢复延迟变成 **2.0 秒**。

## 4. 各动作消耗

基础值（负担 ≤ 15 kg），按负担放大的倍率见第 5 节。

| 动作 | 消耗 | 说明 |
|---|---:|---|
| 走路 | 1.5 / 秒 | 不打断恢复，净值仍在回 |
| 潜行移动 | 1 / 秒 | 不打断恢复 |
| 疾跑 | 8 / 秒 | 满耐力约跑 12.5 秒、70 米 |
| 跳跃 | 5 / 次 | 疾跑中跳 7 / 次 |
| 游泳（水中疾跑） | 7 / 秒 | |
| 水中普通移动、踩水 | 2.5 / 秒 | |
| 爬梯子、藤蔓 | 3 / 秒 | |
| 挖掘（按住破坏方块） | 2 / 秒 | 只在真的在挖时算 |
| 近战挥击 | 空手 3；普通武器、工具 5；撬棍 8 | 每挥一次 |
| 开枪 | 9mm 0.4；7.62 0.6；.50 AE 1.2；12 号 1.5；12.7 2.5 | 每发，按枪的弹种；BR51 连射约 6 / 秒 |
| 开镜保持 | 不消耗，恢复减半；HR55 这类重枪 1.5 / 秒 | 端稳枪也费力 |
| 换弹 | 1；重枪 2 | 每次 |
| 放方块、用物品、吃喝、被打 | 0 | 不算“出力” |

## 5. 负重倍率（Weight modifier）

按负担比例（负担 / 舒适负重 30 kg），点之间线性：

| 负担 | 移动类消耗 ×（走、潜行、跑、跳、游、爬） | 其它动作消耗 ×（挥、挖、枪） | 恢复 × |
|---|---:|---:|---:|
| ≤ 15 kg | 1.0 | 1.0 | 1.0 |
| 30 kg | 1.3 | 1.15 | 1.0 |
| 40 kg | 1.6 | 1.3 | 0.8 |
| 50 kg | 2.0 | 1.5 | 0.6 |
| ≥ 60 kg | 2.5 | 1.75 | 0.4 |

“其它动作”的倍率只取移动类多出部分的一半：背着东西挥砍会更累，但没有爬坡那么明显。

举例：
- 35 kg 疾跑每秒约 11 点，大约跑 9 秒。40 kg 以上本来就不能跑。
- 60 kg 走路每秒消耗约 3.75，恢复约 6，走路还能慢慢回；但每跳一次要 12.5 点，背满东西爬山很快会累。

## 6. 耐力耗尽后果（力竭）

耐力降到 0 进入“力竭”，**耐力回到 30 才解除**：
- 不能疾跑（和超重禁跑用同一个机制）；
- 枪械晃动和散布变大（第 8 节）；
- 近战伤害 ×0.6；
- 挖掘速度 ×0.8；
- 有喘息声（第 7 节）。

不做这些（避免极端）：
- 不额外减速（负重已经有减速）；
- 不禁止跳跃（不会被一格台阶卡住）；
- 不扣血，不晕倒，不黑屏。

耐力不到 0 但很低时（< 20），只有喘息声和枪械晃动的轻微增加，没有其它影响。

## 7. 喘息音效

- 有，用**鼻息**（2026-10-03 用户定）：只用鼻子呼吸的气流声，没有嗓音，听不出男女，也不容易显得怪。张嘴喘气的版本试过，生成出来偏女性化，而且人声做不好很突兀，所以不用。
- 不做长循环，**一口一口随机播放**：
  - 从素材里切出两组单口鼻息：重的（力竭用）和轻的（疲惫用），每组 6–8 口；
  - 每次随机挑一口，音高随机浮动 ±3%；
  - 间隔按疲劳程度变：越累越密、越重。
  这样每次都不一样，素材里个别不完美的地方也不容易听出来。
- 什么时候响：
  - 耐力 < 20 时出现轻的鼻息，间隔较长；
  - 力竭时换成重的，间隔最短；
  - 耐力回到 30 以上后渐渐变稀，然后停止。
- 音量放低，混在脚步声下面，只在力竭时比较明显。拿到素材先进游戏试听，不满意就先不加，不影响耐力其它部分。
- 谁能听见：
  - 自己听得最清楚；
  - 其他玩家在 8 格内小声听到（沿用翻找声的同步方式）；
  - 感染者能不能听到，留给以后的感染者听觉系统。
- 不分男女版本：鼻息本身听不出性别。项目里没有角色性别，也不按皮肤猜。以后如果有更多人声（受伤、咳嗽），再统一做“声音类型”选项。素材由用户生成。

## 8. 枪械晃动（sway）与散布

已有的第一人称持枪晃动（`NativeWeaponSway`）只是模型在动；真正影响命中的是散布（`NativeAccuracyProfile`）。两边都接：

- 疲劳度 = 耐力从 50 降到 0 时，从 0 涨到 1；耐力 50 以上没有影响。
- 视觉晃动：幅度 × (1 + 1.5 × 疲劳度)，最多 2.5 倍；呼吸节奏也变快（周期最多缩短到 60%）。
- 散布：腰射和开镜的散布都 × (1 + 0.4 × 疲劳度)，最多 +40%。

所以跑完马上开镜会晃、会不准，停下喘一会儿才稳。

## 9. 创造 / 旁观模式

- 不消耗，耐力锁在满值，没有力竭、喘息和晃动加成。
- 从生存切到创造时补满；从创造切回生存时从满开始。
- HUD 不显示（和负重条一样）。

## 10. 其它规则

- 死亡重生：满耐力。
- 退出重进：保存当前耐力，避免靠重进刷满。
- 骑乘：骑马、坐船时不消耗（坐骑自己出力），恢复照常。
- 办公椅（2026-10-03）：
  - 坐着不动：不消耗，正常恢复，不产生运动热；
  - 坐着滑行：用脚蹬算低强度活动，每秒 0.5–1.0，负重越高消耗略多；不打断恢复，会产生一点点运动热；
  - 椅子速度会和走路一样被负重、寒冷、缓慢拖慢。
- 和平难度：耐力照常运作，它不是饥饿值。
- 原版的饥饿消耗不变：疾跑照样消耗饱食度，耐力是另外一套。

## 11. 实现方向（确认后再写）

- 服务端算耐力，同步给本人（同负重状态的做法）。客户端负责疾跑拦截（复用负重的疾跑 mixin）、晃动和声音。
- 数值放在 `data/apocalypse_firstlight/stamina/stamina_v1.json`，`/reload` 可调。
- 调试命令 `/aflstamina`：看当前耐力、各项消耗、负重倍率。

## 12. HUD 需求（记给以后的正式 HUD）

- 数值：0–100，变化快（每秒可以掉 10 点以上）。
- 显示时机：不满时出现，回满后 2 秒淡出；低于 30 变成警告色；力竭时有明显标记。
- 和负重条关系最紧。
- 开发期间先在负重条上方加一条细的临时耐力条，正式 HUD 时重做。

## 13. 给以后的系统预留

- 口渴：缺水时恢复 ×0.5。
- 体温：**已实现（体温 V1）**。寒冷时恢复变慢（C1 ×0.8、C2 起 ×0.6），不降上限，因为降上限要改耐力环的显示；炎热时消耗增加（H1 ×1.1、H2 起 ×1.25），中暑起恢复 ×0.75。花掉的耐力也会让身体发热。见 `temperature_system_v1.md`。
- 身体部位伤害：腿伤时移动类消耗 ×1.3；手臂伤时挥砍、开镜消耗增加。
- 特质 / 训练：改最大耐力和恢复，不改动作本身的消耗。
