# MAIN_NATION Biome Region Planner V1

当前群系分布由seed-only区域规划接管。**Biome planner change requires new world**。Scorched biome直接删除，不保留legacy注册，不迁移旧chunk。新世界/Xaero视觉验收待用户完成。

## 地表规划

| 地域 | 当前结果 |
| --- | --- |
| MAINLAND Startup | 必定1个小型Plains |
| MAINLAND Additional | 0～3个连续Plains pockets |
| MAINLAND其余LAND | Fallout Barrens |
| SATELLITE_ISLAND及其他主国岛屿LAND | Fallout Barrens |
| 干Macro COAST | Beach |
| Macro water | Ocean；宏观海床高度<32为Deep Ocean |

实现类：`src/main/java/com/antaurora/apofirstlight/world/biome/MainNationBiomeRegionPlan.java`。构建只依赖seed与MacroGeography，immutable，最多缓存16份seed计划；单次查询不重建列表、不读取Level/chunk、不依赖加载顺序。

Startup复用StartupPlainsEnclave：核心160，基础半径208，边缘±32（约176～240）。Macro出生预留384与主陆核心3800保持，不扩大为Plains。Startup是一小片幸运绿区。

Additional目标数量0/1/2/3概率为40%/40%/15%/5%。每slot最多128候选；前32次偏好coastDistance≤最大半径+1024，其后允许一般内陆。候选范围来自主岛majorAxis的保守外接界。失败slot跳过，实际数量可低于目标。

每片基础半径96～224、扰动24～48，轮廓为：
`r(theta)=radius+amplitude*(0.65*sin(3*theta+phase)+0.35*sin(5*theta-phase))`。
低频角度扰动保持正半径连续星形，不使用逐点Vanilla climate阈值。Startup最大半径240与各pocket最大包络radius+amplitude之间、pockets之间均留128格。候选外接方形按32格间距检查MAINLAND LAND且coastDistance≥112；最终查询仍由water/COAST优先，不能覆盖Beach。Plains不保证幸存者基地。

## 最终路由与地下政策

`ClimateParameterListMixin` 初始化时把plan绑定到 `StartupEcologyState`，findValuePositional RETURN解析最终biome。SurfaceSystem通过 `SurfaceSystemStartupBiomeMixin → BiomeManagerStartupSurfaceMixin → StartupSurfaceBiomeContext` 调同一个plan的 `biomeAt`，使用同资源preliminary density和4格quart坐标；没有第二套pocket算法。

优先级：Deep Dark→Fallout回退；地下Lush/Dripstone保留；Macro water→Ocean/Deep Ocean；干COAST→Beach；MAIN_NATION LAND→region plan。Lush/Dripstone地下判据沿用水域海床深度>12、陆地上方12格initial density>0.390625；贴近表面则跟随surface planner。

`AflVanillaBiomePolicy`、OverworldBiomeBuilderMixin、MultiNoiseBiomeSourceMixin过滤Deep Dark候选，最终resolver再次拦截，关闭自然Deep Dark及其sculk来源。Ancient City空tag不变。Lush/Dripstone保留；Surface Cave Seal仍DEFERRED，不改carver、canyon、spaghetti、noodle。

`AflOverworldRegion` 仅保留Fallout候选兜底，weight190不变；Vanilla weight10不再决定主国LAND的Plains面积。原始Plains、marine及其他普通地表候选在该地域统一由plan覆盖。

## Scorched Removal、流体与方块

删除Scorched key、biome JSON、surface rule、biome tag项、biome翻译、Settlement诊断分类、ScorchedSurfaceSampler/ScorchedLiquidSampler以及 `/afl dev scorched_surface_sample`、`/afl dev scorched_liquid_sample`。

Scorched专属近地表抑水与SurfaceWaterSuppressingAquifer删除。`NoiseChunkMacroWaterMixin` 保留原Macro补水条件isWater且surfaceHeight≤y<63，以及256槽完整XZ键缓存；Ocean/Bay/Strait/Inland Sea不改。生成诊断上下文更名MacroAquiferContext。地表熔岩湖抑制tag移除Scorched，其他条目保持。

`scorched_soil` / `fused_ground` 的Block/Item、模型、纹理、掉落、工具标签和翻译完整保留；不再由Scorched biome铺地。前者用于火灾/爆炸/核打击外围，后者用于高温/爆心/弹坑核心。未来交给Global Damage/Crater/Strategic Strike，本轮未实现这些系统。

## 辐射、粒子与结构

BiomeRadiationResolver删除Scorched→EXTREME，Fallout继续HEAVY_FALLOUT、Plains继续SAFE，marine仍UNKNOWN。Startup辐射保护及既有数值不重构。EXTREME能力保留，未来独立Blast Zone/Facility damage尚未接入。

Rural仍允许Plains/Fallout；原Scorched土地转Fallout而扩大资格是允许变化，没有旧密度补偿。Highway仅清理tag旧ID，路由、几何、Sea Bridge未改。Terrain relief/elevation、Macro topology、海岸线均未修改。
