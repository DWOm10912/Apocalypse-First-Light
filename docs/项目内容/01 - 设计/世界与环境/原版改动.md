# 原版机制调整

本页记录 AFL 对原版成长与世界内容的删减目标；感染者规则见 [感染者基础规则](感染者基础规则.md)。

### 1. 删减的原版机制
- 附魔系统
- 附魔书
- 铁砧附魔/铁砧修复
- 酿造台/药水制作
- 信标
- 不死图腾
- 末影箱
- 末影珍珠
- 附魔金苹果
- 普通金苹果
- 村民魔法交易
- 经验等级系统
- 进度
- 下界/末地
- 刷怪笼
- 废弃矿井
- 刷怪房
- 所有生物群系
- 大部分原版结构
- 打火石配方（2026-10-05：没受过训练的幸存者不会打火，以后做打火机；`data/minecraft/recipes/flint_and_steel.json` 用 `forge:false` 关掉，已有的打火石照样能用）

### 2. 原版装备与魔法退役 V1（2026-10-19，分支 AFL-Vanilla-Rework，用户 2026-10-20 实机 PASS，未合并）

详细见 `docs/gameplay/vanilla_survival_rework_v1.md`

- 原版剑、盾牌、盔甲完全不能用：做不出来、拿不到；旧的还在，拿着或穿着都没有效果（伤害、护甲、附魔、横扫、格挡、保暖都没有）
- 附魔台、铁砧、酿造台、砂轮、锻造台、末影箱：生存模式打不开，配方去掉；附魔书、附魔之瓶拿不到
- 一份清单（`data/apocalypse_firstlight/tags/*/retired/`、`vanilla_retirement/v1.json`），一个总开关（`config/apocalypse_firstlight-common.toml`）
- 下界、末地也并进这份清单；要塞改成和其他原版结构一样用空标签关掉，不再算位置
- 创造栏不显示这些装备，`/give` 还能拿
- 以后的替代：现代近战武器、防暴盾 / 防弹盾、防弹衣、防护服、防辐射装备
- 柴炉：打火石配方关了、火焰弹要下界材料；2026-10-20 加了翻盖打火机，点着能点柴炉，但它现在只能从创造栏拿，生存里还是点不着，等开局物资或 V2 制造
- V2：配方知识属于每一位幸存者，见 `docs/gameplay/survivor_recipe_knowledge_v2_plan.md`

### 3. 原版木头退役 V1.1（2026-10-20，同分支，用户 2026-10-20 实机 PASS）

详细见 `docs/gameplay/vanilla_survival_rework_v1.md` 4.6 节

- 原版 11 个树种整套退役：原木、木板、楼梯、台阶、栅栏、门、活板门、告示牌、船、树苗、树叶……做不出来、不掉落、创造栏隐藏
- 通用木制品也一起退役：木棍、碗、工作台、箱子、木桶、书架、梯子、床、木工具、火把、展示框、画、盔甲架等；等 V2 制造台用 AFL 木材配方补
- 已有的照常能用，放下的方块挖掉不掉落；放下的工作台照常能合成
- 营火、弓箭、钓竿、红石零件当时没退役（V1.2 起营火、弓箭、红石也退了，见第 4 节）
- 高山草甸、湖滨沼泽改长 AFL 网格树；繁茂洞穴不再长杜鹃树
- 地堡、老宅结构里的原版树种方块换成 AFL 白栎或铁、石方块；梯子、床、书架等通用木制品方块先留着
- 以后的建筑不用原版树种方块（`docs/authoring/afl_industrial_palette_v1.md` 第 6 条）

### 4. 原版内容大清理 V1.2（2026-10-20，同分支，用户 2026-10-20 实机 PASS）

详细见 `docs/gameplay/vanilla_survival_rework_v1.md` 4.7 节

- 退役（做不出来、不掉落、创造栏隐藏，已有的照常能用）：下界方块和材料（含石英、萤石、岩浆块、下界合金）、末地方块（含鞘翅、末影之眼）、潜影盒、海晶类、青金石、红石全套、幽匿、信标
- 原版功能性方块和容器：熔炉、高炉、烟熏炉、营火、附魔台、铁砧、酿造台、砂轮、锻造台、末影箱、切石机、炼药锅、钟、灯笼、蜡烛、旗帜、花盆、陶罐、头颅等；配方不要紧，等 AFL 自己的功能性方块
- 铁轨和矿车全部退役，以后做网格铁路网
- 弓、弩、箭
- 青金石矿和红石矿不再生成（新区块）
- 原版生物不再进入世界，只留僵尸（AFL 感染者就是它）；旧存档里已有的生物照常加载；刷怪蛋页隐藏
- 保留：原版玻璃（等 AFL 玻璃板，Main 建议一起退）；TNT、铁门、铁活板门、锁链、避雷针、指南针、时钟当时保留，V1.3 也退了

### 5. 工具、食物和剩下的原版件 V1.3（2026-10-20，同分支，用户 2026-10-20 实机 PASS）

详细见 `docs/gameplay/vanilla_survival_rework_v1.md` 4.8 节；用户："我们后面会做自己的工具，按照真实逻辑"

- 原版全部工具：所有斧、镐、锹、锄，剪刀、打火石、烈焰弹、钓竿、指南针、时钟、望远镜、地图、拴绳、命名牌、书与笔
- 桶和各种桶装液体、骨粉、末影珍珠、山羊角、烟花、马鞍、马铠、不死图腾、三叉戟、唱片
- 原版全部食物和药水
- TNT、铁门、铁活板门、避雷针、遮光玻璃、锁链、紫水晶；紫水晶晶洞不再生成，普通洞穴照常
- 影响：新世界生存里挖不了石头和矿、砍不了树、没有食物（饥饿照常），等 AFL 自己的工具和食物
- 保留：原版玻璃和玻璃板、玻璃瓶（口渴装水）、铁栏杆（V1.6 起退役）

### 6. 砖、砂岩、深板岩、铜、钻石和绿宝石 V1.4（2026-10-20，同分支，用户 2026-10-20 实机 PASS）

详细见 `docs/gameplay/vanilla_survival_rework_v1.md` 4.9 节

- 红砖、砂岩、红砂岩、泥砖、强化深板岩退役
- 深板岩只退装饰件（圆石、磨制、砖、瓦），天然深板岩和深层矿石等地下重做时再定
- 铜只退建筑件（铜块、切制铜、粗铜块），铜矿、粗铜、铜锭留着（电线要用）
- 钻石、绿宝石退役，钻石矿、绿宝石矿不再生成
- 天然砂岩、红砂岩还在地表规则里（C 的），挖了不掉落
