# 枪械数据

AFL 使用 Native Gun Framework；本页只记录当前正式枪械的最终数据。

佩戴 HEAD 简易隔音耳罩时，已参与枪声耳鸣的枪在统一 `GunshotExposureTracker` listener pass 中仍用原始 exposure 积累并判阈值；输出 raw severity 后于 `AflNetwork.sendTinnitusImpulse` 发送前统一乘 0.50。客户端耳鸣声音播放实例另乘当前 HEAD 音量倍率 0.50；不改变各枪是否启用耳鸣、伤害、噪声半径或感染者听觉。耳罩另在本地播放端使世界声音 ×0.50，但耳鸣不经过该世界声音过滤。见 [简易隔音耳罩 V1](simple_hearing_protection_v1.md)。
