## 3. 要用户拍板的事

### 3.1 风格方向和规范 V1 不一样

审校稿整体比现行规范**更书面、更规整**。规范 V1 第 2.3 节和批次 1 选的是口语说法，比如：
- "走路慢""不会自己回血""一直掉血"；
- 把"暂无、当前、未……"改成"没有、现在、还没……"。

审校稿系统地改回：
- "移动速度降低""无法自然恢复生命值""持续失去生命值"；
- "尚未""无法""未连接"。

这不是零星几条，310 条 OK 里也普遍是这个方向。

用户这次的要求（避免"过度口语化"）和风格基准（"不要为了避免 AI 腔而将所有用语改得粗俗、口语化"）都指向审校稿的方向。但规范 V1 是用户 2026-10-18 批准并冻结的。要合并，就得改：
- 第 2.3 节的"暂无 / 当前 / 未 → 没有 / 现在 / 还没"那一行；
- 第 4.1 节的批次 1 例子。

**建议：** 采纳审校稿的方向，在规范里记一条用户决定（第 20 条），内容：
- 机制说明（HUD 状态、属性、Jade、错误提示）用规范书面语，词要准：移动速度、生命值、无法；
- 口语只留给体感消息、人物背景、角色说的话；
- 规范第 2.3 节那一行改成只禁"暂无 / 当前"这类空泛的系统腔，"无法 / 尚未"在机制说明里可以用。
