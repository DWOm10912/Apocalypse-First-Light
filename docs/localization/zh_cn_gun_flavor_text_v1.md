## 1. 2077 简中枪械描述的研究

**样本：** 赛博朋克中文维基（cyberpunk.huijiwiki.com）"分类:枪械"下的全部 47 个页面。通过 MediaWiki API 读取每页 `{{DB/Weapon}}` 模板里的标题和内容，共 8529 字。WebFetch 被站点拒绝（403），改用内置浏览器读取。本文只写归纳，不摘抄原文。

### 1.1 数字

| 项目 | 结果 |
|---|---|
| 每条字数（去掉空白） | 最短 75，四分之一处 140，中位数 183，四分之三处 210，最长 319 |
| 写了缺点或代价的（但、可惜、不过、缺陷） | 34 条（72%） |
| 写了谁在用的（警察、帮派、佣兵、公司保安、士兵） | 30 条（64%） |
| 直接对玩家说"你"的 | 21 条（45%） |
| 提到价格的 | 17 条（36%） |
| 拿别家厂商作比较的 | 至少 8 条 |
| 用了问句的 | 8 条 |
| 用了省略号的 | 6 条 |

### 1.2 标题

标题是**厂牌 + 型号代码 + 中文名**。

- 型号代码保留原样（SPT32、M-10AF、DB-4）。
- 枪的名字翻成中文，取原名的意思或意象，不硬直译。
- 厂牌按三种办法译：
  - 意译：军用科技、海啸、平价火力、宪法军工；
  - 日文汉字直接用：荒坂；
  - 音译：康陶、罗斯托维奇、诺科他、马洛里安。

### 1.3 正文的结构

大多数条目按下面的顺序走，但不是每条都走全：

1. **开头一句钩子。** 下面几种最常见：
   - 拿过去和现在作比较；
   - 从城市里的一种现象说起；
   - 先给一个结论，后面再拆开说。
2. **谁在用、在哪里见得到。** 用的人有警察、帮派、公司保安、穷人、收藏的人。这一句就把社会面貌带出来了，不用另讲历史。
3. **手感和用法。** 轻、小、好藏、好修、打得穿墙。写具体的感受，不罗列数据。
4. **代价。** 后坐力大、笨重、贵、容易坏、零件停产。几乎每条都有，这是这些描述可信的关键。
5. **和别家比。** 用别的厂牌作参照，顺带把厂牌的性格立起来。
6. **一句落点。** 收尾往往是一句冷幽默，或者一个出人意料的结论。

### 1.4 厂牌的性格靠反复写出来

同一家厂的不同枪，描述里反复出现同一种性格：

- 某家厂：精致、贵、技术领先；
- 某家厂：便宜、粗糙、能用就行；
- 某家厂：廉价塑料、一次性；
- 某家厂：结实、可靠、量大。

玩家不读任何公司简介，只看几把枪的说明，就知道各家是什么样的公司。**这是最值得 AFL 学的一点。**

### 1.5 不适合 AFL 的地方

2077 是朋克讽刺的语调，AFL 的规范是"冷静、具体、克制"（规范第 2.1 节）。下面这些不学：

- **粗口和网络梗。** 例如在描述里骂一句，或者用"有炸鸡腿就不要烤乳鸽"这类俗语。
- **夸张。** 例如"以光速发射"，写出来的效果和设定都站不住。
- **叙述者统一的讽刺腔。** 例如拿公司偷税开玩笑。
  - AFL 不碰政治，也不强行给企业安排阴谋。
  - 但企业可以有现实里的矛盾，比如某型号召回、质量争议、厂子经营不善。这些可以平实地写进背景文字（用户 2026-10-18，规范第 2.11 节）。
- **年份和历史大事。** 例如"21 世纪 40 年代发布"。AFL 的时间线还没锁定（企业档案第 0 节）。
- **写死的数值。** 例如弹匣装几发、射速多少。AFL 的平衡还会调，写死就会过期。

## 2. AFL 的写法（建议）

### 2.1 放在哪里

现在每把枪只有一行功能说明（`tooltip.*.<gun>.description`），本地化第二批会把它润色得更短（规范第 4.3 节 #25–29）。

背景文字比功能说明长得多，**不能挤进同一行**。建议：

- 新加一个键 `tooltip.apocalypse_firstlight.<gun>.lore`；
- 物品提示里按住 Shift 才显示，或者只在枪械维护台的检视界面显示。

这要改代码，另排。新键要 en_us 和 zh_cn 一起写（规范第 6 节第 1 条）。

### 2.2 规则

| 项目 | 规则 |
|---|---|
| 字数 | 60–120 字。2077 的中位数是 183 字，但 Minecraft 的提示框一行只放得下大约 20 个汉字，120 字已经有 6 行 |
| 口吻 | 枪店店员、老猎人、枪械杂志编辑那样的口吻：懂行，说话平实，偶尔带一点干巴巴的幽默。不当说明书写，也不当广告写 |
| 时态 | 用现在时写这把枪本身。末日之后的情形最多点到一句，不铺开讲 |
| 必须有 | 厂牌（第一次出现用全称）；一个具体的手感或用法；一个代价 |
| 可以有 | 谁在用、在哪里见得到（只写已确认的，比如 P9 在警察局）；和别的枪或别家厂作比较；一句落点。**落点不是必须的**（用户 2026-10-18）：这把枪、这家厂的口吻里有幽默就写，没有就平实收尾 |
| 不能有 | 年份；采购和合同；政治事件；企业阴谋；粗口；网络梗；夸张到违背物理的说法 |
| 数值 | 只写不会因为平衡而改动的事实：口径、结构（双管、折开装弹）、射击方式（能切全自动）。不写弹匣发数、伤害、射速、价格 |
| 机制 | 不暗示游戏里没有的机制。比如游戏里没有卡壳，就不写"从不卡壳" |
| 厂牌性格 | 每家厂定一个性格，同一家的所有枪都按这个写（见 2.3） |
| 标点 | 按规范第 2.4 节。句末可以用句号（这是段落文本，不是短句界面）；不用感叹号；省略号用"……"，整段最多一处 |

### 3.1 P9-01 制式手枪 · 斯坦顿枪械公司

> 斯坦顿枪械公司做了几代转轮手枪，P9-01 是它的半自动手枪。9mm，握着不沉，打起来不跳，拆开保养也简单。警察局的枪柜里常能见到它。快慢机能拨到连发，可手枪连发很难压住，大多数人拨过一次就拨回去了。

- 字数：约 100 字。
- 用到的事实：
  - 9×19mm；能切全自动（`p9_01.json` 的 modes 是 semi 和 auto）；
  - 在警察局里能找到（已确认）；
  - "转轮手枪起家"（**候选背景**）。
- 避开的内容：没写"制式"是怎么来的，也没写采购史（档案 2.7）。

### 3.2 BR-51 战斗步枪 · 凯斯勒兵工厂

> 凯斯勒兵工厂的战斗步枪，打 7.62×51mm。枪沉，钢件多，打得远，也打得透。能切全自动，但枪口会一路往上走，第三发往后就很难说落在哪里。兵工厂要的是结实，好不好看不在考虑之内。

- 字数：约 85 字。
- 用到的事实：
  - 7.62×51mm；能切全自动，全自动后坐力大（现有说明）；
  - 兵工厂（**候选背景**）。
- 避开的内容：BR-51 的"51"没有写成年份（档案第 0 节）。

### 3.3 HR-55 战斗步枪 · 黑岭枪械

> 黑岭是一家小厂，只做大口径。HR-55 打 12.7×55mm，弹头又粗又重，近中距离一枪就能把人放倒。代价是枪重、后坐力冲，制退器一响，半条街都听得见。厂子小，造得不多，碰上一把算运气。

- 字数：约 90 字。
- 用到的事实：
  - 12.7×55mm；近中距离制止力强（现有说明）；有枪口制退器（`heavy_suppressor_01` 的说明）；
  - 小厂、产量小（**候选背景**）。
- 要注意：
  - "碰上一把算运气"要和掉落表的实际稀有度一致。如果 HR-55 并不少见，删掉这句。
  - "半条街都听得见"要和噪声半径的感觉一致。

### 3.4 Blackridge .50 重型手枪 · 黑岭枪械

> 黑岭的重型手枪，打 .50 AE。枪身大，握把粗，手小的人握不满。每打一发，手腕都像被人往后推了一把。买它的人很少是为了多打几枪，大多是为了只打一枪。

- 字数：约 75 字。
- 用到的事实：.50 AE；半自动（`blackridge_50.json`）；黑岭是大口径厂（**候选背景**）。
- 没写弹匣发数。

### 3.5 Silverwood 12 双管霰弹枪 · 银木枪厂

> 银木枪厂是几代人传下来的霰弹枪厂。Silverwood 12 是并排双管，折开装两发 12 号弹，合上就能打。打猎、打靶、看院子都用它。没有弹匣，也没有什么容易坏的地方。只是打完两发就得折开重装，所以两发都要算数。

- 字数：约 100 字。
- 用到的事实：
  - 左右并列双管，无击锤盒式枪机（`docs/native_guns/silverwood_12_v3_sxs.md`）；
  - 折开装弹；12 号弹；
  - 家族厂（**候选背景**）。
- "两发"是结构决定的（两根枪管），不算会被平衡改动的数值。

### 3.6 C.A.T · 来源不明

> 找不到厂牌，也查不到是谁造的。打 7.62×51mm，能切全自动，射得比同口径的步枪快得多。拿到它的人一般都先翻来覆去找刻字，最后放弃。别问它是怎么做到的。

- 字数：约 75 字。
- 用到的事实：
  - 7.62×51mm；能切全自动；射击间隔 2 tick，BR-51 全自动是 3 tick（`cat.json`、`br51_01.json`）；
  - 来源不明（已确认）。
- 最后一句沿用现在的彩蛋说明。
- 要注意："射得快"依赖现在的射速差。平衡改了以后要复核。
