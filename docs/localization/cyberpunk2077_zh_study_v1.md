## 1. 2077 做得好的地方

### 1.1 每种文本都像真的那种文本

2077 最强的地方是**语域分得清**：谁写的、写给谁看，就用什么口吻。

| 文本 | 口吻 | 特征 |
|---|---|---|
| 数据库（世界观、人物、载具、武器） | 有立场的百科编辑，或者一个懂行的熟人 | 第二人称，反问，先下结论再拆开说；最后一句落点 |
| 一句话简介 | 产品手册、评测节目 | 短，一个数字或一个评价，常带一点反转 |
| 中间人短信 | 人物本人的口语 | 每个人的口头禅和用词不同：有人粗，有人客气但冷，有人爱引经文，有人带乡土气 |
| 官方网站、公告 | 公关腔 | 故意写满套话和漂亮话，比如"我们不会止步不前""我们表示十分感谢" |
| 新闻 | 标题加导语 | 写到一半截断，后面跟"[更多内容]" |
| 网民评论 | 网民 | 粗口、错字、偏激 |
| 广告 | 推销 | 感叹号、问句、"立刻订阅" |

**AFL 要学的：** 每一条文本，先问"这是谁写的、写给谁看"，再动笔。例如：

- 战前的加油站促销、警察局公告、电力局的停电通知、药房的处方袋；
- 战后幸存者留的便条、应急广播。

这几种应该一读就听得出是谁在说话。

### 1.2 中文是写出来的，不是对着英文逐字翻的

- **常用俗语和四字格：** 吃百家饭、一分钱一分货、打铁要趁热、肥水不流外人田、迟到总比不到强。读起来像中文作者写的。
- **口语虚词：** 嘛、呗、对吧、嗨。短信里用得最多，人物因此有了声音。
- **句子短：** 长句拆开，靠节奏推进。
- **也有过头的时候：** 偶尔会用中国本土饭桌上的俗语，或者网络流行说法，读起来会出戏。

### 1.3 专有名词的译法分层

| 类别 | 做法 | 例子 |
|---|---|---|
| 超级公司、军火商 | 有意思的词意译 | 军用科技、海啸防御系统、平价火力、宪法军工、可敬物流、网络监察 |
| 日本公司 | 用日文汉字 | 荒坂、水谷、岐路司、藤原、卷贝 |
| 其他外国公司 | 音译 | 康陶、罗斯托维奇、维勒福尔、雷菲尔德、埃雷拉、梅赫 |
| 消费品牌（车厂） | 音译时挑像品牌的字，有时干脆换个意象 | Thorton 霆威、Archer 天穹、Chevillon 雪佛利 |
| 型号 | 代码保留，名字翻译 | 科尔比 CX410 孤峰、柯提斯 V5000 勇气 |
| 改装车的绰号 | 带引号，按意思翻 | "小骡子""西猯""雪怪" |
| 城区、帮派 | 意译为主 | 夜之城、太平洲、六街帮、虎爪帮 |
| 人名 | 按通行规则音译 | 杰佛逊·佩拉雷斯、罗格·阿曼迪亚斯 |

**问题：** 有些译名不够准确。比如 Coyote 被译成"野狼"，实际是郊狼。动物名也被当成"像个名字就行"来处理。

### 1.4 用细节写世界，不靠讲历史

最有效的世界观信息，往往藏在很小的细节里：

- 价格；
- 谁在用这样东西；
- 保险分几档；
- 警察只管哪几个区；
- 套餐清单里多出来的一行。

玩家读到的是一件具体的东西，世界的样子是自己推出来的。

### 1.5 具体的数字

时间、百分比、价格、销量，都写成具体的数。这些数字让文本像档案，不像小说。

## 2. 2077 的黑色幽默是怎么做出来的

2077 的笑点主要来自四种手法：

1. **官腔说可怕的事。** 用公关或者教育节目的语气，介绍一件残酷的事。
2. **清单里的反转。** 一串正常的条目，最后一条突然露出这个世界的真相。
3. **夸张。** 把东西比成天体、神话怪物，或者"千里之外"。
4. **嘲讽。** 嘲讽的对象几乎总是超级公司、政府、警察和消费主义，也常拿死人、尸体和疾病开玩笑。

这四种手法都服务于一个立场：**作者在笑这个世界。** 这是赛博朋克这个类型的核心，在 2077 里是对的。

## 3. 为什么 AFL 不能照搬

| 2077 | AFL | 原因 |
|---|---|---|
| 叙述者统一用讽刺腔，嘲讽公司、政府和警察 | 不用统一的讽刺腔。企业不强行安排阴谋，但可以有经营失败、产品争议、管理问题这类现实矛盾；人物可以发牢骚 | 企业档案第 0 节（用户 2026-10-18 两轮决定） |
| 叙述者拿死人和尸体开玩笑 | 灾难和死者都是真的。人物可以用黑色幽默扛事，文本不拿死者逗乐 | AFL 是写实的末日 |
| 粗口很多 | 粗口每一处都要用户定 | 规范第 2.9 节 |
| 夸张的比喻 | 写实，物理上站得住 | AFL 设计原则是"写实逻辑优先" |
| 年份和历史大事 | 时间线不锁定 | 企业档案第 0 节 |
| 网络梗、本土俗语 | 北美背景，用通用中文 | 带着中国网络语境的梗会出戏 |
| 动物名翻得随意 | 物种名必须准确 | AFL 的动物是真实的北美物种（生物规划） |

**一句话：** 2077 的幽默是叙述者统一的讽刺；AFL 的幽默属于文本里的人和文本的来源。

**核心原则**（用户 2026-10-18）：**每种文本都像它真实所属的文本。** 写成那种文本该有的样子：

- 汽水广告俏皮，写成俏皮的；
- 卡车司机爱吐槽，便条里就吐槽；
- 停电通知老老实实，就写成老老实实的。

反差不必靠叙述者点破。一张积满灰的战前海报，上面还写着"24 小时营业"，不需要旁白。

> 2026-10-18 第一版写的是"作者不笑"。用户确认基调要克制写实，但**不禁止幽默**，于是改成上面的说法。

## 4. AFL 怎么用：幽默的分寸（已按用户调整改过，正式规则见规范第 2.11 节）

### 4.1 分文本类型

| 文本 | 可以学 2077 的什么 | 幽默 | 例子 |
|---|---|---|---|
| HUD、提示、读数、按钮 | 不学 | 没有 | 规范第 2.2 节照旧 |
| 物品的功能说明 | 不学 | 没有。个别彩蛋例外，比如 C.A.T | 规范第 4.3 节 |
| 物品、枪械、载具的背景文字 | 口吻（懂行的熟人）；结构（谁在用、手感、代价）；厂牌性格要反复写 | 看厂牌和口吻：有就写，没有就平实收尾。不强制每篇都加冷幽默；不拿死者开玩笑 | [zh_cn_gun_flavor_text_v1.md](zh_cn_gun_flavor_text_v1.md) |
| 战前广告、包装、促销 | 文体还原：广告就要像广告，感叹号、"限时"都可以 | 可以有商业幽默：俏皮话、双关、夸张的推销语。不用叙述者的反讽 | PRAIRIE 促销、Marais Cola 瓶身 |
| 战前公告、通知 | 官方口吻，具体的数字、时间、电话 | 一般没有。来源本身随意的除外，比如店员的手写告示 | 停电通知、警察局告示、处方袋 |
| 战后人写的东西 | 每个人的声音不同 | 按人物：可以吐槽、自嘲、苦中作乐，也可以一点都不好笑 | 便条、日记、短信、无线电。属于叙事审校（第 2.9 节） |
| 幸存者背景 | 口吻按身份区分 | 很少 | 第 2.9 节 |

### 4.2 写作规则

1. **先定"谁写的、写给谁看"。** 定不下来，就先不写。
2. **幽默跟着人和来源走。** 叙述者不加"讽刺的是""可笑的是"这类点破的话；人物自己要吐槽，就让他吐槽。
3. **背景文字的落点只落在东西身上，而且不是必须的。** "这把枪很难压住"可以；拿被枪打的人开玩笑，不可以。
4. **用具体细节代替历史叙述。** 价格、营业时间、保修期、型号、谁在用。不写"战争爆发以后"这类大事。
5. **数字分两种：**
   - 战前文本（价格、营业时间）可以写具体的数；
   - 会随平衡调整的游戏数值（伤害、弹匣发数），在背景文字里不写。
6. **俗语只用通用的。** 不用网络梗，不用带中国特定场景的说法（饭桌、节日、地方方言）。
7. **专名按企业档案第 6 节译。** 物种名用中文正式名，不图好听。
8. **粗口、性内容、宗教讽刺：** 默认没有，要用的话每一处单独问用户。

### 4.3 同一个意思，三种写法

下面的句子都是本文自己写的示例，不是 2077 的原文。写的是一张战前的电力局停电通知。

| 写法 | 示例 | 判断 |
|---|---|---|
| 2077 式 | 电力局温馨提示：线路检修期间请自备蜡烛，反正你家的电表也从来没准过 | **不用。** 嘲讽机构，作者在笑 |
| 说明书腔 | 因线路检修需要，本局将于指定时段对相关区域实施停电作业 | **不用。** 翻译腔，一读就不像真的 |
| AFL | 联邦电力局：周四上午 9 点到下午 3 点，Linden 北边的线路检修，这段时间停电。有问题打电力局办公室 | **用这种。** 具体、真诚。玩家在一座早就没电的镇子里读到它，反差自己会出来 |

注：
- 按第 5 节的决定，这张通知是玩家打开来读的，所以按当前语言显示。
- 对比用的另一种情况：如果来源换成店员贴在柜台上的手写告示，带一点脾气或者玩笑，也是对的。这种文本在现实里就是那样。

## 5. 游戏里可读的文件用哪种语言（用户 2026-10-18 已定）

**用户的决定：**

- **保持英文：** 世界里的商店招牌、路牌、企业 Logo、车辆铭牌、海报上的主要品牌文字。
- **按当前游戏语言本地化：** 玩家打开来读的报纸、便条、日记、说明书、通知、短信、邮件，以及广播字幕。中文环境下写自然的简体中文，企业名称用已确认的中文译名。
- 正式规则在规范第 2.6 节。

下面是提给用户时的原始问题，留作记录：

现在的规则是：**标牌、招牌、铭牌一律英文；界面、物品名、提示用中文**（规范第 2.6 节）。可是以后会有很多**玩家打开来读的文件**：报纸、便条、日记、说明书、停电通知、广播。这条规则没有覆盖它们。

2077 的做法是：街上的招牌保留原样，玩家打开来读的数据碎片、网页、短信全部翻译。

**建议：**

- **挂在墙上、只是看一眼的东西保留英文：** 招牌、海报大字、车身字样、价格牌。
- **玩家打开来读的东西走翻译：** 报纸、便条、日记、说明书、通知、广播字幕。按当前语言显示，en_us 和 zh_cn 一起写。
