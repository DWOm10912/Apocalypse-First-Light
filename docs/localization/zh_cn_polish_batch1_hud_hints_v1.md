## 看过但没改的

| 文本 | 为什么不改 |
|---|---|
| "耐力"全部 | 用户 2026-10-18 决定 Stamina 叫"耐力" |
| 状态卡"没有"（无效果时）、HUD 的"无背带 / 无枪套" | 前者是口语读数，后者是紧凑标签，都合规范 |
| 辐射病第 1–4 级里的百分比和"每 5 秒" | 这些数字就是玩家需要的读数，保留 |
| "身上在滴油""体温在回升""饿得掉血""开车时腾不出手" | 已经是目标语气 |
| 驾驶提示里的"加挡 / 减挡 / 两驱 / 四驱 / 低速四驱" | 行业说法，短 |
| 插头和布线的提示（"电线够不着""插孔都占了""只看本路"等） | 合规范 |
| `effect.*` 四个状态名（辐射病、肠胃感染、沾汽油、沾柴油） | 合规范 |
| `key.*` 驾驶按键后面的"（驾驶）" | 等驾驶按键单独分类（代码改动，另排）时一起改 |

## 校验（本轮做过的）

脚本在会话临时目录里，没有放进仓库。逐项检查结果如下：

- 31 条都先比对过原文，原文一致才替换；
- JSON 能解析；
- zh_cn 和 en_us 都是 1276 个键，1320 行，键逐行对齐；
- 每条改动前后的占位符一致（`%s`、`%%`）；
- 改动行里：
  - 没有句末"。"和"！"；
  - 提示里没有括号；
  - 没有半角标点，没有 `...`；
- 中文和数字之间的空格逐条看过；
- 工作区文件保持 CRLF 换行，没有 BOM。

**没做过的：** 没进游戏，没看截断，没编译（语言文件改动不需要编译）。
